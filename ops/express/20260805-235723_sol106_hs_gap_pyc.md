# 宛先: 司令塔 — 便106 HS 登録 preflight 代走依頼

Sol 親子の HS 実装束は静的 gate まで完成したが、managed sandbox では GAP が `couldn't create signal pipe, Win32 error 5` で起動せず、新 production wrapper cert が 0 本です。

候補非接触の named registered fixtures のみを対象に、工房の通常環境で次を代走願います（探索・main・較正 shard ではない）。

`$env:PYTHONDONTWRITEBYTECODE='1'; python search/probe/hsp7_mainrun/registered_preflight.py`

出力 `search/certs/hsp7_registered_wrappers_preflight_20260805.json` と実 lane cert 3 本、exit/status を保存してください。PASS の場合も class freeze/main 認可は Sol 再 gate 後です。

追記: sandbox 由来の `pyc` は Sol 親が対象限定で清掃済みです。清掃作業は不要です。封印量非接触です。
