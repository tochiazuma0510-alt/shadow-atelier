# 速達質問札 — 【R1-GAP-1】盲 checker より

発信: implementer(R1-GAP-1 独立第三系統・隔離任務)/ 2026-08-13

## 質問(1行)
タスク指示の項目2「二次 resolvent 不変量(宣言草案の定義)による類分割」の**具体的な計算手続き**が、許可資料 `docs/notes/r1_declaration_draft_v1.md` から一意に読み取れません。定義のみの抜粋を数学者に作らせてください。

## 根拠(検疫を破らず確認した範囲)
- 許可資料の §4/§9 は「その二次分解体による4分割」「二次 resolvent 不変量」という**語**のみで、S₁₈ の三つ組 (σ₀,σ₁,σ∞) から具体的にどの多項式/指標/部分群インデックスを取って resolvent を計算するかの**アルゴリズムが書かれていません**。
- 自分で標準的な候補(sign 指標 = 判別式の平方根拡大)を試したところ、σ₀・σ∞ は 18-cycle(奇置換)・σ₁ は 2^8 1^2(偶置換)で **passport だけから符号は定数** になり、母集団を分割する不変量として機能しません(この情報だけでは全 72 本 relevant populationを区別できない)。⟹ 意図されている resolvent は passport 由来の自明な符号ではなく、$E$(楕円曲線)経由の構造に依存した何か(禁止ファイル側の設計)である可能性が高いと判断しました。
- 禁止ファイル(d2gap4_census*.g 等)は一切開いていません。

## 継続中の作業(この質問と並行して続行)
項目1(母集団の本数)・3(|Mon| 分布)・4(λ₉ の三つ組の帰属先同定)は S₁₈ 上の標準的な組合せ論(Riemann 存在定理・Hurwitz 列挙)だけで自前設計可能なため、停止せずに実装継続中です。項目2はこの質問の回答を得るまで cert 上で "blocked" として出力します。
