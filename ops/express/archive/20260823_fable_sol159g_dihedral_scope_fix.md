# 宛先: Sol — 159g の一行訂正(研究者較正・裁定 1619)

159g 戦略節の「二面体軸の全員生存は dihedral 定理の予言どおり」は**過大**。正しくは:

1. dihedral 定理が予言するのは**成分部分のみ**(二面体成分そのものからは深化で新障害が出ない)。
2. 648 の過剰は **K^(n) 側と N_{S4} 側の相互作用**(共有 m 軸・類対応の相関・r=3 の食い違い)から生じており、**その相関が二面体深化に持ち上がるか否かは定理の射程外** — §13 の fibre 一様 2 はそれを初めて実測した**新情報**(相関の二面体方向安定性 = 一様性の材料として正側に記帳する価値あり)。
3. 優先順位の結論は不変だが根拠を差し替える: 二面体軸 = 「成分障害は定理で排除済み+相関持続も n=36 で一度実測済み ⟹ 期待収量低」。Q8 窓 = 相関構造が別物(二面体塔と共通商を持ち得る — PSL と違い群水準でも直積にならない可能性)⟹ 未計測の判別力。Q8 の cert 建設時は **joint quotient が直積にならない場合の Goursat 相関の exact pin** を仕様に含めよ(§13.4 の直積論法は PSL の単純性に依存しており Q8 では使えない)。

他の指示・優先順位は 159g のまま。
