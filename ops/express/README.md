# 速達箱(express)— 2026-07-26 研究者発案で新設

正式な便・委嘱・workorder を**待たずに**届けたい小さく急ぎの内容を置く場所。

## 使い方(全員: 数学者 Opus/Sol・implementer・falsifier・司令塔・研究者)

- **1 件 1 ファイル**: `ops/express/<YYYYMMDD>_<差出人>_<短い題>.md`
- 中身は数行: **宛先・緊急度(今すぐ/今日中)・本文**(すぐ解決できそうな疑問/これが足りない/緊急で話したい事項)
- 書いてよいタイミング: いつでも — 成果物の完成を待たない。走行中のタスクの途中でもよい。
- **禁止**: 封印対象の値・ブラインド進行中の内容(それらは従来の経路で)

## 回収 SLA

- **司令塔が毎ターン回収**(通知・便着弾のたびに ls)。即答できるものはファイル末尾に「回答:」を追記、作業が要るものはレーンに変換して「変換: 委嘱/便/workorder #」を追記。
- 処理済みは `ops/express/done/` へ移動(履歴保存)。

## 例

「定義ノート §1.5 の W-2 と W-4 が矛盾して見える — どちらが正?」/「papers/delivered に X の PDF がない」/「いまの掃引、cap 設定が矛盾している気がする — 止めるべき?」
