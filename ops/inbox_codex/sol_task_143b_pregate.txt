## 0. 追補の理由

便 142 §1.2 の強化版(改訂後)を読んだ。逐語:

> $M_{\rm ord}=18$、NW(7) の $N_{\rm ord}=7$ なので、任意の二つの $m$-class は中国剰余定理で同時に持ち上がる。… 二因子に共通非自明商がないため二つの全射成分を持つ $T_{m,f}$ の像も Goursat により直積全体である。従って **各 $g\in GT(M)$ と 294 個の各 NW(7) shadow は、共通細分 $M\cap\mathbf N$ 上で compatible** である。内訳は各 $g$ について `PENT_W`-PASS の有限 B3 common-refinement 42 個、FAIL の有限 B3 common-refinement 252 個。

これは word-level ではなく **shadow-level の独立性**であり、便 142 の反証を一段強くしている。受理する。

## 1. 事前ゲート(本走の前に必ず判定すること)

**問**: 同じ Goursat 独立性は、便 143 が使う窓

$$C_M=\bigcap_{i=1}^4p_i^{-1}(M),\qquad \tilde K=C_M\cap\tilde{\mathbf N}^{*}\le L,\qquad \tilde K_{PB_3}\le M\cap\mathbf N_0$$

の **fiber 判定を空振りにするか**。

懸念の形は具体的である。$\tilde K_{PB_3}\le M\cap\mathbf N_0$ で $PB_3/(M\cap\mathbf N_0)$ が $H_M\times P_7$ 型の直積になるなら、任意の $g\in GT(M)$ の fiber は **294 個の NW-shadow を全て含み、そのうち 42 個が `PENT_W`-PASS** ということになりかねない。その場合「全 fiber が (2.20)-FAIL」は**構造的に成立し得ない** ⟹ 便 143 の判定は検出力ゼロである。

★ ただし司令塔は**これを主張しない**(本セッションで型の誤りを 3 度出しているので、判定は貴殿に委ねる)。**`PENT_W`-PASS は (2.20)-PASS を意味しない**(B4-DIR は FAIL 方向の含意のみ)ため、空振りが確定するとは限らない。**どちらであるかを、走る前に判定してほしい。**

### 1.1 空振りが確定した場合

それは **定理**である(名前を付けて記録すること)。B4-VAC・PENT-NODESCENT に続く**三つ目の B₄ 側盲目性定理**として、被覆台帳に加わる。

⟹ その場合は**そこで止まらず、便 142b §2 の在庫の次項へ進むこと**。未消化として残っているのは:

- ③ B₄ 側細分による survival(2008 Prop 3.3 + 補題 CORE-4)
- ④ **非可換 B₄ 窓 4 個**([192,1489/1490/1492/1494]・$Q_8$ 商)— ★ `gtshadow_predicates: false` 宣言のまま**一度も shadow も pentagon も評価していない**
- ⑥ MIRROR-SHADOW-B4(空の確認をもって消化可)
- ⑦ ISO-FIBER-ENUM-140 を次の order event($B=2|Q|$・$|\ker\psi|=2$・$Q$ の central $C_2$-extensions)から続行
- ⑧ §4.2 の四命題(CHIEF-COFINAL / REL-VANISH / GEN-NONCOVER / CHAR-LIFT)

★ **空振り定理を 1 本得ただけで終端にしない**。在庫が尽きるまで進むこと。

### 1.2 空振りでない場合

便 143 本体をそのまま実行する(全 fiber の charming・hexagon・SURJ・(2.20) 判定 ⟹ 決着)。

## 2. 一般化した要求(以後の全便に適用)

★ **計器を作る前に「その述語の定義域は標的と一致するか」「その窓で検出力は非零か」を一行で判定し、返書に書くこと。** 便 142 の PENT-NODESCENT も、便 138 の B4-VAC 事前除外も、この確認で先に落とせた型である。

## 3. 終端(便 142b・143 と同じ・変更なし)
