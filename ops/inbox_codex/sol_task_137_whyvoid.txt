## 0. 一行

同じ現象が**二つの素数で**出た。

```text
p=3  ESCAPE-28  dim V=28  dim H²(C₃,V)=2  1,099,008 行  非零障害 0
p=2  ESCAPE-2   dim V=12  dim H²(C₂,V)=2      2,268 行  非零障害 0
```

障害群は両方とも生きている(しかも次元がどちらも 2)のに、**実障害写像の像が恒等的に零**。便 135 §2 が「残る紙の問い」と定式化したものが、いま二例になった。本便はその理由を取りに行く。

## 1. 委嘱 — 作業仮説 (H-SPLIT) の判定(★これは司令塔の仮説であって定理ではない・反証歓迎)

### 1.1 仮説

両例とも $E=V\rtimes(P\times G_3)$ という**半直積**で構成されており、細分の拡大

$$1\longrightarrow V\longrightarrow PB_3/K\longrightarrow PB_3/M\longrightarrow 1$$

は $s(g,p)=(g,(0,p,\pi(g)))$($\pi:G_9\twoheadrightarrow G_3$)で**分裂する**ように見える。

**(H-SPLIT)**: この分裂が $\theta,\tau$ と可換(= 同変)なら、任意の shadow $(m,f)$ に対し $s(f)$ が上の hexagon を自動的に満たす ⟹ **全 shadow が持ち上がる**。これが全消滅の理由ではないか。

### 1.2 仮説の弱点(先に自己申告する)

$H^1(\Gamma,V)$ の**非零 class は $\theta,\tau$ の作用を cocycle でひねる**ので、標準補群 $P\times G_3$ が $\theta,\tau$-安定でなくなる可能性がある。ESCAPE-2 では零 class は降下して除外され、**残った 7 class は全て非零**で、それでも障害は消えた。⟹ 素朴な形の (H-SPLIT) はそのままでは 7 class を説明しない。

判定してほしいのは次:

1. 各全射 class について、拡大 $1\to V\to PB_3/K\to PB_3/M\to1$ は**実際に分裂するか**(補群の存在)。同変分裂か、単なる分裂か、非分裂か。**機械で直接検査できるなら生値で**(既存 cert の行列から出るはず)。
2. 分裂していても $\theta,\tau$-同変でない場合、障害が消える別の理由があるか。**cocycle のひねりが障害類に効かない**構造的理由(例: ひねりが coboundary に落ちる・$H^2$ への写像が $H^1$ の作用で不変)が立つか。
3. 立つなら命題として書き、立たないなら (H-SPLIT) を**棄却**して、代わりの機構の候補を挙げてほしい(候補が無ければ「無い」で可)。

### 1.3 ★ SPLIT-NULL との区別(混同防止・司令塔で確認済み)

**定理 SPLIT-NULL の仮定は「純商が直積」**(`ab_instrument_redesign_v1.md` §26 の逐語: 共通非自明商なし ⟹ $PB_3/M\cong G_n\times PB_3/N'$)。本仮説の仮定は**「拡大が(同変)分裂する」**で、**別物**。ESCAPE-28/ESCAPE-2 の $PB_3/K$ は fiber 積+半直積で**直積ではない**ので SPLIT-NULL 族には入らない(便 134 の族監査と整合)。この区別を保ったまま判定すること。

## 2. 射程(仮説が真だった場合の帰結 — ★重大なので慎重に)

(H-SPLIT) かそれに近い機構が成立するなら、**compact 路(vN-BIT / ESCAPE-28 / ESCAPE-2)が構成する窓は全部その形**である。すなわち

$$\text{compact 路の窓は原理的に検出力ゼロ(新しい盲族)}$$

という結論になりうる。これは A 側探索の設計を根本から変える(**非分裂の細分を作る技術**が新たに要る)。**この帰結は重大なので、成立の判定は慎重に**。逆に (H-SPLIT) が棄却されるなら、compact 路は検出力を持ちうるが「たまたま二例で消えた」ことになり、次は**より大きい $H^2$ をもつ窓**を狙う設計になる(その最小候補も挙げてほしい)。

## 3. 機械側(紙が要求する範囲のみ)

- 各 class の補群存在判定(分裂性)。
- 二例の共通量の照合: どちらも $\dim H^2=2$ だったのは偶然か構造か(次元の一致に意味があるか)。
- 新規の大規模走査は不要。既存の凍結 cert(escape28 系・escape2 系)の再利用で足りる範囲に留めること。
