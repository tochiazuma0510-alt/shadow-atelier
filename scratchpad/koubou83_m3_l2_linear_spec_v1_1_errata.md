# spec v1.1 — errata(M3 押し出し線形則)

著者: 工房数学者(Opus 5)/ 2026-08-23 / 対象 = koubou83_m3_l2_linear_spec_v1.md。

## 裁定: 定理 PUSH は正しい。誤りは §3 の v2 定義行 1 行と、それが依拠した §0 の ad_convention 文。定数(Σ_e・(A^e−I)・半線型則)と ①〜⑤ の予測はすべて不変。

### E-1(根本原因)ad_convention の向きが逆だった

W-1 は paper と GAP を**反同型**で結ぶ(ι(AB)=ι(B)ι(A))。反同型は逆元を保つので

ι(Ad_paper(g)(v)) = ι(g⁻¹)ι(v)ι(g) = ι(g)⁻¹ι(v)ι(g) = GAP `iota(v)^iota(g)`。

**paper Ad(g) ⟷ GAP `v^g`(NOT `v^(g^-1)`)**

v1 §0 の「paper Ad は `v^(x^-1)`」は、paper↔GAP が同型なら正しい文で、反同型の下では逆。⟹ v1 §3 の `v2 := Image(q, s^(x^-1))` は paper で A⁻¹v₁ を作っており、以後 constant matrix A が実質 A⁻¹ を表していた。

### E-2(修正 1 行)

```gap
v2 := Image(q, s^x);;      # paper Ad(xbar) v1 = x v1 x^-1   <-- v1 では s^(x^-1) と誤記
```

これだけで §2 の全式が逐語で成立(定数 A=[[0,−1],[1,−1]]、Σ₁=I、Σ₂=I+A、θ̄A=A^e θ̄ は不変)。

### E-3(gate の設計欠陥 — v1 の Assert 2 本は向きに盲)

I+A+A²=0 も Ad(ȳ)=Ad(x̄) も A↔A⁻¹ で対称ゆえ両方 PASS してしまう。同じ理由で [0,1] と [0,f₁] も向きに盲([f] の座標 (0,0),(1,0) が基底交換で不変)。ν=2 が最初の向き感受例。⟹ **例文を必須 gate に格上げ**:

```gap
# GATE-ORIENT (必須・fail-closed)
Assert(0, Image(q, x^-2*y^2) = v1*v2);        # paper [y^2 x^-2] = v1+v2 = (1,1)
Assert(0, Image(q, y*x^-2*y) = v2^-1);        # paper [y x^-2 y] = -v2 = (0,3)   陰性 canary
```

誤った向きでは第 1 式が (0,3)、第 2 式が (1,1) を返して**必ず落ちる**(実測どおり)。

### E-4(自己検証 3 例目の訂正・正しい期待値)

| 例 | paper 語 | GAP 語 | 正基底での [f] | 期待 θ̄ | det |
|---|---|---|---|---|---|
| [0,1] | 1 | `One(G)` | (0,0) | I | 1 ✓ |
| [0,f₁] | yx⁻¹ | `x^-1*y` | (1,0) | A=[[0,3],[1,3]] | 1 ✓ |
| **[0,f₂]** | y²x⁻² | **`x^-2*y^2`** | **(1,1)** | (A−I)(1,1)ᵀ+(1,0)ᵀ=(3,3) ⟹ θ̄=[[3,1],[3,0]]=A² | −3≡1 ✓ |

**「θ̄=A² になる f」**: 補題 U′ の T_{0,f_ν}=Ad(x^ν) より ν=2、すなわち f=f₂=y²x⁻²(GAP `x^-2*y^2`)。P^ab への制限が A²。∎

(実測 `x^-1*y^2*x^-1` の (1,1) は**誤基底での**値で、正基底へ移すと (0,3)。palindrome ゆえ反転不変でも共役位置が違うので f₂ とは別クラス — 3 例目の代表には使わないこと。)

### E-5(①〜⑤ への影響)= なし

det・−I・「Cartan 正規化群に入る」・2P^ab 所属・[y³]=[x³]・[z³]=−2[x³] は**すべて基底不変**。とくに **④ Weil canary は今回も設計どおり作動した**: 誤基底での出力 [[2,2],[2,0]] は det≡0 で非可逆 — θ̄ は P^ab の自己同型でなければならないので、④ 単独でも fail-closed になった。追加の canary は不要、E-3 の GATE-ORIENT を足すだけでよい。

### E-6(記録の同期・別件)

memo §7.8 項 2 の「cert の Ad(x̄) は数学者の Ad(x̄⁻¹)」という符号説明は、W-1 が反同型であることを踏まえると向きが逆(GAP `u^x` = paper Ad(x̄))。結論(ν↔class の反転は規約由来で bug ではない)は不変。cert の `ad_convention` 欄に「**paper↔GAP は反同型・paper Ad(g) = GAP `v^g`**」を明記すること。
