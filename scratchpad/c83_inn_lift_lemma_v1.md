## §3 タスク 2 — 補題 KER-π(仮定を閉じた最終言明と証明)

### 3.1 定理文

> **定理 KER-π.** 次の設定を固定する。
> 1. **群と完全列**: 1 → N → B₃ →^{π} Q → 1(N ⊴ B₃ 有限指数、Q := B₃/N)。
> 2. **素数と加群**: p を素数、K := [N,N]N^p、**V := N/K**。V は初等 p-可換群、すなわち F_p-ベクトル空間。
> 3. **作用**: B₃ は共役で N/K に作用する。**N はこの作用に自明に作用する**(n,n′ ∈ N ⟹ nn′n^{-1}n′^{-1} ∈ [N,N] ⊆ K)。よって作用は π を通って分解し、**V は F_p[Q]-加群**である。B₃ 上の係数加群としては V を π で引き戻したもの(N が自明に作用するもの)を用いる。
> 4. **拡大類**: 1 → V → B₃/K →^{ρ} Q → 1 は Q の V による群拡大であり、その類を **e ∈ H²(Q,V)** とする。
> 5. **π\***: π^*: H²(Q,V) → H²(B₃,V) を π による inflation(引き戻し)とする。
>
> **このとき**
> $$\boxed{\ \ker\bigl(\pi^*: H^2(Q,V) \to H^2(B_3,V)\bigr) \;=\; \{\,\varphi_*(e) \;:\; \varphi \in \mathrm{End}_{F_p[Q]}(V)\,\}\ }$$
> ここで φ_*: H²(Q,V) → H²(Q,V) は係数 φ: V → V が誘導する写像。右辺は H²(Q,V) の **F_p-部分空間**であり、**次元は ≤ dim_{F_p} End_{F_p[Q]}(V)**。特に **φ = id** を取って **π^*(e) = 0**。

**射程の明記(Sol §2 の要求)**: 本定理は「dim ker π^* ≤ dim End_{F_p[Q]}(V)」という**上からの評価**しか与えない。**dim End = 24/12 と dim H² = 23/11 の比較から「核は小さい」「障害消失は安くない」を導くことはできない**(像が H² 全体でありうる。実際 24 > 23、12 > 11 なので、この不等式は H² 全体を排除しない)。この読解は **撤回**する。定量的な主張が要るなら **像の次元 dim(End_{F_p[Q]}(V)·e) を直接測る**しかない(= 線型写像 φ ↦ φ_*e の階数)。`docs/notes/c83_closure_index_v1.md:34` と `docs/状態.md:9` はこの中立文言へ同期すること。

### 3.2 証明(自己完結・スペクトル系列不要)

コチェインは非斉次コチェインで取り、正規化(c(1,·) = c(·,1) = 0)する。集合論的切断 s: Q → B₃、s(1)=1 を一つ固定し、**因子系** ε: Q×Q → N を
  ε(q₁,q₂) := s(q₁)s(q₂)s(q₁q₂)^{-1} ∈ N
で定める。V での像 ε̄ := (ε mod K) は正規化 2-コサイクルであり **[ε̄] = e**(拡大 1→V→B₃/K→Q→1 の類の標準表示)。

**(A) ⊇ の向き(初等)**。π^*(e) = 0 を示せば φ_*(e) についても π^*(φ_*e) = φ_*(π^*e) = 0 が従う(π^* と φ_* は係数と底空間の別方向の関手性ゆえ可換)。π^*(e) は拡大 1→V→B₃/K→Q→1 を π: B₃→Q で引き戻した拡大 1→V→ B₃×_Q(B₃/K) → B₃ →1 の類である。この引き戻し拡大は **切断 g ↦ (g, gK) を持つ**(well-defined な群準同型)ので分裂し、π^*(e) = 0。∎

**(B) ⊆ の向き**。c ∈ Z²(Q,V) を正規化コサイクルとし π^*(c) = δu、u ∈ C¹(B₃,V) とする(π^*c(g₁,g₂) := c(πg₁,πg₂))。
 δu(g₁,g₂) = g₁·u(g₂) − u(g₁g₂) + u(g₁)(g の作用は π(g) 経由)。

**(B-1) u|_N は準同型**。n₁,n₂ ∈ N に対し π(n_i)=1 で N は V に自明に作用するから
 c(1,1) = 0 = u(n₂) − u(n₁n₂) + u(n₁) ⟹ **φ := u|_N: N → V は群準同型**。V は初等 p-可換群ゆえ φ([N,N]) = 0, φ(N^p) = 0、したがって **φ は V = N/K を経由**する。以下 φ ∈ End_{F_p}(V) と同一視。

**(B-2) φ は Q-同変**。g ∈ B₃, q := π(g), n ∈ N とする。正規化ゆえ c(q,1) = 0 なので
 δu(g,n) = q·u(n) − u(gn) + u(g) = 0 ⟹ u(gn) = q·φ(n) + u(g)。
また c(1,q) = 0 と π(gng^{-1}) = 1 より
 δu(gng^{-1}, g) = u(g) − u(gn) + u(gng^{-1}) = 0 ⟹ u(gng^{-1}) = u(gn) − u(g) = q·φ(n)。
すなわち **φ(gng^{-1}) = π(g)·φ(n)**。⟹ **φ ∈ End_{F_p[Q]}(V)**。

**(B-3) 補助コチェインの余境界**。u′ ∈ C¹(B₃,V) を u′(g) := φ(n)(ただし g = n·s(q), q = π(g), n ∈ N は一意)で定める。g_i = n_i s(q_i) と書くと
 g₁g₂ = n₁·(s(q₁)n₂s(q₁)^{-1})·ε(q₁,q₂)·s(q₁q₂)
ゆえ u′(g₁g₂) = φ(n₁) + q₁·φ(n₂) + φ(ε(q₁,q₂))(φ が準同型かつ Q-同変)。したがって
 δu′(g₁,g₂) = q₁·φ(n₂) − u′(g₁g₂) + φ(n₁) = **−φ(ε(q₁,q₂)) = −π^*(φ_*ε̄)(g₁,g₂)**。
(これが **transgression tg(φ) = −φ_*(e)** の明示形である。符号は集合 {φ_*e : φ} には影響しない — End は −1 倍で閉じる。)

**(B-4) 差を Q へ降ろす**。v := u − u′ と置くと δv = π^*(c + φ_*ε̄)。v|_N = φ − φ = 0。(B-2) と同じ計算((B-2) を c の代わりに c+φ_*ε̄ に適用)で v(gn) = v(g)(∀g ∈ B₃, n ∈ N)。よって v は Q 上の関数 v̄ を経由し v = π^*(v̄)。すると
 π^*(c + φ_*ε̄) = δ(π^*v̄) = π^*(δv̄)。
π: B₃ ↠ Q が全射ゆえ **コチェインの引き戻し π^* は単射**、したがって c + φ_*ε̄ = δv̄。すなわち
 **[c] = −[φ_*ε̄] = (−φ)_*(e) ∈ End_{F_p[Q]}(V)·e**。∎

**注(整合)**: 上の (B) は Hochschild–Serre の 5 項完全列
 0 → H¹(Q,V) → H¹(B₃,V) → H¹(N,V)^Q →^{tg} H²(Q,V) →^{π^*} H²(B₃,V)
の transgression 部分の**手計算による再導出**である(N が V に自明に作用するので H¹(N,V) = Hom(N,V) = Hom_{F_p}(V,V)、その Q-不変部分が End_{F_p[Q]}(V))。**本証明は 5 項完全列を前提として使っていない**ので、Lean 形式化の際も Mathlib の inf-res を待つ必要がない(必要なのは群コホモロジーの標準コチェイン複体のみ)。

### 3.3 裁定

**proved**(格: 紙の証明・Lean 未形式化ゆえ verified ではない)。**End 次元からの定性的読解は撤回**(§3.1 の射程の明記)。

## §4 タスク 3 — K₆ の fibre-product compatibility

### 4.1 定理文(互いに素な一般形)

> **定理 K-CRT.** N ∈ NFI_{PB₃}(B₃)、a,b ≥ 1 は **gcd(a,b)=1**。K_n := [N,N]N^n(n = a,b,ab)と置く。このとき
> (0) K_n ⊴ B₃、K_n ≤ N、有限指数(K_n は N の characteristic 部分群)。
> (1) **K_{ab} = K_a ∩ K_b** かつ **K_aK_b = N**。
> (2) **(K_a)_{F₂}·(K_b)_{F₂} = N_{F₂}** かつ **(K_a)_{F₂} ∩ (K_b)_{F₂} = (K_{ab})_{F₂}**。
> (3) **gcd((K_a)_ord, (K_b)_ord) = N_ord** かつ **lcm((K_a)_ord, (K_b)_ord) = (K_{ab})_ord**。
> (4) **Λ_{K_a} ∩ Λ_{K_b} = Λ_{K_{ab}}**。
> (5) **[m,f] ∈ GT(N) が K_{ab} へ survive する ⟺ K_a へも K_b へも survive する。**
>
> 特に (a,b) = (2,3):**K₆ への生存は K₂ への生存 ∧ K₃ への生存と同値**。⟹ 「K₆ は新情報を持たない」は **定理**(条件つきではない)。

### 4.2 証明

記号: A := N/[N,N](可換)、W := N_{F₂} = N∩F₂。K_n の A における像は nA。

**(0)** [N,N] と N^n は N の characteristic 部分群、N ⊴ B₃ ゆえ K_n ⊴ B₃。K_n ⊇ [N,N]N^{|N/[N,N]|·…} で有限指数。

**(1)** A の中で aA ∩ bA = abA:⊇ は自明。⊆ は Bézout:ra+sb=1 なら α ∈ aA∩bA に対し α = raα + sbα ∈ a(bA') + b(aA'') ⊆ abA(α = aα' = bα'' と書けば raα+sbα = ra(bα'')+sb(aα') = ab(rα''+sα'))。よって K_a∩K_b は A で abA に対応 ⟹ K_a∩K_b = K_{ab}。また aA + bA = A(Bézout)⟹ K_aK_b = N。

**(2)** **積**: w ∈ W に対し ra+sb=1 を取ると w = w^{ra}·w^{sb}、w^a ∈ N^a ⊆ K_a かつ w^a ∈ F₂ ⟹ w^{ra} ∈ (K_a)_{F₂}、同様に w^{sb} ∈ (K_b)_{F₂}。よって W ⊆ (K_a)_{F₂}(K_b)_{F₂} ⊆ W。
**交わり**: (K_a∩F₂)∩(K_b∩F₂) = (K_a∩K_b)∩F₂ = K_{ab}∩F₂。

**(3)** t ∈ {x,y,c} について ord(tK_n) = ord(tN)·(N/K_n における t^{ord(tN)} の位数)で、後者は exp(N/K_n) | n を割る。ゆえに N_ord | (K_n)_ord | N_ord·n、すなわち (K_n)_ord = N_ord·e_n(e_n | n)。gcd(e_a,e_b) = 1 ゆえ gcd = N_ord。また K_{ab}=K_a∩K_b より t^k ∈ K_{ab} ⟺ t^k ∈ K_a ∧ t^k ∈ K_b ⟹ ord(tK_{ab}) = lcm(ord(tK_a), ord(tK_b))、3 つの t で lcm を取って (K_{ab})_ord = lcm((K_a)_ord,(K_b)_ord)。

**(4)** ⊇ は Λ が包含で単調(K_{ab} ⊆ K_a,K_b)。⊆:λ ∈ Λ_{K_a}∩Λ_{K_b} とし u ∈ (K_a)_{F₂}, v ∈ (K_b)_{F₂} を ab(u)=ab(v)=λ に取る。ra+sb=1 なる r,s を取り
  **t := u^{sb}·v^{ra}** と置く。
 ab(t) = (sb+ra)λ = λ。t ∈ (K_a)_{F₂}: u^{sb} ∈ (K_a)_{F₂}(u が既に K_a に居る)、v ∈ W ⊆ N ⟹ v^{a} ∈ N^a ⊆ K_a、かつ v^{ra} ∈ F₂ ⟹ v^{ra} ∈ (K_a)_{F₂}。t ∈ (K_b)_{F₂}: 同様に v^{sb} … ではなく v^{ra} ∈ (K_b)_{F₂}(v が K_b に居る)、u^{b} ∈ N^b ⊆ K_b ⟹ u^{sb} ∈ (K_b)_{F₂}。ゆえに t ∈ (K_a)_{F₂}∩(K_b)_{F₂} = (K_{ab})_{F₂} で ab(t) = λ ⟹ λ ∈ Λ_{K_{ab}}。∎
 (a,b)=(2,3) では r=−1,s=1 が取れて **t = u³v^{−2}**。

**(5)** (⟹) K_{ab} ⊆ K_a, K_b と関手性 R_{K_a,N}∘R_{K_{ab},K_a} = R_{K_{ab},N}(2401 の (5.3))から自明。
(⟸) [m_a,f_a] ∈ GT(K_a), [m_b,f_b] ∈ GT(K_b) がともに [m,f] へ還元するとする。charming ゆえ f_a, f_b は **[F₂,F₂] の代表**に取り替えてよい(ab(f_a) ∈ Λ_{K_a} だから代表を [F₂,F₂] 内に選べる。以下ではこの取り替えは不要で、ab(f_a) ∈ Λ_{K_a} という事実だけ使う)。
 - **m の貼り合わせ**: m_a ≡ m ≡ m_b (mod N_ord) と (3) の gcd = N_ord より、**m_* ∈ ℤ で m_* ≡ m_a (mod (K_a)_ord), m_* ≡ m_b (mod (K_b)_ord)** が取れる(整数 CRT)。
 - **f の貼り合わせ**: 群の CRT(A,B ⊴ G なら (gA, hB) が G/(A∩B) の像 ⟺ g ≡ h (mod AB);実際 h = gαβ なら k := gα が両方を満たす)を G=F₂, A=(K_a)_{F₂}, B=(K_b)_{F₂} に適用。f_a ≡ f ≡ f_b (mod N_{F₂}) と (2) の AB = N_{F₂} より、**f_* ∈ F₂ で f_* ≡ f_a (mod (K_a)_{F₂}), f_* ≡ f_b (mod (K_b)_{F₂})** が取れる。
 - **hexagon**: hexagon 条件は類 (m + K_ord ℤ, f K_{F₂}) のみに依存する(2401 の (3.4) 直後の注)。よって (m_*,f_*) は mod K_a でも mod K_b でも hexagon を満たす。hexagon は「ある元が K に入る」形の条件だから、**その元は K_a∩K_b = K_{ab} に入る** ⟹ **(m_*,f_*) は mod K_{ab} で hexagon を満たす**。
 - **charming(単元)**: 2m_*+1 ≡ 2m_a+1 (mod (K_a)_ord) ゆえ gcd(2m_*+1,(K_a)_ord) = 1、同様に (K_b)_ord とも互いに素。(3) より (K_{ab})_ord = lcm なので **gcd(2m_*+1, (K_{ab})_ord) = 1**。
 - **charming(可換化)**: ab(f_*) ∈ ab(f_a) + Λ_{K_a} = Λ_{K_a}、同様に ∈ Λ_{K_b}。(4) より **ab(f_*) ∈ Λ_{K_{ab}}**。
 - **全射性**: K_{ab}=K_a∩K_b・K_aK_b=N より **B₃/K_{ab} ≅ (B₃/K_a) ×_{B₃/N} (B₃/K_b)**(fibre product)。V_a := N/K_a は指数 a の可換群、V_b := N/K_b は指数 b の可換群で **gcd(|V_a|,|V_b|)=1**。H := Im(T_{m_*,f_*}) ≤ B₃/K_{ab} は B₃/K_a と B₃/K_b の双方へ全射(それぞれ T_{m_a,f_a}, T_{m_b,f_b} の全射性)。よって |H| は |B₃/N||V_a| と |B₃/N||V_b| の双方で割り切れ、gcd(|V_a|,|V_b|)=1 より lcm = |B₃/N||V_a||V_b| = |B₃/K_{ab}| で割り切れる ⟹ **H = B₃/K_{ab}**。
 ⟹ **[m_*,f_*] ∈ GT(K_{ab})** かつ R_{K_{ab},N}([m_*,f_*]) = (m_*+N_ord ℤ, f_*N_{F₂}) = [m,f]。∎

### 4.3 裁定と射程

**proved**。Sol §2 の「K6: 部分群等式は受理、survival 推論は要補題」の**要補題がこれで埋まった**。よって
- 逐語「合成細分 K₆ は CRT で分解し新情報なし」は **条件つきでなく定理として使える**(ただし K_n = [N,N]N^n というこの形の細分に限る)。

## 8.4 問 2(a) — v2 full-48 の cond1/cond2 はどちらの規約で正しいか / 48/48 の格

- `AVecp[j] := (ABGamma(basis_j)[1] mod p)` は p=2 で **全成分 0**、`augTarget` の A-行も `(−ABGamma(f₀)[1]) mod 2 = 0` ⟹ **augMat の A/B/γ 行は 0=0 の空虚な行**。⟹ 「cond1/cond2 は augMat に焼き込まれている」という主張は **p=2 では中身が空**。
- `cond1x := (abgF0[1]+abgW[1]) mod 2 = 0` は両項偶数ゆえ **常に真** ⟹ cert の cond1/cond2 が 192/192 で true なのは**検査の結果ではなく検査の不在**。
- **正典単位での実測**(`c83_a2check_cond3_v1.py` 改訂): produced witness に対する**真の** cond1∧cond2 は **p=2 の 96 行中 62 行で FALSE**(154161 で 32・154163 で 30)。**p=3 は 96 行中 0 行 FALSE**(= p=3 は完全に正しい)。真の legal(γ≡0 mod p)は 192 行中 0 行 FALSE。

> **裁定 2(a)**: **p=2 の「full-48 生存」は撤回。格 = UNKNOWN(未検査)。**
> v1 も v2 も p=2 では **charming を一度も課さず・一度も検査していない**。p=2 で実際に確かめられたのは「hexagon mod K₂ + tCoord=0 の可解性」だけである。
> 62/96 行は「produced witness が真の charming を満たさない」ことが判明したにすぎず、**死ではない**(kernel coset 内に別の witness がありうる — その探索は行われていない)。34/96 行は produced witness で真の charming も満たす(= これらは正しく生存)。
> **p=3 の full-48(48/48)は無傷・維持。**(Sol F1 の修正も、その適用も p=3 では正しい。)
> なお **§7 の裁定(55 死は artifact)は維持**(8.6)。ただし「artifact だから 48/48」は**二重に否定**される(誤 cond3 + 空虚 cond1/2)。

## 8.5 問 2(b) — K₃ 24 行 cross-checked への波及

`crosscheck/check_koubou83_survival_k3.py:124-141` の `strand_linking_abgamma` は **producer と同じ un-halved 規約**(/2 なし)。⟹ **両系は規約を共有している** — falsifier 格付け条件 ①(cross-checked は実装独立性であって仕様正当性ではない)が指す状況そのもの。

しかし判定は `cond1 = 3|(a_f+a_w)`、`cond2 = 3|(b_f+b_w)`、`cond3 = 9|(a_fw+b_fw)`、legal は `γ mod 3` — **法は全て 3 の冪**。定理 UNIT-INV(gcd(2,3)=gcd(2,9)=1)より、**共有された 2 倍は判定の真偽を一切変えない**。

> **裁定 2(b)**: **K₃ 24 行の cross-checked 格は維持。波及なし。**
> ただし **維持の理由を cert に明記すること**が条件: 「両系は un-halved 規約を共有するが、K₃ の全判定の法が 3 の冪であり 2 は可逆なので、正典規約との一致が独立に成立する(定理 UNIT-INV)」。**「二系統が一致したから」では格を維持してはならない。**
> 補足: 私の §2.7 の独立復号は **正典単位(/2 あり)**で行っており、報告値(例: C6-elt2 の abg(f)=(−1,1,0))は正典値である。照合器の値はその 2 倍になる。**f″ の (0,0,0) はスケール不変**なので LEG-1 の結論は無条件で不変。

## 8.6 問 2(c) — A2-TAUT・裁定 1518(artifact)の頑健性(明示確認)

- **定理 A2-TAUT**(§7.2)は「3|S」「3|(a_w+b_w)」「gcd(p,3)=1 ⟹ 3|T」だけを使う。全て**法 3** ⟹ gcd(2,3)=1 ⟹ **単位規約に完全に不変**。✔

## 8.7 問 3 — 便 155 に載せる規約 pin(逐語・そのまま貼れる形)

> ### 【PIN-AB-1】可換化規約の正本(独立照合器はこれを実装せよ)
> 1. **対象**: f ∈ F₂ = ⟨x, y⟩(x := x₁₂ = σ₁², y := x₂₃ = σ₂²;2401.06870 §1.3 によりこれは**自由**群)。
> 2. **定義**: **ab(f) := (deg_x f, deg_y f) ∈ ℤ²** — 自由群 F₂ の可換化 F₂/[F₂,F₂] ≅ ℤ² の基底 (x̄, ȳ) に関する座標。
> 3. **単位の pin(必須 assert・4 行)**: **(a,b,γ)(σ₁²) = (1,0,0)**、**(a,b,γ)(σ₂²) = (0,1,0)**、**(a,b,γ)(Δ²) = (0,0,1)**(c = Δ² の F₂-成分は自明・γ のみ 1)、および**生の交差数**が Δ² で **(2,2,2)**(= 2×絡み数)。**この 4 点を assert しない実装は使用禁止。**
>    ※ 起草時、私自身がこの pin を最初 `(a,b,γ)(Δ²) = (1,1,1)` と誤記し、**自分の assert に落とされて訂正した**(絡み数 ℓ(Δ²) = (1,1,1) と (a,b,γ) = (0,0,1) の混同)。**pin が機能した実例**としてここに記録する。
> 4. **σ-語から計算する場合**: 絡み数 **ℓ_{jk} := (符号つき交差数)/2**(pure braid では交差数は必ず偶数 — **偶数性と最終置換 = 恒等を assert すること**)。
>    **(a, b, γ) := (ℓ₁₂ − ℓ₁₃, ℓ₂₃ − ℓ₁₃, ℓ₁₃)**、**γ = 0 ⟺ その元は F₂ に属する**。
> 5. **charming at K**: **ab(f) ∈ Λ_K := ab(K ∩ F₂)**。K = K_n = [N,N]N^n では **Λ_{K_n} = n·Λ_N**(補題 LAT)⟹
>    **charming at K_p ⟺ p | a ∧ p | b ∧ 3 | ((a+b)/p)**(Λ_N = {(a,b) : 3 | a+b} を代入)。
>    - **p ≠ 3**: 第 3 条件は cond1∧cond2 の下で**恒真**(定理 A2-TAUT)⟹ 実質 **p|a ∧ p|b**。
>    - **p = 3**: **3|a ∧ 3|b ∧ 9|(a+b)**。
> 6. **禁止事項**: 判定式に素数を直書きしない(p でパラメトライズし、cert に判定式そのものを記録する — SEMA-1)。
> 7. **【規約 UNIT-1】**: 可換化のスカラー誤り α は **gcd(α, 判定の法) = 1 の素数では原理的に不可視**である。したがって
>    **「他の素数で全部通ったから単位は正しい」は根拠にならない。単位は生成元での値でしか検査できない**(項目 3 の assert が唯一の防衛線)。
