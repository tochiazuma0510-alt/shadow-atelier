### 1.5.1 規約(**正本** — これ以降すべての文書・コード・証明書がこれに従う)

> #### 規約 W-1(語の掛け算の向き — **作用式で定義する**)
> 論文(2401.06870 / 2405.11725)および本工房の全数学文書は **paper 規約**、GAP は **GAP 規約**であり、両者は次の作用式で定義される。**「先に掛ける/後で掛ける」という時間語は正本に置かない**(便 09 W75)。
>
> $$ \textbf{paper(左作用)}:\quad (AB)\cdot i \;=\; A\cdot\bigl(B\cdot i\bigr) \qquad\qquad \textbf{GAP(右作用)}:\quad i^{\,B*A} \;=\; \bigl(i^{B}\bigr)^{A} $$
>
> 二つは同一の写像を与える。したがって
> $$ \boxed{\ \text{paper 語 } "AB" \;\longleftrightarrow\; \text{GAP 乗算 } \texttt{B*A}\ } $$
> **既監査の等式 `paper rs ↔ GAP s*r`(§2 の合成規約)と一致する**(便 09 F7)。
>
> #### 規約 W-2(語レベル評価の正本 = **prepend**)
> 語 $w = L_1^{e_1}L_2^{e_2}\cdots L_n^{e_n}$($L_i \in \{x,y\}$)を有限商 $P$ で評価するときの**正本の手続き**は、**語を左から右へ読みながら、GAP 側で像を左から掛け足す**ことである:
> ```
> elt := One(P);
> for i in [1..n] do  elt := Image(L_i)^{e_i} * elt;  od;
> ```
> これは **M₅ explorer(`search/week3-M5-explorer.g`)が採用した規約**であり、これを工房の正本とする。
> 関数合成の向きで実装する言語(`mul(a,b)(i) = a(b(i))` を採る node/python 等)では、**同じ手続きが「左から順に append」**になる。**名前(prepend/append)は実装の乗算の向きに依存するので、名前ではなく W-1 の作用式で照合すること。**
>
> #### 規約 W-3(証明書 `f_word` の読み書き)
> 証明書スキーマの `f_word = [[letter, exponent], ...]` は **paper 語の順序**で並べる。読み手は必ず W-2 の手続きで評価する。**書き手と読み手が別実装のときは §1.5.4 の適合テストを先に通すこと。**
>
> #### 規約 W-4(判定式の積も paper 積)
> 簡約 hexagon の $(sf)^2 = 1$、$(t^{-1}Y^m f)^3 = 1$、$\theta(f)f = 1$ 等の**すべての積は paper 積**である。GAP 実装では $(t^{-1}Y^m f)^3$ は `(f * Y^m * t^-1)^3` と書く。
> **規約 W-1 は語の評価だけでなく、判定式そのものにも効く。**
>
> **鈍感な式と敏感な式**:
> - **(H-a) $(sf)^2 = 1$ は向きに鈍感**【**紙で閉鎖・便 11 F9**】。$s^2=1$ より $fs = s(sf)s$ ゆえ $(fs)^2 = s(sf)^2 s$、すなわち $(sf)^2 = 1 \iff (fs)^2 = 1$。同値に $\theta = \mathrm{Ad}(s)$ で書けば $f\theta(f) = 1 \iff \theta(f)f = 1 \iff \theta(f) = f^{-1}$。
> - **(H-b′) $(t^{-1}Y^mf)^3 = 1$ は敏感**【**明示反例で閉鎖・便 11 F10**】。A1 の marking $t = (1\,2\,3)$、$Y = (1\,3\,4\,5\,2)$ で、受理 shadow の一つ $m = 1$、$f = (1\,5)(3\,4)$ を取ると
>   $$ \text{paper 積 } t^{-1}Yf = (2\,3\,5)\ (\text{位数 }3) \qquad\text{対}\qquad \text{反転しない積 } fYt^{-1} = (1\,3\,5\,2\,4)\ (\text{位数 }5). $$
>   **この反例は集計値 `12/20` に依存しない**(便 11 F10)。集計値そのものは **node 単系統 candidate**(W93)。
>
> ★ **だからこそ危険である**: (H-a) だけを見て「規約は効いていない」と判断すると (H-b′) で静かに壊れる。**判定式を GAP 順で書き、語だけ paper 順で評価する**という中途半端な混在が最悪である。

### 1.5.2 補題 W1 — 規約を取り違えたときに何が計算されるか

規約を取り違えた(語を逆順に掛けた)評価を $\mathrm{ev}^{\mathrm{bad}}$、正しい評価を $\mathrm{ev}$ と書く。語 $w$ に対し、**指数だけを一斉に反転して順序は変えない**操作を
$$ \iota\bigl(L_1^{e_1}\cdots L_n^{e_n}\bigr) \;:=\; L_1^{-e_1}\cdots L_n^{-e_n} $$
と定める。$\iota$ は $x \mapsto x^{-1},\ y \mapsto y^{-1}$ で定まる **$F_2$ の involutive automorphism**(D2)。**$\iota(w)$ と群の逆元 $w^{-1}$ は別物**である($\iota(xy) = x^{-1}y^{-1} \ne y^{-1}x^{-1} = (xy)^{-1}$)。

> **補題 W1.** 任意の語 $w$ と任意の商 $P$ について
> $$ \boxed{\ \mathrm{ev}^{\mathrm{bad}}(w) \;=\; \mathrm{ev}(w^{\mathrm{rev}}) \;=\; \mathrm{ev}\bigl(\iota(w)\bigr)^{-1}\ } $$

**証明.** $\mathrm{ev}^{\mathrm{bad}}(w) = \mathrm{ev}(w^{\mathrm{rev}})$($w^{\mathrm{rev}} = L_n^{e_n}\cdots L_1^{e_1}$)。一方 $\bigl(\iota(w)\bigr)^{-1} = \bigl(L_1^{-e_1}\cdots L_n^{-e_n}\bigr)^{-1} = L_n^{e_n}\cdots L_1^{e_1} = w^{\mathrm{rev}}$ なので両辺は同じ語の評価である。∎(便 09 F8: 等式合格)

★ **教訓**: 語規約の取り違えは「順序が逆になる」だけでなく、**指数反転と逆元の二重の捻れ**として現れる。この二重性が次節の盲点を生む。

### 1.5.3 二重打ち消しの罠(盲点)

補題 W1 から直ちに従う。**これらの条件下では規約を取り違えても答えが変わらない — その対象・その語では規約バグを検出できない。**

> **(a) $P$ が可換 ⇒ 完全に不可視.** $\mathrm{ev}(\iota w) = \mathrm{ev}(w)^{-1}$ が全語で成立し、$\mathrm{ev}^{\mathrm{bad}} = \mathrm{ev}$。
> **(b) 単一生成元の冪 $w = x^a$ または $y^a$ ⇒ 不可視.** $\iota(w) = w^{-1}$ ゆえ。**空語も含む。**
> **(c) 偶発的一致(必要十分条件).** その語だけで $\ \mathrm{ev}(\iota w) = \mathrm{ev}(w)^{-1}\ $ が成り立つ場合も不可視。**本ノートが主張するのはこれだけである。**
> > **⚠ 撤回済み(D3)**: 「$\mathrm{ev}(w)$ が対合」は盲点の十分条件では**ない**。**反例**: $P = S_3$、$x \mapsto (1\,2)$、$y \mapsto (1\,2\,3)$ で $\mathrm{ev}(xy) = (2\,3)$、$\mathrm{ev}^{\rm bad}(xy) = \mathrm{ev}(yx) = (1\,3)$ — **両方とも対合だが値が異なる**。
> **(d) 過度な一般化の禁止.** 「$[P,P]$ が可換だから安全」とは**言えない**。理由(D4)は、$\iota$ が商 $P = F_2/N_{F_2}$ に降りるには $N_{F_2}$ の $\iota$-不変性が必要で、一般には保証されないこと。**盲点かどうかは対象ごと・語ごとに実測するしかない。**
> > 例: class 2 の $P$ と交換子語 $w = xyx^{-1}y^{-1}$ では $\mathrm{ev}(\iota w) = [X^{-1},Y^{-1}] = [X,Y] = \mathrm{ev}(w)$ なので $\mathrm{ev}^{\mathrm{bad}}(w) = \mathrm{ev}(w)^{-1}$ — 不可視ではないが**符号だけ**の違いになり、$f \mapsto f^{-1}$ で閉じた判定条件((H-a) は $\theta(f) = f^{-1}$ ゆえまさにそう)では**やはり検出されない**。

## 2. groupoid GTSh(2401 §3)

**対象**: NFI_PB₃(B₃) = {N ⊴ B₃ | 指数有限, N ≤ PB₃}。各 N に:
