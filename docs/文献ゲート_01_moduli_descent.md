# 文献ゲート 01 — moduli→definition 降下(文献要請 1 の関所処理・2026-07-27 司令塔)

## 機構抽出(司令塔)

1. **Aut = 1 ルート(要請の字面)**: 被覆 X の field of moduli K_m に対し、降下の障害は「共役 σX と X の間の同型の族が cocycle 条件 φ_{στ} = φ_σ ∘ σφ_τ を満たすよう選べるか」(Weil 1956 の判定)。**Aut = 1 なら各同型が一意**なので条件式の両辺とも同型で、一意性から自動成立 — 障害の受け皿(Aut に値を取るコホモロジー)が消える。一般論の正典は Dèbes–Douai 1997(mere cover の障害 = H² 内の複数の特性類)。dessin での直接言明は Herradon Cueto(arXiv:1409.7736 — 「Aut 自明な dessin は field of moduli 上定義可能」を明示証明)。
2. **marked ルート(こちらの設定に自然)**: smooth な ℚ-有理 marked point があれば Dèbes–Emsalem 判定で降下(Sijsling–Voight 2016, arXiv:1504.02814 が Birch の主張の再検討として整理)。**うちのテンプレは前件 (4) で「ℚ-有理な全分岐 cusp + actual marking」を最初から要求している**ので、Aut = 1 の場合分けに依存しない別経路として整合が良い。

## 採否(裁定)

- **採用(引用の第一候補)**: Dèbes–Douai 1997(査読済・一般論の正典)+ Sijsling–Voight 2016(marked 版・うちの設定に直撃)。
- **条件付き採用**: Herradon Cueto(字面一致だが正典性(査読誌か)未確認 — 論文段階で reader が定理番号精読の上、一次定理(Dèbes–Emsalem 等)への再出典を試みる)。
- **保留**: Coombes–Harbater 1985(「mere cover は常に降下可能」という検索合成の言明は UNVERIFIED — D–D 1997 が mere cover の障害類を構成している事実と緊張するため、精読なしに引用しない)。Weil 1956(一次未達・基礎機構としてのみ言及)。
- **reader 精読(定理番号・前提の逐語確認)は論文執筆段階まで保留** — 補題 Q の監査(便 30)には機構レベルで足りる。

## B₃-gentle 翻訳(降ろすときの一工夫)— 裁定 26 時に Opus へ

- 標的 dessin(次数 10・Aut = 1・smooth・P¹ 上 3 点分岐・標数 0)は機構 1・2 の**どちらでも降下が閉じる見込み**。補題 Q(GT 側から moduli = ℚ)+ 本降下で「**ℚ 上のモデルの存在**」まで。
- **【重要・混同禁止】「存在」と「明示」は別**: 降下定理が与えるのは ℚ-モデルの存在のみ。前件 (4) が要求するのは**明示** ℚ-モデル+ℚ-有理 cusp+actual marked identification(u の抽出に必要)。したがって補題 Q+降下は (4d) を「存在レベルで保証された探し物」に格下げするだけで、**(4) を弱めてはならない**。
- 2 標的 dessin(K⁽⁵⁾ の新現象)にはそれぞれ独立に適用 — 「非同型な 2 個がともに ℚ-有理」の主張は dessin ごとの降下で閉じる。
