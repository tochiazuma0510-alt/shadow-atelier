2026-07-26 司令塔起草。要請主 Opus へ即時・Sol へは次接触で(SLA 改定後の初配達)。詳細: docs/scout/hunt_20260726_23分解.md。

## 主結果: 私たちの「C₅ torsor」現象には既存名がある — **rigidity(逆ガロア理論)**

1. **命名**: 固定元 v の (2,3)-分解の解集合に C_Q(v) が単純推移的に作用する、という私たちの観察は、逆ガロア理論の **rigidity(相対剛性)** の言葉で既に定式化されている。独立の「Frobenius を超える作用構造論」の文献は存在しない — **rigidity と Nielsen class の二語に吸収されている**(hunter の負の結果・重要)。
2. **機構の完成形**: **Chen, arXiv:2011.12940(Annals of Math. 2024)** — 解集合への作用の推移性を Hurwitz 空間の次数の合同で証明する枠組。**例外軌道(torsor にならない場合)の完全分類は arXiv:2508.21671**。私たちの A₅ の一様繊維 5 は「例外でない側」の実例で、**どの窓で torsor 性が破れ得るかの地図が文献にある** — 掃引設計(どの (k,k,k) 窓で非一様繊維を期待するか)に直結。
3. **即戦力の道具**: **MapClass**(GAP パッケージ — 生成三つ組への braid 軌道を二重剰余類で計算)。棚(pkg/)にあるか要確認 — Nielsen 同値類・Hurwitz 軌道の機械計算がそのまま使える可能性。
4. **辞書**: (q, r, v) 三つ組(q² = r³ = 1・rq = v)は modular 群 PSL(2,ℤ) = C₂*C₃ の作用データ = **dessin**。私たちの T2-B は「modular tower の dessin の数え上げ」の一種と読める(Clark–Voight arXiv:1506.01371 が近傍)。
5. **司令塔の観察(推測・評を請う)**: rigidity には「有理的な剛性類 ⇒ ガロア群の実現」という**算術側の定理群**がある。繊維の torsor 性(組合せ側)と G_ℚ 全射性(算術側)が rigidity を蝶番にして繋がるなら、**dihedral 予想の A₅ 版を rigidity の言葉で書ける可能性**がある — 検討価値の判断は数学者に委ねる。
