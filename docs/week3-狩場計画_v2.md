## 1. 塔の照合(委嘱 02 の急所)— **結論: 二つの塔は同一対象である**

### 1.1 問題設定

裁定 05 は「restricted 次元部分群と verbal 部分群は一般に別物」として照合を命じた。比較対象:

| | Sol 案(P37–P39) | Opus 案(v1 §3.1) |
|---|---|---|
| 中段 | **N₂ := π⁻¹(D₃⁽²⁾(F₂))** | **N_{P₂} := π⁻¹(F₂⁴γ₃(F₂))** |
| 細段 | **N₃ := π⁻¹(D₄⁽²⁾(F₂))** | **N_{P₃} := π⁻¹(F₂⁴γ₄(F₂))** |
| 定義 | 2-restricted 次元部分群 **D_n⁽²⁾(F₂) = Π_{i·2^j ≥ n} γ_i(F₂)^{2^j}** | verbal 部分群 |
| 主張位数 | 32 / 128(restricted Lie 次元 2,3,2) | 32 / **未確定**(v1 【GAP-D1】: 見込み 128〜512) |

**一般論としては裁定 05 の警告が正しい**(D_n⁽ᵖ⁾ と F^{p^k}γ_n は一般に異なる)。しかし **n = 3, 4 かつ p = 2 かつ rank 2 のこの場所では一致する**。以下が証明である。

### 1.2 明示比較(包含は自明・逆包含が本題)

定義を展開する(p = 2)。

> **n = 3**: i·2^j ≥ 3 を与える極小データは (i,j) = (3,0), (2,1), (1,2)。ゆえに
> **D₃⁽²⁾(F₂) = F₂⁴ · γ₂(F₂)² · γ₃(F₂)**。
> **n = 4**: (i,j) = (4,0), (2,1), (1,2)。ゆえに
> **D₄⁽²⁾(F₂) = F₂⁴ · γ₂(F₂)² · γ₄(F₂)**。

(j ≥ 2 の γ₁^{2^j} は w^{2^j} = (w⁴)^{2^{j-2}} ∈ F₂⁴ なので新規寄与なし。)

したがって **包含は自明**:
$$ F_2^4\gamma_3 \;\subseteq\; D_3^{(2)},\qquad F_2^4\gamma_4 \;\subseteq\; D_4^{(2)}, $$
差は**ちょうど因子 γ₂(F₂)²**(= 交換子の 2 乗が生む部分)である。ゆえに逆包含は

> **γ₂(F₂)² ⊆ F₂⁴γ₃(F₂)?** および **γ₂(F₂)² ⊆ F₂⁴γ₄(F₂)?**

すなわち「**自由 exponent-4 class-2(resp. class-3)群の中で [X,Y]² = 1 か**」に帰着する。

### 1.3 中段の一致(定理 T1a)

> **定理 T1a.** **D₃⁽²⁾(F₂) = F₂⁴γ₃(F₂)**、すなわち **N₂ = N_{P₂}**。共通の商 P₂ は位数 **32**。

**証明.** P₂ := F₂/F₂⁴γ₃ は class ≤ 2・exponent | 4 の多様体の階数 2 の相対自由群。class 2 では
$$ (XY)^4 = X^4Y^4[Y,X]^{\binom42} = [Y,X]^6, $$
exponent 4 より (XY)⁴ = 1 = X⁴ = Y⁴ ゆえ **[X,Y]⁶ = 1**。また [X,Y]⁴ = [X⁴,Y] = 1。ゆえに [X,Y]^{gcd(6,4)} = **[X,Y]² = 1**。
よって γ₂² は P₂ で自明、すなわち γ₂(F₂)² ⊆ F₂⁴γ₃(F₂)。逆包含と合わせて等号。
位数: P₂^{ab} = C₄×C₄(16)、γ₂(P₂) = ⟨[X,Y]⟩ ≅ C₂ ⇒ |P₂| = **32**。∎

### 1.4 細段の一致(定理 T1b)— **【GAP-D1】の解消**

> **定理 T1b.** **D₄⁽²⁾(F₂) = F₂⁴γ₄(F₂)**、すなわち **N₃ = N_{P₃}**。共通の商 P₃ は位数 **128**、class 3、exponent 4、**[P₃,P₃] ≅ C₂³**(位数 8)。

**証明.** 二重不等式で挟む。
**(上から)** N := F₂/γ₄(自由 class-3・階数 2)で計算する。Hall 基底を x, y, w := [x,y], p := [w,x], q := [w,y](γ₃ = ⟨p,q⟩ は中心)とする。
1. [x⁴,y] = [x,y]⁴[[x,y],x]^{\binom42} = w⁴p⁶ ∈ N⁴、かつ w⁴ ∈ N⁴ ⇒ **p⁶ ∈ N⁴**。同様に [y⁴,x] から **q⁶ ∈ N⁴**。p⁴, q⁴ ∈ N⁴ と合わせ **p², q² ∈ N⁴**。
2. 収集計算(下の (★))により
 $$ (xy)^4 = x^4y^4\,w^{-6}p^{-4}q^{-14}. $$
 p², q² ∈ N⁴ を法として (xy)⁴ ≡ x⁴y⁴w^{-6}、ゆえに **w⁶ ∈ N⁴**。w⁴ ∈ N⁴ と合わせ **w² ∈ N⁴**。
3. ゆえに N/N⁴ は x⁴ = y⁴ = w² = p² = q² = 1 を満たし、位数 ≤ 4·4·2·2·2 = **128**。
**(下から)** F₂⁴γ₄ ⊆ D₄⁽²⁾ より F₂/F₂⁴γ₄ ↠ F₂/D₄⁽²⁾。後者の位数は **Jennings/Quillen** で決まる: p = 2・階数 2 の自由 restricted Lie 代数の次数別次元 c_n は
$$ \prod_{n\ge1}(1+t^n)^{c_n} \;=\; \frac1{1-2t} $$
から c₁ = 2, c₂ = 3, c₃ = 2 と定まり(t, t², t³ の係数 2, 4, 8 を順に合わせる)、|F₂/D₄⁽²⁾| = 2^{2+3+2} = **2⁷ = 128**。
**(挟み込み)** ゆえに |F₂/F₂⁴γ₄| = 128 で、包含 F₂⁴γ₄ ⊆ D₄⁽²⁾ が**指数の等しい包含**だから等号。∎

**(★) 収集計算の明示**(自由 class-3 群 N での恒等式。以後の E_m 計算でも使う):
$$ y^bx^a = x^ay^b\,w^{-ab}\,p^{-b\binom a2}\,q^{-a\binom b2},\qquad w^cx^a = x^aw^cp^{ca},\qquad w^cy^b = y^bw^cq^{cb}, $$
$$ (xy)^m = x^my^m\,w^{-\binom m2}\,p^{-\binom m3}\,q^{-\frac{(m-1)m(2m-1)}6}. $$
(第 3 式は m = 1,2,3,4 で直接検算した: 指数 (0,0,0), (1,0,1), (3,1,5), (6,4,14)。第 1・2 式から §2.3 の検算スクリプトを構成し、結合律と位数 128 を機械確認した。)

### 1.5 照合の結論

## 2. 新定理 — hexagon が常に解ける構造的理由

v1 の定理 H5(k ≤ 3)・H6(class 2)は「charming がちょうど必要な分だけ hexagon を救う」という**説明のない偶然**として現れていた。委嘱 02 でその偶然の**正体が判明した**。

### 2.1 定理 H8(3 と互いに素な導来群 ⇒ (3.11) は常に可解)

記法は v1 §1.3 のまま: 許容対象 N(c ∈ N)、**P := F₂/N̄**、**A := [P,P]**、
$$ E_m := X^mZ^mY^m \in A,\qquad \mathcal N_m(\bar f) := (\tau^2\bar f)^{Z^mY^m}(\tau\bar f)^{Y^m}\bar f, $$
**(H-b′)** E_m · 𝒩_m(f̄) = 1(= 簡約 hexagon (3.11))。

> **定理 H8.** A = [P,P] の位数が **3 で割れない**ならば、**任意の m ∈ ℤ に対し (H-b′) は解 f̄ ∈ A をもつ**。(charming 条件も可換性も class の仮定も不要。)

**証明.** σ: A → A を **σ(a) := (τ_P a)^{Y^m}**(= Y^{-m}τ_P(a)Y^m)で定める。τ_P ∈ Aut(P) と A char P より σ ∈ Aut(A)。h := Y^m と置くと
$$ \sigma^2(a) = \tau^2(a)^{\tau(h)h},\qquad \sigma^3(a) = a^{\tau^2(h)\tau(h)h}. $$
τ(Y) = Z, τ²(Y) = X なので **τ²(h)τ(h)h = X^mZ^mY^m = E_m**。ゆえに
$$ \boxed{\ \sigma^3 = \mathrm{Inn}_A(E_m)\ }\qquad(a\mapsto E_m^{-1}aE_m), $$
また τ(E_m) = Y^mτ²(Y^m)τ(Y^m) より **σ(E_m) = E_m**。
したがって、A と新しい元 u で生成され関係
$$ u\,a\,u^{-1} = \sigma^{-1}(a)\quad(a\in A),\qquad u^3 = E_m $$
をもつ群 **Ĝ** が矛盾なく定義される(整合条件 u³au^{-3} = σ^{-3}(a) = E_m a E_m^{-1} と u E_m u^{-1} = σ^{-1}(E_m) = E_m がともに成立)。Ĝ は拡大
$$ 1 \longrightarrow A \longrightarrow \hat G \longrightarrow C_3 \longrightarrow 1 $$
を与える。u^{-1}fu = σ(f) に注意して、任意の f ∈ A について
$$ (uf)^3 = u^3\,(u^{-2}fu^{2})(u^{-1}fu)\,f = E_m\cdot \sigma^2(f)\sigma(f)f = E_m\cdot\mathcal N_m(f). $$
ゆえに **(H-b′) ⟺ 剰余類 Au が位数 3 の元を含む ⟺ 上の拡大が分裂する**(位数 3 の補群の生成元は Au または Au² に入り、後者なら平方が Au に入る)。
gcd(|A|, 3) = 1 なので **Schur–Zassenhaus の定理**により拡大は分裂する。∎

★ **これが v1 の定理 H5・H6 の背後にあった機構である。** 「τ の 3 サイクル」は C₃-作用、𝒩_m はその**捻れノルム**、E_m は σ³ の**内部自己同型としてのずれ**。hexagon (3.11) は「この C₃-拡大が分裂するか」という**古典的な問い**にすぎなかった。

> **系 H8′(p 群・p ≠ 3).** P が p 群(p ≠ 3)ならば A も p 群で 3 ∤ |A|。さらに f̄ ∈ A ⊆ Φ(P) かつ gcd(u, p) = 1 より **全射性も自動**(Frattini)。ゆえに **m-full か否かは (H-a) θ(f̄) = f̄⁻¹ との同時可解性だけに帰着する**。

> **系 H8″(狩場の必要条件・v1 の §2.4 を置き換える).** N から fake が出るには、v1 の (k ≥ 4) と (class ≥ 3 または非巾零)に加えて
> $$ \textbf{3 } \big|\ |[P,P]| $$
> が**必要**(定理 H8 の対偶)。**2 群・exponent 4 は最も無防備どころか、定理 H8 で完全に守られている。**

### 2.2 定理 H9(class 3 の両塔は m-full)— 紙上計算

> **定理 H9.** P₃ = F₂/D₄⁽²⁾(位数 128)について、[P₃,P₃] = ⟨w,p,q⟩ ≅ C₂³(w = [X,Y], p = [w,X], q = [w,Y])であり
> $$ \theta:\ w\mapsto w,\ p\leftrightarrow q; \qquad \tau:\ w\mapsto wp,\ p\mapsto q\mapsto pq\mapsto p, $$
> $$ E_0 = 1,\quad E_1 = wp,\quad E_2 = wq,\quad E_3 = 1. $$
> f̄ = w^α p^β q^γ と書くと **𝒩_m(f̄) = w^α p^{αm} q^{α(1+m)}**(β, γ は完全に消える)、**(H-a) ⟺ β = γ**。ゆえに
> $$ \mathfrak M(N_3) = \{0,1,2,3\} = \mathcal X_{N_3}\quad(\textbf{m-full}),\qquad |\mathrm{GT}(N_3)| = 4\cdot 2 = \mathbf 8, $$
> 各 m の f̄ は m = 0,3 で {1, pq}、m = 1,2 で {w, wpq}。**R_{N₃,N₂} は全射・繊維一様 2・ker ≅ C₂ = {[0,1], [0,pq]}。**

**証明の要点.** ①(H-a): A の exponent が 2 なので θ(f̄) = f̄⁻¹ ⟺ θ(f̄) = f̄ ⟺ β = γ。②(H-b′): A は可換で、共役作用は P^{ab} = C₄×C₄ を経由し w ↦ w p^{ε_X} q^{ε_Y}、p, q は中心。ε(Z^mY^m) = (−m, 0)、ε(Y^m) = (0, m) から
𝒩_m の p 指数 = (α+β+γ+αm) + (α+γ) + β = αm、q 指数 = (α+β) + (β+γ+αm) + γ = α+αm(mod 2)。
③ E_m: (★) の収集公式と Z^m = ((XY)^m)^{-1} から E_m = w^{c_m}p^{a_m+c_m m}q^{b_m}·[X^{-m},Y^m] を計算(c,a,b は §1.4 の指数を mod 2 したもの、[X^{-m},Y^m] = w^{m²}p^{m\binom{-m}2}q^{-m\binom m2})。結果が上表。
④ 各 m で 𝒩_m(f̄) = E_m は **α のみを一意に定め**、β, γ を自由に残す。(H-a) が β = γ を課して各 m に 2 解。
⑤ 全射性は 系 H8′(2 群)。∎

★ **α のみが決まる理由**(構造的説明): [P₃,P₃] の層 γ₂/γ₃ = ⟨w⟩ は **τ-自明加群**で 1+τ+τ² = 3 = 1(F₂ 上)⇒ 同型 ⇒ 一意解。層 γ₃/γ₄ = ⟨p,q⟩ は **F₄ 上の非自明既約 F₂[C₃]-加群**で 1+τ+τ² = 0 ⇒ **ノルムの像に寄与せず、f̄ の自由度としてそのまま残る**。これは v1 §6 で A₄ の V₄ に見た現象(τ が V₄ を 3-巡回し 1+ρ+ρ² = 0)と**同一の機構**である。

## 5. 配達文書 B(Guillot GT(G))の比較写像課題への評

**課題(配達文書 01 §B-4)**: 「PB₃ ≅ F₂ × Z(c) ゆえ、c を先に殺す商に限れば Guillot 塔は主線塔の『c-自由断面』に見える。自然な写像 GTSh(N) → GT(G) の構成と核・余核の定量は新規性のある小課題候補」。以下は**推測と証明を峻別**した私の見立てである。

**(1) 構成が最も通りやすい形(推測 — ただし根拠は具体的)。** 我々の言葉では、**c ∈ N なる許容対象**がちょうど「c-自由断面」である。この場合 PB₃/N ≅ F₂/N̄ = P であり、shadow のデータ [m, f̄] は **(u, f̄) ∈ (ℤ/2N_ord)^× × [P,P]** として P の中だけで完結する(v2 で分離命名した χ̃_N が第 1 成分)。Guillot の GT₁(G) の元は(配達文書 §B の系統札 (b) により)λ 座標も (m,f) データも持たない **outer 変種**なので、自然に期待できるのは
$$ \mathrm{GTSh}(N) \longrightarrow \mathrm{GT}_1(P)\quad\text{ではなく}\quad \mathrm{GTSh}(N)\big/\!\!\sim\ \longrightarrow \mathrm{GT}_1(P), $$
すなわち **「u を忘れ、f̄ を内部自己同型を法として見る」写像**である。核には少なくとも χ̃_N の核方向(円分方向)が丸ごと入る見込みが高い。**これは証明していない** — Guillot の GT₁ の定義(1407.3112 の原文)を我々は読んでいないので、対応が定義レベルで整合するかは【UNKNOWN】である。上記は系統札 3 軸からの**型の推測**にすぎない。

**(2) 差別化点は定量できる(ここは我々の側で証明できる見込みが高い)。** 配達文書 §B-4 の指摘「**c 生存系(M₅ の円分 C₄)は彼の塔から原理的に見えない**」は、我々の側の既証明の事実と正確に噛み合う。定理 B(iii) の ker R_{M₅,K⁽³⁾} ≅ C₄ は **c ↦ t(位数 5)で c が生き残る**ことに由来し(命題_円分持ち上げ v2 §1 の (M4): ord(c̄) = 5 が M₅_ord = 30 を作る)、その C₄ は χ̃ の核として**純粋に円分方向**にある(系 A3 の対比軸)。Guillot 塔は F₂ の G-完備化であって PB₃ を経由しないから、**この C₄ を担う座標が構造的に存在しない**。したがって比較写像の**余核(または核)の中に C₄ が現れる**ことを、我々の側の計算だけで**定量的に示せる**見込みがある。これは「同名別物」を曖昧に言うのではなく、**具体的な有限群の差**として提示できるという意味で、当工房の差別化の**最も安い証拠**である。

**(3) 優先度の見立て(戦略評)。** 比較写像は **fake 狩り(G3 ルート)には直接効かない**。効くのは (i) 対外的な位置づけ(第三変種との関係を我々が把握していることの証明)、(ii) 配達文書 §B-5 の**計算技法の輸入許可条件**である。とくに §B-5(iii) の「計算済み表(PSL(2,q)・M₁₁ 等)は**比較写像が確立するまで較正に使わない**」という留保は正しく、**私はこの留保を強く支持する** — 対象が別物である以上、答えの錨づけは較正ではなく汚染になる(ブラインド破れと同種の事故)。一方 §B-5(i) の **両側剰余類パラメータ化 + θ 前段フィルタ**(1407 Lemma 5.1)は、我々の (H-a) θ(f̄) = f̄⁻¹ と**同じ型のフィルタ**であり、比較写像の確立を待たずに**アルゴリズムとして**輸入してよい(数学的主張を輸入するのではなく、探索順序を借りるだけだから)。

> **要請 1(最優先・【GAP-E2】に対応).**
