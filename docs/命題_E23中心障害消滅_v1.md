## 2. 定理 E23

> **定理 E23(中心持ち上げ障害の恒等消滅).** 上の設定に加えて
> **(G2)** $C^\sigma = 0$、**(G3)** $C^\theta = (1+\theta)C$
> を仮定する。このとき **すべての $\bar f\in\mathcal L$** について
> $$ q_N(\bar f) = 0 \quad\text{(厳密)},\qquad q_\theta(\bar f)\in(1+\theta)C, $$
> したがって
> $$ \boxed{\ \omega\equiv 0\ \text{on}\ \mathcal L\ }\qquad\text{ゆえに}\qquad
> \boxed{\ \mathcal S_m\cap\mathcal B_\theta\ne\emptyset \iff \mathcal L\ne\emptyset\ } $$
> すなわち **中心持ち上げ障害は存在しない — 判定は線型段だけで完結する。**

**証明.**

**(a) 第一座標: $q_\theta(\bar f)$ は $\theta$-固定。**
$g = s\bar f$ と置く。$\theta^2 = \mathrm{id}$ ゆえ
$$ \theta\bigl(q_\theta(\bar f)\bigr) = \theta^2(g)\,\theta(g) = g\,\theta(g). $$
class 2 の交換子則 $uv = vu[u,v]$ を $u = g$, $v = \theta(g)$ に使うと
$$ g\,\theta(g) = \theta(g)\,g\cdot[g,\theta(g)] = q_\theta(\bar f)\cdot\beta\bigl(\bar f,\ \bar\theta\bar f\bigr). $$
$\bar f\in\mathcal L$ ゆえ $\bar\theta\bar f = -\bar f$、$\beta$ は交代的だから $\beta(\bar f,-\bar f) = -\beta(\bar f,\bar f) = 0$。
ゆえに $\theta(q_\theta) = q_\theta$、すなわち $q_\theta(\bar f)\in C^\theta$。**(G3)** より $q_\theta(\bar f)\in(1+\theta)C$ で、これは $\mathrm{im}\Lambda$ の第一座標成分そのものだから $\pi$ で消える。

**(b) 第二座標: $q_N(\bar f)$ は $\sigma$-固定。**
$y := \sigma^2(g)\sigma(g)$ と置く。$\sigma(E_m) = E_m$ と $\sigma^3(g) = E_m^{-1}gE_m = g\cdot\beta(\bar f,\bar E_m)$ から
$$ \sigma\bigl(q_N(\bar f)\bigr) = E_m\,\sigma^3(g)\sigma^2(g)\sigma(g)
= E_m\cdot g\,\beta(\bar f,\bar E_m)\cdot y . $$
再び $gy = yg\cdot[g,y]$ を使い、$[g,y] = \beta(\bar f,\ \bar\sigma^2\bar f + \bar\sigma\bar f)$ だから
$$ \sigma\bigl(q_N(\bar f)\bigr) = q_N(\bar f)\cdot\beta(\bar f,\bar E_m)\cdot\beta\bigl(\bar f,\ \bar\sigma^2\bar f+\bar\sigma\bar f\bigr). $$
ここで $\bar f\in\mathcal L$ の第二条件 $\bar{\mathcal N}\bar f = -\bar E_m$ より
$$ \bar\sigma^2\bar f+\bar\sigma\bar f = \bar{\mathcal N}\bar f - \bar f = -\bar E_m-\bar f, $$
したがって(β の交代性 $\beta(\bar f,\bar f)=0$ を使って)
$$ \beta\bigl(\bar f,\ -\bar E_m-\bar f\bigr) = -\beta(\bar f,\bar E_m). $$
**二つの補正項がちょうど打ち消し合い**、$\sigma(q_N) = q_N$、すなわち $q_N(\bar f)\in C^\sigma$。**(G2)** より $q_N(\bar f) = 0$。

(a)(b) より $\Xi(\bar f)\in(1+\theta)C\times\{0\}$。系 E22.6 の $\mathcal N_C = 0$ の下では $\mathrm{im}\Lambda = (1+\theta)C\times\{0\}$ なので $\Xi(\bar f)\in\mathrm{im}\Lambda$、すなわち $\omega(\bar f) = 0$。定理 E22′ に代入して主張を得る。∎

> **★ 証明の芯は (b) の一行**である。$\sigma^3 = \mathrm{Inn}(E_m)$ が生む捻れ $\beta(\bar f,\bar E_m)$ と、class-2 の並べ替えが生む捻れ $\beta(\bar f,\bar{\mathcal N}\bar f-\bar f)$ が、**線型段の方程式 $\bar{\mathcal N}\bar f = -\bar E_m$ によって符号違いの同じ量になり相殺する**。すなわち「線型段を解いた」という事実そのものが、二次段の障害を殺している。**これが 384 系 POSITIVE の正体である。**

> **系 E23.1(観測の定理化).** 定理 E23 の下で $F = \pi\ell+\pi\mathcal Q \equiv 0$ on $K$。
> **証明.** $F(\bar k) = \omega(\bar f_0+\bar k)-\omega(\bar f_0) = 0-0 = 0$(命題 E22.3 (3.2))。∎
> **⇒ implementer の観測「F|_K ≡ const」は正しく、その定数は 0 である。**

> **系 E23.2(独立に成り立つ退化).** さらに $K$ 上では極化 $\pi B$ も消える(⇒ $F$ は二次でなく**準同型**)。
> **理由**: 命題 E22.5 §5.4 より $\beta(\bar u,\bar v) = (u_wv_p-u_pv_w)t_5+(u_wv_q-u_qv_w)t_6$ は **$w$-座標を必ず一方に要求する**。ところが $\bar k\in K\subseteq\ker\bar{\mathcal N}$ の $L_2 = \gamma_2/\gamma_3$-成分は $3k_w = 0$(σ̄ は階数 1 の $L_2$ 上恒等 ⇒ $\bar{\mathcal N}|_{L_2} = 3$)を満たし、**3 は $\mathbb Z/2^j$ で可逆だから $k_w = 0$**。ゆえに $\beta|_{K\times K} = 0$。
> **これは定理 E23 とは独立の第二の退化**であり、「$K$ の生成元は $\gamma_3$ の上に載る」という implementer の観測(θ̄ = −ς 固定部分空間)と整合する。

## 3. 普遍 class-5 対象で (G2)(G3) が成り立つ理由

命題 E22.5/§5.2 より $C = \langle t_5,t_6\rangle$、基底 $(t_5,t_6)$ で
$$ \sigma|_C = \begin{pmatrix}0&-1\\1&-1\end{pmatrix},\qquad \theta|_C = \begin{pmatrix}0&1\\1&0\end{pmatrix}. $$

| 条件 | 成立理由 | 検算(j = 1..8) |
|---|---|---|
| **(G2)** $C^\sigma = 0$ | $\det(1-\sigma|_C) = 3$ は**奇数** ⇒ $\mathbb Z/2^j$ 上可逆 ⇒ $\ker(1-\sigma) = 0$ | `\|C^σ\| = 1` ✔ |

| $\mathcal N_C = 0$(系 E22.6) | $\sigma|_C$ の特性多項式 $\lambda^2+\lambda+1$ | ✔ |

> **★ 両方とも「2 群だから」効いている。** (G2) は 3 の可逆性、(G3) は $C$ が $\langle\theta\rangle\cong C_2$ の**正則表現**であること。前者は $p\ne3$ の話、後者は $C$ の $\theta$-加群構造の話で、**独立の二つの理由**である。
