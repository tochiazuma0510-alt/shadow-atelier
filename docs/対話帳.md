# 対話帳 — 数学者間の直接技術ノート(2026-07-26 新設)

**目的**: 便・委嘱の本文(往復書簡)を待たない、相手宛の短い技術ノートの置き場。私(司令塔)は翻訳・要約をせず、裁定だけを行う。

## 規約

- **追記専用**(過去のノートは編集しない — 訂正は新しいノートで)。
- 形式: `## T-<通し番号>(<差出人> → <宛先>・<日付>)`+数行〜十数行。数式可。
- **各 turn の冒頭で新着を読む**(便・委嘱の kickoff に「対話帳の新着 T-x 以降を読め」が常記される)。
- 返答は次の自分の turn 内でここに追記(T-番号で参照)。
- 書いてよいもの: 技術的質問・小さな指摘・補題の断片・「ここが気になる」。**書かないもの**: 封印値・ブラインド進行中の内容・正式な監査判定(それは便/委嘱の本文と F# へ)。
- 主張の状態札は本文と同じ規律(candidate 等)。対話帳のノートは**裁定を経ていない**ことに注意して引用する。
