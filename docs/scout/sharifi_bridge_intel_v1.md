## 1. 主発見 — 我々の E(k,p) と「同じ形の欠損」が Galois 側で定理化済み

Sharifi(Luminy 2002・arXiv:math/0104116): X=P¹−{0,1,∞} の pro-p 表現から得る井原 Galois Lie 代数 𝔤(ℤ_p-Lie 代数・Ihara Thm 1)に対し、Soulé 元由来の生成元 σ_m で自由 ℤ_p-Lie 代数 𝔰 を作り、標準射 ψ: 𝔰 → 𝔤 を考える:

- **Thm 2**: p が奇の**正則**素数 ⟹ Ψ(群版)は**全射**(Deligne 予想下で同型)。
- **Thm 3**: p が**非正則**+Greenberg 予想 ⟹ ψ, Ψ は**同型でない**(Deligne 予想下で全射でない)。
- 道具: σ_{m+p−1} を σ_m から作る帰納構成(**p−1 シフトで生成元を昇らせる**)。

つまり「**⊗ℚ_p では全射(Hain–Matsumoto)・ℤ_p では非正則 p で欠損**」— 我々の E(k,p)(Brown の e が ℚ 上同型・ℤ 上で非正則対に余核)と**同じ形**。ただし向こうは **Galois 側で条件付き定理**、こちらは Lie(ls)側の測定。

## 2. 空白の確定(hunter の最大の負の結果)

**ls(線形化二重シャッフル)の ℤ-整構造・格子・捩れを正面から扱う文献は発見できず**(Brown・Racinet・Ecalle・2026 の stabilizer 系まで一貫して ℚ 上)。⟹ 整レベルの欠損理論は Galois 側(Ihara–Sharifi 線)**にのみ**存在する。

- 帰結①: 我々の E(k,p) 測定は文献の空白地帯に落ちる(novelty の側面 — ただし発表保留規律のとおち内部評価まで)。
- 帰結②: **橋の建設方向は「Galois 側の整理論を ls 側へ輸送」が自然**(逆向きではない)。P4-0 の設計に直結。
- Hain–Matsumoto(ℚ_ℓ 係数のみ)は「整レベルは空白」の**否定的引用**として使える。

## 3. 司令塔の翻訳(一工夫・candidate — 数学者が破壊してよい)

P4-0 の比較射は「E ⟹ CE」を一段で狙わず、**Sharifi の余核を中継点**に二段で設計するのが自然:

```
E(k,p) = Tor_p coker(e)   ←→   coker_p(ψ: 𝔰 → 𝔤)   ←→   窓側の算術像欠損
   (ls 側・我々の測定)         (Galois 側・条件付き定理)      (北極星側・未建設)
```

- **左の橋**: 両側とも非正則指数(p | B_{p−k} 型)に支配されるか・Sharifi の p−1 シフトが深さ次数の周期性として現れるか、が照合観点(hunter 指定)。CONE-B の「一事象の二面」は、Galois 側の第三面を得て初めて比較射になる。
- **右の橋**: 𝔤 は我々の塔(K^{(n)} 族・B₃ 有限商)の逆極限側の対象 — ここは既存の「逆極限 ⟷ 有限窓」辞書(帯 3 領有)の圏内で、WR-6(cofinality)と同じ場所に未決が集中する。
- **道具箱**: McCallum–Sharifi の cup 積全射性(p<10⁴ 計算検証・**p=37 は証明済**)は「全射性の破れを有限係数線形代数で測る」雛形 — 我々の M-S 検証域の扉・SAT-37(37 の窓)と直接接触する。E の余核計算を cup 積対の退化と突合する検査が立ち得る。
