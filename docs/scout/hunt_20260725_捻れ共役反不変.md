- 発令: 司令塔(文献ゲート① 要請 1)
- 遠征係: paper-hunter
- 実施日: 2026-07-25
- 困難: 有限群 A(典型 2 群)、σ ∈ Aut(A) with σ³ = Inn(E)、θ ∈ Aut(A) 位数 2。
  gcd(|A|,3)=1 のとき σ²(f)σ(f)f = E⁻¹ の解集合は単一の σ-捻れ共役類。
  **この類が θ(f) = f⁻¹ を満たす元を含む十分条件が欲しい。**
  障害: gcd(|θ|,|A|) = 2 のため Glauberman(coprime action)が使えない。

## 1. 困難の抽象化 3 通り(+ 各々から導いた探索分野・当たり理由)

### 抽象化 A: 「捻れ共役類 ∩ 反不変超曲面 ≠ ∅」= twisted reality 問題
θ(f) = f⁻¹ という条件は、**捻れ実性(twisted reality)**そのもの。
非捻れ版「g が実 ⟺ ∃t: tgt⁻¹ = g⁻¹」の自己同型捻れ版が文献では
**strongly ι-real / twisted involutions m_σ = |{g : σ(g) = g⁻¹}|** として確立している。
- 導かれる探索分野: **有限群の実性理論(reality / strong reality)** と
  **捻れ Frobenius–Schur 指標**(Kawanaka–Matsuyama, Bump–Ginzburg, Vinroot)。
- 当たり理由: 我々が欲しいのは「集合 S_θ = {f : θ(f)=f⁻¹} が特定の類と交わるか」。
  捻れ FS 指標理論は **S_θ の位数を指標和で計算する道具**を持つ
  (m_σ = Σ_χ ε_σ(χ)χ(1))。位数が正であることを示す ⟹ 存在。
  さらに「類ごとの交わり」は捻れ指標の類関数展開で局所化できる。
  主題(有限単純群・二面体群)は全く違うが、**機構(不動点集合の指標和による数え上げ)は移送可能**。

### 抽象化 B: 「非 coprime 作用での不動点」= Glauberman 補題の代替
解集合 Ω は A が(σ-捻れ共役で)**推移的に**作用する集合で、θ が Ω に作用する
(f ↦ θ(f)⁻¹ が Ω を保つよう仕組める)。求めるのは **θ の Ω 上の不動点**。
これは「N ⋊ J が Ω に作用、N 推移的、J の不動点は?」という Glauberman 補題の型そのもの。
- 導かれる探索分野: **有限群論の非 coprime 不動点定理**(operator group・complement の共役性)。
- 当たり理由: 困難の記述が Glauberman 補題の仮定を一つだけ壊した形なので、
  「その仮定を壊した版」の専門文献が存在するなら直撃。実際 Burkhart 2 本が該当。
  機構: 「各素数 p の Sylow_p(J) が不動点を持てば J が持つ」型の**素数ごとの局所化**。
  我々の J = ⟨θ⟩ は 2 群なので Sylow 条件は自明化しうる — 代わりに N(=A)側の
  可換性/冪零性の仮定が効く(A が 2 群 ⟹ 冪零、条件充足に近い)。

### 抽象化 C: 「Z/3-コサイクルを S₃ に延長する」= 非可換コホモロジーの制限写像
σ²(f)σ(f)f = E⁻¹ は本質的に **⟨σ⟩ ≅ Z/3 係数 A の 1-コサイクル条件**(E 捻れ付き)。
θ(f) = f⁻¹ を追加するのは、そのコサイクルを **⟨σ,θ⟩ ≅ S₃ 全体のコサイクルへ延長**すること。
つまり制限写像 H¹(S₃, A) → H¹(Z/3, A)^{Z/2} の像に入るか、という問題。
- 導かれる探索分野: **非可換群コホモロジーの inflation–restriction 完全列**と
  **Springer/Borovoi の非可換 H² 障害理論**(延長の障害が非可換 H² の中性性)。
- 当たり理由: 「一つの類が対合安定 ⟹ 対合固定点を持つ」は正に
  「H¹(Z/3,A)^{Z/2} の元が H¹(S₃,A) から来るか」であり、差は **H²-中性性**という
  単一の障害に集約される。3 と 2 が分離しているので Z/3 側は自明(Schur–Zassenhaus)、
  障害はすべて Z/2 = θ 側に落ちる — これは困難の障害記述と完全に一致する。

補助角度(司令塔指示分): Nielsen–Reidemeister 系の bi-twisted 共役、Coxeter/代数群の
twisted involution 理論(どの捻れ類が twisted involution と交わるかの分類)。

## 3. 機構ベース評 + 当工房への翻訳可能性 + 深読み時の照合観点

### #1 Burkhart 2308.12286(抽象化 B 直撃)
機構: Glauberman 補題の仮定「(|J|,|N|)=1」を外し、**「各素数 p につき Sylow_p(J) が Ω に
不動点を持てば J 全体が持つ」**に置換。N 可換、または N 冪零かつ N⋊J 超可解が仮定。
翻訳: 我々の N = A(2 群 ⟹ 冪零)、J = ⟨θ⟩(位数 2、Sylow_2 = J 自身)。
Sylow 条件は自明化するので**そのままでは循環**。しかし「J が可解・N が冪零」側の
補題群(論文中の帰納構造)は、A のフラッチニ商 A/Φ(A) へ落として初等可換化する道を与える。
照合観点: 論文の主定理の証明が「N 可換への還元」をどこで行うか。そこが我々の
「A を可換商へ落として θ-反不変元を持ち上げる」帰納法の雛形になるか。

### #2 Burkhart 2211.16616(抽象化 B・補群版)
機構: 可換底の分裂拡大での**補群の共役性を素数ごとに判定**、系として非 coprime の
Glauberman 型不動点定理。捻れ共役類 = 補群の共役類と読み替えるのが要点。
翻訳: 解集合 Ω(単一の σ-捻れ共役類)は A ⋊ ⟨σ⟩ 内の「σ を含む Z/3-補群の集合」と
同一視できる。θ-反不変元の存在 = **θ-不変な補群の存在**。この辞書が成立すれば
本論文の「素数ごとの Sylow 判定」がそのまま十分条件になる。
照合観点: Higman の条件緩和(超可解の仮定をどこで使うか)。A ⋊ S₃ が超可解でない場合の
反例の作り方 — 我々の有限商が該当するかの判別に使える。

### #3 Kawanaka–Matsuyama 1990(抽象化 A の**原器**)
機構: 位数 2 の自己同型 σ に対し捻れ FS 指標 ε_σ(χ) を定義し、
**|{g : σ(g)=g⁻¹}| = Σ_χ ε_σ(χ) χ(1)** を証明。存在問題を**指標和の正値性**に変換。
翻訳: θ が我々の位数 2 自己同型。S_θ = {f : θ(f)=f⁻¹} の位数は指標和で計算可能。
必要なのは「S_θ ∩ (与えられた σ-捻れ類) ≠ ∅」だが、σ-捻れ類の指示関数を
捻れ類関数として展開すれば、交わりの個数も同種の指標和になる(要導出)。
照合観点: 指標和公式の証明が対合の反自己同型性のどこに依存するか。σ(=位数 3)と
θ の相互作用(⟨σ,θ⟩ = S₃)を指標側でどう表すか — Shintani lift の項が鍵になりうる。

### #4 Vinroot 1811.05343(抽象化 A・存在定理の型)
機構: **strongly ι-real**(ι(g)=g⁻¹ を満たす 2 元の積として g が書ける)を定義し、
古典群の大族で「適当な ι を選べば**全元が strongly ι-real**」を示す。
つまり S_ι·S_ι = G という**強い存在定理**の実例集。
翻訳: 我々が欲しいのは S_θ が特定の類と交わること。S_θ·S_θ = A が言えれば
(あるいは S_θ が A の生成系を含めば)、任意の類との交わりに関する強い制約が出る。
2 群での類似(#5 の m_σ 分類・#付録 strongly real special 2-groups)が近場の実験場。
照合観点: ι の**選び方**(どの外部自己同型を取るか)の議論。我々は θ が与えられている
ので、逆に「θ が良い自己同型である条件」を論文の判定条件から抽出する。

### #5 Yerrapati–Dixit–Shukla 2605.22127(抽象化 A・小さい群での明示分類)
機構: m_σ = |{g : σ(g)=g⁻¹}| を位数 p, 2p, p² の群と二面体族で**完全分類**し、
T(G) = Σχ(1) との不等式 T(G) ≥ m_σ を証明。
翻訳: 直接の定理は小さすぎるが、**m_σ の明示計算例**が我々の有限商(2 群)での
数値実験の較正データになる。dihedral 族が主題なのは当工房の dihedral 予想と偶然一致
(機構的一致ではない — 過大評価しないこと)。
照合観点: m_σ = 0 になる σ の特徴づけ(空になる条件 = 我々の反例源)。

### #6 Senden–Tertooy 2603.01679(抽象化 A + Nielsen 系)
機構: **bi-twisted 共役**(2 つの準同型による x ↦ φ(g) x ψ(g)⁻¹ 型)の類数を
既約指標と通常共役類の 2 通りで数える。我々の条件は φ = σ 捻れ、ψ = θ 反転の
**2 自己同型が同時に効く**構造であり、bi-twisted の枠が最も近い定式化。
翻訳: 「σ-捻れ類が θ-反不変元を含む」は、bi-twisted 作用の**軌道が特定の集合に当たる**か
という形に書き直せる可能性が高い。類数公式が正値性判定に直結。
照合観点: 指標による類数公式の導出(Frobenius 型の直交関係の使い方)。
fixed-point free 自己同型との関係節 — 我々の σ が固定点自由な場合の特別扱い。

### #7 Carnovale 1104.0216(抽象化 A の**幾何版・分類の型**)
機構: 「どの θ-捻れ共役類が **twisted involution**(θ(w)=w⁻¹ を満たす元)と交わるか」を
Bruhat セルで完全に特徴づける。**まさに「捻れ類 ∩ 捻れ対合の軌跡」の分類定理**。
翻訳: 舞台は代数群/Weyl 群で有限 2 群ではないが、**問いの形が同型**。
「球型(spherical)」という条件が交わりの十分条件になっている — 我々の設定で
球型に対応する不変量(類の大きさ vs 中心化群の次元 → 有限群では |類| vs |C_A(σ)|)が
何かを探るのが翻訳作業。
照合観点: 十分条件が「類の大きさの上界」の形で書かれているか。有限群版に
落とすときの代替(Bruhat 分解の代わりに A のフィルトレーション/下降中心列)。

### #8 Gagnon-Ririe–Young 2310.03566(抽象化 A の圏化・遠い保険)
機構: twisted Real 表現論の FS 指標を 2 次元非有向 TQFT の crosscap 状態として実現。
「反転を含む対称性(Z/2 グレーディング)」を系統的に扱う枠組み。
翻訳: 直接使う見込みは薄いが、**θ を Z/2-グレーディングとして扱い、σ を係数側に置く**
定式化(π: Ĝ → {±1} の Ĝ に S₃ を取る)が可能なら、指標和の一般化が既製品で手に入る。
照合観点: 一般化 FS 元の定義が非可換係数(捻れ 2-コサイクル θ̂)でどう書かれるか。

## 4. 空振りの当たり(負の結果の申告)

- **抽象化 C(非可換 H¹(S₃, A) の消滅条件)は事実上空振り**。
  非可換 inflation–restriction 完全列と Springer/Borovoi の非可換 H² 障害は
  一般論としては確かに存在する(Grothendieck の非可換 H² 定理・Borovoi の実代数群
  Galois コホモロジー計算)が、検索範囲では **有限係数・S₃ 係数の具体的消滅判定**を
  与える文献に当たらなかった。ヒットは実代数群/数論幾何の文脈に偏り、
  「有限 2 群係数で計算する」型の道具は見つかっていない。
  → 一般論から自前で組む(H¹(Z/3,A) 自明 + Z/2 側の障害の直接計算)方が速い可能性。
  この判断は司令塔に委ねる。
- **同変 Schur–Zassenhaus(operator group での不変補群)**は、教科書レベル
  (crossed homomorphism 経由の証明・京大数理研講究録 1357 に解説)には当たったが、
  **対合同変版の独立した研究論文**は特定できず。#2 の補群共役性が最も近い代替。
- **Fel'shtyn / Gonçalves–Wong 系の「対合安定な Reidemeister 類」**は、
  検索した限り R_∞ 性(類数無限)の研究に集中しており、
  「類が対合で安定 ⟹ 対合固定点を含む」型の定理は見つからなかった。
  代わりに有限群向けの #6(bi-twisted)が同系統で最も使える。
- MathOverflow の該当質問は特定できず(検索経由でヒットなし)。
