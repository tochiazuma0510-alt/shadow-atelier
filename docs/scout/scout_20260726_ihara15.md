**入手経路候補(1 行)**: 大学図書館の LMS Lecture Note Series 200 現物 or ILL(相互貸借)、あるいは Cambridge Core 機関購読。

### 2. Schneps, AWS 2005 notes(★最有力の代替)

- 取得: `papers/delivered/schneps_2005_AWS_GT_notes.pdf`(= docs/scout/papers/schneps_gt_notes.pdf と同一)。SHA-256 = `175d5ffea590b17df7fa53dd4f18caf1d405ea37cb55f4dbd61f0e5d9995b629`。出典 URL: https://swc-math.github.io/notes/files/05SchnepsNotes.pdf(Arizona Winter School 資料サイト)。
- **要旨(3-4 行)**: Grothendieck-Teichmüller 群 GT の標準的な講義ノート。§I.1–I.3 で GQ ↪ GT の構成を Drinfeld/Ihara の仕事として解説し、GQ の作用の第二成分 f を「F̂₂ の交換子部分群(F̂₂'/derived subgroup)」に属する元として導入、続けて GT の 3 関係式(hexagon (I)(II)・pentagon (III))を提示する。
- **接基点+経路 0→1 の逐語(txt 行 412–414、pdftotext 抽出・ハット等の記号は失われるが文意保存)**:
  > "Ihara explained that the geometric meaning of the element f(x, y) is that if p denotes the path from 0 to 1 (taking tangential base points), then σ(p) = p f(x, y)."
  この文の直前(行 410-412)は「GQ acts... on (homotopy classes of) paths on X from one Q-point to another」で、続く議論(行 414–421)は基点 0 から 1/2 への経路 r と写像 ψ(z)=1−z を使って、hexagon 関係式 (I) を f(x,y)=g(y,x)⁻¹g(x,y) の形に幾何学的に導出する — **これは Ihara の元の議論そのものの再現**。
- **f ∈ 交換子部分群の逐語(txt 行 55–56)**:
  > "As for f ∈ F̂₂ [の記法上 F̂₂′], which is the derived subgroup of the profinite completion of the free group F2 on two generators..."
  (pdftotext がプライム記号 ′ を欠落させたため、文面上は F̂₂ = F̂₂′ に読めるが、文脈上「f は F̂₂ の導来部分群 F̂₂′ に属する元」という意味で書かれている。原 PDF の当該行を画像でも確認済み — 数式内のプライム記号は抽出時に落ちるがレイアウトからは明確に微分記号ではなく群論的プライムの位置にある。)
- **なぜスペックの困難に効き得るか(機構ベース)**: この一節は目標文献 Ihara [15] の**核心主張(GQ ↪ GT の構成そのもの)の教科書的再述**であり、(a) 標準接基点(0 から 1 への経路、"taking tangential base points")と (b) f の交換子部分群への所属、の**両方**を同一段落〜近接段落で明示的に述べている。「原著が読めなくても、原著の内容そのものを引き写した信頼できる代替」として機構的に効く — B₃-gentle 系(hexagon のみ)の設定変換に直接使える語彙(m, f, hexagon 関係式 (I)(II)、pentagon (III) との対応)も揃っている。
- **深読み時の照合観点**: (i) 「path from 0 to 1」が本当に Ihara の標準接基点(速度 1・0⃗1 記法)と同一物か、Nakamura LNS 256 (1.1) の一般接基点定義と突き合わせる。(ii) f ∈ F̂₂′ が「定義の要求」か「(1.5)-(1.6) からの帰結」かを、この講義ノートの記述だけで確定できるか(2405.11725 の分析では後者=帰結だった。本ノートの言い回しは定義寄りの語調で書かれている点に注意)。(iii) プライム記号消失の可能性があるため、**原 PDF ページ画像での再確認を強く推奨**(reader による画像照合が必要)。
- **懸念**: 講義ノート(査読なし・簡略化あり)であり、一次資料としての権威は Ihara 原論文に劣る。数式記号の pdftotext 抽出でプライムが欠落する既知の癖があり、機械的 grep だけでの断定は危険(上記の通り画像確認要)。

### 3. Furusho, RIMS 1357 survey

- 取得: `papers/delivered/furusho_RIMS1357_mzv_gt.pdf`。SHA-256 = `bf877ce27fd352913fcbbead4f89ee21f461f0f9976c2e121034ec910005fa96`。出典 URL: https://www.kurims.kyoto-u.ac.jp/preprint/file/RIMS1357.pdf
- **要旨**: MZV と GT 群の pro-ℓ 版サーベイ。§4.1 Lemma 4.1.1 で pro-ℓ 版 GT₁(ℓ) を定義し、条件 (0) として「f ∈ [F₂(ℓ), F₂(ℓ)]」(位相的交換子部分群、Note 4.1.2 で明記)を掲げ、続けて hexagon 型関係式 (i)(ii) と 5-cycle 関係式を提示。引用元は `[Ih91]`(Ihara の 1991 年出版物 = ICM 1990 講演録と推測)。
- **なぜ効き得るか**: 交換子条件の明示は非常にクリーン(条件 (0) として独立に切り出されている)。ただし**接基点の語は本文中に不出現**(grep 0 件)— pro-ℓ 版の代数的記述に終始しており、幾何学的な「経路 0→1」の説明は省略されている。
- **照合観点**: [Ih91] の書誌を確定させれば(おそらく ICM 1990 講演録)、「交換子条件」側の一次引用元が絞れる。
- **懸念**: 基点言及なしのため、スペックの二条件同時充足という点では Schneps ノートより弱い。交換子条件の補強証拠としてのみ有効。

### 8. Deligne(1989)— 系統注意

接基点(tangential base point)という用語・概念そのものの初出級の文献。ただし Deligne 論文自体は「Ihara の f_γ ∈ [F̂₂,F̂₂]」の記法とは独立の体系(Ihara-Anderson の l-進 pro-l 理論とは別に、Deligne はモチーフ的/l 進混合の枠組み)で書かれている可能性があり、**そのまま同一の言明があるとは限らない** — 深読みするなら「接基点概念の起源」としてであって、目標の二条件同時言明の直接証拠としては期待しすぎないこと。取得試行(publications.ias.edu/deligne/paper/407)は 403 Forbidden で失敗。
