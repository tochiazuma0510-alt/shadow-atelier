## 1. 古典 Goursat 補題の定式化

**Thm 2.1 (Goursat's lemma, p.3)** A, B 群、π₁, π₂ 射影、ı₁, ı₂ 包含。
> A×B の部分群 G と五つ組 {Ḡ₁, G₁, Ḡ₂, G₂, θ} の間に全単射対応がある。ここで G₁ ⊴ Ḡ₁ ≤ A, G₂ ⊴ Ḡ₂ ≤ B, θ: Ḡ₁/G₁ →≈ Ḡ₂/G₂ は同型。

対応(p.3): Ḡᵢ = πᵢ(G)(第 i 射影像)、G₁ = ı₁⁻¹(G) = {a ∈ A | (a,e) ∈ G}(同様に G₂)、θ([a]) = [b] where (a,b) ∈ G。逆向きは Γ′₂(Q′) := p⁻¹(G_θ)(G_θ は θ のグラフ ≤ Ḡ₁/G₁ × Ḡ₂/G₂、p は自然射影)。この五つ組を *Goursat quintuple*(Def 2.2, p.3)と呼ぶ。

**Thm 2.3(非対称版, pp.3-4)** [Sch94, Thm 1.6.1] 由来:
> A×B の部分群 G と四つ組 {Ḡ₁, Ḡ₂, G₂, θ₁} の間に全単射対応がある。ここで Ḡ₁ ≤ A, G₂ ⊴ Ḡ₂ ≤ B は任意の部分群、θ₁: Ḡ₁ ↠ Ḡ₂/G₂ は**全射準同型**。

θ₁(a) = [b] for (a,b) ∈ G。Γ₂(Q) := p⁻¹(G_{θ₁})(G_{θ₁} ⊆ Ḡ₁ × (Ḡ₂/G₂) は θ₁ のグラフ)。Ker(θ₁) = G₁(p.4 で明示計算)。同型 θ とは第一同型定理で相互変換。**この非対称版が n 因子への一般化の鍵**(対称版は n≥3 に一般化不能 — §5 Appendix)。

**Remark 2.4 (p.5)** 便利な補足:
- (a) (G₁×G₂) ⊴ G ≤ Ḡ₁×Ḡ₂
- (b) G/(G₁×G₂) ≈ Ḡ₁/G₁ ≈ Ḡ₂/G₂
- (c) |G| = |G₁|·|Ḡ₂| = |G₂|·|Ḡ₁|
- (d) 短完全列 ι₂(G₂) = Ker(π₁|G) ⊴→ G ↠ Ḡ₁(および 1↔2 交換版)

## 2. n 因子直積への一般化(最重要項目)

**Def 3.1 (p.5)** S ⊂ {1,…,n} = n̲, j ∈ n̲∖S に対し
> G(j|S) := {xⱼ ∈ Aⱼ | (x₁,…,xⱼ,…,xₙ) ∈ G for some xᵢ ∈ Aᵢ (i≠j), with xᵢ = e if i ∈ S}

例: G(1|∅) = π₁(G) =: Ḡ₁、G(1|{2,…,n}) = {x₁ | (x₁,e,…,e) ∈ G}。n=2 では Ḡ₁ = G(1|∅)、G₁ = G(1|2) 等。単調性: T ⊆ S ⇒ G(j|S) ⊴ G(j|T)。Πᵢ = 先頭 i 因子への射影。

**Thm 3.2 (Goursat's lemma for n ≥ 2, p.6)**
> G ≤ A₁×⋯×Aₙ の部分群と (3n−2) 個組
> Qₙ(G) := {Ḡ₁, Ḡ₂, G(2|1), θ₁, …, Ḡₙ, G(n|1,…,n−1), θ_{n−1}}
> の間に全単射対応がある。ここで Ḡᵢ ≤ Aᵢ、G(i|1,…,i−1) ⊴ Ḡᵢ、θᵢ: Λᵢ ↠ Ḡ_{i+1}/G(i+1|1,…,i) は全射準同型。Λᵢ ≤ A₁×⋯×Aᵢ は再帰的に定義: Λ₁ := Ḡ₁、
> Λ_{i+1} := Γ₂({Λᵢ, Ḡ_{i+1}, G(i+1|1,…,i), θᵢ}) ≤ (A₁×⋯×Aᵢ)×A_{i+1}
> (Γ₂ は Thm 2.3 のもの。本文は「Theorem 2.2」と誤記)。

証明の要点(p.6): 帰納法で Λᵢ = Πᵢ(G) を示し、θᵢ(x) := [a_{i+1}](x = (a₁,…,aᵢ) を G 内に延長した第 i+1 成分の剰余類)。well-defined 性は (e,…,e,a⁻¹_{i+1}a′_{i+1},…) ∈ G ⇒ a⁻¹_{i+1}a′_{i+1} ∈ G(i+1|1,…,i) から。逆向きは Γₙ(Q) := Λₙ。この (3n−2) 個組を *Goursat decomposition*(Def 3.3, p.6)と呼ぶ。

**Remark 3.4 (p.7)** G ≤ Ḡ₁×⋯×Ḡₙ は成立するが、Remark 2.4 の残り((b)(c)(d) 型の等式)は n≥3 で直接には成立しない。

### 「対ごとの条件」と「全体の条件」の関係(委嘱の最重要点)

**(i) 分類データは対ごとではなく「累積型」**。θᵢ の定義域は Λᵢ = Πᵢ(G)(先頭 i 因子の同時射影)であり、対 (i, i+1) のデータではない。i 段目の正規部分群も G(i+1|1,…,i)(**先頭 i 個すべてを e に固定**)であり、対ごとの G(i+1|j) より小さい。

**(ii) 全体が直積になる判定(§4 冒頭, p.7)**:
> "an immediate consequence of the lemma is that the subgroup G is a sub-direct product if and only if θⱼ is the trivial homomorphism, 1 ≤ j ≤ n−1."

ここで "sub-direct product" は文脈上「部分群の直積 G = Ḡ₁×⋯×Ḡₙ」の意(通常の subdirect product の語義とは異なるので注意)。実際 θⱼ 全自明 ⟺ 各段で G(j+1|1,…,j) = Ḡ_{j+1} ⟺ Λₙ = Ḡ₁×⋯×Ḡₙ。**θ_{n−1} の自明性は G(n|1,…,n−1) = Ḡₙ という累積条件**であり、対ごとの条件 G(n|j) = Ḡₙ (∀j<n) の連言より真に強い(下記 Remark 5.1)。

**(iii) 「対ごとに共通商がない ⇒ 全体が直積」型の定理: 本論文には存在しない**。この形の主張(仮定・結論とも)は全文のどこにも述べられていない。また、この型の主張への**直接の反例も本論文には無い**。関連するのは次の 2 点のみ:

- **§5 Appendix (pp.16-19): 対称型・対ごとデータの不十分性の反例**。n=3 で、12 個の部分群(各 Ḡᵢ ⊵ G(i|j) ⊵ G(i|j,k) の 3 格子)と 6 個の同型 θ, φ, ψ(Ḡᵢ/G(i|j) 間)+ θ̃, φ̃, ψ̃(G(i|k)/G(i|j,k) 間)をすべて一致させながら **V ≠ V′** となる 2 つの 3 次元部分空間 V, V′ ≤ A×B×C(各 dim ≥ 2 のベクトル空間、ℝ でも ℚ でも可)を構成:
  - V = Span{(a₁,b₁,c₁), (a₂,b₂,c₂), (a₁+a₂, b₁+2b₂, c₁+3c₂)} (p.17)
  - V′ = Span{(a₁,b₁,c₁+2c₂), (a₁,b₁−b₂,c₁), (a₁+2a₂,b₁,c₁)} (p.17)
  - 両者の対ごとデータは完全一致(12 部分空間・6 同型、p.17-18 に明示計算)だが、Thm 3.2 の累積データ θ₂: Λ₂ ↠ Ḡ₃/G(3|1,2) が異なる: θ₂(a₁,b₁) = c₁ (V) vs c₁+2c₂ (V′)、G(3|1,2) = 0 ゆえ不定性なし(p.19、画像照合済み)。ℝ⁶ での具体化(Grassmann 多様体 G_{6,3} 内、rank 4 の 4×6 行列で V ≠ V′ を確認、p.19)。
  - **結論: 「対称版 Goursat 補題は n=3 で成立しない」**(p.19)。
  - **注意(読解係)**: この例では対ごとの共通商は**非自明**(θ([a₁]) = [b₁] ≠ 0 等、各対が 1 次元の共通商を持つ)。したがってこれは「対ごとに共通商なし ⇒ 直積」の反例では**ない**。反証しているのは「対ごとの Goursat データが全体を決定する」という別命題である。混同しないこと。

- **Remark 5.1 (p.19、画像照合済み)**: 対称版の失敗の根源は
  > "the trouble stems from the fact that G(1|2,3) is not necessarily equal to the intersection of G(1|2) and G(1|3), and similarly for G(2|1,3) and G(2|1,3) [原文ママ — 後者は G(3|1,2) の誤植と思われる]. It seems very likely that a symmetric version of Goursat's lemma is available with this additional hypothesis."

  すなわち **G(1|2,3) = G(1|2) ∩ G(1|3)(等)を追加仮定すれば対称版が回復するだろう**、というのは著者の**予想(未証明)**。証明は無い。

**(iv) 読解係による補足(導出値・周知事実 — 本論文には無い)**: 「各対の射影が全射(= 対ごとの Goursat 商が自明)⇒ G = 全直積」は一般には**偽**。周知の反例: G = {(x,y,z) ∈ (ℤ/p)³ | x+y+z = 0}。任意の対への射影は全射(Π₁₂(G) = (ℤ/p)²、かつ G(2|1) = ℤ/p = Ḡ₂ なので対ごとの共通商は自明)だが G ≠ (ℤ/p)³。実際 G(3|1,2) = 0 ≠ ℤ/p = G(3|1) ∩ G(3|2) で、まさに Remark 5.1 のギャップが実現している。Thm 3.2 の言葉では、直積性の唯一の障害は **θ₂: Λ₂ ↠ Ḡ₃/G(3|1,2) の非自明性 = 「Λ₂ = Π₂(G) と Ḡ₃ が共有する非自明な共通商 Ḡ₃/G(3|1,2) の存在」**である(Ḡ₃/G(3|1,2) は定義により Λ₂ の商かつ Ḡ₃ の商)。ゆえに 3 因子補題を正当化するには「**Λ₂ と G₃ に非自明な共通商が無い**」を保証する仮定が要る。ここで Λ₂ は Ḡ₁×Ḡ₂ の部分群にすぎず、有限群の部分群の組成因子は全体の組成因子に含まれるとは限らない(例: F₂₀ ≤ S₅ は C₅ を組成因子に持つ)ため、「Ḡ₁, Ḡ₂ 各々と Ḡ₃ の対ごとの共通商なし」から機械的には従わない — ただし Λ₂ の**商**(部分群ではない)の組成因子は Λ₂ の組成因子に含まれ、Λ₂ ≤ Ḡ₁×Ḡ₂ の組成因子は… という細部は当工房の監査対象なのでここでは踏み込まない(本論文はこの問いに答えを与えない)。共通商型の議論の文献としては本論文は Ribet [Rib76] を §1 で挙げるのみ。

## 3. 副有限群(profinite)版

v3 で拡充された応用(独立の章ではなく **§4 内の一項目**)。前提設定(p.8): A, B が profinite、A×B に積位相、G ≤ A×B に部分空間位相。Ḡᵢ には πᵢ: G ↠ Ḡᵢ による**等化位相(identification/quotient topology)**、G₁ ⊴ Ḡ₁ には部分空間位相を入れる。

**Prop 4.2 (p.8、画像照合済み)**
> Let A, B be profinite groups and G ≤ A×B as above. Then G is a profinite group **iff** each of the subgroups in the Goursat decomposition for G are profinite groups **and θ₁ is continuous**.

証明の骨子(pp.8-9): (⇒) ({e}×B) ∩ G は閉部分群ゆえ profinite、π₂ はコンパクト→Hausdorff の連続全単射準同型ゆえ位相同型で G₂ が profinite。Remark 2.4(d) から Ḡᵢ も profinite。G_{θ₁} = (id×p)(G) はコンパクト像ゆえ閉、**閉グラフ定理**で θ₁ 連続。(⇐) θ₁ 連続 ⇒ グラフ閉 ⇒ G = q⁻¹(G_{θ₁}) は profinite 群 Ḡ₁×Ḡ₂ の閉部分群ゆえ profinite。

- **逆極限との両立**: 論文は profinite の特徴づけとして「有限群の逆極限(離散位相)」=「コンパクト・Hausdorff・完全不連結な位相群」を使う(p.8)のみで、**逆極限系との明示的な両立条件(例: 各有限商レベルでの Goursat 分解と極限の可換性)は述べていない**。両立は「閉部分群・閉正規部分群による商・任意直積で閉じる」という一般論経由。UNKNOWN: 逆極限表示レベルの明示的整合性命題は本論文に無い。
- **n 因子版**: 「Proposition 4.2 は 2 個より多い因子の有限直積の部分群にも明白な仕方で一般化される」(p.9)と**主張のみ・証明なし・明示定式化なし**。各 θᵢ の連続性を要求する形になると推測される(推測)。
- 関連: [Gre09, Lemma 4.6](Greicius, adelic Galois 表現)と近い関係にあるが**どちらも他方を含意しない**(p.9)。

## 4. Sylow p-部分群への応用(概要)

任意の群の Sylow p-部分群 = 極大 p-部分群(Zorn)。鍵となる有限性仮定は **virtual p-group**(有限指数の p-部分群を持つ群)。virtual p-group ⇒ FC_p(有限個の共役をもつ Sylow p-部分群の存在。FC_p 定理 [DKU38][Baer40] で通常の Sylow 定理群が回復)(pp.12-13)。

- **Prop 4.6 (p.13)**: G virtual p-group, M ≤ G p-部分群のとき、M が Sylow ⟺ [G:M] が p と素。
- **Lemma 4.7 (p.14)**: π: G ↠ H, M ≤ G, K = Ker π, K₁ = Ker π|_M, H₁ = π(M) のとき [G:M] = [H:H₁]·[K:K₁](濃度としても成立)。
- **Cor 4.8 (p.14)**: virtual p-group の正規部分群・商群は virtual p-group。
- **Thm 4.9 (p.15、画像照合済み)**: G ≤ A×B virtual p-group。(a) M が G の Sylow p-部分群 ⇒ M̄ᵢ は Ḡᵢ の、Mᵢ は Gᵢ の Sylow p-部分群。(b) 逆に N ≤ G の Goursat quintuple (N̄₁,N₁,N̄₂,N₂,θ_N) で N̄ᵢ が Ḡᵢ の、Nᵢ が Gᵢ の Sylow p-部分群なら、N は G の Sylow p-部分群。
- **Thm 4.10 (pp.15-16、画像照合済み)**: n 因子版(証明なしで言明)。(a) M Sylow ⇒ M̄ᵢ が Ḡᵢ の、M(i|1,…,i−1) が G(i|1,…,i−1) の Sylow p-部分群 (2 ≤ i ≤ n)。(b) 逆も同様。※原文は N の組を "(2n-3)-tuple" と書くが列挙されているのは 3n−2 個(Thm 3.2 と同型式)であり誤植と思われる。
- **Remark 4.11 (p.16)**: (a) FC_p 仮定だけでは Thms 4.9/4.10 は**成立しない**(原文の「4.8, 4.9」は改番ずれ)。反例: G = ⟨(1,1)⟩ ≤ ℤ×ℤ₃, p=3。Sylow 3-部分群 M = {0} ゆえ M̄₁ = {0} だが Ḡ₁ = ℤ₃ の Sylow 3-部分群は ℤ₃。(b) 未解決問: virtual p-group の任意の部分群は virtual p-group か?

### 実務上の示唆(推測を含む)

1. **即時に使えるもの**: Thm 3.2 の分解データ 7 成分 {Ḡ₁, Ḡ₂, G(2|1), θ₁, Ḡ₃, G(3|1,2), θ₂} は有限群では GAP で直接計算でき、PB₃/J の像の**一意な証明書(certificate)**になる。特に G(3|1,2)(= 第 1,2 成分を e に固定した第 3 成分の芯)と θ₂ の非自明性が「像が直積からどれだけずれるか」の完全な不変量。指数は Remark 2.4(b) の反復で |Ḡ₁×Ḡ₂×Ḡ₃ : G| = |Ḡ₂/G(2|1)|·|Ḡ₃/G(3|1,2)|(導出値: Thm 3.2 の Λ 構成から |G| = |Ḡ₁|·|G(2|1)|·|G(3|1,2)|)。
2. **工房の 3 因子補題(対ごと ⇒ 全体)は本論文では正当化も反証もされない**。監査は続行が必要。補題を修正するなら「対ごとに共通商なし」を「**Π₂(G) と Ḡ₃ に共通商なし(および置換対称に)**」へ強めるのが Thm 3.2 から見て自然(推測)。あるいは Remark 5.1 の予想線(G(3|1) ∩ G(3|2) = G(3|1,2) の直接検証)を有限群で計算確認する手もある — こちらは GAP で機械検査可能な述語。
3. §5 Appendix の V ≠ V′ 例は「対ごとデータだけで像を同定した」と主張する任意の議論への**標準的な反例テンプレート**(ベクトル空間 = アーベル群の例なので忘却関手で群の圏でも有効、p.17)。工房の falsifier の adversarial 例として登録する価値あり。
