## 0. 困難スペックの要約

有限群 Q(Δ(2,3,2k) の商・特に PSL(2,q))で、指定元 v の分解 v = rq(r³=1, q²=1)の解集合
Σ_v = {(r,q) : rq = v, r³=q²=1} と、その上の C_Q(v)-共役作用(工房での観測: Σ_v が C₅-torsor)。

## 1. 困難の抽象化(3 通り)+ 当たり付けの理由

### 抽象化 A: 「指定元のファイバー上で中心化群が単純推移的に働く」= **rigidity(剛性)そのもの**
Σ = {(g₁,g₂,g₃) ∈ C₁×C₂×C₃ : g₁g₂g₃ = 1} への G-共役作用が単純推移的、というのが逆ガロア理論の
**rigid triple** の定義。第三成分 v を固定して見ると作用群は C_Q(v) に落ち、
「Σ_v が C_Q(v)-torsor」= **v を固定した相対剛性**と一字一句同じ機構。
工房の C₅-torsor は「剛性の定量版」であり、剛性理論には
(i) Frobenius 公式による |Σ| の計算、(ii) 作用の自由性(∩ 中心化群 = Z(G))、(iii) 軌道数 = 被覆の連結成分、
という**完成した三点セット**がある。→ 探索分野: **逆ガロア理論の剛性法・Hurwitz 空間・braid 軌道**。

### 抽象化 B: 「q²=r³=1 の対 = trefoil 群 ⟨a,b|a²=b³⟩ = B₃ の表現」= **結び目群/生成対の Nielsen 類**
v=rq は Hom(B₃/⟨c⟩, Q) のデータ。B₃ = トーラス結び目 3₁ の群。
したがって Σ_v の構造は「トーラス結び目群の有限群表現の数え上げと、その表現空間への
Nielsen/Vieta 変換の作用」と同型な問題。ここで **PSL(2,q) の生成対の Nielsen 同値類は
トレース不変量で完全分類**されており(Macbeath 系譜)、
「解集合が 1 軌道(=torsor)か複数軌道か」を**トレースで判定する既製の道具**が存在する。
→ 探索分野: **Nielsen 同値・Markoff/Vieta 力学系・SL₂ 指標多様体**。

### 抽象化 C: 「(2,3,∞) 生成データの分類」= **modular 群の有限指数部分群のカタログ化**
PSL(2,ℤ)=C₂*C₃ の有限指数部分群 ↔ (2,3)-置換対 ↔ 三価リボングラフ ↔ dessin。
v が指定されるとは dessin の「第三の巡回型」を固定すること = **passport 固定**。
Millington/Stothers の specification、Kulkarni の Farey symbol、Stallings グラフ統計が
この宇宙の**既存の全数カタログ技術**。→ 探索分野: **modular 群の部分群列挙・dessins の cartography**。

(+ 司令塔提示の当たり: Frobenius/Hurwitz 数・subgroup growth・Fried の Nielsen classes は上の A/C に吸収)

## 3. 機構ベース評 + 当工房設定(B₃-gentle: hexagon のみ・c 中心・NFI_PB₃(B₃)・有限商)への翻訳可能性

**C1 Dèbes 概説(A)** — 剛性 → Hurwitz 空間 → 成分環 → modular tower までを 26 頁で通す最新の地図。
機構: 「三つ組の集合への共役作用の軌道 = 被覆族の連結成分」という辞書が全編の背骨。
翻訳: 我々の Σ_v は r=3 点分岐データの v-ファイバー。C_Q(v)-torsor 性は「対応する Hurwitz 空間の
ファイバーが 1 点(rigid)」の言い換えになるはずで、**torsor 観測に既存の名前を与える最短路**。
c(中心)の扱いは B₃ → PSL(2,ℤ) の中心商であり、Hurwitz 側の「中心による捻り」に対応させられる。
照合観点: 剛性の定義における「∩C(gᵢ) = Z(G)」条件と、我々の C₅ が Z の役をしていないかの確認。

**C2 Chen (Annals 2024)(A,B)** — 最重要候補。機構: **生成対の Nielsen 同値類の濃度に対する合同式**を
Hurwitz 空間の次数の合同から導き、それで「解集合への群作用が推移的」を証明する。
つまり「**解集合の軌道構造を、被覆の次数計算から決める**」という、我々が Σ_v にほしい論法の完成形。
翻訳: Markoff 方程式 = SL₂(F_p) の生成対のトレース座標。我々は (2,3) 型なので座標は
(tr r, tr q, tr v) と縮退するが、Vieta 対合 ↔ Nielsen 移動 ↔ **braid 作用**の三重辞書はそのまま使える。
θ/τ 対称性が Vieta 対合の役を果たすか、が照合の第一点。

**C3 Chen 概説 (2025)(B,C)** — 非合同 modular 曲線 = 楕円曲線の被覆の Hurwitz 空間、という辞書の教科書的整理。
機構: 「modular tower の各層 = 有限群 G の生成対データ」。我々の K⁽ⁿ⁾ 塔(2405.11725)と
構造的に同型な塔が扱われている可能性が高い。翻訳: 我々の「有限商の塔を昇る」を
被覆の塔として読み替える辞書の供給源。**C2 を読む前の入口として費用対効果が高い**。

**C4 McCullough–Wanderley(B)** — 機構: PSL(2,q)/SL(2,q) の生成対の Nielsen 同値類を
**Higman 不変量 + 交換子トレース**で分類。これは「解集合の軌道を、群の元から計算できる不変量で切る」道具。
翻訳: 我々の Σ_v の軌道分離不変量の候補が直ちに得られる(v のトレース・r,q のトレースは固定なので、
分離は交換子トレース [r,q] = r q r⁻¹ q⁻¹ のトレース側に落ちる)。**C₅-torsor が「1 軌道」である理由の
不変量的説明**が期待できる。注: 論文の主要主張の一部は予想の形で、C2/2508.21671 が部分解決。

**C5 MapClass / braid orbit(A)** — 機構: 与えられた有限群 G と型に対し、**Nielsen 三つ組の braid 軌道を
実際に計算する GAP パッケージ**。長さ 3 の三つ組では二重剰余類経由で軌道を決定する(=まさに我々の (r,q,v⁻¹))。
翻訳: 当工房の GAP 探索器に**そのまま接続できる唯一の即戦力**。Σ_v の軌道計算を独立実装で再現でき、
照合器(node/python)との二系統一致の第三系統になりうる。事前登録した宇宙(位数・生成系)に直結。

**C6 Liebeck–Shalev(A)** — 機構: Hom(Δ, G) の個数を Frobenius 型の指標和 Σ_χ χ(x)χ(y)χ(z)/χ(1) の
**評価技術**(指標比・Witten ζ)で漸近的に押さえる。翻訳: 我々が欲しいのは |Σ_v| の**厳密値**だが、
この系統は「主項 = |G|^{μ+1}、誤差 = 指標比」という分解を与えるので、
torsor 性(|Σ_v| = |C_Q(v)|)が**どれだけ例外的な現象か**を定量化する背景として使える。
即戦力ではなく「観測の希少性の格付け」用。

**C7 Bassino–Nicaud–Weil(C)** — 機構: PSL(2,ℤ) の部分群を Stallings グラフで符号化し、
**サイズ n の部分群を一様ランダム生成するアルゴリズム**と漸近統計を与える。
翻訳: 我々の atlas 構築で「有限商の候補宇宙をどう全数化/標本化するか」の既製手法。
Millington/Stothers の specification(= 楕円点・カスプの分布)は v の共役類データに対応するので、
「不可能な specification」の理論は**空の Σ_v の存在(=UNKNOWN でなく非存在)を先に切る**のに使える。

**C8 Clark–Voight / Duque-Rosero–Voight(C)** — 機構: 三角群の**合同部分群**を定義し、
PSL(2,q)/PGL(2,q) を正則にガロア群として実現、対応する曲線を (2,3,n) Belyi 写像として列挙。
翻訳: 「(q,r,v) 三つ組 = dessin」という辞書の**最も直接的な既存実装**であり、
Δ(2,3,2k) → PSL(2,q) の商が実際にどう分類されているかの一次資料。
低種数の全列挙表は、我々の atlas の**外部較正データ**(既知例の positive control)候補。

## 5. 空振りの当たり(負の結果)と使用クエリ

**空振り 1: 「Frobenius 公式の作用付き精密化」を主題とする独立文献**
クエリ: `number of ways to write group element as product of involution and element of order three character formula conjugacy class centralizer orbits`
→ 出たのは類代数の標準公式(α_{C,k} の指標和)と 3-transposition 群の周辺のみ。
**「解集合への中心化群作用の軌道分類」を主題化した独立文献は見つからなかった** —
この機構は独立分野を形成しておらず、**剛性(A)と Nielsen 同値(B)に吸収されている**、というのが本遠征の結論。
これは負の結果として一級: 「Frobenius を超える構造論」は既存名では *rigidity* と *Nielsen class* の二語で呼ばれている。

**空振り 2: トーラス結び目群の有限群表現の数え上げ**

**共役類の個数**を数えるのみで、我々が欲しい「指定元 v のファイバー上の作用構造」を扱っていない。
かつ書誌の一次確認をしていないため候補表に載せない(要すれば再遠征)。

**空振り 3: dessins 側の一般 cartography(Zvonkin 系)**

→ Adrianov–Pakovich–Zvonkin(重み付き木・Davenport–Zannier)、Jones–Zvonkin 等が出るが、
主題が「個々の dessin の Galois 不変量」であり、**(2,3,2k) の商の族としての構造**には届かない。
この方角は C8(Voight 系)の方が我々の設定に近い、と判定。
