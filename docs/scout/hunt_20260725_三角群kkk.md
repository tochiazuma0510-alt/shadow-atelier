# 遠征報告 hunt_20260725 — 対称的 (k,k,k) 生成と 3 | |[P,P]|

- 日付: 2026-07-25 / 担当: 論文遠征係(文献ゲート①)
- 困難スペック: P = ⟨X,Y⟩ 有限、ord X = ord Y = ord Z = k(Z = (XY)⁻¹)、θ:X↔Y と τ:X→Y→Z→X が Aut(P) に延びる。**3 ∤ k かつ 3 | |[P,P]| は起こるか**。
- **結論(採否判断ではなく事実報告)**: 存在側。最小例 **P = A₅, k = 5**(下記 §4 の GAP 実測)。文献側も無限系列を保証する定理が複数ある。

---

## 1. 困難の抽象化 3 通り(当たり付け)

### 抽象化 A — 「S₃ 対称な三つ組生成」=**有向正則ハイパーマップの外部対称性**
XYZ = 1・三位数が等しい生成三つ組は、定義上 **type (k,k,k) の orientably regular hypermap**(monodromy 群 P)。生成子の S₃ 置換が Aut(P) に延びる、とは hypermap 操作群 Σ ≅ S₃(hypervertex/hyperedge/hyperface の交換 = 双対性・triality)で不変ということ、すなわち **totally self-dual**(+ θ が付くと reflexible 寄り)。
→ 探索分野: **位相的組合せ論 / dessins d'enfants / regular maps**(Conder・Širáň・Jones・Breda d'Azevedo 系)。

### 抽象化 B — 「指数 6 の正規包」= **Δ(k,k,k) ◁ Δ(2,3,2k)**
Fuchsian 測度 μ(p,q,r) = 1 − (1/p+1/q+1/r) を比べると μ(k,k,k)/μ(3,3,k) = 3、μ(3,3,k)/μ(2,3,2k) = 2。よって
**Δ(k,k,k) ◁ Δ(3,3,k) ◁ Δ(2,3,2k)、指数 3・2・合計 6、商は S₃**。
S₃ 対称な (k,k,k) 商とは、**Δ(2,3,2k) の有限商 G で、Δ(k,k,k) の像 P が指数 6 のもの**にほかならない。3 | |P| ⟺ 9 | |G|。
→ 探索分野: **三角群の有限商の存在論**(MacBeath・Marion・Jones–Mačaj–Širáň)。

### 抽象化 C — 「導来部分群の素因子を生成元位数で押さえる」= **アーベル化の計算に潰れる**
Δ(k,k,k)^ab = (Z/k)²。よって P^ab は (Z/k)² の商 ⇒ 3 ∤ k なら 3 ∤ |P^ab| ⇒
**3 | |[P,P]| ⟺ 3 | |P|**。
問いは「3 ∤ k の対称 (k,k,k) 商で位数が 3 で割れるものはあるか」に完全に還元する。したがって(b)型の「押さえる定理」は**存在しえない**(押さえられるのは P^ab だけ)。
→ 探索分野: **有限単純群の三角生成 / 確率論的群論**(Liebeck–Shalev・Everitt・Beauville 構造)。

## 3. 機構の翻訳(当工房 B₃-gentle 設定への持ち込み)

**(i) 抽象化 B は B₃ に直結する。** PSL(2,Z) = Δ(2,3,∞) であり B₃ ↠ PSL(2,Z)(核 = 中心 ⟨c⟩)。Δ(2,3,2k) は PSL(2,Z) の商。よって
> S₃ 対称な (k,k,k) 群 P は、**c が死ぬ B₃ の有限商 G の指数 6 部分群**として現れる。
当工房の「c 中心・有限商・NFI」の枠組みと同じ土俵であり、θ・τ は **G/P ≅ S₃ の共役作用**として自動供給される(外から貼るのではなく、塔の中に既にある)。これは fake 狩場を「B₃ の (2,3,2k) 型有限商の族」として事前登録できることを意味する。

**(ii) 対称化は core を取るだけで済む(soft 構成)。** Δ = Δ(k,k,k) ◁ Δ̂ = Δ(2,3,2k)。任意の有限商 Δ ↠ Q(核 K)に対し N := ∩_{g∈Δ̂} K^g は Δ̂-正規かつ Δ 内で有限指数。P := Δ/N は**自動的に S₃ 対称**で、Q を商に持つ。ゆえに「3 | |Q| なる (k,k,k) 商が一つでもあれば、対称版 P も存在する」。#7/#8 と組めば存在は即決。

**(iii) hexagon-only / pentagon-なしとの相性。** (k,k,k) の S₃ は pentagon 由来ではなく **hexagon 的な三重対称**(x,y,z の巡回)である。当工房の GT-shadow が hexagon のみを課す構造と、Δ(k,k,k) ⊂ Δ(3,3,k) の τ(位数 3)は同じ形の対称性を要求する — 翻訳時は τ を「三本の分岐点の巡回」として読むのが自然。

## 4. 実測(遠征係による裏取り・GAP 4.16.0)

スペックの θ・τ を**文字通り**符号化して探索した(θ: X^a = Y ∧ Y^a = X、τ: X^a = Y ∧ Y^a = Z、いずれも a ∈ Aut(P))。

- **P = A₅, k = 5**: 存在。3 ∤ 5、[A₅,A₅] = A₅ の位数 60、**3 | |[P,P]|**。位数 < 60 の全群(3 | |[G,G]| なるもの)を悉皆走査して該当なし ⇒ **これが最小例**。
- **P = PSL(2,8), k = 7**: 存在。|P| = 504 = 2³·3²·7、完全群なので [P,P] = P、**3 | |[P,P]|**。#3 の等 trace 機構の実例。

走査スクリプト(scratchpad, 恒久化はしていない): 位数 3..120 の SmallGroups を、3 | |[G,G]| かつ 3 ∤ k で篩い、Aut(G) 全体を走査。ヒット `order=60 id=5 k=5`。
**注意**: 二系統照合ではないので「照合済み」ですらない — 司令塔が implementer に独立再現させる前提の**一次観測**として扱われたい。

## 5. 深読み時の照合観点

1. **θ の向き**(最重要): 文献の hypermap 対称性はしばしば x ↦ y⁻¹ 型(reflexible = 向き反転)を混ぜる。スペックの θ は x ↦ y(向き保存)である。#4/#5/#6 を読む際は **Σ ≅ S₃(操作群)と反射(位数 2 の外側)を分離**して読むこと。§4 の実測はスペック通りの θ で取っているので、文献側との突合の基準に使える。
2. **#1 (2508.10434) は非有向**の hypermap である点。有向版(orientably regular)への移送で type が保存されるか、本文の Prop を確認。
3. **#8 は種数 ≥ 2 の Fuchsian 群**が仮定に入る版が流通している。種数 0 の三角群 Δ(k,k,k) が主定理の適用範囲かを Theorem 1.x の仮定で必ず確認(表で PARTIAL とした理由)。
4. **#3 は DOI 未取得**。引用するなら Proc. Sympos. Pure Math. XII の実物か、#2/#4 経由の二次引用に置き換えること。
