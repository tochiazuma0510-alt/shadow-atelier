## A. 一般化 Goursat 補題(arXiv 1109.0024, Bauer–Sen–Zvengrowski)

**使える機構**:
1. **n 因子の分類は累積型**(Thm 3.2): 部分直積 G ≤ G₁×…×Gₙ は (3n−2) 個データで分類。第 i 障害 θᵢ は「先頭 i 因子の**結合像** vs 第 i+1 因子」に住む(対ごとではない)。直積判定 = 全 θ 自明。
2. **副有限版**(Prop 4.2・2 因子): profinite ⟺ 各群 profinite+θ 連続(閉グラフ定理)。n 因子版は言明のみで文献上未展開。
3. 「対ごと共通商なし ⇒ 全体直積」型の**定理も反例も文献に無い**(§5 反例は対ごと共通商が非自明な別命題向け・Remark 5.1 の対称版は未証明予想)。

**翻訳(工房への適用形)**:
- J の 3 因子補題は監査確定後、「θ₂ の障害 = (G₁×G₂ の結合像) と G₃ の共通商」+「非自明共通商 ⇒ 単純共通商 ⇒ 片側因子を経由」の還元補題、という 2 段の形に書き直すと文献整合的で n 因子拡張が自動化する。
- 将来の多重交わり M = K ∩ N₁ ∩ … ∩ N_k の宇宙事前登録書式に累積型データ(結合像の列)を採用。
- genuine 判定で逆極限を昇る際、θ の連続性が閉グラフで無料に付く — Lean 化の証明義務が 1 個減る見込み。

**引用注意**: v3 は本文の相互参照が定理番号と 1 ずれ(読解ノートの対応表参照)。頁+主張文で引用のこと。

## B. Guillot GT(G)(arXiv 1407.3112 v3 / 1604.04415)

**系統の札(引用時必須・3 軸)**: (a) pentagon **無** — hexagon 階層・逆極限は Drinfeld の ĜT₀。(b) **outer 変種** — λ 座標も (m,f) データも無し(k は well-defined ですらない)。(c) 塔は **F₂ の G-完備化 N_G** — PB₃/B₃ ではなく、**中心 c が存在しない**。⇒ 主線(gentle GTSh)とも副線(B₄ 本来系)とも別の**第三変種**。同名 GT₁ の混同はこの 3 軸で防ぐ。

**使える数学**:
1. **fake の文献先例**(1407 Prop 3.1+§3 末尾): 粗い dihedral 塔では GT₁(D_n)(n 奇)の位数 2 元が D₄ₙ への持ち上げで全滅(lim = 1)。(i) **fake 検出 = より細かい宇宙への持ち上げテスト**という当工房設計の独立な先行例。(ii) **fake は塔相対的** — 同じ dihedral 世界でも、粗塔(N_G)は fake だらけ・うちの K⁽ⁿ⁾ 塔は 2 冪で全射証明済み。atlas の解釈節に「塔相対性」の注を追加すべき。
2. **単純因子 menu 定理**(1407 Thm 1.2): G 単純非可換 ⇒ GT₁(G) の単純因子は C₂ / C₃ / Out(G) の部分商 / A_s(s ≤ m²/|G|)に限る。Q1(非可換 P)設計の sanity 束縛に流用の余地 — ただし**枠組が別物ゆえ直接適用不可**(比較写像の確立が前提)。
3. **λ 成分の算術全実現**(1407 Lemma 2.3): 任意の許容 k が Galois 元で実現され、しかも「Galois に訴えない証明は知られていない」と著者明記 — 全射性の難所がどの成分に住むかの示唆。
4. **比較写像の予想**(読解者発案・推測=未証明): PB₃ ≅ F₂ × Z(c) ゆえ、c を先に殺す商に限れば Guillot 塔は主線塔の「c-自由断面」。自然な写像 GTSh(N) → GT(G) の構成+核・余核の定量は新規性のある小課題候補。**c 生存系(M₅・円分 C₄ 繊維)の情報は彼の塔から原理的に見えない** — 工房の差別化点の定量化にもなる。

**使える計算技法(実装レーン行き)**:
5. **両側剰余類パラメータ化+θ 前段フィルタ**(1407 Lemma 5.1: f 候補 ∈ C_x\Ḡ/C_y・条件 1 ∈ C_x f θ(f) C_y^{θ(f)}): WP2 の f 列挙の枝刈りへ直訳候補。
6. **packet 法**(centralizer ∩ Young を軌道不変量でブロック化して分割統治): GAP の中心化群爆発の標準回避策。
7. **計算済み表**(PSL(2,q) 全系列・PSL₃(F₃)・A₇・M₁₁): 比較写像確立**後**に第三者 fixture 候補。**それまで較正には使わない**(対象が別物 — 答えの錨づけ禁止)。
