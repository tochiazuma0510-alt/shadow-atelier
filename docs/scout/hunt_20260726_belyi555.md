## 1. 困難の抽象化(当たり付けと理由)

司令塔スペックの困難を、分野非依存の機構語に 4 通り翻訳した(要請 3 通り+1)。

### A1. 「境界での局所座標の n 乗根が作る Galois 加群」
機構語: *base point at infinity における inertia の分裂と、そのスケール自由度が μ_n-torsor を生む*。
局所パラメータ t を u·t にスケールし直すと、t^{1/n} は u^{1/n} 倍だけずれる。u^{1/n} 上の Galois 作用 = **u の Kummer コサイクル**。すなわち「主係数 u の n 冪剰余類が torsor 類を決める」は Kummer 理論のトートロジーであり、非自明なのは *それを π₁ の基点として正当化する枠組み* のほう。
→ 探索分野: **副有限/モチーフ的 π₁ の接基点理論**(Deligne §15・Anderson–Ihara の Puiseux 実現・Nakamura)、および最近の **log 幾何による接基点の再定式化**。
→ 当工房への含意: B₃-gentle 系の c(中心)は inertia 生成元の像であり、hexagon 側の「c 中心」条件は接基点のスケール自由度が torsor を生む構造と**同型の位置**にある。要請 9 の定理型は「基点の取り替え = Kummer クラス」という形で必ず現れる。

### A2. 「Out 層で解けている問題を Inn 層へ持ち上げる障害」
機構語: *中心拡大 1 → Z(G) → Aut(G) → Out(G)-像 に沿った持ち上げ障害 = 非可換 H²/gerbe*。
rigidity/Hurwitz 論法は「被覆が同型を除いて一意」= **Out 層(mere cover)**の主張しか出さない。rigidification(= 具体的な同型・基点・標識)を降下させるには別の障害が要る。
→ 探索分野: **field of moduli vs field of definition の gerbe 理論**(Dèbes–Douai)、代数スタックの剛性化。
→ **射程限界の正確な位置(遠征係の主観測)**: Dèbes–Douai の障害は H²(K, Z(G)) に値をとる。本件は G = A₅ で **Z(A₅) = 1** だから、その障害は**自動消滅**する。したがって要請 11 の「rigidity は Inn 層の torsor に届かない」は、Dèbes–Douai 型の中心障害が消えたあとに**なお残る別種の障害**(= 慣性/接基点由来の μ₅-torsor、A1)を指していることになる。この「二層の障害の分離」は司令塔が翻訳するとき最も効く観点だと思われる。

### A3. 「三点分岐被覆の一意性 = Hurwitz 空間の ℚ 有理点が 1 個」
機構語: *モジュライ空間の孤立点上の算術構造*。passport が 1 点なら Hurwitz 空間 H(A₅; 5A,5B,…) は ℚ 上の 1 点で、field of moduli = ℚ。だが「点が ℚ 有理」と「その点上の対象が ℚ 上 rigidify できる」は別問題(= A2 の言い換え)。
→ 探索分野: **Hurwitz 空間の接基点構成**(Nielsen 類 g に付随する coalescing tangential base point v(g))。A1 と A3 を**同じ論文が繋いでいる**(候補 5・Example 4)。これが本遠征の最大の収穫かもしれない。

### A4. 「明示式の計算」= 三点分岐被覆の数値解析/Groebner
→ 探索分野: **計算数論の Belyi 写像データベース**(Voight 系)+ 独立系列(Adrianov–Shabat の露系計算)。二系統照合の材料が揃う。

### 候補 5: Nakamura, *Tangential base points and Eisenstein power series* ★(要請 9 と 11 を繋ぐ)
PDF 実取得済み(`http://www4.math.sci.osaka-u.ac.jp/~nakamura/zoo/crocodile/eisen99.pdf`)。本文から確認できた要点:
- **(1.1) Definition**: k-有理接基点 = 射 `v : Spec k((t)) → X`。Anderson–Ihara に従い Puiseux 体 Ω = k̄{{t}}(t^{1/n} を含む)を固定し、G_k が **Puiseux 係数への作用**でファイバー関手に作用 → 分裂 `s_v : G_k → π₁(X, v)`。
- **主係数依存性が明記されている**: 標準接基点 `01`(X = P¹−{0,1,∞}, Q(t) ↪ Q((t)))について「**t の正規化(例: スケール)を変えると、表される接ベクトルは 01 と異なる**」("If we change normalization (e.g., scale) of t ∈ Q((t)) relative to the standard coordinate t of P¹, the represented vector will differ from 01")。**接ベクトル = 向き + 速さ**("direction + speed")という言い方で、まさに主係数の自由度を明示している。
- **§I Example 4**: モジュライ多様体上の接基点構成。**Nielsen 類 g ∈ Ni(G,C) に付随して Hurwitz モジュライ空間 H(G; C₁,…,C_r) 上に "coalescing tangential base point" v(g) を作る**方法(退化した admissible cover Y_s を P¹ の線形鎖 P 上に組み、smoothing する)。逆 Galois 問題の文脈で言及。
**機構評**: 要請 9(接基点上の μ₅-torsor)と要請 11(rigidity/Hurwitz の射程)を **同じ枠組みの中で** 扱っている唯一の候補。「Hurwitz 空間の点が ℚ 有理」だけでなく「その点に ℚ-有理な**接基点**を与えられるか」が Inn 層の rigidification に対応する、という読み替えが可能。
**翻訳可能性(B₃-gentle 系へ)**: Example 3 が **Artin 組紐群 B̂_n への Galois 作用** を接基点 v: t ↦ (t, t², …, t^n) で与え、(1.4) `σ(σ₁) = σ₁^{χ(σ)}`, `σ(σᵢ) = f(yᵢ,σᵢ²)^{-1} σᵢ^{χ(σ)} f(yᵢ,σᵢ²)` を導く。当工房の hexagon-only 関係式・c 中心はこの (1.3)/(1.4) の族と直結する。**「主係数を変える = 接基点を取り替える = f を Kummer クラスだけずらす」**という当工房語への翻訳がここから作れる可能性が高い。
**照合観点**: (a) Th.3.5(Eisenstein 冪級数と Ihara の Jacobi 和冪級数の明示関係)は本件には遠いが、Part I の (1.1)–(1.4) だけで十分。(b) 引用 [N2],[N3],[IN] が接基点の μ_n 比較を定量化しているはず — そこが要請 9 の定理の本体。
