## 2. 比較対象(CV-9-1 ②)— **合成の左右と共役の向きを文章で固定**

### 2.1 精水準の作用(T′ 整合規約・裁定 298 で採択された側)

$(m,q)$ に対し $u:=2m+1$、
$$T'_{m,q}\ :\ \Psi(x)\mapsto\Psi(x)^{u},\qquad \Psi(y)\mapsto q\,\Psi(y)^{u}\,q^{-1},\qquad \Psi(c)\mapsto\Psi(c)^{u}.$$
**共役は $q(\cdot)q^{-1}$**(混成規約 $q^{-1}(\cdot)q$ は使わない)。根拠 = `pent_settled_cent_v1.md` §6・裁定 298。

### 2.2 粗水準の 2 つの座標(**どちらも定義し、両方で照合する**)

- **著者側ラベル** $f:=\theta(\mathrm{WordOf}(q))$(順方向・`coarse_of`)。**著者の作用** $E_{m,f}:\bar x\mapsto\bar x^u,\ \bar y\mapsto f^{-1}\bar y^u f$(= 実装の `PhiOf(m,f)`)。
- **我々側ラベル** $g:=\rho(q)$(`redMap`)。**我々の作用** $\Phi'_{m,g}:\bar x\mapsto\bar x^u,\ \bar y\mapsto g\,\bar y^u g^{-1}$。

両者は定理 ORI で $g=\tau(f)=\hat c(f)^{-1}$、$\tau$ は反自己同型。

### 2.3 積の順序(★ 4 件目の事故が起きるとすれば**ここ**)

$\Psi$ は**反準同型**である。ゆえに:

| 座標 | 積の順序 | 出所 |
|---|---|---|
| 著者側 $(m,f)$ | $f''=f_1\cdot E_{m_1,f_1}(f_2)$ | 正典 2401.06870 **(3.53)**(定義ノート L171 逐語) |
| 我々側 $(m,g)$ | $g''=\Phi'_{m_1,g_1}(g_2)\cdot g_1$ | 対話帳 **T-21 補題 OPP**(9600 対機械確認済) |
| 精 $(m,q)$ | $q''=T'_{m_1,q_1}(q_2)\cdot q_1$ | **本稿の予言**(§3 P-GTPI-1) |

$m$ 成分はどの座標でも共通:
$$u''\equiv u_1u_2 \pmod{N_{\rm ord}=5},\qquad m''=\text{the unique }m\in\{0,1,3,4\}\text{ with }2m''+1\equiv u_1u_2 .$$
(正典 (3.53) の $m''=2m_1m_2+m_1+m_2$ と mod 5 で一致することも probe で照合する。)

### 2.4 「合成」の定義に GAP の `*` を使わない

GAP の写像積 `f*g` の向き(左から)と数学の $\circ$(右から)の取り違えは既知の罠。**probe では写像を一切掛けず、生成元の像を明示的に二段代入して合成を作る**。すなわち
$$(T'_1\circ T'_2)(\Psi(y)):=T'_1\bigl(T'_2(\Psi(y))\bigr)$$
を `Image(hom1, Image(hom2, ...))` の順で書き、$\circ$ = 「右を先に施す」で固定する。

### 4.1 識別力を持つ dummy fixture(CV-9-5 / §1.3.2)

二層の正規化を明示する。

- **入力層 datum** = $(m,q)$ の組。
- **出力層 判定対象** = $(m'',q'')$ が $\mathcal G$ の元か。

**DUM-G1(出力層の外に出る dummy)**: $q_2$ を、そのままでは $\mathcal G$ に属さない元 $q_2^{\rm bad}:=q_2\cdot z$($z\in V=Z(Q_P)$、$z\ne1$)に差し替える。$\rho$ は $z$ を潰すので**粗ラベルは不変**、しかし $q_2^{\rm bad}\notin A$ ゆえ $c_4$ が落ちる。⟹ **粗側だけ見ていると区別できないが、精側の判定は変わる**。この dummy で `closure` 判定が `false` に変わることを機械確認する(識別力の証明)。

**DUM-G2(積の順序に対する識別力)**: 意図的に**逆順**の $q''_{\rm rev}:=q_1\cdot T'_{m_1,q_1}(q_2)$ も併せて計算し、$\mathcal G$ 所属率を記録する。**両方が 400/400 で通ってしまうなら、この実験は積の順序について識別力がない**(= 主張を弱める)。$F_{20}$ は非可換なので、逆順は落ちるはずである。

**DUM-G3(共役の向きに対する識別力)**: 混成規約 $T$($q^{-1}(\cdot)q$)でも同じ 400 組を計算し、閉性率を記録する。$T$ 側で率が落ちれば、規約選択が識別可能であったことの証拠になる。

**DUM-G4(入力層の外に出る dummy)**: $m$ に非 charming 値 $m=2$($u=5\equiv0$)を入れた行を 1 本混ぜ、$T'$ が自己同型にならない(核が非自明)ことを確認する。
