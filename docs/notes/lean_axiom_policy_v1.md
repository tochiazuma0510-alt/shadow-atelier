# Lean 公理化方針 v1(研究者裁定 2026-08-01・裁定 332)

**原則**: Lean 化で Mathlib に無い定理は、通常の数学の公理に加えて **公理(axiom)としてブラックボックス化して追加**する。何を公理として追加したかは**明示**し、公理を使用する箇所には**必ずコメント**を入れる。(研究者原文の方針。)

## 実装規約(司令塔強化 4 点・研究者方針の施行細則)

1. **機械追跡が主・コメントは副**: 全公理は namespace `ShadowAxioms` 配下に宣言。主定理群には CI で `#print axioms` を走らせ、**出力 ⊆ 公理台帳(§manifest)を機械照合**(未申告公理・sorryAx の混入を fail-closed 検出)。コメント(出典・理由)は人間用 — ドリフトし得るため保証は カーネル側(CV-12 の精神)。
2. **言明監査**: 各公理の Lean 言明は (a) 原論文と逐語照合(Sol 監査対象・画像照合の流儀) (b) **sanity インスタンス**(公理の小さな帰結を既知値で独立検証・言明ミスの検出網) (c) **使用する最弱形で言明**(M2-DESC の「BCL 粗形のみ」の紙規律を移植)。
3. **階層(v1.1 訂正・研究者指摘 2026-08-01)**: 分類基準は「誰が書いたか」でなく**認識論的な格**。**T1 古典**(Belyi・Weil 降下等・出典明確)/ **T2 論文固有**(2405 Thm 5.3・2008 Cor 2.8 等 — 監査済みでも「人間の論文依存」と明示)/ **T2b 標準的・精密出典未特定**(TB1/TB3/TB4ᵘ/A3 — folklore 級・**自前再導出の紙が既にあるため、将来は Mathlib 待ちでなく再導出自体の形式化で公理を消せる**)/ **T3 真に未証明の仮説**(FAITH 等)— **T3 は原則 axiom にしない**: 定理の言明に明示仮定(`(h : _) → …`)として載せ、型に条件性を運ばせる。全域で要る場合のみ `assumption_` 接頭辞の最終手段。
5. **差し替え規約(研究者方針)**: 公理は Mathlib 到着待ちのプレースホルダ。台帳に **Mathlib 状況欄**(不在/PR/取込済)を持ち、到着時は公理宣言を Mathlib 参照へ置換 — CI の `#print axioms` 照合が「公理が減った」ことまで機械検証する。T2b は Mathlib を待たず自前再導出の形式化でも消せる。
4. **公理台帳(manifest)**: `lean/AXIOMS.md`(Lean 線始動時に新設)— 公理名・階層・原典(定理番号+照合記録の裁定番号)・Mathlib 不在の確認方法・使用箇所一覧。追加は司令塔裁定を経る(勝手な公理追加の禁止)。

## 既存方針との関係

- framework-assumptions-policy(2026-07-28「Lean 化せず Mathlib 待ち」)を**本方針が更新**: 待たずに T3 assumption として形式化に含める(格の明示つき)。
- 「verified」の語は従来どおり Lean 通過に予約 — ただし公理つき検証は **verified-modulo-axioms(公理台帳参照)** と表記し、無印 verified と区別する。
