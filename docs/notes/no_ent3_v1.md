## 2. 定理

> ### 定理 NO-ENT(3)
> 上の設定($N'\trianglelefteq B_3$、$N'\subseteq K^{(3)}$、$[K^{(3)}:N']=3$)で、拡大
> $$1\longrightarrow Z=K^{(3)}/N'\ (\cong C_3)\longrightarrow \Gamma=PB_3/N'\longrightarrow G_3\longrightarrow 1$$
> について次が成り立つ。
> **(1)** $G_3$ の $Z$ への作用は**自明**である(すなわち $Z\subseteq Z(\Gamma)$)。
> **(2)** 拡大は分裂し、補群 $C\le\Gamma$ は**ただ一つ**である。
> **(3)** その $C$ は $\Gamma$ で**正規**(実際 $\Gamma=Z\times C$)かつ **$B_3$-安定**($C\trianglelefteq\widehat\Gamma$)。
> ⟹ **命題 ENT-CRIT (b) が成立する。したがってこの class に本質的 entangled 屋根は存在せず、$\mathfrak F_0$ 方向の検出力は(SPLIT-NULL の残りの前件が満たされる限り)ゼロである。**
> とくに **$G_3$ の非分裂 $\chi_i$-拡大で $B_3$-正規な $N'$ から得られるものは存在しない**(標的 ENT-1 の class は空)。

**射程の再掲**: 指数 3・$B_3$-normal・$K^{(3)}$ 内。**他の指数・他の $n$ には移さない**(§6)。

## 3. 検分(3 段・当方の証明)

### 3.1 段① — 作用指標の候補は 4 個

$Z\cong C_3$ は可換ゆえ自分自身に自明に作用する。よって共役作用 $\Gamma\to\mathrm{Aut}(Z)=C_2$ は $\Gamma/Z\cong G_3$ を経由し、
$$\rho\in\mathrm{Hom}(G_3,C_2)=\mathrm{Hom}(G_3^{\rm ab},C_2).$$
$G_3^{\rm ab}\cong C_2^2$(下記)ゆえ $\lvert\mathrm{Hom}(G_3,C_2)\rvert=4$: 自明指標 + 非自明 3 個 $\chi_1,\chi_2,\chi_3$。∎

> **$G_3^{\rm ab}\cong C_2^2$ の当方の確認(2 経路)**
> **(紙)** $G_3=\{(a_1,a_2,a_3)\in D_3^3:\sum_j\delta_j=0\}$($\delta_j$ = 第 $j$ 座標の反転パリティ)。$A=C_3^3\subseteq G_3$ で $G_3/A\cong\{\varepsilon\in C_2^3:\sum\varepsilon_j=0\}\cong C_2^2$ は可換、かつ $[(r,1,1),(s,s,1)]=(r^2,1,1)$ 型の交換子で $A$ 全体が出る ⟹ $[G_3,G_3]=A$ ⟹ $G_3^{\rm ab}\cong C_2^2$。
> **(機械)** `AbelianInvariants(G_3) = [2,2]`、`|[G_3,G_3]| = 27`、`AbelianInvariants([G_3,G_3]) = [3,3,3]`、`[D_3^3:G_3] = 2`(§7 A2/A3/A4/A6)。

### 3.2 段② — 作用指標は $S_3$-不変、かつ非自明 3 個は一軌道

#### 3.2.1 $S_3$-不変性(2 行)

$Z\trianglelefteq\widehat\Gamma$ だから共役作用は準同型 $c:\widehat\Gamma\to\mathrm{Aut}(Z)=C_2$ を与え、$\rho=c\vert_\Gamma$。$\mathrm{Aut}(Z)$ は**可換**なので $c$ は $\widehat\Gamma^{\rm ab}$ を経由し、任意の $s\in\widehat\Gamma$、$g\in\Gamma$ に対し
$$c(sgs^{-1})=c(s)c(g)c(s)^{-1}=c(g).$$
$\widehat\Gamma$ の共役が誘導する $S_3=\widehat\Gamma/\Gamma Z$ の $G_3$ への作用に対して $\rho$ は不変 — すなわち $\rho\in\mathrm{Hom}(G_3,C_2)^{S_3}$。∎

> **注意(well-defined)**: $S_3$ の $G_3$ への作用は内部自己同型の分だけ曖昧だが、$C_2$ が可換ゆえ内部自己同型は $\mathrm{Hom}(G_3,C_2)$ に自明に作用する。したがって上の不変性の主張は**持上げの選択に依存しない**。

#### 3.2.2 一軌道性・経路 R1(抽象 — 置換加群の不変部分空間)

$\mathrm{Hom}(G_3,C_2)\hookrightarrow\mathrm{Hom}(PB_3,C_2)$($K^{(3)}$ 上自明な指標として)。$PB_3^{\rm ab}\cong\mathbb Z^3$(基底 = 純組紐生成元 $x_{12},x_{13},x_{23}$ の類)ゆえ
$$\mathrm{Hom}(PB_3,C_2)\cong\mathbb F_2^3=\langle\delta_1,\delta_2,\delta_3\rangle$$
は $S_3$ の**置換加群**である($B_3$ の共役は 3 本の生成元を「2 元部分集合 $\{i,j\}\subset\{1,2,3\}$ の置換」として動かす — 標準事実。正典 2405 (4.8) の $\tau(r^{2n_1},r^{2n_2},r^{2n_3})=(r^{2n_3},r^{2n_1},r^{2n_2})$ はこの巡回置換の像側の表れ)。
$K^{(3)}\trianglelefteq B_3$ より像 $\mathrm{Hom}(G_3,C_2)\subseteq\mathbb F_2^3$ は **$S_3$-不変部分空間**で、次元は 2(段①)。ところが $\mathbb F_2^3$ の $S_3$-不変な 2 次元部分空間は**和ゼロ部分空間**ただ一つである(不変超平面 $\iff$ 定義する線型形式が $S_3$-固定 $\iff$ 形式 $=\delta_1+\delta_2+\delta_3$)。ゆえに
$$\mathrm{Hom}(G_3,C_2)=\{0,\ \delta_1\delta_2,\ \delta_1\delta_3,\ \delta_2\delta_3\},$$
非自明 3 個は「欠けている座標」で標識され、$S_3$ は座標を推移的に動かす ⟹ **一軌道**。∎

#### 3.2.3 一軌道性・経路 R2(具体 — $D_3^3$ 模型)

$G_3\le D_3^3$ の 3 個の非自明指標は座標パリティ $\delta_1,\delta_2,\delta_3$ の制限であり、$G_3$ 上で $\delta_1\delta_2\delta_3=1$(定義式)だが $\delta_i\ne\delta_j$($i\ne j$)。$S_3$ は座標を置換する(各因子の $\mathrm{Aut}(D_3)$ による捻れが入っても、$\mathrm{Aut}(D_3)$ は唯一の指数 2 部分群 $\langle r\rangle$ を保つので**パリティ指標 $\delta_j$ は捻れの影響を受けない**)⟹ 3 個は推移的に置換される。∎

> **機械確認**(§7 A10–A12): $G_3$ の指数 2 部分群はちょうど 3 個、座標巡回 `cyc` はそれらを $[3,1,2]$ と巡回置換し、**固定されるものは 0 個**。さらに $x,y,z=(xy)^{-1}$ の abel 化像は相異なる 3 個の非自明元で積が 1(= 和ゼロ描像の実物確認・A13–A15)。

#### 3.2.4 段②の結論

$\rho\in\mathrm{Hom}(G_3,C_2)^{S_3}$ かつ非自明 3 個は一軌道(位数 3 の軌道に固定点なし)⟹ $\rho=\mathbf 1$。すなわち **$Z\subseteq Z(\Gamma)$**。∎(定理 (1))

### 3.3 段③ — split・補群一意・正規・$B_3$-安定

#### 3.3.1 split

自明作用ゆえ $[\,\cdot\,]\in H^2(G_3,\mathbb Z/3)$(自明係数)。**補題 NO-CENTRAL**($H^2(G_n,\mathbb Z/3)=0$・奇 $n$;`roof2_cv9_freeze_v1.md` §7.2)より $H^2(G_3,\mathbb Z/3)=0$ ⟹ **分裂**。∎

> **NO-CENTRAL($n=3$)の当方の独立確認**: 自明係数では普遍係数で
> $$H^2(G_3,C_3)\cong\mathrm{Hom}(M(G_3),C_3)\oplus\mathrm{Ext}^1(G_3^{\rm ab},C_3),$$
> $G_3^{\rm ab}\cong C_2^2$ ゆえ $\mathrm{Ext}^1$ 項は 0、GAP の `AbelianInvariantsMultiplier(G_3) = [2]`(§7 A16)より $\mathrm{Hom}(M(G_3),C_3)=\mathrm{Hom}(C_2,C_3)=0$ ⟹ $H^2(G_3,C_3)=0$。
> **これは roof2 §7.2 の LHS スペクトル系列による証明とは独立の経路**(Schur 乗数)であり、NO-CENTRAL の $n=3$ instance の cross-check になっている(単系統 GAP の値 $M(G_3)=C_2$ に依存する点は明記する)。

#### 3.3.2 補群の一意性

自明作用ゆえ $H^1(G_3,C_3)=\mathrm{Hom}(G_3,C_3)=\mathrm{Hom}(C_2^2,C_3)=0$。中心 $Z$ による分裂拡大では、補群全体の集合は $Z^1(G_3,Z)=\mathrm{Hom}(G_3,Z)$ と全単射(自明作用ゆえ coboundary は 0)。ゆえに**補群はただ一つ**。∎

#### 3.3.3 正規性($B_3$-安定性の前に要る一行 — Sol の文に無かった段)

$Z$ は中心、$\Gamma=ZC$、$Z\cap C=1$ ⟹ $[Z,C]=1$ ⟹ $\Gamma=Z\times C$ ⟹ **$C\trianglelefteq\Gamma$**。∎
(付随: $\gamma=zc$ による共役は $\gamma C\gamma^{-1}=zCz^{-1}=C$ — 共役でも補群は動かない。§3.3.2 の「一意」はしたがって**共役類の一意**より強い。)

#### 3.3.4 $B_3$-安定性

$K^{(3)},N'\trianglelefteq B_3$ より $\widehat\Gamma$ の共役は $\Gamma$ の自己同型で $Z$ を保つ。したがって補群を補群へ写す。§3.3.2 の一意性より $C$ は固定される ⟹ $C\trianglelefteq\widehat\Gamma$(= $B_3$-安定な正規補群)。∎(定理 (2)(3))

## 4. ENT-CRIT との接続(なぜこれが「entangled でない」なのか)

命題 ENT-CRIT(`roof2_cv9_freeze_v1.md` §2)は
> (b) $K^{(n)}/M$ が $PB_3/M$ の中に **$B_3$-安定な正規補群**をもつ $\iff$ (a) 屋根が分裂($PB_3/M\cong G_n\times PB_3/N''$)

であった。定理 NO-ENT(3) は (b) を**この class の全ての $N'$ について**与える。$C$ の $PB_3$ における原像を $N''$ とすれば $N''\trianglelefteq B_3$、$K^{(3)}\cap N''=N'$、$PB_3/N'\cong G_3\times PB_3/N''$。

> **構造上の注意(記録)**: 一般に「正規補群が存在 ⟹ 作用は自明」である($[C,B_0]\subseteq C\cap B_0=1$)。すなわち **ENT-CRIT (b) は「作用が自明」を含意する**。逆に作用が非自明なら (b) は自動的に破れる(= 本質的 entangled)。本定理はこの class で「作用は必ず自明」を示したのだから、(b) の成立は「自明作用 + $H^2=H^1=0$」の 3 点セットで閉じている。

## 9. 申し送り

1. **司令塔へ(射程の外・起票候補)**: 同じ 3 段が「奇 $n$・核 $C_3$・$B_3$-正規・指数 3」で回るかは、$\mathrm{Hom}(G_n,C_2)^{S_3}=0$ と $\mathrm{Hom}(G_n,C_3)=0$ の 2 点に帰着する(どちらも $G_n^{\rm ab}\cong C_2^2$ と (4.8) から出る見込み)。**本稿は主張しない**。一般化を起票するなら別委嘱で。
