本工房には「9」を含む窓が複数あり、混同を避けるため明記する。

| **S4窓**(u_meas campaign) | $N_{S4}\cong\mathrm{Hol}(\mathbf Z/9)$、monodromy $\mathrm{PSL}(2,8)$ | $\deg\lambda=9$、$M=9$(奇数) | $F=\mathbf Q(\zeta_{18})$ | ★ **証明済み**(docs/notes/u_meas_m3_design_v1.md §1.2、proof 格) |

## 2. 破れ方の整理(判定ではなく構造の記述)

$$\boxed{\ \textbf{U-LOC の証明の最終ステップ(sign-triviality)は }M\textbf{ 奇数を本質的に使う。}K^{(9)}\textbf{ の }M_9=18\textbf{ は偶数。}\ }$$

これは「窓固有か窓非依存か」という問い以前に、**命題の前提が数論的に満たされない**という、より基礎的なレベルの不一致である。K⁽⁹⁾側で U-LOC「類似」を作るには、少なくとも:

1. **E3(商被覆 $\varphi$ の存在)を K⁽⁹⁾側で独立に確立する**必要がある(未着手・R-0b の自明 deck 群という生値はこの問いに部分的に関連するが直接答えない)。
2. **E2(sign-triviality)を $M$ 偶数版に書き換える**必要がある($-1$ が $\mathbf Q^{\times}/(\mathbf Q^{\times})^{18}$ で非自明класс になる分、$[u_9^{-1}]_{18}$ と $[c]_{18}$ の関係式に符号の余分な因子が残る可能性が高い — 具体形は未導出)。
3. **E6(較正用の既知値)が無い** — K⁽⁹⁾側でパイプラインを端点間較正する材料が今のところ無い。

一方、**生き残る可能性がある部分**:
- E4(Shanks三次の公式そのもの、$S_3$対称性由来)
- E5 の論法パターン(自己正規化 $\Rightarrow$ 降下障害なし)— 入力事実(自己正規化)は K⁽⁹⁾側でも既に成立が確認されている

## 3. 可否の生値報告(判定ではない)

| 項目 | 生値 |
|---|---|
| U-LOC の一般形の前提「$M$ 奇数」 | K⁽⁹⁾の $M_9=18$ は**偶数** ⟹ 前提不成立 |
| これまでの適用例の $M$ 値 | S4窓 $M=9$(奇)・$A_5$窓 $M=5$(奇)。**偶数 $M$ への適用例は本工房に無い**(grep 済) |
| sign-triviality の等号 $-1=(-1)^M$ | $M=18$ で **成立しない**($(-1)^{18}=1\ne-1$) |
| E3(商被覆 $\varphi$)の K⁽⁹⁾側での確立状況 | **未確立**。関連生値: $\mathrm{Deck}(\lambda_9)$ は自明(このセッション既走、r13_r0b_v1cert) — ただし E3 の $\varphi$ と厳密に同一対象かは未検証 |
| E5 の入力事実(自己正規化) | K⁽⁹⁾側でも成立(このセッション既走、r13_r0_v1_1cert) |
| 較正材料(E6 相当) | K⁽⁹⁾側に**無し**(grep 済) |

**結論として報告する生値**: 「そのまま移植可(不変更で成立)」ではない — 命題の証明の最終ステップが $M$ の偶奇という数論的属性に依存しており、K⁽⁹⁾はその属性が異なる側に落ちる。移植を試みるなら最低でも上記1〜3の3点の新規作業(うち2点は本質的な数学、E2は書き直し可能かもしれないが未検証)が要る。**「W₉のモデル構成が丸ごと不要になる」という最良のシナリオの確認はできなかった** — ただし「不可能」の証明もしていない(E3が独立に確立できれば話は変わる)。判定・次の一手の決定は数学者→司令塔に委ねる。
