# χ_vir 一斉点検 v1 — P93-1 型の穴(2m+1≡1 mod 2^a の二値性)の工房内捜索

- 起草: 反証前哨(falsifier)/ 2026-08-01
- 委嘱: 司令塔(裁定 306 (a) 上申)。**修理はしない**(発注は司令塔)。30 分規律。
- 対象バグの型(参照): P93-1 — 「2m+1 ≡ 1 (mod 2^a)」から「m ≡ 0」を結論する推論は偽。実際は m ∈ {0, 2^{a-1}} の**二値**が残り、偽解 [2^{a-1},1] は **χ_vir(mod K_ord) だけを見ていると単位元と区別できない**(χ_vir(2^{a-1})=2^a+1≡1)。修理は χ̃(mod 2K_ord への精密化)または「無限成分から先に割る」経路。

## 方法

`χ_vir` / `chi_vir` / 「2m+1 ≡ … mod …」/ 「m ≡ 0」等を repo 全体(docs/notes・docs・sol・ideas・provenance。`.claude/worktrees/**` は旧世代のミラーなので対象外)で grep し、ヒットした文書を実際に読んで判定した。時間の都合で「m を χ_vir から一意に復元/確定していると読める箇所」を優先し、**法(modulus)が偶数・とくに 2 冪であるか**を軸に危険度を付けた(2 冪でなければ 2m+1 ↦ m は単射なので、この型の穴は原理的に発生しない — gcd(2, 奇数)=1 だから)。

## 総括

- **重大**に分類したのは #1(u2_unramified_bridge_v1.md 本体)のみ。ただしこれは「新たに見つかった穴」ではなく**既知の P93-1 そのもの**であり、修理は addendum 方式で完了済みと記録されている(`sol/sol_reply_93_math20.md` 最終ゲート宣言「U2-BR: P93-1 を本文へ反映した改訂版に限り PASS」)。**erratum 方式(本体は書き換えない)の副作用として、本体単独を読むと今も偽推論に出会う**という運用上のリスクが残る。これは数学的な穴ではなく**文書運用の穴**であり、司令塔判断で「本体冒頭に addendum への誘導 1 行を足すか」を検討する価値がある(修理はしない、と申し送るのみ)。
- 他に見つかった候補(#3・v1 円分持ち上げ)も**旧版が訂正されずに保存されている**という同種の運用リスクであり、v2 で数学的には解消済み。
- **命題 (円分持ち上げ)・(W2)-fam/W2-arith・E1 の χ_4 対応**は、いずれも P93-1 と同型の「2 冪法での 2m+1 の逆算」に対して**χ̃(2 倍の精密水準)を明示的に導入する**という同じ修理パターンを、P93 発覚以前から独立に実装していた。これは工房の設計規律(命題文書の相互監査・v1→v2 の訂正運用)が実際に機能していたことの傍証であり、過度な安心はしないが「同型の穴が野放しで多数残っている」という状況ではない。
