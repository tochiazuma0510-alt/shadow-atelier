## 1. なぜ A14 が最安の決定実験か

三つの既測/既予言窓では **2 つの法則が区別できない**:

| 窓 | $N_{\rm ord}$ | 核の奇部分 | $C_{N_{\rm ord}}$ 律 | 1 乗律($\operatorname{rad}$) |
|---|---|---|---|---|
| idx162 | 3 | $C_3$ | ✓ | ✓ |
| A16 | 11 | $C_{11}$ | ✓ | ✓ |
| A18 | 13 | ($C_{13}$ と予言) | ✓ | ✓ |
| A20 | 15 $=3\cdot5$ | $C_{15}$(1 乗まで・**委嘱文報告**) | ✓ | ✓ |

**$N_{\rm ord}$ が今まで全て平方因子をもたなかった**ため、両律は**同じ値を出し続けてきた**。$N_{\rm ord}=9=3^2$ で初めて分岐する:

$$\boxed{\ \textbf{枝 A}\ (C_{N_{\rm ord}}\ \text{律}):\ \text{核の奇部分}=C_9
\qquad\Longleftrightarrow\qquad
\textbf{枝 B}\ (1\ \text{乗律}):\ =C_3\ }$$

**族の形**(段階 1 から読める $P\cong A_{n+5}$・$\bar x,\bar y$ は $n$-サイクル・余り 5 点): $n=9$ で $9+5=\mathbf{14}$ — **窓名 A14 と一致**。既測 A16($n=11$)・A18($13$)・A20($15$)の直前の項である。

**決定コスト**: 核の位数は**単一の charming $m$ の `shadow_total` 1 個**で確定する(補題 FIB: $\widetilde\chi$ は準同型なので非空ファイバーは全て $|\ker|$)。両枝の予測値は
$$\textbf{枝 A}:\ |\ker|=8\cdot9=\mathbf{72}\qquad\text{vs}\qquad\textbf{枝 B}:\ |\ker|=8\cdot3=\mathbf{24}$$
で**3 倍離れている**。段階 2 の単一 $m$ 試行だけで決着する — **フル実行すら要らない。**

## 3. 予言

### 3.1 **committed な一言**

$$\boxed{\ \textbf{枝 A に賭ける}:\ \ker\widetilde\chi\cong C_9\times D_8\ (\text{位数 }72),\qquad |GTSh|=72\times6=\mathbf{432}\ }$$

**根拠(1 行ずつ)**:
1. **1 乗律には独立な witness が 1 つもない**。A20 の $C_{15}$ は $15$ が平方因子をもたないので $C_{N_{\rm ord}}$ 律の予測と**同一**であり、1 乗律を支持する証拠になっていない(**記述であって法則ではない**)。
2. $C_{N_{\rm ord}}$ 律には**機構の候補がある**: 族の $P\cong A_{n+5}$ で $C_P(\bar y)=\langle\bar y\rangle\times A_5\cong C_n\times A_5$。核の奇部分として自然に立つのは $\langle\bar x\rangle\cong C_{N_{\rm ord}}$ **そのもの**である。A16 の $C_{11}$ はまさに $11$-サイクルの生成する巡回群。$n=9$ でも $\langle\bar x\rangle\cong C_9$ が**そのまま**ある。
3. 枝 B が起きるには「$C_9$ のうち位数 3 の部分群だけが核に残る」必要があり、**残す機構より削る機構のほうが説明を要する**。
