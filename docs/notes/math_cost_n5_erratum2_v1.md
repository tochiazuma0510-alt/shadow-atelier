## 4. T/D の再ラベル(裁定 2285)

### 4.1 なぜ 1 run・5 点の OLS SE を推論に使ってはいけないか

1. **SE が測っている散らばりが狭すぎる。** df = 3 の残差は「同一 run 内の 5 区間が直線からどれだけ外れるか」だけを表す。**run 差・runner 速度差・版差を一切含まない。** 実際、同じ量を run 間チャネルで測ると SE は 7.8115e-3 — **72 倍**である。この 72 倍の差は「in-run が精密」なのではなく、**2 つの SE が別の分散成分を測っている**ことの表れである(§4.3 D21・§5.2)。
2. **比較相手の誤差を伝播していない。** z = (θ̂_in-run − 0.008883)/SE(θ̂_in-run) は **0.008883 を定数扱い**している。正本の 0.008883 は別 run(v6)の 3 点当てはめから来た推定値であり、それ自身の誤差がある。**両者の差の検定には、両方の誤差と run 間分散成分が要る。** したがって 18.1331 は「棄却」ではなく**距離の目安**にすぎない。
3. **5 区間は独立標本ではない。** 同一プロセス内の逐次実行であり、page cache の温まり・GC・CPU 周波数変動で系列相関する。P 層費用計の残差は **+0.0128 / −0.0209 / +0.0338 / −0.0560 / +0.0303** と符号がほぼ交互で、iid 正規の想定は**検証していない**。
4. **層の中でも R と版が共線。** 5 層は 5 つの異なる producer 版(batch-parent … batch-parent-v7)が作った成果物である。「R が違う」と「作った版が違う」は層内でも分離されていない。
5. **「効果が無い」は示せない。** 影の R 傾き −0.93 SE は**棄却失敗**であって不在の証拠ではない(§4.3 D22)。
6. **cap の値は区間ではない。** n ≈ 56 は 1 個の点推定を、追加仮定(R = 48,384 まで affine 一定・影一定・候補相の扱い)を通して**決定論的に伝播**したもの。**[56, 57] は「2 通りの補助仮定で得た 2 個の点」であって予測区間ではない。**
7. **c₂ = 64·c1 はモデル内の恒等式。** L(R) = a + c1·R と R_i が等差、という**モデルの中でのみ**正しい係数変換であり、モデルの仮定をすべて継承する。**c₂ に SE を付けても、それは c1 の SE を 64 倍しただけで、新しい情報は無い。**

### 5.2 【実質的な論点】2 つのチャネルは別の推定対象を測っている

erratum-1 は「in-run が 71.9 倍精密だから run 間は要らない」と読める書き方をした。**これは誤りである。**

| | in-run チャネル | run 間チャネル |
|---|---|---|
| 推定対象 | **この run の中で層 i を再認証するのに掛かった秒の R 傾き** | **層を 1 枚余分に保持した run の総費用の増分の R 傾き** |
| 測る分散 | 単一 run 内の区間ばらつき(s_resid 0.0439) | run 差 + runner 差 + 版 churn + 区間ばらつき(s_resid 3.1619) |
| 計器区間の外の仕事 | **含まない** | **含む** |
| 差 | — | **影 9.650392 s/層(D22)** |

**影は雑音ではない。** 計器化された 3 stage の外にある、層由来の仕事である(うち finish-inputs 按分が 2.34〜2.66 s、残り約 7.16 s は未同定)。

> **⇒ cap モデルの限界費用は L_P(R) + 影(R) であり、影の R 依存は未測である。** in-run の 71.9 倍という精度比は「同じ量をより精密に測った」ではなく「**より狭い量を測った**」ことの帰結。**run 間チャネル(すなわち n=6, 7 の観測)は、影の R 依存を見る唯一の経路として依然として必要である。**
