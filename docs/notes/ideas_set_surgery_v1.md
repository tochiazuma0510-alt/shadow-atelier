## 札 I-SET-1 — トーサー分解: $|GT(N)|=|GT^{\rm settled}(N)|\cdot\#\mathcal C(N)$(集合手術の第 0 定理)

**規模**: 中間峰級 / **出所**: 正典 L170 の再読 + groupoid 一般論(自前知識・標準機構の翻訳)/ **種**: 構成+予想(発注方向 2 への回答)

**1. 主張の種**: 正典 L170 は $GTSh(K,N):=\{[m,f]\in GT(N)\mid\ker T_{m,f}=K\}$ を定義する ⟹ $GT(N)=\bigsqcup_K GTSh(K,N)$ は定義から従うファイバー分解。ここに groupoid の標準論法を足す:
> **【予想 TORSOR】** 非空な各ファイバー $GTSh(K,N)$ の上で、vertex group $GTSh(N,N)=GT^{\rm settled}(N)$(SETTLE-AUT による同定)は**後合成で自由推移的に作用**する($t,t'\in GTSh(K,N)$ ⟹ $s:=t'\circ t^{-1}\in GTSh(N,N)$ が唯一)。⟹
> $$\boxed{\ |GT(N)|\ =\ |GT^{\rm settled}(N)|\ \times\ \#\mathcal C(N),\qquad \mathcal C(N):=\{K:\ GTSh(K,N)\ne\emptyset\}\ }$$

**fixture 3 点が既に整合**(settled_layer_verdict §1 の表の再解釈): $K^{(9)}$: $108=108\times1$(isolated ⟹ $\#\mathcal C=1$)✓ / 83 窓 [1008,521]: $48=24\times2$ ⟹ **$\#\mathcal C=2$ を予言**(未実測・検証の一手目)/ $N'$: $|GT(N')|=2\,\#\mathcal C(N')$。さらに**円分だけで無料の下界**: 像は全 30,360 個の $u$ 値を取り(settled_layer_verdict §7.2)、$u$ が異なれば別 shadow・各ファイバーは 2 元 ⟹ $\#\mathcal C(N')\ge15{,}180$。

**帰結(発注方向 1・2 への回答)**: (i) 「settled 層 $C_2$ の作用の軌道空間」= $\mathcal C(N')$ そのもの — **軌道手術の第一実装は既に正典の中にあり、縮約率は $|C_2|=2$ に過ぎないが、値域が「shadow のペア集合」から「$B_3$ の正規部分群の集合」へ変わる質的転換**が本当の獲得物。(ii) 発注方向 2(partial monoid / groupoid 構造)の答え: $GT(N')$ の部分合成構造は groupoid の star 構造**そのもの**であり(COMP-E の「$E$ が $N$ を保つ限り合成できる」= 合成可能な射対の条件)、新しい圏を発明する必要はない。Frattini 類似を立てるべき場所は shadow の集合ではなく**対象側 $\mathcal C(N')$**(札 2 へ)。(iii) 比較 $GT(N')\setminus a_{N'}(G_\mathbf Q)$ も核写像 $[m,f]\mapsto\ker T_{m,f}$ で $\mathcal C(N')$ 上へ押し出せる(像の核集合 vs 全体の核集合 — ファイバー内の差は settled $C_2$ の分だけ・§2.2 の $f_c$ 1 ビットと整合)。

**規模会計**: $10^{17}\to10^{17}/2$ — 数だけ見れば無力。買うのは**座標**(核×$C_2$)であり、以後の全札はこの座標の上で動く。

**2. 何が新しいか**: ファイバー分解は正典 L170 既出・settled = vertex group の同定は SETTLE-AUT(settled_grp_proof)既出。**自由推移性(トーサー)とそれによる計数公式は 0 hit** — gt_settled_identification §4.1 は「$|GT(N')|$ は数えられない ⟹ 分母を settled に**付け替える**」(全体を諦める)、本札は全体を**因数分解して取り戻す**。settled_layer_verdict §1 の表(1・1/2・実質 0 の「比」)は本公式の $1/\#\mathcal C$ の観測に他ならない、という再解釈も新規。

**3. 検証の一手目**: (i) 数学者へ紙 1 枚: 合成 (3.53) の source/target 規約(Thm 3.10)で「$t'\circ t^{-1}\in GTSh(N,N)$・唯一性」を逐語証明(COMP-E + (3.54) の source 側交換・Prop 3.8 と整合確認・演習級の見込み)。(ii) implementer: 83 窓 [1008,521] の 48 shadow の $\ker T$ を GAP で分類し **相異なる核 = 2 個**(かつ各ファイバー 24 元)を実測 — 既存 census 資産の再走・秒級・$u$/$c$ 非接触。

**4. 破綻しそうな点**: ① (3.53) の合成可能条件(target と source の噛み合い)を私は式でなく圏論の慣例から推測している — 規約が逆でも左右トーサーが入れ替わるだけで公式は生きるはずだが、**逐語確認前に「自由推移的」と言うのは越権**(だから予想札)。② 正典の $GT(N)$ が「ペアの集合」で、同一の $T$ に複数ペアが対応する場合($f$ の $C_Q(\bar y^u)$ 曖昧さ)、ファイバーのサイズ勘定にペア/写像の型ずれが混入する — fixture (ii) が最初の検死。③ $\#\mathcal C(N')\ge15{,}180$ は「$u$ が異なれば核も異なる」を暗黙に使っていない(異なる shadow が同じ核を持ち得る)— 正しくは shadow 数 ≥ 30,360 とファイバーサイズ 2 から $\#\mathcal C\ge15{,}180$。ここは合っているが、**下界が「像由来」であること**(GT 側の固有の下界ではない)は弱み。

## 札 I-SET-2 — 核 census の指標計数: 列挙 $10^{35}$ を指標和 $10^5$ に潰す(Frobenius 貫通)

**規模**: 中間峰級(装置)/ **出所**: trefoil 表示(照合済【GAP-E10】)+ Frobenius 1896 系の古典計数(自前知識・別分野の標準機構の翻訳)/ **種**: 構成(発注方向 3 への回答・SL-GAP-3 の「列挙は別問題」への直接回答)

**1. 主張の種**: 札 1 により分母の計数は $\#\mathcal C(N')$ = 「$B_3\twoheadrightarrow\tilde H$ 型の(shadow-adapted な)核の個数」に変換された。これは列挙せずに数えられる:
- $B_3\cong\langle a,b\mid a^2=b^3\rangle$($a=\Delta$, $b=\delta$・照合_B3表示 (D3))⟹ $\#\mathrm{Hom}(B_3,H)=\#\{(A,B)\in H^2:A^2=B^3\}=\sum_{g\in H}N_2(g)\,N_3(g)$($N_k(g):=\#\{h:h^k=g\}$)。
- Frobenius の古典: $N_k$ は類関数で $N_k(g)=\sum_\chi\nu_k(\chi)\chi(g)$、$\nu_k(\chi)=\frac1{|H|}\sum_h\chi(h^k)$(一般化 Frobenius–Schur 指示数・GAP の PowerMap で即)⟹
$$\boxed{\ \#\mathrm{Hom}(B_3,H)\ =\ |H|\sum_\chi\ \nu_2(\chi)\,\nu_3(\bar\chi)\ }$$
- **項数 = 既約指標数** — 列挙 $|H|^2\approx4\times10^{35}$ が**指標表 1 枚の内積**に潰れる。そこから: 非全射分を部分群格子の Möbius で減算 ⟹ $\#\mathrm{Epi}$ ⟹ $\mathrm{Aut}(\tilde H)$ で割って核数 ⟹ **$\#\mathcal C(N')$ の上界**($\mathcal C$ は「shadow-adapted な核」でさらに狭いので上界)。$S_3$-商との両立(NFI$_{PB_3}$ 条件 = $\ker\subseteq PB_3$)は $A,B$ の $S_3$ 成分を固定した相対計数(同じ和の部分和)で入る。
- **実行面**: mod-$\Phi$ 水準($Q/\Phi\cong PSL(2,691)$・SL-GAP-3)なら $\tilde H_\Phi$ は位数 $\approx10^9$・**類数 $\approx(p{+}5)/2=348$ 規模**・$PSL(2,q)$ の指標表は generic に既知(ctbllib 在庫)⟹ **今日走る**(和は $\sim10^5$ 項)。$\tilde H$ 本体($SL(2,\mathbf Z/691^2)$ 型・類数 $O(p^2)\approx5\times10^5$)は和 $10^{11}$ 項 = クラウド級だが**原理的に射程内** — $10^{17}$ の分母が「規模の壁を表現論で貫通」する。

**規模会計**: 列挙 $O(|H|^2)=10^{35}$ → mod-$\Phi$ 指標和 $10^5$ 項(GAP 秒級)/ 本体 $10^{11}$ 項(分割可・クラウド級)。**列挙の壁を回避する現状唯一の計数装置**。ただし数えるのは分母(と 2 窓会計の材料)であり、分子(算術像)の代金は不変。

**2. 何が新しいか**: 指標計数・FS 指示数の使用は主 repo 0 hit。SL-GAP-3(mod-$\Phi$ 影)は「窓を潰す」提案で止まっており「**その窓で何をどう数えるか**」が空欄だった — 本札はそこに「核 census の指標計数」を差し込む。$B_3$ の trefoil 表示は照合済資産の**初の計数への転用**。

**3. 検証の一手目**: 較正ゲート流の 3 段 — (i) implementer: 可解 fixture([1008,521] の $B_3/N\cong$ 位数 1008 の群)で $\#\mathrm{Hom}(B_3,H)$ を「指標和」と「全数列挙」の**二系統**で計算し一致確認(GAP 数行・秒級)。(ii) 同じ窓で Möbius 減算 → 核数を出し、**札 1 の一手目 (ii) の実測値 $\#\mathcal C=2$ と突合**(装置の較正完了)。(iii) $PSL(2,691)$ で走らせ mod-$\Phi$ census の分母上界の第一号を出す。

**4. 破綻しそうな点**: ① **shadow-adapted の緩み**: 数えるのは「epi の核」全体で、shadow の source になる核($\sigma_i$ の像が標準形)はその部分集合 ⟹ 出るのは上界のみ。緩みの大きさは fixture (ii) で最初の実測(核数 vs $\#\mathcal C$ の比)。② Möbius 減算には $\tilde H_\Phi$ の部分群格子(の epi 像を持ち得る部分)が要る — $PSL(2,691)$ は Dickson で既知だが、$S_3$ 拡大 $\tilde H_\Phi$ の格子は組み立てが要る(数学者 1 枚)。③ $\tilde H$ 本体の指標表($SL(2,\mathbf Z/p^2)$ 型)は**正典外** — 文献要請(paper-hunter 経路)か自前構成(Clifford 理論)の司令塔裁定が要る。④ mod-$\Phi$ の census と $N'$ 本体の census の間の fiber 対応(押し出しの多重度)は未設計 — SL-GAP-3 の残務がそのまま残る。

## 札 I-SET-3 — isolated-reduction 上界: 2 窓のサイズ比較だけで $GT(N')\setminus a_{N'}(G_\mathbf Q)\ne\emptyset$ を出す存在検定(+ α/β 弁別)

**規模**: 中間峰級(装置)〜夢級(帰結)/ **出所**: 正典 (3.60)+Prop 3.14+Thm 5.2 の組み合わせ(正典再読からの構成)/ **種**: 予想+装置(発注の「比較の道具が存在しない」への挑戦)

**1. 主張の種**: 正典の 3 部品 — (a) reduction $R_{M,N'}:GT(M)\to GT(N')$($M\le N'$・(3.60))、(b) $N'^\diamond$ := 成分の全対象の交わりは **isolated**(Prop 3.14)、(c) $\widehat{GT}_{\rm gen}\cong\varprojlim_{\rm isolated}GT(N)$(Thm 5.2)— から包含鎖が出る(要逐語確認・下記一手目 (i)):
$$a_{N'}(G_\mathbf Q)\ \subseteq\ \mathcal{PR}_{N'}\bigl(\widehat{GT}_{\rm gen}\bigr)\ \subseteq\ R_{M,N'}\bigl(GT(M)\bigr)\qquad(\forall\,M\le N',\ M\ \text{isolated})$$
⟹ **検定**: $|GT(M)|<|GT(N')|$ なる isolated $M\le N'$ が**一つでも**あれば、$GT(N')\setminus a_{N'}(G_\mathbf Q)\ne\emptyset$ が**確定**(witness の名指しなし・**算術入力ゼロ**の存在証明)。settled_layer_verdict §7.3 の道具表への**5 行目**。
**α/β 弁別(意味論の整備・独立の価値)**: $GT(N')\setminus a_{N'}(G_\mathbf Q)$ の非空性には 2 つの別の意味がある — **(α)** $GT(N')\setminus\mathcal{PR}_{N'}(\widehat{GT})\ne\emptyset$(**fake shadow の存在** = $\widehat{GT}$ 由来でない・Cor 5.4 の survive 語彙)と **(β)** $\mathcal{PR}_{N'}(\widehat{GT})\setminus a_{N'}(G_\mathbf Q)\ne\emptyset$(**genuine だが非算術** = 井原型全射性の真の反例)。本検定が出すのは **α**(a fortiori で発注の問いには YES を与えるが、井原には直接触れない)。既存文書(settled_layer_verdict §2.2 の $f_c\ne1$ 枝を含む)はこの弁別を明示していない — **台帳の型整備として独立に安い一手**。

**規模会計(正直)**: 検定の実行には両辺の計数が要る。左辺 $|GT(M)|$ の証明上界は gt_settled_identification §3 の論法の一般化で $|GT(M)|\le N_{\rm ord}(M)\cdot|C_{\mathrm{Aut}(Q_M)}(\bar x)|\cdot|C_{Q_M}(\bar y)|$ 型(isolated ⟹ 全 shadow settled ⟹ $\mathrm{Aut}(Q_M)$ に写る)— $N'$ 級の窓で $\approx10^{16}$。右辺 $|GT(N')|=2\#\mathcal C(N')$ の現在の下界は $3\times10^4$(札 1)。**ギャップ 12 桁 — 現状この検定は発火しない**。発火経路は二つ: 札 2 の指標計数が $\#\mathcal C(N')$ を確定(または桁上げ)する / isolated 窓の shadow 数の非自明上界(下記設問 (iii))が立つ。⚠ **W-48 注意**: 「isolated 窓の $|GT|$ は実測では窓サイズよりはるかに薄い」(83 窓・K 族・m=18 の 2280 等)は**経験則であり外挿禁止対象** — 会計には証明上界のみを使う。

**2. 何が新しいか**: U-5(fake = 延長障害)は **isolated poset 内部**(dihedral 族)の照準器で、非 isolated 窓には触れていない。本札の新規分は ① **非 isolated 窓 $N'$ に対して** isolated 窓からの reduction 像で**算術像を上から抑える**使い方(0 hit)② 「2 窓のサイズ比較 ⟹ 非空」という**列挙なしの存在検定の形**(サイズ会計 I-CEX-1 系は同一窓内の会計・2 窓比較は 0 hit)③ α/β 弁別の明文化。

**3. 検証の一手目**: (i) 数学者へ設問 1 枚: 包含鎖の中段 $\mathcal{PR}_{N'}=R_{M,N'}\circ\mathcal{PR}_M$ が正典の $\mathcal{PR}$ の定義と整合するか(Thm 5.2 の錐の可換図・演習級の見込みだが**ここが折れたら札全体が落ちる**)。(ii) 較正: $K^{(n)}$ 塔で Thm 4.3 の明示式から $R$ の像サイズを機械計算し「reduction がどれだけ痩せるか」の正解データ(implementer・GAP)— U-2 (T1) の資産と同便化可能。(iii) 数学者へ第二設問: isolated 窓の $|GT(M)|$ の非自明上界(上の中心化群鎖の精密化 — $\ker\Psi_M$ の制御込み)。(iv) 83 窓の非 isolated 窓 [1008,521] で $M=N^\diamond$ を GAP で構成し、$|GT(M)|$ vs $|GT(N)|=48$ の**検定のミニチュア**を完走 — 小窓で装置を丸ごと較正(83 窓回帰の結論と整合的な順序)。

**4. 破綻しそうな点**: ① 中段の包含(一手目 (i))が定義のずれで折れる可能性 — $\mathcal{PR}_{N'}$ の正典定義(非 isolated 窓への射影)を私は逐語確認していない。② 12 桁ギャップが埋まる保証はどこにもない — $\#\mathcal C(N')$ が実際に $10^{16}$ を超えている見込みは「$|\tilde H|$ 規模の braid ペアがあるはず」という**未計数の直感**に過ぎず、逆に $\mathcal C(N')$ が小さければ(例: $10^3$)検定は逆向きに空振る。③ α の発見は井原の反例ではない(意味の格下げを明記済)— ただし dihedral 予想の族的限界(Conj 5.1 型の「genuine 全射」がどの窓族で破れるか)としては一級。④ $N'^\diamond$ の具体構成は「成分の全対象の交わり」で、対象が $10^{16}$ 個あるなら構成自体が非自明 — 検定に使う $M$ は $N'^\diamond$ である必要はなく「手持ちの isolated 細分 1 個」で足りる(そこは救い)が、$N'$ の中の isolated 細分を**具体的に 1 個**作る問題が残る。

## 札 I-SET-4 — 軌道手術の生死判定: SG-GAP-1=NO は「座標捻りが hexagon を壊す」ことの証拠 — 剛性の測定(発注方向 1 への正直な回答)

**規模**: 現在線級 / **出所**: 発注方向 1 の検討 + SG-GAP-1 実測(gt_settled_identification)の再読 / **種**: 反例狙いの装置提案(ただし NO 側の予想を明記)

**1. 主張の種**: 発注方向 1(「$Q$ の作用で $GT(N')$ を軌道に割る・縮約率 $\sim|Q|$」)の第一関門は「作用が $GT(N')$ を保つか」であり、私の検討では**保たれない見込みが高い**:
- 候補作用の自然形は $q\in C_Q(\bar x)$ による座標捻り $[m,f]\mapsto[m,fq]$($T\mapsto\mathrm{inn}_q\circ T$ に対応・核と onto と $\sigma_1$-標準形を保つ)。しかし shadow の定義は「$T$ が準同型」だけでなく **hexagon の関数等式**($f$ の等式)であり、これは $f\mapsto fq$ で保たれる保証がない。
- **既存実測が NO 側の証拠**: SG-GAP-1 = NO($[0,f]$、$\bar f\in C_Q(\bar y)$ の非単位元 **476,789 個すべて**で shadow 不成立)は、「$u=1$ 断面で座標捻りが 1 個も生き残らない」ことの全数観測 — 作用が立つなら少なくとも単位元の軌道は生きるはずだった。
- ⟹ **予想 RIGID(candidate)**: $GT(N')$ は $C_Q(\bar x)$・$C_Q(\bar y)$ 型の座標捻りに対し**剛**(捻りの生存率 $\approx0$)。剛性が立てば: 軌道手術は不可能と**確定**(方向 1 の答えは NO — 「答えが NO でも一級」の発注方向 5 に部分回答)。同時に代償として「ファイバー内 2 元の $f$ 座標は核と $u$ からほぼ決まる」= **shadow の $f$ 座標の強い決定性**が従い、縮約は「作用で割る」でなく「座標(核・$u$)で層化する」(札 1-2 の路線)が唯一の道と結審できる。
- なお「$GT(N')$ の元による右合成」の軌道(真に存在する作用)は札 1 のトーサーそのもので、縮約率は 2 が上限。「像との同変性」(発注文の $a_{N'}$ の同変性)は、$\mathrm{Ih}$ が準同型ゆえ**像の元による合成でしか閉じない** — settled 層 $C_2$ との合成では $a_{N'}(G_\mathbf Q)\cdot[-1,1]$ 型の「像の 2 倍化」だけが正当で、これは $f_c$ 1 ビット([Q4-FINAL])と同じ話に落ちる。

**規模会計**: 作用が立たない場合の縮約率 = **1**(手術不成立)。立った場合のみ $\sim|C_Q(\bar x)|=4.8\times10^5$ で、mod-$\Phi$($\div1.6\times10^8$)と独立に効けば $10^{17}\to10^{3\text{-}4}$ 級 — **発注方向 3 の見積りへの回答**(ただし独立性は楽観仮定・現状は NO 予想が優勢)。

**2. 何が新しいか**: SG-GAP-1 は「$\ker\Psi$ の自明性」の測定として台帳済 — それを「**軌道手術の不可能性の証拠**」と読み替えるのは 0 hit(gt_settled_identification は単射性にのみ使用)。B₄ 副線の GT-orbit(2106・dessins)は別対象。剛性を「座標の決定性」という正の資産に反転する読みも 0 hit。

**3. 検証の一手目**: implementer: 83 窓 [1008,521](48 元・全列挙済)で座標捻り $[m,f]\mapsto[m,fq]$($q$ は $C(\bar x)$・$C(\bar y)$・一般元の 3 種)の**生存率を全数測定**(GAP 分級・$u$/$c$ 非接触)。生存率 0 なら RIGID の最初の族的証拠・非零なら軌道手術が復活(どちらでも地図が塗れる)。

**4. 破綻しそうな点**: ① SG-GAP-1 は $u=1$・$f\in C_Q(\bar y)$ という**特定断面**の全滅で、一般の $[m,f]$・一般の $q$ での生存を排除しない — 「証拠」は状況証拠。② hexagon の関数等式を私は逐語で追っていない(gentle 版 hexagon の $f$ 等式の正確な形は定義ノート該当節の再読が要る)— 「保たれる保証がない」止まりで「壊れる」の証明はない。③ 83 窓 fixture の結果を $N'$ に運ぶのは W-48 抵触(外挿ラベル必須)— fixture は装置の較正であって $N'$ の結論ではない。
