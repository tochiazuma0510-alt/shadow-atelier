## 2. pentagon の明示形(C1 式 (2.20))

N ∈ NFI_{PB₄}(B₄)、f ∈ F₂ ⊂ PB₃ に対し、**PB₄/N の中で**:

> ∂₂₃₄(f) · ∂₁,₂₃,₄(f) · ∂₁₂₃(f) ≡ ∂₁,₂,₃₄(f) · ∂₁₂,₃,₄(f)  (mod N)

hexagon((2.18)(2.19))は **B₃/N_{PB₃} の中**の条件で、工房の翻訳「(fa₁)²=1 ∧ (fb₁⁻¹)³=1」(定理 RED)はこちら側。**pentagon だけが PB₄ 側**にある — ここが GT_gen と GT を分ける一点。

### 2.1 余面写像 5 本(C1 (A.18))— 「置換群に落ちる」ことの本体

5 本の準同型は全て **PB₃ の生成元 x₁₂, x₂₃, x₁₃ 上の値だけで決まる**:

| 余面 | x₁₂ ↦ | x₂₃ ↦ | x₁₃ ↦ |
|---|---|---|---|
| ∂₁₂₃ | x₁₂ | x₂₃ | x₁₃ |
| ∂₂₃₄ | x₂₃ | x₃₄ | x₂₄ |
| ∂₁₂,₃,₄ | x₁₃x₂₃ | x₃₄ | x₁₄x₂₄ |
| ∂₁,₂₃,₄ | x₁₂x₁₃ | x₂₄x₃₄ | x₁₄ |
| ∂₁,₂,₃₄ | x₁₂ | x₂₃x₂₄ | x₁₃x₁₄ |

**工房設定への翻訳(一工夫・candidate)**: 必要なのは 3 つだけ —
1. **PB₄/N を 6 個の置換 (x₁₂, x₂₃, x₁₃, x₁₄, x₂₄, x₃₄) が生成する置換群として持つ**。
2. f を F₂ = ⟨x₁₂, x₂₃⟩ の**語**として持つ。
3. 語の各文字を上表で置換に写し、**5 本の積を比較**する。

⟹ **GAP でそのまま書ける**(語の評価と置換積のみ・コホモロジーも表現論も不要)。我々の judge が hexagon でやっていることと同型の作業。

### 2.2 実装の実在(C3 `pkg/PackageGT/PaB.py`)

`def penta(wm, t)`(508 行〜)が上式そのものを実装 — **6 個の置換タプルによる同一判定**。`NotUsed.py` に `penta_k`・`gener_pr_penta` の別実装があり、**同一命題の第二実装として cross-check に使える**(工房の二系統規律にそのまま乗る)。

計算コスト = 「F₂/N_{F₂} の全語(または交換子部分群の全語)を回して置換積を 5 本比較」。

### 2.3 既存の実データ(C1 §4)

- **N⁽¹⁹⁾**("Philadelphia subgroup"・N_ord=6): pentagon を満たす f が **216 個**、うち hexagon も満たす (m,f) をもつのは **36 個**。
- **N⁽³⁴⁾**("Mighty Dandy"・N_ord=9): [F₂/N_{F₂}, F₂/N_{F₂}] 内で pentagon を満たすのが **4096 個**、うち hexagon も持つのは **243 個**。GT(N⁽³⁴⁾) は位数 486 = 2·3⁵ ≅ (ℤ₂×ℤ₃)⋉(ℤ₉×ℤ₉)。

⟹ **pentagon は hexagon より「緩い」条件ではなく、両者の交わりが本命**という数値感覚が得られる。我々の窓で同じ勘定をするのが最初の実験。

## 4. Furusho property の profinite 版(C1 §4.3)— 予想外の収穫

古典(Drinfeld associator)では **Furusho の定理「pentagon ⟹ hexagon」**が知られる。C1 §4.3 は**その profinite 版を性質として定義し、35 例で機械判定**(強 11/35・弱 13/35)している。

⟹ **profinite では一般には成立しない**(実データつき)。我々にとっての含意: **hexagon を pentagon で置き換えることはできない**が、**どの窓で Furusho 性が成り立つか**自体が新しい問い(そして我々の CENT/SPEC の言葉で答えられる可能性がある)。
