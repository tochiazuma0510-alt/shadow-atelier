## 2. checklist 1 — (15.10.1) の正確な言明と副有限対応物

### 2.1 (15.10.1) の言明(Betti 版・画像✓ p.235/157)

**前提**(§15.10 冒頭・§15.3 の設定): X̄ = Riemann 面、S ⊂ X̄ 有限、X = X̄ − S、s ∈ S、T_s = s での接空間、T_s⁰ = T_s − {0}、t ∈ T_s⁰。R は X の(位相的)被覆、R₍ₛ₎ は §15.7 で構成した T_s⁰ への制限。

> 逐語(15.10): 「Si R est un revêtement de X, de restriction R₍ₛ₎ à T_s⁰, le groupe fondamental π₁(T_s⁰, t) agit sur R_t = R₍ₛ₎ₜ. De là, un morphisme
>
> **(15.10.1)  π₁(T_s⁰, t) ⟶ π₁(X, t) .**
>
> On a π₁(T_s⁰, t) = **Z(1)_B = 2πiZ**(14.2 complété par 14.4)et (15.10.1) se récrit
>
> **(15.10.2)  Z(1)_B ⟶ π₁(X, t) .**」

- **canonical 性の根拠**: (15.10.1) は関手 R ↦ R₍ₛ₎ のみから定まる。R₍ₛ₎ の germ 選択非依存性は **15.7**(証明 present・p.232/154)、その根拠の可縮性は **15.4 LEMME**(証明 present・p.231–232/153–154)。t 以外の選択を含まない。
- **添字 B**: Z(1)_B = 2πiZ は **Betti 実現**(14.2 の Réalisation de Betti・p.225/147)。**この式番号をそのまま (TB4ᵘ) に引くと Betti 版を引くことになる**(campaign FP-6 の版ずれ警告を画像で追認)。
- proof_body_status: **present**(構成が本文・canonicity は 15.4+15.7 の証明 present)。

### 2.2 副有限節での対応物 — ★ 番号つきの単独言明は無い

**§15.13–15.26 の全文を画像で走査した結果**: 副有限節には π₁(T_s⁰) → π₁(X) 型の射の番号つき言明が**現れない**。節が与えるのは関手 R ↦ R₍ₛ₎ の構成(§3.2 の表)まで。射そのものを番号つきで与えるのは:

> **(16.1.1)**(p.255/177・画像✓): 「π₁(T_s⁰, v)_mot ⟶ π₁(X, v)_mot, **correspondant, dans les diverses théories du π₁, au foncteur de restriction de X à T_s⁰**. Le π₁ motivique d'une droite moins l'origine est Z(1) (14.2) et (16.1.1) se récrit
>
> **(16.1.2)  μ_s : Z(1) ⟶ π₁(X, v)_mot .**」

- 前提(16.1): X = P¹_Q − S(S = 有理点の有限非空集合)・良還元・基点 = 接ベクトル v ∈ T_s⁰(15.50 経由)。
- **副有限版の同定**: (16.1.1) の「diverses théories du π₁」は §10 の 3 理論(classique・**profinie**・algébrique — §10.1・テキストのみ)を指す。⟹ **副有限版の射 = (16.1.1) の étale(profinie)実現**であり、その源は π₁^ét(T_s⁰) = **Ẑ(1)**。Ẑ(1) の供給は:
  - **14.2 PROPOSITION**(p.225/147・画像✓)「π₁(G_m,1)_mot est le motif de Tate Z(1)」+ Réalisations ℓ-adiques(p.225–226/147–148・画像✓)逐語: 「Le π₁ profini est donc la limite projective **Ẑ(1)** des noyaux μ_n des u ↦ uⁿ」。
  - **15.23 PREUVE**(p.241/163・画像✓)逐語: 「par le lemme d'Abhyankar, on a **π₁(X) = π₁(X_s^∧) = Ẑ(1)**」(ハット付きを画像で確認)。
- Betti 実現の向きの規約(16.1.3 直後・p.255/177・画像✓): 「En réalisation de Betti, μ_s envoie **le générateur 2πi de Z(1)_B** sur **un petit lacet positif σ_s** autour de s」。
- proof_body_status((16.1.1)(16.1.2)): **present**(§15 の構成群からの組み立て・16.1 内は構成体。(16.1.4) の全射性等は証明 present)。

> ⚠ **注意(誇張の抑制)**: (16.1.1) の置かれた §16.1 は X = P¹_Q − S・良還元の文脈で述べられている。「任意の曲線の副有限版 (15.10.1)」として引くなら、pin は「§15.13–15.18 の関手 + §10.16 の π₁ 形式論から従う標準的な射(Deligne は (16.1.1) で P¹ − S の場合に明示)」という**組み立て表現**になる。単独番号 1 個で済ませたい場合の最短は (16.1.1)。この選択は数学者/司令塔の専権。
