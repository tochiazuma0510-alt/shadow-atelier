## 1. この論文での GT-shadow の定義(§2.1)【画像照合済】

- 群: **B₄/PB₄**(+B₃/PB₃, B₂/PB₂)。**c := x₂₃x₁₂x₁₃ ∈ PB₃**(Z(PB₃) と Z(B₃) を生成)。F₂ = ⟨x₁₂,x₂₃⟩、PB₃ ≅ F₂ × ⟨c⟩。
- **対象: NFI_{PB₄}(B₄)**。N から N_PB₃, N_PB₂ を導出([8, (2.4)])。**N_ord := |PB₂ : N_PB₂|**、**N_F₂ := N_PB₃ ∩ F₂** (2.4)。N は truncated operad **PaB^{≤4}** 上の compatible equivalence relation ∼_N を定める([8, Prop 2.4])。
- **GT-pair**(target N)= operad 射 PaB^{≤4} → PaB^{≤4}/∼_N ↔ 組 **(m, fN_PB₃) ∈ {0..N_ord−1} × PB₃/N_PB₃** (2.5) で:
  - **hexagon**(B₃/N_PB₃ 内): (2.6) σ₁x₁₂^m f⁻¹σ₂x₂₃^m f N_PB₃ = f⁻¹σ₁σ₂x₁₂^{−m}c^m N_PB₃、(2.7) f⁻¹σ₂x₂₃^m fσ₁x₁₂^m N_PB₃ = σ₂σ₁x₂₃^{−m}c^m f N_PB₃
    ※ (m, f) のパラメータ規約が 2401 系(σ^{2m+1} 形)と見かけ上異なる(σ₁x₁₂^m = σ₁^{2m+1})— 同内容。
  - **pentagon**(PB₄/N 内): (2.8) φ₂₃₄(f)φ₁,₂₃,₄(f)φ₁₂₃(f) N = φ₁,₂,₃₄(f)φ₁₂,₃,₄(f) N(φ の明示式は [8, (A.18)])
- **GT-shadow** = onto な operad 射 ⟺ (1) hexagon+pentagon、(2) **2m+1 ∈ (ℤ/N_ord ℤ)^×**、(3) T^{PB₃}_{m,f}: PB₃ → PB₃/N_PB₃ onto。GT(N) := 全体。
- T^{PB₃} の式 (2.12): x₁₂ ↦ x₁₂^{2m+1}, x₂₃ ↦ f⁻¹x₂₃^{2m+1}f, c ↦ c^{2m+1}。T^{F₂} (2.13)(2.14)。
- **groupoid**: N^s := ker(T^{PB₄}_{m,f})、GTSh(N⁽²⁾,N⁽¹⁾) := {[m,f] ∈ GT(N⁽¹⁾) | N⁽²⁾ = ker(T^{PB₄})} (2.11)。
- **合成 (2.21)**: m := 2m₁m₂+m₁+m₂、**f(x,y) := f₁(x,y)·f₂(x^{2m₁+1}, f₁(x,y)⁻¹y^{2m₁+1}f₁(x,y))**。
- 部分クラス: **practical**(f ∈ F₂ で代表可; genuine ⇒ practical なので本論文は practical のみ扱う)/ **charming** (2.22): fN_F₂ ∈ [F₂/N_F₂, F₂/N_F₂](部分 groupoid **GTSh♥**; genuine ⇒ charming)。Remark 2.3: [8] の charming 定義の「T^{F₂} onto」条件は冗長(Prop 2.1 で自動)。
- **isolated**: GTSh♥_conn(N) の対象が N のみ ⇒ GT♥(N) 有限群。isolated poset は coinitial、**lim ML ≅ ĜT**([8, Thm 3.8])。「settled」「virtual cyclotomic character」は本論文では定義非掲載のまま使用([8] 参照)。
- ĜT 側: ĜT = Aut(PaB の profinite 完備化)。既知の元は**恒等と複素共役のみ**(p.2)。複素共役 ↔ **(m̂,f̂) = (−1, 1)**。functor **PR: ĜT_NFI → GTSh**(値域は GTSh♥)。

## 2. dessins の符号化と作用(§2.2–2.4, §3)【画像照合済】

- 符号化 4 通り: (1) permutation pair (c₁,c₂)(⟨c₁,c₂⟩ 推移的)の S_d 共役類; (2) triple (g₁,g₂,g₃), g₁g₂g₃ = id((c₁,c₂) ↦ (c₁,c₂,c₂⁻¹c₁⁻¹) (2.23)); (3) ψ: F₂ → S_d(x↦c₁, y↦c₂)∈ Hom^tran(F₂,S_d)/共役 (2.25); (4) F₂ の指数 d 部分群の共役類(Galois ⟺ 正規)。
- 不変量: monodromy group = ⟨c₁,c₂⟩、**passport** = (ct(c₁), ct(c₂), ct(c₂⁻¹c₁⁻¹))。
- **subordinate**(Def 2.11): [ψ] が N に subordinate ⟺ **N_F₂ ≤ ker(ψ)**。Dessin(N) := その全体。
- **作用(Thm 3.1)**: [m,f] ∈ GTSh(N⁽²⁾,N⁽¹⁾), [ψ] ∈ Dessin(N⁽¹⁾) に **(3.1) ψ^{(m,f)}(x) := ψ(x^{2m+1}), ψ^{(m,f)}(y) := ψ(f⁻¹y^{2m+1}f)** — well-defined、N⁽²⁾ に subordinate、cofunctor **A^sh: GTSh → Dessin**。内部機構 (3.3): ψ^{(m,f)} = ψ̃ ∘ T^{F₂}_{m,f}。
- **Thm 3.2**: A = A^sh ∘ PR が厳密に可換(ĜT 作用との整合)。G_ℚ は Ih 経由で作用。
- **軌道の階層(Cor 3.9, (3.17))**: K ≤ N(共に D を dominate)⇒ **GT♥(N)(D) ⊃ GT♥(K)(D) ⊃ ĜT(D) ⊃ G_ℚ(D)**。
- Remark 3.10: GT♥(N)(D) ⊋ GT♥(K)(D) の例は未発見。**両軌道が計算できた全例で GT♥(N)(D) = G_ℚ(D)**。
- Cor 3.12: **[M_D : ℚ] ≤ |GT♥(N)(D)|**(moduli 体の次数評価 — shadow 軌道は算術情報を与える)。
- Thm 3.16: charming shadow の作用で **passport 不変**。
- §4: **Abelian dessin の GT(N)-軌道は singleton**(Cor 4.7)⇒ 全 Abelian dessin は ℚ 上定義(Cor 4.8, Hidalgo の別証)。

## 3. 計算の機構(Appendix B)

- データ表現: 有限指数正規部分群 N を「準同型 ψ: Fₙ → S_q の核」として表現、商群は置換群 ψ(G) と同一視。メモリ節約: 置換でなく **rank(ラベル)のみ保存**。
- 鍵 2 事実: ker(ψ₁×ψ₂) = ker ψ₁ ∩ ker ψ₂(部分群一致判定)/ χ の全射性(パッケージのテスト)。
- **35 対象 N⁽⁰⁾..N⁽³⁴⁾**: PaB.py 実行で生成。出自は ψ: B₄ → S_d の共役類 generator から ker(ψ)∩PB₄。**うち 27 個が isolated**(Remark 3.14; [8] p.40 Table 1)。
- 機能: 全 (charming) shadow 生成(**全 shadow は i=0..32、charming は i=0..34 で完了済み**)/ isolated 判定 / 合成・逆元 / survive 判定 / **fake charming shadow の探索**([8, Cor 3.13])/ Furusho property 判定 / dessin 側(passport・genus・Galois 判定・軌道計算 orbit( , ) 等)。
- 擬似コード・seed・出所情報は本論文に無し([7] README 依存)。
