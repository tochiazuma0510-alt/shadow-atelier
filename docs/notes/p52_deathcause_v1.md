> **系 L1′(対合・Klein 作用).** $\sigma:(a,p)\mapsto(a,-p)$ は $\mathcal U_B$ 上の不動点なし対合で、

## 4. 補題 BARY(重心障害)と補題 GAUSS — 死因の中核

> **補題 BARY.** stage 1 を通る $(a,p)$ について、$A_4:=a_4/a_5$、$P_1:=[x^1]P$、$Q_1:=[x^1]Q$ とすると
> $$\boxed{\,4A_4=5\,(P_1+Q_1)\,}$$
> がつねに成り立つ。とくに $P_1,Q_1\in\mathbb Z$ ならば **$5\mid A_4$**。

**証明.** $A'=5PQ$ の $x^3$ 係数を比べる。∎

**構造的意味.** 根の重心で読めば、五次 monic $A$ の**臨界点の総和は根の総和の $4/5$ 倍**である。
Pell と T-1 は臨界点集合を **2 つの整係数 monic 二次因子 $P,Q$ に有理的に二分**してしまうので、
$4/5$ の分母 5 が消えるには $5\mid A_4$ でなければならない。
**この 5 は写像 $\mu$ の次数 5(= $P_0,P_\infty$ での全分岐指数)そのもの**であり偶然の数ではない。
$P_1\in\mathbb Z$ は補題 L1($p_2=\pm1$)から、$Q_1\in\mathbb Z$ は次から出る。

> **補題 GAUSS.** T-1 が成り立てば $A=Q^2\ell$、$Q=x^2+bx+c\in\mathbb Z[x]$、$\ell=x+d\in\mathbb Z[x]$、
> $b^2-4c\ne0$、$Q(-d)\ne0$ と書け、この $Q$ は補題 L3 の $Q$ に一致する。

**証明.** $\deg\gcd(a,a')=5-\#\{\text{相異根}\}=2$ ゆえ相異根は 3 個。5 の 3 分割は $[3,1,1]$ か $[2,2,1]$ で、
$\gcd(a,a')$ の squarefree 性が $[3,1,1]$ を排除する。よって $\operatorname{rootpart}(A)=[2,2,1]$、
$A=Q_0^2\ell$($\mathbb Q[x]$、ともに monic)。$A$ は monic 整係数だから Gauss の補題で $Q_0,\ell\in\mathbb Z[x]$。
$A'=Q_0(2Q_0'\ell+Q_0)$ で $\operatorname{lc}(2Q_0'\ell+Q_0)=4+1=5$、他方 $A'=5PQ$ かつ
$\gcd(P,Q_0)=1$($Q_0\mid A$ と $\gcd(a,p)=1$)ゆえ $Q=Q_0$。∎

さらに $2Q'\ell+Q=5x^2+(4d+3b)x+(2bd+c)$ だから **$P$ は $a$ から完全に決定される**:
$$P=\tfrac15\bigl(5x^2+(4d+3b)x+(2bd+c)\bigr)\tag{$\ast$}$$
$P\in\mathbb Z[x]$(補題 L1)より **$5\mid 4d+3b$ かつ $5\mid 2bd+c$**。

## 5. 定理 D(死因定理・ゲージ非依存)

> **定理 D.** $B\le4$ とする。$\mathcal U_B$ の **stage 1 生存者全体**について
> $\operatorname{rootpart}(a)\ne[2,2,1]$、すなわち **T-1 は 1 点の例外もなく不成立**。
> したがって decision lane は全点を REJECT し、primary reason code は
> $[4]$($p_2=-a_5$ のとき)/ $[8]$($p_2=+a_5$ のとき)となる。
> **T-1 違反は全点で起きており、$[4]$ が出る点でも T-1 は同時に破れている** —
> $[4]$ が表示されるのは reject_priority が $[4]<[8]$ だからにすぎない。

**証明.** T-1 を仮定して矛盾を導く。補題 GAUSS の $b,c,d$ を取る。補題 L1 で $P\in\mathbb Z[x]$、
補題 GAUSS で $Q\in\mathbb Z[x]$、よって補題 BARY から $5\mid A_4$。$|A_4|=|a_4|\le B\le4$ ゆえ **$A_4=0$**。
$A=Q^2\ell$ の $x^4$ 係数は $2b+d$ だから $d=-2b$。$(\ast)$ の整数条件は
$5\mid 4d+3b=-5b$(自動)と $5\mid 2bd+c=c-4b^2$、すなわち $c\equiv4b^2\pmod5$。
$d=-2b$ を代入して
$$A_3=2c-3b^2,\quad A_2=-2b(b^2+c),\quad A_1=c(c-4b^2),\quad A_0=-2bc^2 .$$
- **$b=0$**: 合同式は $5\mid c$。$Q$ squarefree $\Leftrightarrow c\ne0$ ゆえ $|c|\ge5$、$|A_1|=c^2\ge25>4$。矛盾。
- **$b\ne0,c=0$**: $5\mid4b^2$ ゆえ $5\mid b$、$|A_3|=3b^2\ge75>4$。矛盾。
- **$b\ne0,c\ne0$**: $|A_0|=2|b|c^2\le4$ より $|b|c^2\le2$、ゆえ $|c|=1$ かつ $|b|\le2$。
  - $|b|=1$: $c\equiv4\pmod5$ と $|c|=1$ から $c=-1$。$|A_3|=|-2-3|=5>4$。矛盾。
  - $|b|=2$: $c\equiv16\equiv1\pmod5$ と $|c|=1$ から $c=1$。$|A_3|=|2-12|=10>4$。矛盾。∎

**注.** この証明は **depressed ゲージを一度も使っていない**(E-1・E-2・E-4 のみ)。

> **系 D′(reason vector 372/372 の完全な説明).**
> stage 1 生存者は系 L1′ の対合 $\sigma$ で完全にペアになり、各ペアで E-3 はちょうど一方だけが通る。
> 両者は同じ $a$ を持つので T-1 の成否も同じ(定理 D により両方 fail)。

> 数学的死因は **全 744 点について一様に T-1** である。

## 5b. 定理 D+(searcher 正規形での鋭い形)

searcher のゲージ(depressed)を認めると、はるかに広い帯まで一気に閉まる。

> **定理 D+.** searcher の正規形(stage 1 = E-1..E-6 + $f_6$ depressed)において、
> $B\le 24$ のすべての stage 1 生存者は $\operatorname{rootpart}(a)\ne[2,2,1]$。
> **この 24 は最良である**(§8.1 で $B=25$ の実例を構成する)。

**証明.** depressed は $A^2=f_6P^2+\hat c_\mu$ の $x^9$ 比較から $2A_4=2P_1+[x^5]f_6=2P_1$、
すなわち $A_4=P_1$ を与える。補題 BARY と併せて $P_1=A_4=-5Q_1=-5b$、
$A=Q^2\ell$ の $x^4$ 係数 $2b+d=A_4=-5b$ から **$d=-7b$**。$(\ast)$ は
$P=x^2-5bx+\frac{c-14b^2}5$ となり、整数条件は **$c\equiv14b^2\equiv4b^2\pmod5$**。係数は
$$A_4=-5b,\quad A_3=2c-13b^2,\quad A_2=-b(7b^2+12c),\quad A_1=c(c-14b^2),\quad A_0=-7bc^2 .$$
$B\le24$ とすると $|A_4|=5|b|\le24$ ゆえ $|b|\le4$、また $b\ne0$ なら $|A_0|=7|b|c^2\le24$ ゆえ $|c|\le1$。
- **$b=0$**: $5\mid c$、$c\ne0$ ゆえ $|c|\ge5$、$|A_1|=c^2\ge25>24$。矛盾。
- **$b\ne0,c=0$**: $5\mid14b^2$ ゆえ $5\mid b$、$|b|\ge5>4$。矛盾。
- **$b\ne0,|c|=1$**: $|A_3|=|2c-13b^2|\ge13b^2-2$。$|b|\ge2$ なら $\ge50>24$。ゆえ $|b|=1$、
  合同式 $c\equiv4\pmod5$ と $|c|=1$ から $c=-1$、$d=-7b$。$b=1$ のとき
  $$A=(x^2+x-1)^2(x-7)=x^5-5x^4-15x^3+5x^2+15x-7,\qquad P=x^2-5x-3$$
  で箱は通る($\|A\|_\infty=15,\|P\|_\infty=5$)。しかし **Pell が破れる**:
  $P$ は squarefree($\operatorname{disc}=37$)で、$x^2\equiv5x+3\pmod P$ を繰り返すと

  Pell 等式 $A^2-f_6P^2=\text{定数}$ は成立しない。$b=-1$ は $x\mapsto-x$ による鏡像で同断。矛盾。∎

## 6. 死因の幾何的読み(なぜ T-1 なのか)

$\mu\cdot\iota^*\mu=\hat c_\mu$ が定数だから $\iota^*\mu=\hat c_\mu/\mu$、すなわち $\mu$ は $\iota$ を
標的側の対合 $v\mapsto\hat c_\mu/v$ と絡ませる(= `N∞-swap`)。商を取れば
$w:=v+\hat c_\mu/v$ に対し $w\circ\mu=\mu+\iota^*\mu=2a$、
すなわち **$a:\mathbb P^1_x\to\mathbb P^1_w$ は $\mu$ の商としての次数 5 の多項式写像**であり、
**T-1 は「$a$ の $w=0$ 上のファイバー型が $[2,2,1]$」**にほかならない。
Riemann–Hurwitz で $\deg R_a=8$、$\infty$ が 4 を使い、残る 4 が $A'=5PQ$ の 4 根に載る:
$Q$ の 2 根が $w=0$ 上(型 $[2,2,1]$ を作る)、$P$ の 2 根が残りの分岐値上。

この描像で定理 D はこう読める:
**「臨界点 4 個を『$w=0$ 側 2 個』と『それ以外 2 個』に有理的に二分せよ」という要求が、
重心の $4/5$ を通じて $5\mid a_4$ という合同を課す。小さい箱はその合同の非自明解を 1 つも含まない。**
死因は**合同条件**であって「たまたま」ではない。

### 8.1 searcher 正規形(depressed)での最小 bound

### 8.2 spec v19 の述語だけを課したときの最小 bound(★)

spec v19 の decision lane に depressed は無い。この条件だけを課すと結論が変わる。
