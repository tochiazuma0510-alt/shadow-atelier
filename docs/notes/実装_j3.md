## 設計判断(便24 §F8 の逐語実装)

§F8 で読取許可された式を実装仕様としてそのまま採用した(再導出はしていない):

- (8.1) `Lm3 <> {} => exists f: f_p==0, f_s3+f_w*f_r2==0 (mod 2)` — 新第一条件(j=3 で新出)。
- (8.2) `Km3 = ker(1+θ̄) ∩ ker N̄_m ⊂ (Z/8)^15`。weight-2 式 `3k_w≡0(mod8) => k_w≡0` —
  fixture で **前提として検証**(safe な合成系 26 生成元で PASS、実 m>0 は未検証・未開示)。
- (8.3) `λ_m^(3)(k) = (k_p, k_s3+W(m)k_r2) mod 2`, `W(m)=C(m+1,2) mod 2` — 生成元ごとに適用し
  GF(2) 上の張る空間(rank 0/1/2、環境が 2 次元なので閉包計算で十分)を計算、各到達値の重複度
  = |K_m^(3)|/|im λ|、基点の実値 `QFirstCond(f0)`(非線型のまま厳密評価)との XOR で 4 値表を構成。
- (8.4) `0 ∈ ob(L_m) <=> QFirstCond(f0) ∈ im λ` — 表の `"0,0"` 重複度が正であることと同値。

**二系統設計**(既存の「二系統一致」規律を踏襲): λ-shortcut(上記)と、K の全 Prod(n_i) 点を
総当たり列挙し各点で `QFirstCond` を厳密評価(非線型項 `f_w*f_r2` をそのまま計算・W(m) 近似を
一切使わない)する brute-force の両方を GAP 側に実装し、両者が厳密一致することを G1 で確認。
Node 照合器は **brute-force のみ**を独立再実装している(λ-shortcut の正しさそのものを
仮定しない、最も強い独立性)。

## fixture(manifest 指定の G1–G4、すべて PASS)

- **G1**(偽陽性検出器・j=3 版): 合成系(rhs=0、m=0,1,2,3)で「重複度表の総和=|L|」と
  「λ-shortcut と brute-force の完全一致」のみを検査(特定の到達パターンは予測に当たるため
  書かない、との manifest 指示に従う)。
- **G2**(class-5/j=2 統制・射影一致): (a) class-5 統制系を j=3(mod 8)で再走 — m=0..63 全可解
  (既存の E23/W3-9 の確立済み事実の j=3 スライス再現、class-6 の開示ではない)。(b) この新規
  モジュールの `ObFromQPair` を R=2 へ射影し、凍結済み j=2 ゲート(`search/e2c6-sweep.g`)自身の
  F1/F2/F6 fixture 出力とバイト一致することを確認(分岐による定義ドリフトが無いことの確認)。
- **G3**(F7 群積突合の j=3 セル追加): 独立に再構築した FromTheLeftCollector 群積を、
  **mod 8 に還元した**Ā₃ ベクトル(j=2 の F7 は未還元の小整数だった点が差分)で 45 通り評価し
  closed form と mod 4 で一致(exact 一致 45/45)。
- **G4**(M 系・mod 4 版): (1+θ)ker(N_C) を R=4 で再計算し、u4 成分が R[2]={0,2} に収まる
  (委嘱16 eq 0.3 の R[2]a 部分の正当化)・u2 成分が mod 2 で 0(R/2R・b̄ 部分の正当化)・
  t5=t6, u1=u3 を確認。
