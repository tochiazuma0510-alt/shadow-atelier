## 【重大】§1. ob 式 (10.2) の `(q_θ)₊` の「+」が定義されていない — q_θ と q_N は非対称

`docs/命題_E23中心障害消滅_v1.md` L50–56 で証明されているのは
$$\theta(q_\theta(\bar f)) = q_\theta(\bar f),\qquad\text{すなわち } q_\theta \in C^\theta$$
のみである。**$q_\theta \in C^\sigma$ は主張されていない。** 一方 $q_N$ は同文書 L58–68 で常に $q_N \in C^\sigma$(中央欠損補題、無条件)。

manifest (10.2) は
$$\mathrm{ob} = (q_\theta)_+ - 3^{-1}(1+\theta)q_N \in (C_j^\sigma)^\theta$$
と書くが、これが well-defined であるためには、右辺の両項がまず $(C_j^\sigma)^\theta$(または少なくとも $C_j^\sigma$)の元でなければならない。$q_N$ の方は $3^{-1}(1+\theta)$ を掛けることで自動的に $C^\sigma$ 内(すでに $C^\sigma$)の $\theta$ 対称化になり辻褄が合う。しかし **$q_\theta$ は一般には $C^\sigma$ に入っていない**(θ-固定なだけで σ-固定とは限らない)。したがって `(q_θ)₊` は

- (A) $3^{-1}(1+\sigma+\sigma^2)$ による $C^\sigma$ への平均化射影を先に施した上で `a,b` 成分を読む、
- (B) $q_\theta$ が実は最初から $\mathrm{im}$ 側で $Ra\oplus Rb$ に収まっている(別の補題で保証されている)ので単に成分を読むだけ、

のどちらとも取れ、manifest 本文にも F10 にもこの選択が明記されていない。`一致確認_E2作用表6.md` 末尾は「可解性/Ob の解釈」を**両文書とも自認する範囲外・未照合**と明記しており、まさにこの層(ob 公式の意味論)は Sol(F10)の単系統導出のままである — 実装者がどちらかを勝手に選んで実装すれば、両者(a)(b)で ob の値が変わり得るのに、その分岐を検出する fixture が manifest の 3 種のどれにも入っていない。

**要求**: 発射前に「(q_θ)₊」の演算を、`a,b` 座標(またはより低次な生の 6 成分)に対する具体式として一行で確定し(A)か(B)かを明記すること。あわせて、この定義選択が結果を左右する合成テストベクトル(q_θ が C^σ から意図的にずれる例)を fixture に追加すること。

## §5. 自主検算: F10 の (a,b) 縮約は class-5 直感の密輸ではない(反証できず)

`docs/week4-E2作用表6_claude_v1.md` §4.3(σ_m の全 21 基底像)から $C$ 上の σ 作用(§9.4 の $\mathcal N_C$ 表とも整合):
$$\sigma(u_1)=u_3,\ \sigma(u_2)=-u_2-u_3,\ \sigma(u_3)=u_1+2u_2+u_3,\ \sigma(u_4)=u_4$$
$v=(a,b,c,d)$(係数 $u_1,u_2,u_3,u_4$)に対し $\sigma(v)=(c,\,2c-b,\,a-b+c,\,d)$。$\sigma(v)=v$ を解くと
$c=a$(u1 成分)、$a-b+c=c\Rightarrow a=b$(u3 成分、**トルジョンなしの厳密な等式**)、$2c-b=b\Rightarrow c\equiv b\ (\mathrm{mod}\ 2^{e-1})$(u2 成分)だが、既に $a=b=c$ が確定しているのでこの式は自動的に満たされ、余分な解は生じない。

結果: $D_6^\sigma=\{(a,a,a,d)\}=R\cdot(u_1+u_2+u_3)\oplus R\cdot u_4$ — これは $\mathbb Z$ 上でも $\mathbb Z/2^e$ 上でも**同一**(2 の因子は最終的に効かず、隠れた 2-トルジョン解は出ない)。(10.1) の a,b と完全一致。

weight-5 側 $D_5^\sigma=0$ も $\det(1-\sigma_C)=3$(裁定 17 / F4 で既出)が $\mathbb Z/2^e$ 上でも単元であることから厳密に成立し、$C^\sigma\subseteq D_6$(左完全性のみで、Maschke 論法なしに)得られる。

以上より、F10 の二方向縮約は**この観点では反証できなかった**(保証ではない — 上記は特定の基底での直接計算の再確認のみ)。
