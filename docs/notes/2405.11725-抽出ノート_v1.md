## 1. 設定 — GT の商の構成と dihedral 群の入り方

- **枠組み**: gentle 版 GT (GT̂_gen; Harbater–Schneps [12] の GT̂₀) に対する **GT-shadows の groupoid GTSh**。定義の正本は **[6] = arXiv 2401.06870**(Dolgushev–Guynee)。**2106.06645 は本論文の参照文献に無い**(child's drawings への言及なし)。[7] = 2008.00066 は original GT̂ 用(対象 NFI_{PB₄}(B₄))で、本論文の GTSh は **B₃ ベース**: Ob(GTSh) = NFI_{PB₃}(B₃) = {N ⊴ B₃ | N ≤ PB₃, 指数有限}(Remark 1.2, p.4)。
- 記号(§1.7, p.9): B₃ = ⟨σ₁,σ₂ | σ₁σ₂σ₁=σ₂σ₁σ₂⟩、x₁₂=σ₁², x₂₃=σ₂², c=(σ₁σ₂σ₁)²(中心)、PB₃ ≅ ⟨x₁₂,x₂₃⟩×⟨c⟩、F₂=⟨x₁₂,x₂₃⟩、x:=x₁₂, y:=x₂₃, z:=y⁻¹x⁻¹。N_ord := lcm(ord(x₁₂N), ord(x₂₃N), ord(cN))、N_F₂ := N∩F₂。
- **GT-shadow**(Def 2.1/2.3, pp.11–12): [m,f] ∈ ℤ/N_ordℤ × F₂/N_F₂ で hexagon 関係 (2.1)(2.2) mod N、charming 条件 gcd(2m+1,N_ord)=1 かつ f ∈ [F₂/N_F₂, F₂/N_F₂]、T_{m,f}: B₃→B₃/N(σ₁↦σ₁^{2m+1}N, σ₂↦f⁻¹σ₂^{2m+1}fN)が全射。合成則 (2.6): [m₁,f₁]∘[m₂,f₂] = [2m₁m₂+m₁+m₂, f₁E_{m₁,f₁}(f₂)]、E_{m,f}(x)=x^{2m+1}, E_{m,f}(y)=f⁻¹y^{2m+1}f。単位元は (0,1)。
- **dihedral の入り方**(§3, p.13、画像確認済): n ≥ 3、D_n := ⟨r,s | rⁿ, s², srs⁻¹r⟩(位数 2n)。準同型 **ψₙ : PB₃ → D_n³** を
  **ψₙ(x₁₂) := (r,s,s), ψₙ(x₂₃) := (rs,r,rs), ψₙ(c) := (1,1,1)** (3.1)
  で定め、**K⁽ⁿ⁾ := ker(ψₙ)**。Prop 3.1 (p.13): K⁽ⁿ⁾ ∈ NFI_{PB₃}(B₃)(証明: K⁽ⁿ⁾ = Core_{B₃}(ker φ)、φ(x₁₂)=s, φ(x₂₃)=rs, φ(c)=1)。**Dih := {K⁽ⁿ⁾ | n ∈ ℤ≥₃}**(dihedral poset)。
- 商の同定: c ∈ K⁽ⁿ⁾ なので PB₃/K⁽ⁿ⁾ ≅ F₂/K_F₂⁽ⁿ⁾ ≅ **Gₙ := ⟨(r,s,s),(rs,r,rs)⟩ ≤ Dₙ³**。x̄=(r,s,s), ȳ=(rs,r,rs), z̄=(r²s,r⁻¹s,r) (3.6)。K⁽ⁿ⁾_ord = lcm(n,2) (3.4, p.14)。
- **Ihara 側**(§1.3): Ih(g) = ((χ(g)−1)/2, f_g) ∈ Ẑ×F̂₂、Ih_N := PR_N∘Ih : G_ℚ → GT(N)。**arithmetical** := Im(Ih_N)(用語は Florian Pop の提案、脚注 3)、**genuine** := Im(PR_N : GT̂_gen → GT(N))。arithmetical ⇒ genuine。**fake の例は執筆時点で一つも知られていない**(p.3)。virtual cyclotomic character χ_vir,N([m,f]) = 2m+1 は (ℤ/N_ordℤ)^× へ全射(円分指標の全射性から、図式 (1.10)(1.13))。

## 2. dihedral 予想の正確な主張(画像確認済・原文)

> **Conjecture 5.1** (p.23) — *For every element K of the dihedral poset Dih, each GT-shadow with the target K is arithmetical. In particular, for every K ∈ Dih, the finite group GT(K) is a quotient of G_ℚ and a quotient of the Grothendieck-Teichmueller group GT̂.*

- 形: 「target K の全 GT-shadow が arithmetical」。GT_arith(K) := Ih_K(G_ℚ) なので **Ih_K : G_ℚ → GTSh(K,K) が全射**と同値(Abstract でも全射形で明言)。
- 範囲: **すべての n ≥ 3**(位数 2n の dihedral 群すべて。奇数・混合位数を含む)。
- 支持証拠として論文が挙げるもの: Thm 4.4(reduction 全射性)+ Thm 5.2(Lochak-Schneps 条件成立)+ Thm 5.3(下限)(p.23 冒頭)。

## 3. 証明済みの結果(2 冪の場合)

> **Theorem 5.3**(主結果、p.25、画像確認済)— n = 2^α n₀ ≥ 3(n₀ 奇数)とすると
> |GT_arith(K⁽ⁿ⁾)| ≥ 2φ(n₀)(α = 0 または 1)、**2^{2α−2} φ(n₀)**(α ≥ 2) (5.4)
> *In particular for n₀ = 1, the group homomorphism Ih_{K^(2^α)} : G_ℚ → GT(K^(2^α)), α ∈ ℤ≥₂ is surjective.*

> **Corollary 5.4**(p.27、画像確認済)— *For every α ∈ ℤ≥₂, the finite group GT(K^(2^α)) is naturally a quotient of G_ℚ and a quotient of GT̂. If α ≥ 3, then the group GT(K^(2^α)) is non-abelian.*(GT̂ の**最初の非可換有限商の族**; Lochak–Schneps [21] Question 1.6/1.7 への一歩、Remark 5.6)

- 全射の理由: α ≥ 2 で |GT(K^(2^α))| = 2^{2α−2}(p.27 で明示)が下限 (5.4) と一致。
- さらに **Theorem 5.7**(p.29): Dih₂ := {K^(2^α) | α ≥ 2} 上の Main Line 関手の極限 lim(ML|_{Dih₂}) は無限非可換副有限群で、G_ℚ からも GT̂ からも全射を受ける。**Proposition 5.8**(p.30、画像確認済): この群 ≅ ker(Ψ: Aff(ℤ₂) → ℤ/2ℤ)、**Aff(ℤ₂) = ℤ₂⋊ℤ₂^× の指数 2 の clopen 部分群**、生成元 (2,1), (1,5), (0,−1) の生成する部分群の位相的閉包。
- **「elementary tools」の中身**: (i) 円分指標 χ: G_ℚ → Ẑ^× の全射性(これのみが算術的入力。χ_vir,N の全射性は「これ以外の証明を知らない」Remark 1.3)、(ii) 複素共役の像 = (−1_Ẑ, 1_F̂₂)(Lochak–Schneps [20, Thm 1]; shadow 側で (0,−1))、(iii) (ℤ/2^{α+1}ℤ)^× = ⟨−1⟩×⟨5⟩(Ireland–Rosen [18])、(iv) CRT、算術の基本定理、(v) Dₙ の置換表現 Dₙ↪Sₙ(r(j)=j+1, s(j)=−j)と直接のコセット計算。エタール理論・Ihara の冪級数は不使用(Ihara embedding の存在のみ前提)。
- Thm 5.3 の証明の核(pp.25–27): χₙ(k̄,ū):=ū : GT_arith(K⁽ⁿ⁾) → (ℤ/2nℤ)^× が全射 → 各ファイバー T_ū は T_1̄ のコセットで同サイズ → (0,−1) による共役で (k̄,5̄)↦(−k̄,5̄) から |T_ū| = 2^{α−2}·n₀/k₁ ≥ 2^{α−2}(算術の基本定理で k₁ の 2 進値を制御)。
- **Theorem 5.2**(p.23、画像確認済): 3 | n なら GT(K⁽ⁿ⁾) の**全**元が Lochak-Schneps 条件 (5.1) を満たす(witness g, h の明示構成つき; §4 参照)。⇒ K ∈ Dih では LS テストで fake を検出できない。

## 5. 未解決の最小ケース

- **論文からは UNKNOWN**(「最小の未解決対象」を明示する文は無い)。
- 論理的帰結(導出): 証明済みは n₀=1(n=2^α, α≥2)のみ。したがって Conjecture 5.1 が open な最小対象は **n = 3(K⁽³⁾ = K⁽⁶⁾、D₃ ≅ S₃)**: |GT(K⁽³⁾)| = 12 に対し保証は |GT_arith| ≥ 4。混合位数(2 冪 × 奇数の両方が非自明)の最小は **n = 12**: |GT| = 24 に対し保証 ≥ 8。
