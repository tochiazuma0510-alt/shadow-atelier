# 第 II 部 — cofinality 疑義の決着

## §4 ★★★ 答え:**正典が YES と言っています**

`docs/week1-定義ノート.md` L173 **逐語**:
> **settled**: $\ker(T_{m,f})=N$。**isolated**: 全 shadow が settled ⟹ $GT(N)=GTSh(N,N)$ は**有限群**。$N^\diamond$ := 成分の全対象の交わりは isolated(**Prop 3.14**)、**isolated poset は cofinal**。

同 L179 **逐語**:
> **Thm 5.2**: $\widehat{GT}_{\rm gen}\cong\varprojlim(\mathrm{ML})$($\mathrm{ML}$: **isolated poset 上の** $N\mapsto GT(N)$)。

$$\boxed{\ \textbf{【isolated 窓は cofinal】= 正典で }\textbf{YES}\ \textbf{(Prop 3.14 系)。GAP ではありません}\ }$$

★ **機構**: 任意の窓 $N$ に対し $N^\diamond\le N$(成分の全対象の交わり)が isolated ⟹ **どの窓にも isolated な細分がある** ⟹ cofinal ✔ そして Thm 5.2 が「その部分族の極限で $\widehat{GT}_{\rm gen}$ が復元される」と言い切っています。

## §5 ★★ ⟹ 私の §2.3 の懸念を**自己訂正**します

`cex_structure_audit_v1.md` §2.3 で私は「反例が**見えない場所**に住む可能性は一切減っていない」と書きました。⚠ **これは種類を取り違えていました**:

⟹ ★ **暫定札 m1032-1**: §2.3 の「見えない場所」を**族の問題として書いた**のは不正確。正しくは**深さの問題**。⟹ ★ **教訓 W-5**(提案): **「見えない」と言うときは *族が欠けている* のか *深さが足りない* のかを必ず分けて書く**(前者は cofinality、後者は Cor 5.4 の非対称性が支配する — **対処法が全く違う**)。
