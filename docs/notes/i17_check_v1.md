## 2. 設定と (T) の二本差し(検分点 ①)

$q\ne3$ を奇素数($q\ge5$)、$N:=3q$、$F_m:=\mathbb Q(\zeta_{4m})$ とする。

> **補題 A(体の塔).** $F_3=\mathbb Q(\zeta_{12})\subset F_{3q}=\mathbb Q(\zeta_{12q})$、$F_q=\mathbb Q(\zeta_{4q})\subset F_{3q}$、かつ
> $$[F_{3q}:F_q]=2,\qquad F_{3q}=F_q(\zeta_3)=F_q(\sqrt{-3}),\qquad \sqrt{-3}\notin F_q .$$

**証明.** $12\mid12q$、$4q\mid12q$ より包含 ✓。$q\ne2,3$ ゆえ $12q=4\cdot3\cdot q$ は両々素で $\varphi(12q)=2\cdot2\cdot(q-1)=4(q-1)$、$\varphi(4q)=2(q-1)$、比は $2$ ✓。$\zeta_3=(-1+\sqrt{-3})/2$ ゆえ $F_q(\zeta_3)=F_q(\sqrt{-3})$、次数 $2$ なので $\sqrt{-3}\notin F_q$(仮に属せば $F_{3q}=F_q$ となり $4(q-1)=2(q-1)$ の矛盾)。$\blacksquare$

**(T) の適用条件**(t63 §2.1–2.2 の A4–A7):$d\mid n$、**$d\ge3$**、ともに奇。$(n,d)=(3q,3)$ と $(3q,q)$ はいずれも条件を満たす($3\ge3$、$q\ge5\ge3$)。各脚が要求するもの:

| 前件 | $(3q,3)$ / $(3q,q)$ での状態 |
|---|---|
| **A4** 体の塔 | 補題 A ✓(初等) |
| **A5** cover $\bar\pi_{n,d}$(HF-2) | HF-2 は「$n$ 奇・$d\mid n$・$d\ge3$」で証明済 ✓。機械検分の 11 対には $(15,3),(15,5),(21,3),(21,7)$ が含まれ、**$q=5,7$ の両脚は実測済** |
| **A6** cusp 全分岐・$M_{3q}=\operatorname{ord}(X_{3q})=6q$ | HF-1(b)(c)+(W4)。**ODD-H が全奇数 $n$ で供給**(§4 補題 G/H: $H_{2,1,0}$ は $\alpha=1\ne0$ ゆえ good、指数 $=2n=\operatorname{ord}(X)$、$\langle X\rangle$ 単純推移)。さらに §6 命題 ODD-P で $d=\gcd(1,3q)=1$ ゆえ ordered passport は $K^{(3)}/K^{(5)}$ と同型 $(2N,2^{N-1}1^2,2N)$ ✓ |
| **A7** 局所 Kummer・$[u]_M$ のモデル非依存(BFC B-5) | **合成窓 $3q$ での instance が要る**(→ caveat **C-3q**) |
| (TB1) 圏同値 | 枠組仮定(自前再導出・Lean 化せず — 2026-07-28 裁可) |

> **①への回答**: 「合成窓 $3q$ の窓データ (W3)(W4) が要るか」→ **要る。そして既に閉じている。** ODD-H/HF-1 は全奇数 $n$ で立っており、$3q$ は奇数だから追加の群論的仕事はゼロである。$q=5,7$ については HF-2 の機械検分に $(15,\cdot),(21,\cdot)$ が既在で、A5 は実測済みですらある。**残るのは A7(BFC 側)だけ**であり、ここが発案の caveat 表から落ちている(§5)。

## 3. 平方類の計算(検分点 ②)

> **⚠ 型の注意が**不要**である理由**: (T) すなわち (2.3) は $u_n=u_d\cdot w^{2d}$ という **$F_n^\times$ の元の等式**である(t63 §2.2)。したがって平方類 $[\,\cdot\,]_2:F_{3q}^\times\to F_{3q}^\times/F_{3q}^{\times2}$ を両辺に直接適用できる。**(6.3-cls) と (6.3-chr) の型混同(t63 §2.3 の第一の発見)は、$a_n$ 同士を $\bmod\ 2d$ で比べるときの注意であって、本論法には一切関与しない。** なお $[u]_2=[u^{-1}]_2$ なので $u$ と $v=u^{-1}$ の取り違えも無害、$[\,\cdot\,]_2=\mathrm{pr}_{2m\to2}$ の像として $a_m$ の言葉にも直せる。

> **補題 B(二次拡大の平方核).** $\operatorname{char}K\ne2$、$L=K(\sqrt\delta)$、$[L:K]=2$ とすると
> $$\ker\bigl(K^\times/K^{\times2}\to L^\times/L^{\times2}\bigr)=\{1,\,[\delta]\}.$$
> **証明.** $a\in K^\times$、$a=y^2$、$y=s+t\sqrt\delta\in L$($s,t\in K$)とすると $y^2=s^2+t^2\delta+2st\sqrt\delta\in K$ より $2st=0$、$\operatorname{char}\ne2$ ゆえ $s=0$ または $t=0$。$t=0$ なら $a=s^2$、$s=0$ なら $a=t^2\delta$。逆は明らか。$\blacksquare$(発案の「$y=a+b\sqrt{-3}$、$ab=0$ の 2 行」と同じ)

> ### 命題 SQ-3q
> $q\ne3$ を奇素数とし、$(3q,3)$ と $(3q,q)$ の両脚で (T) の前件(A4–A7・TB1)が成立するとする。さらに $u_3=-4$ が $H_3^{\rm fun}$ 窓の主係数である(caveat C1)とする。このとき
> $$\boxed{\ [u_q]_2\ \in\ \{\,1,\ [-3]\,\}=\{1,[3]\}\quad\text{in }F_q^\times/F_q^{\times2}.\ }$$

**証明.**
1. **(T)@$(3q,3)$**: $u_{3q}=\operatorname{res}_{F_{3q}/F_3}(u_3)\cdot w_1^{6}$($w_1\in F_{3q}^\times$)。$w_1^6=(w_1^3)^2$ は平方だから
 $$[u_{3q}]_2=[\operatorname{res}(u_3)]_2=[-4]_2=[-1]_2\cdot[4]_2=[-1]_2 .$$
 $\zeta_4=i\in F_{3q}$($4\mid12q$)ゆえ $-1=i^2$ は平方、よって $[u_{3q}]_2=1$。
2. **(T)@$(3q,q)$**: $u_{3q}=\operatorname{res}_{F_{3q}/F_q}(u_q)\cdot w_2^{2q}$($w_2\in F_{3q}^\times$)。$w_2^{2q}=(w_2^{q})^2$ は平方だから $[\operatorname{res}(u_q)]_2=[u_{3q}]_2=1$。
3. **降下**: 補題 A より $F_{3q}=F_q(\sqrt{-3})$ は二次拡大、補題 B より
 $$[u_q]_2\in\ker\bigl(F_q^\times/F_q^{\times2}\to F_{3q}^\times/F_{3q}^{\times2}\bigr)=\{1,\,[-3]\}.$$
 $i\in F_q$($4\mid4q$)ゆえ $[-3]=[-1][3]=[3]$。$\blacksquare$

> **註(二択が真に二択であること)**: $\sqrt{-3}\notin F_q$(補題 A)なので $[-3]\ne1$ in $F_q^\times/F_q^{\times2}$ ✓。発案の主張どおり退化しない。
> **註(3 の役割)**: 論法が要求するのは「$d\ge3$ 奇で $[\operatorname{res}(u_d)]_2=1$ が既知」かつ「$[F_{dq}:F_q]=2$」の二つだけである。$[F_{dq}:F_q]=\varphi(4dq)/\varphi(4q)=\varphi(d)$ なので**二次になるのは $\varphi(d)=2$、すなわち $d=3$ に限る**($d$ 奇)。$d\ge5$ では核が依然位数 2 になる場合もある(巡回拡大なら二次部分体は一意)が、$[u_d]_2$ が既知でなければ何も出ない。**現時点の公開台帳で $[u_d]_2=1$ が言えるのは $d=3$ のみ**である(他の $d$ の値は封印または未測定)。したがって「二本目の $d$ を足して二択を潰す」道は**現状は開いていない**(方法としては存在する — §6 M2)。

## 4. RAD-2 との整合と右枝の意味(検分点 ③)

**追加前件(明示)**
* **(K) Kummer 辞書**: $v_q:=u_q^{-1}$、$a_q:=[v_q]_{2q}\in F_q^\times/F_q^{\times2q}$、飽和の固定体は $L_q=F_q\bigl(v_q^{1/2q}\bigr)$ で $[L_q:F_q]=\operatorname{ord}(a_q)$(BFC (7.2)/Sol 便 73 (5.1) の枠組)。

> **補題 C.** $\mu_q\subset F_q$($q\mid4q$)の下で
> $$\operatorname{ord}(a_q)\mid q\iff[u_q]_2=1 .$$
> **証明.** ($\Rightarrow$)$a_q^q=1$ は $v_q^q\in F_q^{\times2q}$、すなわち $v_q^q=z^{2q}$。両辺の $q$ 乗根を取れば $v_q=\zeta z^2$($\zeta\in\mu_q$)。$q$ 奇より $\zeta=(\zeta^{(q+1)/2})^2$ は平方だから $[v_q]_2=1$、$[u_q]_2=[v_q]_2=1$。($\Leftarrow$)$v_q=z^2$ なら $v_q^q=z^{2q}\in F_q^{\times2q}$ ゆえ $a_q^q=1$。$\blacksquare$
> $\operatorname{ord}(a_q)\mid 2q$ は自動なので、$[u_q]_2\ne1\iff2\mid\operatorname{ord}(a_q)$。

**(i) 左枝**: $[u_q]_2=1\iff\operatorname{ord}(a_q)\mid q$ — 発案の「素数窓の C4 型上界が $u_3=-4$ 一点から族的に従う」は**正しい**(命題 SQ-3q + 補題 C)。

**(ii) 右枝の含意 — 発案より強い**:
$$[u_q]_2=[-3]\ \Longrightarrow\ 2\mid\operatorname{ord}(a_q)\ \Longrightarrow\ \operatorname{ord}(a_q)\ne q\ \overset{(5.1)}{\Longrightarrow}\ \operatorname{Ih}_{K^{(q)}}\ \text{は非全射}.$$
すなわち右枝は **RAD-2 の反証にとどまらず、(5.1) の全前件の下で dihedral 予想 Conj 5.1 が窓 $q$ で偽**であることを意味する。
**RAD-2 との直接整合計算**(設問が求めたもの):RAD-deg(v2 §3.2)より $[\,\mathbb Q(\zeta_{4q},2^{1/q}):F_q]=q$ は**奇数**。(K) の下で $\sqrt{v_q}=(v_q^{1/2q})^{q}\in L_q$ だから $F_q(\sqrt{u_q})\subseteq L_q$。奇数次拡大は二次中間体をもたないので $\sqrt{u_q}\in F_q$、すなわち
$$\boxed{\ \text{RAD-2}\ \wedge\ (\mathrm K)\ \Longrightarrow\ [u_q]_2=1\ (\text{左枝}).\ }$$
対偶が発案の「右枝なら RAD-2 反証」✓。

> **⚠ 誇張の抑制**: 右枝は「Conj 5.1 の反例」という**極めて強い**主張なので、右枝が実現する確率は事前には低いと見るのが自然である。したがって本ビットの実用的な内容は**左枝(上界)の確認**であり、「1 ビットで RAD-2 を検定する」という売り文句は、実質「1 ビットで Conj 5.1 を検定する」と読み替えるべきである。**測定前凍結の対象としてはむしろ価値が上がる**(予言が強いほど反証力が高い)。
