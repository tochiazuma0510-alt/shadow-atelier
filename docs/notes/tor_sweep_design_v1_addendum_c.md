## 1. なぜ HNF が要らないか(前提の確認)

$A\in\mathbf Z^{m\times n}$($m=210$, $n=123{,}270$)、$r=\mathrm{rank}_\mathbf Q A$。単因子 $s_1\mid s_2\mid\cdots\mid s_r$ は
$$d_i:=\gcd\{\text{全ての }i\times i\ \text{小行列式}\},\qquad s_i=d_i/d_{i-1}\quad(d_0=1)$$
で**定義から決まる**。$d_i$ は行・列の unimodular 変換で不変(補題 QD-1 系の前提確認 ✔ — 実際 $d_i$ は $\mathrm{coker}$ の同型不変量)。
⟹ **飽和基底(HNF)は単因子を得るための一手段にすぎず、必要条件ではない。**

## 2. ★ (b) の代替整数証明書 — **3 段階・全て小成分**

### 2.1 段階 1: 支持の**上界**(1 個の巨大数だけ・行列は小さいまま)

$r\times r$ の非特異小行列を**数個**選び、その行列式 $D_1,D_2,\dots$ を厳密に計算して
$$g:=\gcd(D_1,D_2,\dots)\qquad\Longrightarrow\qquad d_r\mid g\qquad\Longrightarrow\qquad\boxed{\ \{q:\ q\mid s_i\ \exists i\}\subseteq\{q:\ q\mid g\}\ }$$
**これは証明であって発見的ではない**($d_r$ は全 maximal minor の gcd ゆえ任意の部分集合の gcd を割る)。発見的なのは「$g$ が因数分解できる程度に小さいか」だけ。

- **サイズ**: Hadamard 境界で $\lvert D\rvert\le r^{r/2}\max\lvert a_{ij}\rvert^{r}$。$r=210$、成分が 1 桁なら $\lesssim10^{455}$ ⟹ **1 個の 455 桁整数**(4300 桁の行列とは桁違いに軽い)。
- **実務**: $D_i$ 自体は**多素数 modular 行列式 + CRT** で計算(各素数で $210\times210$ の $\bmod q$ 消去 = ミリ秒)。
- **経験則(予言ではない)**: 独立な 2〜3 個の $D_i$ の gcd は $d_r$ に急速に落ちる。k=12 の実測(単因子はごく小さい・(32,5) は単因子 5 一個)から、$g$ は**数桁**に落ちると見込む。落ちなければ段階 1 を数個追加。

### 2.2 段階 2: 各素数での**存在判定**($\bmod q$ 階数のみ・巨大数ゼロ)

$$\boxed{\ \#\{i:\ q\mid s_i\}\ =\ r-\mathrm{rank}_{\mathbf F_q}(A)\ }$$
**証明**: $A$ の Smith 形を $\mathrm{diag}(s_1,\dots,s_r)$ とすると $\bmod q$ での階数は $q\nmid s_i$ なる $i$ の個数。∎
⟹ **$q\mid g$ の各 $q$ について $\bmod q$ ガウス消去を 1 回**($210\times123{,}270$ の $\mathbf F_q$ 消去 ⟹ 成分は $<q$・メモリは $210\times123{,}270$ バイト級 $\approx26$ MB で足りる)。$r-\mathrm{rank}_q=0$ なら **$q$ は支持外(確定)**。

### 2.3 段階 3: **重複度と $q$-進価**(法 $q^N$ の Smith・成分 $<q^N$)

$q$ が支持に入った場合、$\mathbf Z/q^N$ 上の Smith 形(最小価ピボットのガウス消去)で $v_q(s_i)$ を全て決める。$N$ は $q^N>g$ で十分($s_i\mid d_r\mid g$)。
$$\boxed{\ \textbf{成分は常に }<q^N\le q\cdot g\ \textbf{ ⟹ 4300 桁は原理的に現れない}\ }$$

### 2.4 段階 1′(任意・より強い): **modular Smith 一発**

$m$ を $d_r$ の倍数(= $g$)として $\mathbf Z/m$ 上で Smith 形を計算すれば、$s_i\mid d_r\mid m$ ゆえ**全単因子が一度に復元される**(Storjohann 型)。成分は $<m$。段階 2・3 を包含するが、$m$ が大きいと遅い ⟹ **$g$ が数桁なら段階 1′ 一発、大きければ段階 2+3**。

## 3. (a) への回答 — 小成分の飽和基底が**どうしても要る**場合

| 手法 | 判定 | 理由 |
|---|---|---|
| **弱サイズ簡約**(先行行の整数倍を引く) | △ 部分的 | 膨張は「ピボット選択の悪さ」由来ゆえ改善はするが、**保証がない**(最悪は同じ) |
| **列ピボット順の工夫** | △ 同上 | HNF の膨張は本質的に非可換な繰り上がりの累積 ⟹ 順序で消えない |
| **純 python LLL(210×123,270)** | ✘ **非現実的** | LLL は階数 $d$・次元 $n$ で $O(d^5n\log^3B)$ 級。$d=210,n=1.2\times10^5$ ⟹ 純 python では**桁外れ**。**やらないこと**を推奨 |
| ★ **modular HNF**(法 $g$) | ○ | 成分が $<g$ に**保証つきで**抑えられる(Domich–Kannan–Trotter 型)。$g$ は §2.1 で既に手に入る |
| ★★ **「核として取る」** | ◎ **推奨** | $\ker$ は**自動的に飽和**($\mathbf Z^n\to\mathbf Z^k$ の核は飽和部分格子)⟹ 飽和化の手続きが**消える**。$\hat L=\ker(K)$、$K=$ 直交補空間の基底 $=\ker(A^{\mathsf T})$ |
| ★ **多素数核 + $p$ 進持ち上げ**(裁定の提案) | ○ **有効**・上記と併用 | $\bmod q$ で核基底 → Hensel/線形持ち上げ → 有理復元。**答えの成分が小さければ**少ない素数で復元でき、$4300$ 桁は現れない |

> ### ★ 設計提案(a の最終形)
> $$\boxed{\ \textbf{飽和基底は「行空間の HNF」ではなく「}\ker\ \textbf{の基底」として取る — 核は定義から飽和ゆえ、飽和化の膨張源が消える。}}$$
> 手順: ① $K:=\ker_\mathbf Z(A^{\mathsf T})$ を多素数 + 有理復元で構成(成分は $A$ の minor 程度で有界・Cramer)。② $\hat L:=\ker_\mathbf Z(K)$。③ 必要なら $\hat L$ の基底を法 $g$ の modular HNF で正規化。
> **注意**: これは「小さくなることを保証する」ものではなく「**膨張の主要因(飽和化のための連鎖的な整数除算)を回避する**」もの。成分の実サイズは $A$ の minor で決まる下限を下回れない。

## 4. $N_{13}$ 再構成(二巨大法)への含意

- 4300 桁の $B_{13}$ に依存した再構成は**設計から外す**。$N_{13}$ の成分が小さいなら、二素数 CRT の法は $2\max\lvert N_{13}\rvert$ を超えれば足り、**巨大基底は不要**。
- ⟹ **順序の入れ替えを提案**: 先に §2 で単因子を確定 → その情報で $N_{13}$ の成分サイズを見積る → 必要な法だけ CRT。
- **mod-$q$ レーンは非影響**(評価前還元)= 裁定の記載どおり ✔(§2 の全段階は mod-$q$ レーンと同じ計算資源で走る)。

## 5. 発注仕様 **SNF-MOD-13**(実装係へ・粒度確認済)

> 1. $A_{13}$($210\times123{,}270$)から**非特異 $210\times210$ 部分行列を 3 個**(列をランダムに、$\bmod$ 小素数で階数 210 を確認して採択)。
> 2. 各行列式を**多素数 modular + CRT** で厳密計算 → $g=\gcd(D_1,D_2,D_3)$ を出力(**桁数を報告**)。
> 3. $g$ の素因数 $q$ ごとに $\mathrm{rank}_{\mathbf F_q}(A_{13})$(全 123,270 列)を計算 → $r-\mathrm{rank}_q$ を出力。
> 4. $r-\mathrm{rank}_q>0$ の $q$ について $\mathbf Z/q^N$($q^N>g$)上の Smith で $v_q(s_i)$ を全出力。
> **カナリア**: 同一手順を **k=12** に適用し、既収の単因子(**(32,5) を含む**)を**完全再現**すること。再現しなければ停止・報告。
> **中止条件**: $g$ が 200 桁を超えて因数分解できない場合は停止して報告(段階 1 の小行列を追加して再試行の可否を司令塔判断へ)。
> **禁止**: HNF・LLL・飽和基底の明示構成(本追補の要点)。
