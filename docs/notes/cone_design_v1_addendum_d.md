# 1. PS-1 — CC-1 のパリティ補強

## 1.1 検分: **成立**(2 行)

> ### 系 CC-1a(candidate・本追補。**追補 C 補題 CC-1 の系として編入**)
> $k$ を偶数、$p$ を奇素数とする。$p\mid\mathrm{num}\bigl(\zeta(k)\pi^{-k}\bigr)$ かつ $p>k$ ならば
> $$\boxed{\ p\ \ge\ k+3\ }$$
> **証明.**
> (i) $p=k+1$ のとき $p-1=k$ ⟹ $(p-1)\mid k$ ⟹ **von Staudt–Clausen** より $p\mid\mathrm{denom}(B_k)$、すなわち $v_p(B_k)=-1<0$ ⟹ $v_p(\zeta(k)\pi^{-k})=v_p(B_k)-v_p(k!)<0$ ⟹ 分子に立てない。
> (ii) $p=k+2$ のとき、$k$ 偶ゆえ $p$ は偶数 ⟹ 奇素数でない(**空**)。
> ゆえに $p\ge k+3$。∎
> **自前検算**: $k=12,\dots,32$ の全偶重みで (i) の $(p-1)\mid k$ と (ii) の偶数性を確認 ✔(11/11)

## 1.2 ★★ 帰結 — 【CC-GAP-1】の正体が確定した

追補 C 補題 CC-1 は「$v_p(\mathrm{num}B_k)\le1$」という実測依存の仮定を置いていた(【CC-GAP-1】)。**系 CC-1a によりこの仮定の必要な場所が正確に特定できる**:

> ### 定理 CC-1★(candidate・本追補。**CC-1 の最終形**)
> $p$ 奇素数、$k$ 偶数($k\ge12$)。
> $$\boxed{\ p\mid\mathrm{num}\bigl(\zeta(k)\pi^{-k}\bigr)\ \Longleftrightarrow\ (p,k)\ \textbf{が非正則対}\quad\textbf{または}\quad \bigl(p\le k\ \textbf{かつ}\ v_p(B_k)>v_p(k!)\ \bigr)}$$
> かつ後者は $v_p(k!)\ge1$ ゆえ **$v_p(B_k)\ge2$**、すなわち $p^2\mid\mathrm{num}(B_k)$ を要する。
> **証明.** ($\Leftarrow$ 非正則対)$p\ge k+3>k$ ⟹ $v_p(k!)=0$ ⟹ $v_p(\zeta)=v_p(B_k)>0$ ✔
> ($\Rightarrow$)$v_p(\zeta)>0\Rightarrow v_p(B_k)>v_p(k!)\ge0\Rightarrow p\mid\mathrm{num}(B_k)$。$p>k$ なら 系 CC-1a で $p\ge k+3$ ⟹ 非正則対。$p\le k$ なら $v_p(k!)\ge\lfloor k/p\rfloor\ge1$ ⟹ $v_p(B_k)\ge2$。∎

> ### ★ 帰結(**PS-1 の主張の正確形**)

# 2. PS-5 — det カナリアの会計検分

## 2.1 骨格は正しい

命題 CONE-A′ の $\rho_k=e\circ C_k$、$C_k\in\mathrm{End}(\mathsf P_k^{\mathbf Z})$、$e$ 飽和(実測 $k=16..32$)。

> $e:\mathsf P_k^{\mathbf Z}\to M$ が**飽和埋め込み**(= 分裂単射)なら
> $$\mathrm{SNF}(\rho_k)=\mathrm{SNF}(e\circ C_k)=\mathrm{SNF}(C_k),\qquad \prod_i d_i=\lvert\det C_k\rvert .$$

> $$\Longrightarrow\ \boxed{\ p\mid d_i\ \text{なる }i\ \text{が在る}\ \Longrightarrow\ p\mid\det C_k\ }$$

## 2.2 ★ 補正 2 点(**札のままでは危険**)

> ### 補正 (i): 「$\det C_k$ の分子 $=$ こだま分子」は**仮定**

> ⟹ カナリアの前提として明示すること。**破れたら「非こだま素数の発見」ではなく「$\det C_k$ の同定の誤り」の可能性が先**。

> ### ★★ 補正 (ii): $\rho_k$ の**整性が UNKNOWN**(これが本質)

# 4. T1 定理化の当否と着手判断

## 4.1 ★★ 証明の鍵は **Kummer の無繰上り定理**(札の「二項単元」の正体)

T1 = 「$p>k$ なら ls 世界の全層の coker 捩れはこだま分で尽きる」。

> ### 観察 T1-a(本追補・**証明の芯**)
> 深さ 2 床 $\beta_k$ の行列成分は、$\bar\sigma_a=(-1)^{(a-1)/2}(\mathrm{ad}\,x)^{a-1}y$ の Ihara 括弧から出る **二項係数 $\binom{a-1}{j}$($a-1\le k-4$)** である。**Kummer の定理**: $v_p\binom nj$ = $j$ と $n-j$ を $p$ 進で足したときの繰上り回数。
> $$\boxed{\ n<p\ \Longrightarrow\ \textbf{繰上りゼロ}\ \Longrightarrow\ \binom nj\ \textbf{は }p\textbf{-単位}\ }$$
> $p>k>a-1$ ゆえ、**$\beta_k$ の全成分に現れる二項係数は $p$-単位**。
> ⟹ 札の「α(二項単元梯形)」の前半は**定理**である。

> ### ★ ただし梯形性(後半)は別仕事
> 全成分が $p$-単位でも階数保存は従わない(単位成分の行列でも行列式が $p$ で割れることはある)。必要なのは
> $$\exists\ \text{行・列の順序}:\ \beta_k\ \text{が下三角で対角成分がすべて }p\text{-単位}$$
> という**梯形性**。⟹ これが T1 床版の実質的な仕事。
> ★ **見込みは高い**: $\beta_k$ は $\le7\times15$ で閉形式があり、階数は $\lfloor(k-2)/6\rfloor$。$\bar\sigma_a\wedge\bar\sigma_b$ を $a$ の昇順に並べ、$X^{a-1}Y^{k-a-1}$ 型の「先頭項」を pivot に取れば、**先頭係数は $\pm1$ になる見込み**(最高次の項に二項係数が掛からない配置)。
