## 1. 真因: τ は braid 共役ではない(c だけずれる)

### 命題 1(B₃ 内の恒等式・**紙上証明あり**)

Δ := σ₁σ₂σ₁、δ := σ₁σ₂、c := Δ²、x := σ₁²、y := σ₂²、z := (xy)⁻¹ とおくと B₃ において

$$\mathrm{Ad}(\Delta): x \mapsto y,\ y \mapsto x \qquad\qquad \mathrm{Ad}(\delta): x \mapsto y,\ \boxed{y \mapsto z\,c}$$

**証明.** B₃ = ⟨a, b | a² = b³⟩(a = Δ, b = δ)を使う。実際 b⁻¹a = σ₁、ab⁻¹ = σ₂(braid 関係から直接)、a² = b³ = c(中心)。
- Ad(Δ): aσ₁a⁻¹ = a(b⁻¹a)a⁻¹ = ab⁻¹ = σ₂ ゆえ Ad(Δ)(x) = σ₂² = y。aσ₂a⁻¹ = a²b⁻¹a⁻¹ = b³b⁻¹a⁻¹ = b²a⁻¹ で、b²a⁻¹ = b⁻¹a ⟺ b³ = a² ✓ ゆえ = σ₁、Ad(Δ)(y) = x。**c-補正なし。**
- Ad(δ): bσ₁b⁻¹ = b(b⁻¹a)b⁻¹ = ab⁻¹ = σ₂ ゆえ Ad(δ)(x) = y。
  x = (b⁻¹a)²、y = (ab⁻¹)² より xy = b⁻¹ab⁻¹a·ab⁻¹ab⁻¹ = b⁻¹ab⁻¹·b³·b⁻¹ab⁻¹ = b⁻¹(aba)b⁻¹、ゆえに z = (xy)⁻¹ = b·a⁻¹b⁻¹a⁻¹·b、zc = z a² = b a⁻¹b⁻¹a b(a² 中心)。
  一方 Ad(δ)(y) = b(ab⁻¹ab⁻¹)b⁻¹ = bab⁻¹ab⁻²。
  よって主張は bab⁻¹ab⁻² = ba⁻¹b⁻¹ab ⟺ ab⁻¹ab⁻² = a⁻¹b⁻¹ab ⟺ a²b⁻¹ab⁻² = b⁻¹ab ⟺ b³b⁻¹ab⁻² = b⁻¹ab ⟺ b²ab⁻² = b⁻¹ab ⟺ b³ab⁻² = ab ⟺ a³b⁻² = ab ⟺ a³ = ab³ = a·a² = a³ ✓ ∎

**機械確認**: LINS(index ≤ 192)の N ⊴ B₃, N ≤ PB₃ **全 66 窓で 66/66**(V1・V2)。

### 系(バグの正体)

論文の τ ∈ Aut(F₂)(x↦y↦z↦x)は **Ad(δ) から c-成分を落としたもの**である。ゆえに

- **c ∈ N のとき** τ ≡ Ad(δ) (mod N) ⟹ τ は F₂/N_F₂ に降り、語をどう取っても同じ。実測 **16/16 の c ∈ N 窓で τ が降りる**(V3a)。
- **c ∉ N のとき** τ ≢ Ad(δ)。実測: c ∉ N の 50 窓のうち **40 窓で τ は F₂/N_F₂ に降りない**(W-C-p5 も idx192-s4 も降りない)。この 40 窓では **「τ を語レベルで適用して商で評価する」という手続きが shadow 座標 [m, f·N_F₂] の関数になっていない** — 同じ群元 f でも語を替えると値が変わる。

これは commit 9fcb893 の罠(簡約形は c ∈ N を暗黙前提)の**同族だが別箇所**である。9fcb893 は「θ/τ を商上の準同型として評価する近道」を禁じた。今回はその処方(語レベル評価)**自体が不十分**であることが判明した。

## 2. 補正則(実装がそのまま使える形)

### 命題 2(ずれの明示・**紙上証明あり**)

A := PB₃/N、τ̃ := Ad(δ)|_A、θ̃ := Ad(Δ)|_A(N ⊴ B₃ ゆえ**常に** A の自己同型として well-defined)。語 w ∈ F₂ の x-指数和・y-指数和を e_x(w), e_y(w)、総指数和を e(w) = e_x + e_y とすると A において

$$\tilde\tau(\overline w) = \overline{\tau(w)}\cdot c^{\,e_y(w)},\qquad \tilde\tau^2(\overline w) = \overline{\tau^2(w)}\cdot c^{\,e_x(w)}$$

したがって W := y^m f に対し

$$\boxed{\;R_{\tilde\tau}(m,f) \;:=\; \tilde\tau^2(W)\,\tilde\tau(W)\,W \;=\; R_{\text{naive}}(y^m w)\cdot c^{\,m+e(w)}\;}$$

**証明.** τ̃(x) = y = τ(x)、τ̃(y) = zc = τ(y)·c、c は中心 ⟹ 語の y-文字 1 個ごとに c が 1 個出る。τ̃²(x) = τ̃(y) = zc = τ²(x)·c、τ̃(z) = (τ̃(x)τ̃(y))⁻¹ = (y·zc)⁻¹ = c⁻¹(yz)⁻¹ = c⁻¹x ゆえ τ̃²(y) = τ̃(zc) = c⁻¹x·c = x = τ²(y)。W = y^m·w に対し τ̃(W) = (zc)^m τ̃(w) = z^m c^m τ(w)c^{e_y}、τ̃²(W) = x^m τ²(w)c^{e_x}。∎

### 正しい判定条件(2 つの等価な形)

> **(F2) 商規律【推奨】**: 語を一切使わず、**PB₃/N の中で**
> $$f\cdot\tilde\theta(f) = 1 \quad\wedge\quad \tilde\tau^2(y^m f)\,\tilde\tau(y^m f)\,(y^m f) \;=\; c^{\,m} \quad\wedge\quad \langle x^u, f^{-1}y^u f\rangle = F_2/N_{F_2}$$
> ここで θ̃ = Ad(Δ)、τ̃ = Ad(δ)。**c ∉ P_N の窓でも成立**(idx192-s4 は c ∉ P_N)。
