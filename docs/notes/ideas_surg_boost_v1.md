## 札 SB-1 — crown 分解: 検定 1 本 → primitive 商ごとの小検定の束(各検定の算術入力は位数 ≤ 6 の商で足りる)

## 札 SB-2 — Möbius 定量化: 二値 → 「欠損指紋」𝔐(A)(r はどの極大に見えるか)+ receipt 予算の逐次設計

**種**: 装置強化+定量化 / **一行主張**: 検定の出力を二値から **𝔐(A) = {A を含む極大の類}(欠損指紋)** へ拡張する — 指紋は **X/Φ 内で完全に計算可能**(M ⊇ Φ ゆえ A ⊆ M ⟺ AΦ/Φ ⊆ M/Φ)で、不足の「方向」を返す: 972 屋根なら**どの直線(4 値)に joint 像が潰れているか**。さらに Hall–Möbius(部分群束の μ)で「受診 k 本で mod-Φ 飽和する確率」が閉形式になり、**receipt 予算(SURG-A6)の逐次設計**(k 本で未飽和 ⟹ 欠損の証拠が定量化)が立つ。

**機構**: (i) 指紋の mod-Φ 完全性は 1 行(上記)。(ii) 指紋 ⟹ [X : AΦ] ⟹ **\|X∖A\| ≥ \|X\|(1 − 1/[X:AΦ]) の下界が無料**(mod-Φ 情報だけで反例の最小規模が出る — I-CEX-2(a) の塊構造の下界版)。(iii) Hall 1936 の Eulerian 関数: P(k 元が生成) = Σ_H μ(H,X)/[X:H]^k(X/Φ 上で計算・両商とも位数 ≤ 108 で即算)。帰無仮説 H0(= A = X・予想成立)下で receipt が窓体上 Chebotarev 等分布するなら、期待受診数 E = Σ_k (1−P(k)) が**事前に**出る ⟹ 「E を大きく超えて未飽和」が欠損のシグナルになる逐次検定。(iv) d(X) = d(X/Φ) 実測: K(9) = 2 本・972 屋根 = **3 本** — **最良選択なら receipt 3 元で屋根全体の生成が判る**(予算表の下限行)。

**前件**: (iii) の等分布は**モデル仮定**(Chebotarev の適用正当化 = 数学者前件・窓の分解体の同定込み)。(i)(ii)(iv) は標準。**何が新しいか**: Hall–Möbius は配達済+双子繊維で使用済(grep)— **算術像の欠損局在・receipt 予算の逐次設計への適用が未**。**破綻しそうな点**: receipt は「選べない」(Frobenius は来るものを受けるだけ)ので最良選択予算 d(X) は下限に過ぎず、等分布仮定が崩れる窓(分解群の偏り)では E が無意味になる。

**確信度序数: 3 / 6** / **回し先**: 数学者(等分布前件の紙)→ implementer(指紋関数+E の表を census に併設)。

## 札 SB-3 — 同変強化: χ-crown は無料(円分全射)⟹ 内容のある検定は「Kummer 直線/面の crown」だけに圧縮

**種**: 較正装置(追加軸)/ **一行主張**: crown 分解(SB-1)は陽性対照を**自動生成**する — 各極大類 c の代表 M_c 自身を「fake 算術像」として注入すると、**極大どうしに真の包含がない**(M ⊆ gM′g⁻¹ で両方極大なら同類)という 1 行事実により、**注入 c はちょうど検定 c だけを落とす = 較正行列が厳密に対角**。off-diagonal の発火はすべて実装バグの検出器になる。

**機構**: 検定 c′(A) = 「A が X/M_{c′} に不動点を持たない」。A = M_c のとき: 不動点あり ⟺ M_c ⊆ ある共役 gM_{c′}g⁻¹ ⟺(両極大)同類 c = c′。⟹ 期待行列 = 単位行列(窓ごと・crown 数 × crown 数: K(9) は 5×5・972 屋根は 8×8)。S2(非空虚性)の窓ごと較正(audit A3 の要求)が**設計不要・網羅的・数秒**で走る。

**前件**: なし(標準 1 行+SB-1)。**何が新しいか**: 裁定 961 の陽性対照規範・A3 は「人工反例を注入せよ」まで — **注入族の正準化(極大類)と対角性の証明つき期待行列は未**(grep: 較正行列/陽性対照の既存は個別設計のみ)。**破綻しそうな点**: M_c は「χ-両立」等の算術像らしさを持たない裸の部分群 — SB-3 の同変検定まで較正するには χ-切断を持つ注入族(M_c ∩ χ-型の細工)が別途要る(第 2 世代の較正として明記)。

**確信度序数: 2 / 6** / **回し先**: falsifier(S2 設計の検分)→ implementer(SB-1 バッテリーに較正モード同梱)。

## 付記 — 札間の結線と発火順の推薦(採否は司令塔)

- **結線**: SB-1(束)が土台 → SB-2(指紋・定量)と SB-6(対角較正)は束の直接の子 → SB-3(χ 無料化)が束の列を 3 分類(無料/1bit/有料)→ SB-4 は有料列の二段構え(⚠ 順序裁定待ち)→ SB-5 は束の profinite 極限 = 屋根の上の夢。研究者の原発案(I-CEX-6)→ joint 適用(1037)→ 本便で「束・指紋・無料化・二段・持ち上げ・較正」の 6 方向に強化、という系譜。
- **発火順の推薦**: ①SB-1 の S1 紙+SB-6 の較正(数学者 1 枚+implementer 数秒・prereg 非接触)② SB-3 の χ pin と 𝒵₂ ビット同定(軽)③ SB-2 の指紋関数を census に併設 ④ SB-4 は**上程のみ**(F3 順序検査が先・次屋根の prereg-native 化を本命に)⑤ SB-5 の P1〜P3 pin は 121 返書後の数学者 queue へ(1037 の mod-Φ 影の紙と同便が効率的)。
- **正直な総括**: 本便の強化はどれも「算術入力を消す」ものではない(SURG-A6 は不変)。買っているのは ①入力の**局在**(位数 ≤ 6 の商)②出力の**方向情報**(指紋)③無料列の**確定**(χ)④測定の**二段化**(安→重)⑤対象の**一本化**(pro-Frattini)⑥較正の**自動化** — 手術は「安くなる」のではなく「**どこが高いかが正確になる**」。そして高い場所は毎回同じ名前をしている: **Kummer 直線/面**。反例が住むならそこ、という照準の再確認でもある。
