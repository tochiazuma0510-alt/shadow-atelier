## 札 1【SPLIT-6E】83 窓の三分述語 — 型で落ちる/χ 容量非零/深い c∉N(現在線級・値からの推測)

## 札 2【Z-CENSUS-83】c の残存位数 z の一括測量 — 集落の新座標軸(現在線級・構成)
**種**: 測定装置。z(N) := ord(c·N) in B₃/N。ab 下界 z_ab = ord(6 mod e) = e/gcd(e,6) との比 δ = z/z_ab(≥1 の整数)を「c∉N の非可換深度」として 83 窓+M₅+N₅ で表化。
**新しさ**: WIN-CNOTN-J は e,j のみで z 未測(grep: repo に ord(c mod N) の census なし)。T(c)=c^{2m+1} は正典(Prop 3.2)ゆえ、z は shadow の c への作用の位数座標そのもの — 集落を「e だけの地図」から「(e,z) の地図」へ。
**一手目(機械・GAP 秒〜分級)**: lins_census cert の canonical_id_words から N を再構成(index≤2000 の coset enumeration)→ Order(c 像)。**無料の較正ゲート同梱**: 対照群の c∈N 窓 57 件で「c∈N ⟹ e|6」(札 1 の 1 行観察)を全数検査 — 1 件でも e∤6 なら観察が誤りで即停止。予言は凍結しない(裁定 828 の流儀 = 記述統計)。
**破れ方**: 全窓で δ=1(z が ab で説明し尽くし)なら新座標は退化 — その場合も「twin 集落の c∉N は全部 ab 現象」という否定的成果として台帳化できる。words→N 再構成の同一性(lins の N と同じ部分群か)は cert の canonical word 規約に依存 — 一手目の前に index/ab 不変量の一致で自己検査。

## 札 5【HEX-CM-BRIDGE】hexagon の c^m 項 → m への合同橋 — c∉N 窓固有の障害の有無(中間峰級・正典からの外挿)
**種**: 予想(紙)+ 計数実験。正典 (3.3)(3.4) の右辺には c^m 項が明示的に立つ(定義ノート L160-161)。c∉N では c^m≠1 があり得るので、「hexagon 成立が m に z 由来の合同条件を課す窓クラスがあるか」を問う。N₅ では raw hexagon が全 m で通り絞りは単元条件のみだった(C-3)— これが普遍(c^m 項は決して単独障害にならない)なら、その証明は GT 列挙の高速化補題(charming 条件だけ検査すればよい)に直結。非普遍なら「c∉N 固有の hexagon 障害」の初観測。
**新しさ**: c^m 項の挙動の系統的計数は N₅ 単点(C-3)のみ。83 窓級の母集団での「charming PASS ∧ hexagon FAIL」計数は未実施。
**一手目(機械同梱+設問)**: 札 3 の列挙時に窓ごと「charming PASS ∧ hexagon FAIL」の (m,f) 数を無料記録(N₅ では 0)。並行して数学者へ設問形:「(3.3)(3.4) の c^m 項が obstruction になる必要十分条件を e, z, N_ord で書けるか。x^{-m}c^m の x 側との絡みは f=1 切片に制限した弱形から分離できるか」。
**破れ方**: c^m 項は hexagon の両辺で相殺し常に vacuous、が正解の可能性(N₅ の 0 はその兆候)— それなら補題として確定させる価値に切り替わる(どちらに転んでも列挙コストの知見)。
