## 3. 依頼 2 — runner 間成分の大きさの上界(D)

### 3.1 上界の構成と読み方

同一版・同一 envelope の 2 run から、**「版を変えずに起き得た差」の 1 観測**が得られる。これを対数尺度で v9 → v10a の差と並べる(§0(A) の表)。

> **上界(D)**: 層費用の水準について、版内 1 対が示した差は **|ln 1.24779| = 0.2214**(= 24.8 %)。v9 → v10a の差は **|ln 0.81289| = 0.2072**(= 18.7 %)。
> **⇒ v9 → v10a の層費用差 18.7 % は、版を固定しても観測された 24.8 % の中に収まる。** 同じことが R 傾き(0.6319 対 0.6345)・p1/行(0.2512 対 0.3330)・producer_total(0.1678 対 0.2403)・six-phase(0.2115 対 0.2740)・checker_total(0.1838 対 0.2528)・切片(0.0277 対 0.0310)でも成立する。**7/7 で版間 ≤ 版内。**

### 3.2 この上界が言えないこと(明示)

1. **識別ではない。** 版内対は 1 対しかない。母集団の runner 間分散を推定しておらず、区間推定でもない。「版効果は存在しない」とは言えない。
2. **上界の向きは片側だけ。** 言えるのは「版間差は版内差を超えていない」であり、「版効果 ≤ X %」という数値上界ではない。真の版効果は打ち消し合っている可能性もある。
3. **runner の割当は制御されていない。** GitHub Actions の runner は割当が観測できないので、「版内差」は runner 差・cache 差・同時実行負荷差の混合である。**どの要因かは依然として未識別。**
4. **2301 の 3 つの理由はそのまま有効**: 異なる R の観測は同一条件の反復でない・等バイトから動的仕事量の同一性は導けない・同一版の再走は交絡を解消しない。

### 4.3 「両方を raw 系列に保持し『同一 n の 2 観測』として記録する」案の評価(結論なし)

**賛成材料**:
- **選択を要しない。** §4.1 が示すとおり、どちらか 1 本を選ぶ行為自体が結論を決めてしまう。

**反対材料 / 副作用**:
- **系列が n の関数でなくなる。** 残差系列に対する OLS は、平均を取る(分散情報を捨てる)か両点を使う(n=7 だけ重み 2 になり設計が不均衡)かを選ばねばならない。

- **他の n との比較不能性。** n=0..6 の各点は「たまたま引いた 1 本の runner」であり、n=7 の 2 点と対等ではない。**この非対称は、両方を保持しても解消しない。**

> **評価(D)**: 両方の保持は**記録としては正しく、当てはめの入力としては不均衡を持ち込む**。私の見立ては「raw 台帳には両方を残し、系列への当てはめは全 n が 2 観測以上になるまで行わない」が最も整合するが、**これは結論ではなく選択肢の評価である。裁定は司令塔に委ねる。**
