## 0. 何を照合するのか(一文)

`ob(f̄) = 0` の枝ごとに、**中心 C を掛けたファイバーの中に本物の持ち上げがちょうど `|ker Λ|` 個ある**
— これを **λ-shortcut 由来の重複度表**(F8 項目 3)と、**PcpGroup の積で直接確かめた個数**の
二系統で突き合わせる。項目 5 の「×8」はこの `|ker Λ|` のことであり、**定数として書き込まず毎回計算する**。

## 1. 数学(構成の根拠・3 行)

`g ∈ P` を `f̄` の標準持ち上げ(C-成分ゼロ)、`z ∈ C`(中心)とすると
`θ(gz)(gz) = θ(g)g · (1+θ)z`、`E_m 𝒩(gz) = E_m 𝒩(g) · 𝒩_C z`。すなわち **Ξ(gz) = Ξ(g) + Λ(z)**、
`Λ(z) := ((1+θ)z, 𝒩_C z)`。ゆえに本物の持ち上げの集合は `{z : Λ(z) = −Ξ(g)}` であり、
**空(ob≠0)か、`ker Λ` の torsor(ob=0、位数 `|ker Λ|`)かのどちらか**。これが照合すべき等式の全内容。

## 2. 実装手順(そのまま書ける粒度)

- **(S1) `LambdaOnC(z6, m)`**: `[ ModVec(z6 + ThetaOnCVec(z6), R), ModVec(z6*(I + S + S²), R) ]`。
  `S := SigmaOnCMat(m)`、`R := 2^(j-1) = 4`。返り値は 12 成分の平坦ベクトル(辞書キーに使う)。
- **(S2) `LambdaTable(m)`**: `z6` を `(ℤ/4)^6` 全 4096 元にわたり走査し、`Λ(z)` をキー、`z` のリストを値とする
  辞書を作る。**SNF は使わない**(この規模では悉皆が最も安全)。同時に `kerΛ := LambdaTable[0-vector]` を取得。
- **(S3) ファイバー元の構成**: `f̄` に対し `Ξ(f̄) := [q_θ, q_N] mod R` を **route-G の群積で**計算
  (`G3RouteGQTheta(f̄)` / `G3RouteGQN(f̄, m)`)。`fib := LambdaTable[ −Ξ(f̄) mod R ]`(未登録なら空)。
  ファイバー元は `g_z := G3ElemFromVec( G3PadTo21(f̄) + EmbC(z) )`、`EmbC(z)` は `z` の 6 成分を
  `CIdx21` の位置に置いた 21-ベクトル(C は P の中心なので積の順序は不問)。
- **(S4) 直接検査(M8 本体)**: 各 `g_z` について `Exponents(θ(g_z)·g_z)` と `Exponents(E_m σ²(g_z)σ(g_z)g_z)` を取り、
  **`AbarIdx21` 成分 ≡ 0 (mod 2^j = 8) かつ `CIdx21` 成分 ≡ 0 (mod R = 4)** を確認する
  (これが当該セル `A^{(j)}` での「= 1」の定義。既存 G3 の `G3CExtract` は C 成分しか見ないので**流用不可**、
  21 成分すべてを見る新関数を書くこと)。
- **(S5) 符号の決め方**: `Λ(z) = −Ξ` の符号を紙で決めようとしない。**(S2) の辞書と (S4) の直接検査が一致する
  向きを (M8-a) で実測して固定する。** ただし「解集合が `ob≠0` 側とちょうど相補になった」場合は
  符号バグではなく**設計の破れなので FAIL 報告**(勝手に符号を反転して PASS にしない)。

## 3. 予算配分(全数は不可・段階的に)

`|𝓛_m| = 512`・`ob=0` が 256 なので全数直接検査は 1 つの m で 4096 群積 — 現実的でない。三段に割る。

- **M8-a(torsor 律・必須・安価)**: `m ∈ {0,1,2,3}`、各 1 個の `f̄`、`z` は
  「C の基底 6 個 + `ker Λ` の生成元 2 個 + 混合 4 個」の 12 個。
  **PASS**: 全 48 ケースで `Ξ_group(g_z) = Ξ_group(g) + Λ(z) (mod R)`。群積 96 回、G3 と同規模。
- **M8-b(ファイバー実現・必須)**: `m ∈ {0,1,2,3}`、各 `m` で `ob=0` の `f̄` を 4 個
  (`f̄₀` と `f̄₀+κ_i`、`κ_i` は `λ_m(κ_i)=0` なる核生成元)。各々 `|fib| = 8` 元すべてを (S4) で直接検査。
  **PASS**: `|fib| = |ker Λ|` かつ 8 元すべてが両式で 21 成分ゼロ。群積 256 回。
- **M8-c(mass 恒等式・必須・群積なし)**: 各 `m` で `𝓛_m` の全 512 点について `fib` の空/非空だけを辞書引きで判定。
  **PASS(これが本体)**: `{f̄ : fib ≠ ∅}` が `ob_table` の `"0,0"` クラスと**集合として一致**し、
  `Σ_f̄ |fib| = |ker Λ| · mult_m("0,0")`。ob 式を使わずに可解性を再定義して突き合わせる形になっている。
- **M8-d(負の統制・必須)**: `ob ≠ 0` の `f̄` を各 `m` で 1 個取り、`fib = ∅` を確認し、さらに
  `ker Λ` の 8 元を実際に掛けて (S4) が**全て FAIL する**ことを直接群積で確認する
  (空虚な PASS でないことの証拠。これを欠くと M8-b は「常に通る検査」になりうる)。
- ※任意: 実掃引解禁後は M8-c の数値(`|ker Λ|`・`Σ|fib|`・`mult("0,0")`)を全 m で証明書に出す
  (群積は増やさない)。
