# 検算: SG(32,6) 新窓候補の B₃-許容性判定(+ G₄ 較正)

**発注**: 「SG(32,6) 新窓候補の B₃-許容性判定・裁定 19 追記」。`search/smallgroup32-scan.g` の悉皆走査で
判明した SmallGroup(32,6) = (C₂×C₂×C₂):C₄ の (4,4,4)-marked F₂-商(N₆=192、Aut-軌道 3 個 = 核候補 3 個)
が、窓(NFI_PB₃(B₃) の元)たりうるかを **B₃-許容性**(F₂ の外部自己同型 θ, τ が核を保つか)で判定する。

**スクリプト**: `search/sg32-admissibility.g`(実行: `.\gap.ps1 search\sg32-admissibility.g`、elapsed 172ms)
**証明書**: `certificates/a5/sg32_admissibility.json`

## 判定方式

marked pair (a,b)(⟨a,b⟩=G, ord(a)=ord(b)=ord(ab)=4)を核を構成せずに扱う: Aut(G) を marked pair の集合
に対角作用させ、軌道 = 核候補 1 個に対応する(1 軌道 ⟺ 1 核、既存走査の kernels=N_i/|Aut(G)| と整合)。

- **θ: x↦y, y↦x** が核を保つ ⟺ 変換後の対 (b,a) が (a,b) と**同じ Aut-軌道**に入る。
- **τ: x↦y, y↦(xy)⁻¹** が核を保つ ⟺ 変換後の対 (b,(ab)⁻¹) が (a,b) と**同じ Aut-軌道**に入る。

(c の扱いは PB₃=F₂×⟨c⟩ で c↦1 の窓であり自明・不要、発注どおり省略。)

軌道は `Orbit(AutG, pt, ActOnPair)`(GAP、ActOnPair(pt,φ)=[Image(φ,pt[1]),Image(φ,pt[2])])で計算し、
θ/τ 変換後の対がその軌道の要素集合に含まれるかで判定 — **軌道単位の同値判定であり、GAP の部分群比較
(Sol 罠 12 件のうち「GAP の部分群比較でなく marked factor map を使う」)には該当しない**。

## 判定文(機械事実のみ)

**SmallGroup(32,6) の 3 個の核候補は、いずれも θ/τ 両方を核に降ろせない(both_admissible が 3 軌道
すべてで FAIL)。したがって SG(32,6) 由来の (4,4,4)-marked F₂-商はいずれも B₃-許容でなく、窓
(NFI_PB₃(B₃) の元)の新候補にはならない。**

一方 G₄=SmallGroup(32,2) の唯一の核(既知の K̄⁽⁴⁾)は θ・τ 両方 PASS — 較正が想定どおり機能しており、
上記 G₆ の全 FAIL は実装バグではなくこの判定方式が実際に識別力を持っていることの傍証(較正が空虚な
PASS でないことの確認)。

## 注意点(断定はしない)

- 軌道 1 は θ のみ PASS・τ が FAIL という非対称な結果 — G₆ の構造(C₂³ の基底に対する C₄ の作用)と
  θ/τ の非対称性(θ は対合、τ は位数 3)の相互作用によるものと推測されるが、この報告は数値確定までで
  あり構造的説明は数学者・司令塔の判断に委ねる。
- N_i=192, kernels=3 という数字と Aut-軌道数=3 が一致することは事前の期待(kernels=N_i/|Aut|)どおりで
  あり、今回の軌道分割 (Orbit 関数の出力) 各サイズ 64 の合計 3×64=192 が N_6=192 と整合していることも
  確認済み(軌道分割の総和が全数と一致 = enumeration に漏れ・重複がないことの内部整合性チェック)。
