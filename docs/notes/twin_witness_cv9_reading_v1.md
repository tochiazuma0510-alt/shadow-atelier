## 発見した穴

**【重大 1】S-TW-6 カナリアが空虚 — 構造的に落ちない。** 走行スクリプトは `x^-1*(x*y)*y^-1 = 1` を評価するが、これは任意の群で成立する恒等式 a⁻¹(ab)b⁻¹=e。窓にも規約にも実装にも依存しない。実測: 忠実表現でも全窓でも TRUE、順序反転形は FALSE(両形は確かに分離する)— **しかしコードは落ちない方だけを評価する**。さらに τ/θ の実装を一切通らず、簡約済みの式を直書きしているため、較正すべき機構(語順規約 W-4)を通過していない。票 §5.3 (vi)/P-5 は予言外れ時の**第一診断**にこのカナリアを指定しているが、何も教えなかったはずである。

## 任務 3【予言超過の会計】

**7/7 は「7 回の独立な 50/50 的中」ではなく、同時に「測定の癖」でもない。** 正しい会計:

1. P-4 の 50/50 は**紙で決まるか**(MIRROR-OBSTRUCTION に使える特性巡回部分群を名指せるか)の話であって、結果の真の事前確率ではない。「紙で決まらない」を暗黙に「確率 1/2」と読んだのが誤り。
2. 基準率が**選択効果**で M1 側に強く偏る。ι は双子を無料で製造する: 層内で ι(N)≠N なら ι(N) は自動的に同型商をもつ別の census node。つまり「双子を持つ」は「ι-不変でない」から**従う**。census はまさに双子を持つ対象だけを選んでいる。この選択の下では M1 が帰無仮説であって驚きではない。
3. O-1+D-1 の下では M1 は「ありそう」どころか ι(N)≠N から**強制される**。機械の出力は実質 15 ビット「N は ι-不変か」だけ。実質的内容は**陰性側**: この層に**非鏡映(exotic)双子は一つも無い**(指数 ≤1000・c∈N・N≤PB₃)。
4. 数学の実態であって器械の癖でない証拠 = 識別力検査群(同一窓で self/partner が割れる・504/936 で誤相方は落ちる・陰性対照は正しく M0・窓あたり 11〜58 個の独立証人・規約誤りは全て M0 か大音量の失敗に倒れ、偽 M1 を作らない)。
5. 陰性読み(「exotic 双子なし」)の残存依存は census の同型判定。StructureDescription は同型不変量なので前置 filter で同型対を落とすことはなく、15 対は全て位数 ≤936<2000 で IdGroup 利用可(512/1536 でもない)。妥当だが**これは census 側(裁定 548)の依存であり本走が確立したものではない**。

⟹ run cert の `P4_note_per_裁定602`(「紙で 50/50 だった 7 対が全て M1 ⟹ 新しい紙証明の可能性」)は要訂正。紙証明が要るのは「この 7 対で ι(N)≠N」であり、面白い未解決は**陰性命題**(なぜ exotic 双子が無いのか)の方。

## 「cross-checked 付与を支持するか」

**支持する — ただし限定と 6 条件つき。** 支持する主張は次の狭い一文に限る: 「登録 L2 の 15 対それぞれで ι(N)≠N かつ ι(N)=K であり、補題 PIN-A(既在)+ 核同定 ker T₋₁,₁=ι(N) により [−1,1] ∈ GTSh(K,N) は非 settled GT-shadow、ゆえに N は非 isolated。最小指数 126。」条件: (a) W-a の欠落を明記(falsifier の独立検査で補填した旨、または両系統で再実行)(b) S-TW-6 カナリアの差し替えか撤回 (c) 帰属の訂正(PIN-A 既在) (d) P-2 を「定理」・P-3 を「一部演繹/一部未測定」へ格下げ (e) c∈N 限定と N₅ control の引用 (f) MC-1 を凍結 schema に戻すか v1.1 で改版。
