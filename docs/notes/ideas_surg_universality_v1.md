**一行主張**: crown を「**X-作用つき群の圏の単純対象**」として書けば、可換 crown(単純 𝔽_p[X]-加群)と非可換 crown(単純群の冪に X が推移的に絡む型)は**同じ圏の同じ概念の 2 つの係数**であり、全射検定の普遍形は両帯で同一(「各 monolithic primitive 商 X/R_c への合成が socle を覆うか」の epi 判定)。さらにこの検定は算術側で「**G_ℚ の埋め込み問題(核 = crown socle)の可解性**」に翻訳され、可換核 = Kummer(現行 receipt の理論的正体)/非可換核 = 逆ガロア本丸だが **rigidity・center-free 還元という部分技術の在庫がある問題型に名前が繋がる** — 圏論の言葉が買うのは、非可換帯が census に現れた瞬間に検定の**形**と receipt の**型名**が既に定義済みであること。

**機構**:
- **(i) 統一の器(有限群論の標準理論・自前知識)**: Gaschütz–Detomi–Lucchini の crown 理論は chief factor の X-同型類ごとに crown 商を与え、**可換/非可換の別は係数の別であって形の別ではない**。SB-1 の実装(アーベル crown = 指標 1 本・S₃ crown = 1 ビット)はこの一般形の下位 2 段であり、almost-simple crown が出れば「小さい原始置換表現上の不動点判定」として**同じ列の 3 段目**に並ぶ — たたき台 ① のとおり、統一は新設でなく**確認**(既製理論が両帯を最初から統一している)。
- **(ii) 算術への翻訳(たたき台 ②)**: A = im(ρ_N) が crown c を覆う ⟺ 合成 G_ℚ → X → X/R_c が socle を補って全射 ⟺ **埋め込み問題(X/R_c の socle 上の商への既知全射を X/R_c へ持ち上げる)の proper 可解性**。可換核なら可解性は H¹/H² + Kummer 理論の管轄 = **u_n 型 receipt は「可換核埋め込み問題の解の witness」という理論名を得る**(SB-3「高い場所は毎回 Kummer 直線」の圏論的な理由づけ)。非可換核(center-free 単純冪)なら **Z(核)=1 により H² 型のアーベル障害が消え、分裂埋め込み問題へ還元される古典事実**(Malle–Matzat 型の標準補題・自前知識・要 pin)が効く ⟹ **A6 予算表の「非可換列」の receipt 型が命名できる**(Kummer 類ではなく「分裂埋め込み問題の解の specialization データ」)。
- **(iii) 壁の凍結線との接続(たたき台 ③)**: P4(壁予想)は肯定解決済・**FV-WALL 哨戒の再開トリガー = 「非可解窓の算術像を読む道具の獲得(HS Prop 7 有限商翻訳等)」**(地図 P4 行・裁定 386)。非可解窓の算術像読みが「その窓の非可換 crown を A が覆うかの判定」なら、**本札の翻訳はトリガー語の別入口の候補** — ただし HS Prop 7 翻訳(層 (b) の cross-frame 検出器 = pentagon/(III) 可換性の検出)とは**対象が違う可能性が高い**(あちらは条件の検出・こちらは全射性の検定)ので、「同じ問題の別名か」は同一視でなく**設問**として数学者へ出す。先決の機械データ = **壁 4 窓(n=24/28/36/37)の窓群で X/Φ の crown census を回し、非可換 crown が実際に出るか**(出なければ (iii) は空振り — それ自体「壁窓でも検定は可解 crown で足りる」という朗報寄りの一級情報)。

**何が新しいか**: 「埋め込み問題」の語は委嘱 13(B4: 非巡回 C_P(w^u) ⟹ 非可換 H¹)・counterexample_hotspots(局所大域の機構翻訳)で既出 — **「crown 被覆 ⟺ 埋め込み問題可解性」の同値・SURG バッテリーの非可換列の receipt 型命名・壁再開トリガーへの結線は 0 hit**(crown-based = 0 hit・monolithic は grep 語リスト 1 件のみ)。

**破綻しそうな点(自己申告・強い順)**: ①**限界注記 1 の最強形が本札に効く**: center-free 還元は「障害が消える」であって「解ける」ではない — 分裂埋め込み問題の可解性は正則実現型の問いで**逆ガロア級**。圏論は形の統一と**問題の命名**までであり、非可換帯の算術の代金は可換帯より桁違いに高いまま(発注指示の限界注記をそのまま採用)②(ii) の同値は weak/proper 可解の別・Φ 段分解と crown 分解の順序交換の管理が要る — 「1 行同値」に見えて帰納の段組みに隙間が出やすい(数学者検分の主戦場)③壁 4 窓の「非可解性」は ker χ̃ の商の性質であって X/Φ の crown 型とは別の量 — census が可解 crown しか返さない可能性は十分ある ④壁窓の窓群構成が既存資産(P-WALL-2 系)でそのまま回るかは在庫未確認(回らなければ一手目が「在庫確認」に格下げ)。

**検証の一手目**: implementer = **壁 4 窓の crown census の在庫確認 → 回るなら census 実行**(非可換 crown の有無 = (iii) の先決データ・純群論・u/c 非接触)。数学者へ設問形 = 「crown 被覆 ⟺ 埋め込み問題可解性」の正確な言明 1 枚(weak/proper の別・crown ごとの帰納の段組み)+ center-free 還元の pin(自前再導出・外部文献が要るなら文献要請として司令塔へ)。
