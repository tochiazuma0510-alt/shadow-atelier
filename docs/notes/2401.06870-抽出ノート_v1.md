## 3. 射の定義(§3)【最重要・画像照合済】

### hexagon 関係式 mod N(p.10)
(m,f) ∈ ℤ × F₂、B₃/N 内の等式:
- **(3.3) σ₁^{2m+1} f⁻¹ σ₂^{2m+1} f N = f⁻¹ σ₁σ₂ x₁₂^{-m} c^m N**
- **(3.4) f⁻¹ σ₂^{2m+1} f σ₁^{2m+1} N = σ₂σ₁ x₂₃^{-m} c^m f N**

well-defined: (m,f) が満たせば (m + tN_ord, fh)(t ∈ ℤ, h ∈ N_{F₂})も満たす。

### Def 3.1(GT-pair)+ charming(p.11)
GT-pair = (3.3)(3.4) を満たす **(m + N_ord ℤ, f N_{F₂}) ∈ ℤ/N_ord ℤ × F₂/N_{F₂}** (3.5)。

## 8. charming の位置づけ(p.5, p.11)

先行 [5](ĜT 用・B₄ ベース)では charming は部分クラス(GTSh♥ ⊂ GTSh)。本論文は pentagon を落とした代わりに **charming 条件を最初から課す**(groupoid は 1 つ、GTSh と表記)。charming の効用: (i) 簡約 hexagon が成立し検証が F₂/N_{F₂} 内で閉じる、(ii) 可逆性(groupoid 性)、(iii) ĜT_gen の射影が常に charming(Prop 4.1)。
