## 1. (a) 段 C 演算の明示公式

### 1.1 定義(実装係が逐語実装できる粒度)

自由 Lie 環 $\mathrm{Lie}(X,Y)$($X=e_0$, $Y=e_1$)。**深さ = $Y$ の出現回数**(現行実装の規約と同じ)。

> ### 定義 C-1(Ihara 括弧)
> $f\in\mathrm{Lie}(X,Y)$ に対し **$D_f$ = 微分**を
> $$D_f(X)=0,\qquad D_f(Y)=[\,Y,\ f\,]$$
> で定める(テンソル代数へは Leibniz で一意に延長)。**Ihara 括弧**は
> $$\boxed{\ \{f,g\}\ :=\ D_f(g)\ -\ D_g(f)\ +\ [f,g]\ }$$

**規約の固定(正典から)**: 自然な変種を機械枚挙し、Brown (1.6) $\bar\sigma_{2n+1}=(-1)^n(\mathrm{ad}\,e_0)^{2n}e_1$ の下で (1.7) $\{\bar\sigma_3,\bar\sigma_9\}-3\{\bar\sigma_5,\bar\sigma_7\}=0$ を再現するかを判定した:

| 変種 | $D_f(Y)$ | $[f,g]$ 項 | (1.7) を再現するか |
|---|---|---|---|
| **V1** ★ | $[Y,f]$ | $+$ | ✔ **再現** |
| V2 | $[Y,f]$ | なし | ✘ |
| V3 | $[f,Y]$ | $+$ | ✘ |
| **V4** | $[f,Y]$ | $-$ | ✔ 再現(**$=-\mathrm{V1}$**・全体符号のみ違う) |
| V5 | $[Y,f]$ | $-$ | ✘ |

$\Longrightarrow$ **規約は全体符号を除いて一意**。**階数・比例性しか測らないので全体符号は測定に無関係**。
$\Longrightarrow$ ★ **【A-GAP-1】の「符号・正規化」部分は閉じた**(残余は §7 の $f_m$ 正規化のみ)。

> **なぜ $Y$ 側に作用するか(深さの整合)**: $D_f(X)=0$, $D_f(Y)=[Y,f]$ ゆえ $\mathrm{depth}\{f,g\}=\mathrm{depth}(f)+\mathrm{depth}(g)$。これが depth フィルトレーションを Ihara 括弧が保つ理由であり、Brown §1.3 の $\mathfrak{dg}^{\mathfrak m}=\mathrm{gr}_D\mathfrak g^{\mathfrak m}$ が定義できる根拠でもある。**$X$ 側に作用させる鏡像規約はこの整合を壊す** ⟹ 正典の枠組から排除される。

### 1.2 ambient word 上の逐語仕様(現行実装への差分)

現行実装は語(0/1 のタプル)の疎ベクトルを持っている。必要な追加は **$D_f$ の 1 本だけ**:

```
# D_f(g): 微分。 img := word_bracket({(1,):1}, f, p)   # = [Y, f]
def deriv(f, g, p):
    out = {}
    for w, c in g.items():                 # w = 語(タプル), c = 係数
        for i, letter in enumerate(w):
            if letter != 1: continue       # Y の位置だけ
            # w[:i] ⊗ [Y,f] ⊗ w[i+1:] を c 倍して加える(語の連結)
            out += c * concat(w[:i], img, w[i+1:])
    return out

def ihara_bracket(f, g, p):
    return deriv(f,g,p) - deriv(g,f,p) + word_bracket(f, g, p)
```
- `concat` は既存の `word_bracket` が内部で使う語連結と同じ演算。**新規の代数構造は不要**(次数 12 の Lyndon 基底も不要 — 既存の「ambient 語ベクトル上で階数を取る」方針がそのまま使える)。
- コストは無視できる($\sigma_9$ は 510 項・$[Y,\sigma_3]$ は十数項)。

$$\boxed{\ \{y_a,y_b\}\ =\ \sum_{k=0}^{b}\binom{b}{k}[y_k,y_{n-k}]\ -\ \sum_{k=0}^{a}\binom{a}{k}[y_k,y_{n-k}]\ +\ [y_a,y_b]\ }$$

## 3. 段 B も同じ誤り —(d) の判定

現行実装の段 B は `ed.word_bracket(sigma_3, sigma_9, p)` = **単純交換子**である。これは段 C より重い誤りである。

> ### 補題 C-2($\theta$ = $X\leftrightarrow Y$ 交換自己同型)
> $\theta f=-f,\ \theta g=-g$ なら $\ \theta\{f,g\}=-\{f,g\}$。
>
> **証明**: $\theta D_f\theta$ は微分で、$X\mapsto\theta(D_f(Y))=\theta[Y,f]=[X,\theta f]=-[X,f]$、$Y\mapsto\theta(D_f(X))=0$。一方 $D_f+\mathrm{ad}_f$ は $X\mapsto0+[f,X]=-[X,f]$、$Y\mapsto[Y,f]+[f,Y]=0$。よって $\theta D_f\theta=D_f+\mathrm{ad}_f$。ゆえに
> $\theta\{f,g\}=\theta D_f\theta(\theta g)-\theta D_g\theta(\theta f)+[\theta f,\theta g]
> =(D_f+\mathrm{ad}_f)(-g)-(D_g+\mathrm{ad}_g)(-f)+[f,g]
> =-D_fg-[f,g]+D_gf+[g,f]+[f,g]=-\{f,g\}$。∎
> (**機械照合**: $\sigma_3\times H_5$ の全基底で $\theta$-反対称を確認。)

> ### 命題 C-1(単純交換子は $H$ の外に出る)
> $f,g$ が $\theta f=-f,\ \theta g=-g$ を満たすとき、**単純交換子**は $\theta[f,g]=[\theta f,\theta g]=[-f,-g]=+[f,g]$、すなわち **$\theta$-対称**。$H_k$ の定義は $(I+\theta)h=0$($\theta h=-h$)ゆえ、$p\ne2$ で
> $$[f,g]\in H_{k+l}\iff[f,g]=0.$$
> **系**: 実測は $A_{12}=2$($\ne0$)を報告した ⟹ $[\sigma_3,\sigma_9]\ne0$ ⟹ $\;[\sigma_3,\sigma_9]\notin H_{12}\supseteq\mathcal S_{12}$。∎
> (**機械照合**: $\sigma_3\times H_5$ で単純交換子が $\theta$-対称になることを確認。)

理由は 3 本、いずれも**検疫以前の問題**(値の信頼性ではなく**測定対象の同一性**の問題・CV-9 型):

### 7.2 【文献要請 C-1】(**高優先**)— 合同式は深さ 6 以上に伝播するか

- **困難**: P-C-4($A_{12}@691=1$)の正否は「$\{\tilde\sigma_3,\tilde\sigma_9\}-3\{\tilde\sigma_5,\tilde\sigma_7\}\equiv0\ (691)$ が**全深さ**で成立するか」に等しい(補題 C-5)。逐語ノートが確保しているのは **depth 5 まで**で、その根拠 **proposition 6.4(depth-parity)の内容が逐語ノートに無い**。
- **欲しい結果の型**: (i) Brown 1301.3053 **proposition 6.4 の主張文**(逐語)— とくに「重み $N$・深さ $d$ で $N\not\equiv d$ の成分が消える」型の言明かどうか。(ii) §8.5 の $\tilde\sigma$(canonical lift)の**定義**と、その合同が**どの $\mathbb Z$ 格子上の言明か**(逐語ノート §3.2 が UNKNOWN と記録した点)。(iii) 「depth 5 まで」が**技術的限界**なのか**それで十分**なのか(重み 12 で深さ 6 以上の成分が構造的に消えるなら十分)。
