> ### ★★ $L_{12,4}=0$ の正体は**自明**である(Brown §7.4 の事後解剖)
> $12$ を 4 個の奇数 $\ge3$ の和に書く方法は $3{+}3{+}3{+}3$ **のみ**。1 生成元だけの自由 Lie 代数は次数 $\ge2$ で消える ⟹ $\sigma$ 長 4 の空間が**そもそも 0 次元**。
> $$\boxed{\ \textbf{Brown の「4 重 Ihara 括弧が全射でない最小例」は、分割の自明な欠乏であって深い現象ではない。}\ }$$
> ⟹ ★ **P-F-0(重み 16 で $L^{(4)}=0$)の失敗の事後解剖が完了**: 重み 16 には分割が **2 つ**($3{+}3{+}3{+}7$, $3{+}3{+}5{+}5$)あるので、$0$ になる理由が最初から無かった。**「重み 12 で 0 だったから重み 16 でも 0」という類推が、次元の勘定を見れば即座に否定できた**。⟹ 教訓: **類推の前に分割を数える。**
> ★ **実測との一致**: 重み 16 の実測 $\dim L=2$ = 上界 2 ⟹ $\sigma$ 長 4 の自由 Lie から $\mathrm{ls}_4$ への写像は**重み 16 で単射** ✔。他の重みでの単射性は **UNKNOWN**(段 W-b で測る)。

> $$\boxed{\ k\ge14\ \textbf{の全重みで }L_{k,4}\ne0\ \Longrightarrow\ \textbf{QUOT-L(商での判定)は全重みで必須。}\ }$$
> ($k=12$ だけが例外で、そこでのみ $e_{12}$ が canonical — 追補 A §4.2 ②-3 で使った事実。)

## 1.5 (d) 判定基準と再現コマンド

> ### 判定基準(**次元で分岐**)
> - **$\dim\mathsf P_k=1$**($k=16,18,20,22,26$): $e(\mathsf P_k^{\mathbf Z})$ は 1 本のベクトル $\mathbf v$。
> $$\boxed{\ \textbf{飽和}\iff \gcd(\text{の全座標})=1\ }$$
> ⟹ $\mathrm{coker}(\rho_k)_{\rm tors}$ の位数 $=c_k\cdot\gcd(\mathbf v)$ の分子部分。**超過** $=\gcd(\mathbf v)$。
> - **$\dim\mathsf P_k=2$**($k=24,28,30,32$): $e(\mathsf P_k^{\mathbf Z})$ は $2\times N$ 整行列 $E_k$。
> $$\boxed{\ \textbf{飽和}\iff \mathrm{SNF}(E_k)=\mathrm{diag}(1,1)\ }$$
> ⟹ 単因子 $(d_1,d_2)$、$d_1\mid d_2$。**超過** $=(d_1,d_2)$ が $(1,1)$ でない分。
> ★ **この判定に $\dim(\mathrm{ls}_4)_k$ は不要**(ambient 座標で gcd/SNF を取るだけ)⟹ **【CONE-GAP-3】に阻まれない**。

**再現コマンド**(§1.1–§1.4 の全数値):

from fractions import Fraction as F
from math import gcd,factorial
from functools import reduce
import math,random
def bern(n):
 A=[F(0)]*(n+1)
 for m in range(n+1):
  A[m]=F(1,m+1)
  for j in range(m,0,-1): A[j-1]=j*(A[j-1]-A[j])
 return A[0]
def mu(n):
 r=1;d=2;m=n
 while d*d<=m:
  if m%d==0:
   m//=d
   if m%d==0: return 0
   r=-r
  d+=1
 if m>1: r=-r
 return r
def multiWitt(ns):
 n=sum(ns); G=reduce(gcd,ns); s=0
 for d in range(1,G+1):
  if G%d: continue
  num=factorial(n//d)
  for x in ns: num//=factorial(x//d)
  s+=mu(d)*num
 return s//n
def parts(k,c,mv=3):
 if c==0: return [[]] if k==0 else []
 out=[];a=mv
 while a*c<=k:
  for r in parts(k-a,c-1,a): out.append([a]+r)
  a+=2
 return out
def dimL(k,l):
 t=0
 for P in parts(k,l):
  m={}
  for x in P: m[x]=m.get(x,0)+1
  t+=multiWitt(sorted(m.values(),reverse=True))
 return t
def dimS(k): return k//12-1 if k%12==2 else k//12
for k in range(12,33,2):
 print(k,dimS(k),dimL(k,2),dimL(k,3),dimL(k,4),abs(bern(k).numerator))
"

## 2.3 (103,24) の 2 次元こだまの形

$\dim\mathsf P_{24}=2$ ⟹ $\rho_{24}$ は $2\times N$。$103\mid\mathrm{num}(B_{24})$。

> ### 予言 **P-CONE-6**(凍結)
> $$\boxed{\ \mathrm{rank}_{\mathbf F_{103}}\rho_{24}=1\quad(\textbf{103 は 2 本の単因子のうち「大きい方」}d_2\ \textbf{だけを割る})\ }$$
> **根拠**: Eisenstein 合同 $f\equiv E\ (\bmod\ \mathfrak p)$ は Hecke 体の**素点 $\mathfrak p$ ごと**に起きる。$103$ が Hecke 体で**分裂**していれば 2 つの素点のうち 1 つだけが合同を担う ⟹ 階数落ちは 1。
> **自前計算(判別式は要 pin)**: 重み 24 の Hecke 体を $\mathbf Q(\sqrt{144169})$(RA-6 の記憶値・**要 pin**)とすると $\left(\frac{144169}{103}\right)=+\mathbf1$ ⟹ **$103$ は分裂** ⟹ 上の予言と整合。
> **対抗枝**: $\mathrm{rank}_{\mathbf F_{103}}\rho_{24}=0$(両単因子が $103$ で割れる)⟹ $103$ が惰性か、合同が両固有形式に同時に効く ⟹ **判別式の pin が誤り、または機構の理解が誤り**。
> ⚠ **【CB-GAP-2】**: $144169$ は未 pin。予言 P-CONE-6 の**根拠**は pin に依存するが、**予言そのもの(rank 落ち 1)は pin なしで検定できる**。
