## 1. 発見(機械的事実)

較正対象 32 元(K^(3) の 12 元 = `certificates/K3.v1.json` の `shadows` + N_A の 20 元 =
`certificates/A1.v2.2.json` の `settled_witness.detail`)の各 `f_word`(生の自由群語、`[["x",±1],["y",±1],...]`)
について、abelianization(x の指数和, y の指数和)を計算すると:

- **K3(12元)**: abelianization = (0,0) となるのは **4元のみ**(index 6,7,10,11 — いずれも `[x,y,x⁻¹,y⁻¹]` 型)。
  残り **8元**は非ゼロ(例: index 2 の `f_word=[x,x,y⁻¹,y⁻¹]` は `(X,Y)=(2,-2)`)。
- **N_A(20元)**: abelianization = (0,0) となるのは **2元のみ**(index 0,1 — 空語)。
  残り **18元**は非ゼロ(例: index 2 の `f_word=[y,x⁻¹]` は `(X,Y)=(-1,1)`)。

**合計 32 元中 26 元で、生の自由群語としての abelianization が非ゼロ** — すなわち
これらの `f_word` は生の自由群 F₂ の元として **[F₂,F₂](交換子部分群)にすら属していない**。

再現: `python scratchpad/check_ab.py`(スクラッチ・簡易版。恒久化はしていない)。

## 2. 原因(定義の読み直し)

`docs/week1-定義ノート.md` line 164(charming の定義):

> **charming**: 2m+1 が (ℤ/N_ord)^× の元を代表 かつ **fN_F₂ ∈ [F₂/N_F₂, F₂/N_F₂]**。

charming が要求するのは **有限商 F₂/N_F₂ における f の像**が商の交換子部分群に入ることであり、
**生の自由群語 f 自体**が F₂ の交換子部分群 [F₂,F₂] に入ることではない。この二つは厳密に異なる条件で、
後者は前者よりずっと強い(前者 ⊂ 後者 は成り立たない一般に)。

同ノート line 167 の「簡約 hexagon(Prop 3.4)」は明示的に **「f ∈ [F₂,F₂] 前提」**と書かれている —
これは探索器側のショートカット手法の前提条件であり、charming の定義そのものではない。
cert に格納された `f_word` は **coset 代表**(f N_F₂ の一つの代表元)であり、
その代表元固有の Magnus 展開係数は N_F₂ の取り方に依存する **非不変量** である。

**論理的には**: charming の定義から、任意の charming f について
∃ g ∈ γ₂(F₂)(生の自由群の意味での本物の交換子部分群)、n ∈ N_F₂ で f = g·n が成り立つ
(charming ⟺ f ∈ γ₂(F₂)·N_F₂)。しかし **この g を f から機械的に取り出すには N_F₂ の具体的な
生成元・関係式(または帰属判定手続き)が要る** — 生語の Magnus 展開だけでは不可能。

## 3. なぜ「代替として生語係数を記録する」(選択肢 b)を採らなかったか

司令塔裁定より: 生語 Magnus 係数は N_F₂ 依存の**非不変量**であり、これを「較正段の生データ」として
cert に載せることは、**δ 表事件と同型の「読む者だけを騙す飾り」**になる(値はあるが意味がない数を
機械記録として残すと、後で「c₂ の較正結果」として誤引用されるリスクを生む)。
⟹ **値の出力はゼロのまま、この閉塞そのものを記帳して終了する**のが正しい安全側の選択。

## 4. 必要な数学設計(次波・数学者委嘱への入力)

c₂(f) の**有限商版**を正しく定義・機械化するには、以下が要る(実装作業ではなく**数学の定義設計**):

1. **窓ごとの F₂/N_F₂ の具体構成**: K3 窓(`certificates/K3.v1.json` の `conjugator-triple` 型 kernel_cert)
   と N_A 窓(A5 への x↦X, y↦Y 写像)それぞれについて、F₂/N_F₂ を具体的な有限群として
   (生成元 x̄,ȳ・関係式、または GAP で構成可能な表示として)特定する。
2. **f の有限商への正しい落とし方**: 与えられた `f_word`(coset 代表)を F₂/N_F₂ の元として評価し、
   それが γ₂(F₂/N_F₂) の元であることを確認する手続き(charming 条件の再検算に相当)。
3. **γ₂/γ₃ の有限版 c₂ の定義**: (F₂/N_F₂) の下降中心列 γ₂/γ₃(有限巡回群、位数 d)における
   f の像の類として c₂(f) mod d を定義し、これが coset 代表の取り方に依らない(= 真の不変量である)
   ことを示す(または既知定理から従うことを示す)。
   - d 自体は窓ごとに異なりうる有限量で、`docs/notes/fake_void_v1.md` A.4 point 4 が示唆する
     「c₂ は有限商では ℤ/d に落ちる」の d の正体がこれ。
4. **CV-13 との整合**: 本ノート添付の orientation anchor(`c2_of([x,y])=+1` かつ `c2_of([y,x])=-1`、
   自己逆元でない証人での round-trip)は生語 Magnus 展開の**符号規約**を固定するものであり、
   有限商版が確定した後もこの規約(x が y に先行する向きを正とする)をそのまま継承できる設計が望ましい。
