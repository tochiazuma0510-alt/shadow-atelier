## 2. 基本関係式(1.10)–(1.13)(p.4 画像で全文字照合)

- **(1.10)** σ₁Δ = Δσ₂, σ₂Δ = Δσ₁, σ₁⁻¹Δ = Δσ₂⁻¹, σ₂⁻¹Δ = Δσ₁⁻¹
- **(1.11)** σ₁x₁₂σ₁⁻¹ = σ₁⁻¹x₁₂σ₁ = x₁₂, σ₁x₂₃σ₁⁻¹ = **x₂₃⁻¹x₁₂⁻¹c**, σ₁⁻¹x₂₃σ₁ = **x₁₂⁻¹x₂₃⁻¹c**
- **(1.12)** σ₂x₁₂σ₂⁻¹ = **x₁₂⁻¹x₂₃⁻¹c**, σ₂⁻¹x₁₂σ₂ = **x₂₃⁻¹x₁₂⁻¹c**, σ₂x₂₃σ₂⁻¹ = σ₂⁻¹x₂₃σ₂ = x₂₃

## 3. Δ, δ 型の元 — 論文での出現と導出値

**出現状況**: **Δ := σ₁σ₂σ₁ は論文の記号**(§1.1 p.4 の定義表示。p.11 の (3.7) 直後にも「where Δ := σ₁σ₂σ₁」と再掲)。**δ := σ₁σ₂ という命名は論文に存在しない**。

**B₃ の表示**: Prop 3.2 の証明冒頭(**p.11**)に「Since **B₃ = ⟨σ₁, σ₂ | σ₁σ₂σ₁ = σ₂σ₁σ₂⟩**, it suffices to verify that …」— ページ画像で照合済み。braid 関係 σ₁σ₂σ₁ = σ₂σ₁σ₂ を以下 (BR) と書く。

**導出値**(論文に無い主張。すべて上記表示のみから):

- **(D1) σ₁ = δ⁻¹Δ, σ₂ = Δ⁻¹δ²**(自由簡約のみ・関係式不要):
  δ⁻¹Δ = σ₂⁻¹σ₁⁻¹·σ₁σ₂σ₁ = σ₁。Δ⁻¹δ² = σ₁⁻¹σ₂⁻¹σ₁⁻¹·σ₁σ₂σ₁σ₂ = σ₂。
  ⇒ σ₁, σ₂ ∈ ⟨Δ,δ⟩ ゆえ **B₃ = ⟨Δ, δ⟩**。
- **(D2) δ³ = Δ² = c**: δ³ = (σ₁σ₂)³ = (σ₁σ₂σ₁)(σ₂σ₁σ₂) =_{(BR)} (σ₁σ₂σ₁)(σ₁σ₂σ₁) = Δ² = c(最後は p.4 の定義)。braid 関係を **1 回**使用。
- **(D3) trefoil 表示との整合**: φ: ⟨a,b | a²=b³⟩ → B₃, a↦Δ, b↦δ は well-defined(関係 a²=b³ ↦ Δ²=δ³ は (D2))。逆向き ψ: B₃ → ⟨a,b | a²=b³⟩, σ₁↦b⁻¹a, σ₂↦a⁻¹b² は well-defined:
  σ₁σ₂σ₁ = (b⁻¹a)(a⁻¹b²)(b⁻¹a) = b⁻¹·b·a = a、σ₂σ₁σ₂ = (a⁻¹b²)(b⁻¹a)(a⁻¹b²) = a⁻¹b·b² = a⁻¹b³ = a⁻¹a² = a — 一致(a²=b³ を 1 回使用)。
  φ∘ψ, ψ∘φ は生成元上で id((D1) と定義から自由簡約)。⇒ **B₃ ≅ ⟨a,b | a²=b³⟩、a=Δ, b=δ 対応** ✓
