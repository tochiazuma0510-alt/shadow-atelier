# 文献ゲート翻訳メモ — ε=0 機構(【GAP-1】)への外部機構の降ろし v1

**状態札: 司令塔翻訳・candidate**(2026-07-30。出典 = `ops/scout_report_structthm_20260730.md`(遠征報告・書誌のみ)。本メモが数学者へ渡してよい唯一の形 — 論文原文は関所預かり)

## 1. 遠征の収穫(司令塔の読み)

標的だった「自然な対合 ⟹ C₂ 中心拡大分裂」の**一般定理は存在しない**(遠征の負の結果 — 一般には偽)。代わりに使える「理由の型」が 3 つ:

- **(型 I・odd-order 論法)**: extraspecial 2-群の正規化群拡大(量子情報の Clifford 群)で「分裂 ⟺ 4∤|A|・|A| 奇なら障害恒等消滅」という形の定理がある(Galindo 2026 Thm 1.1/Prop 3.2・Griess 1973 が正典)。
- **(型 II・二次形式)**: Q アーベルのとき ε は持ち上げの位数で読める二次形式 Q(x)=x̃² — 「各元が対合(正しくは同位数元)に持ち上がるか」に還元。
- **(型 III・現象の同型)**: Guillot の **GT₁(PSL(2,q)) ≅ (初等アーベル 2-群)×(D₈ のコピー数個)** — 我々の C_N×D₈ 観測と現象が同型。**ただし同名別物ゲートが正面にある**(Guillot の GT は別定式化 — B₃-gentle との定義橋が未架橋)。

## 2. 司令塔の突合(翻訳の一工夫 — 鵜呑みにしない)

**型 I の字面はうちの設定に合わない。** 我々の拡大は 1 → Z(S)=C₂ → C_G(S)/A → Q → 1 で、|Q| = φ(N):

| 窓 | Q | 4 と |Q| | 実測 ε |
|---|---|---|---|
| A16 | C₁₀ | 4∤10 | 0 |
| A18 | C₁₂ | **4\|12** | 0 |
| A20 | C₂×C₄ | **4\|8** | 0 |

「分裂 ⟺ 4∤|A|」をそのまま読むと A18/A20 は**非分裂のはず**が、実測は分裂。⟹ **輸入すべきは定理の主張でなく証明の方法**(障害がどの部分群に台をもつかの分析)。字面輸入は禁止。

**型 II は STR-1.6 と同じ山の別面。** 巡回 Q₂ = ⟨q⟩ に対し「C₂ 拡大分裂 ⟺ q が同位数で持ち上がる」— W4 の系 STR-1.6(u=−1 層の involution 判定)はこの一般原理の N_ord 窓での具体形。**つまり文献の型 II は STR-1.6 の正当性を外から支持する**(新情報というより検算)。

**残る本命は「ε の閉形式」**: 巡回の場合を SL(2,ℤ_N) の表示から初等的に決める手法(Korbelář–Tolar 型)を、Q ≤ (ℤ/N)^× が C₂ に(自明係数で)効く我々の設定に移せれば、**ε(窓) の式**が立つ — それが【GAP-1】の解(なぜ 3 窓とも 0 か)に最短。

## 3. 数学者への設問(この 2 問だけ・論文参照不要の自己完結形)

- **【LG-1】** 巡回 Q に対する一般原理「1→C₂→G̃→Q→1 分裂 ⟺ Q の生成元が G̃ に同位数で持ち上がる」を我々の拡大(G̃ = C_G(S)/A)で正式化し、**三窓の実測 ε=0 を「持ち上げの位数」の言葉で言い直せ**(A20 は Q 非巡回 — C₂×C₄ の各直因子生成元での条件に分解できるか、それとも二次形式の交差項が要るか、を明示)。
- **【LG-2】** その言い直しから **ε(窓) の閉形式候補**を立てよ: 入力 = (N_ord, t, パリティ ε_窓, Q の構造)、出力 = ε ∈ H²(Q;C₂)。GT-shadow の算術(R_τ・f θ̃(f)=1・(3.53))のどこが「持ち上げの位数」を強制するかの特定が【GAP-1】の解になる。仮説の段階でよい(candidate 札・検証実験の形まで)。

**注意**: 型 III(Guillot)は定義橋(同名別物)未架橋のため本メモでは設問にしない — 橋の設計は司令塔が別途(reader 委嘱の可否含め)判断する。凍結済み梯子予言(41b8698)には触れない — 本設問は既測定の三窓のみを対象とする。
