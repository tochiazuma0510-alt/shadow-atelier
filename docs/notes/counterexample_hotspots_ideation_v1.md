## 0. 総論 — 今夜の帰結を「装置の限界地図」として読み直す

BH-α(NW(7) の 42 全算術・裁定 580)と GREEN-A(裁定 578)が確定させたのは、単に「そこに居なかった」ではない。**円分 graded 軸・深さ方向の各 1 次元(depth 1)では、像を強制する装置が四重に張られていて、証人の居場所が「大予想の反例」まで後退する**という構造である。装置は 4 つ:

- **(装置 i)** χ_vir 全射+複素共役の錨(SUP-1・c=[−1 層, 1])— どの窓でも層方向は必ず埋まる。
- **(装置 ii)** Soulé–Kurihara 供給(κ_w mod ℓ 非消滅)— graded の各奇重み 1 次元を埋める。
- **(装置 iii)** Herbrand–Ribet 反転(GREEN-A)— (ℓ, ℓ−w) 正則 ⟹ (装置 ii) が無条件発火。
- **(装置 iv)** Vandiver 検証(ℓ < 2³¹)— 既知不規則対も緑に戻す。

ゆえに「制約を外して狩る」の合理形は一つしかない: **この 4 装置のどれかが構造的に沈黙する直交方向へ出る**。沈黙の型は 5 つあり、以下の 5 札がその各々の最小実例である。

| 札 | 沈黙する装置 | 沈黙の型 | 規模 |
|---|---|---|---|
| 1 | (ii)(iii) | **係数の病理**: ℓ=3 は Kurihara の明示除外点かつ不規則対の定義域が空 | 現在線級 |
| 2 | (ii)(iii)(iv) | **窓の埋め込み非対称**: 装置が「商の抽象群」しか見ないのに像は B₃ 内の位置に依存 | 現在線級 |
| 3 | (ii) の下流(u/Kummer 装置) | **非合同帯**: cusp の円分性(G6b 前件)が保証されない | 中間峰級 |
| 4 | 持ち上げの局所大域 | **Grunwald–Wang 特異帯**: 局所条件全通過・大域不在の唯一の古典実証帯(2-primary C₈) | 中間峰級 |
| 5 | (ii)(iii) の**深さ 2 版が不在** | **モジュラー帯**: 偶重み層は交換子供給のみ・cusp form が供給を削る | 夢級 |

**単数で答えるなら**: 「数学的に最も住みやすい」のは**札 5 の方向(depth ≥ 2・cusp form の住所)**である — 数論史でアーベル的統制(= 装置 ii/iii の世界)が破れた場所は常に cusp form の出現点だった(Ribet の Herbrand 逆・Eisenstein ideal。出所: 自前知識からの類推)。「うちの装置で近づける範囲で最も住みやすい」のは**札 3(非合同 PSL(2,8) 窓)** — 在庫済み・上界実測済み・下界装置が構造的に貧しい、の三拍子が揃う唯一の現物である。

共通則を一つ先に言う: (装置 i) は全窓で生きるから、**どの札でも証人候補は ker χ_vir 側(層 0 の A 成分側)にしか住めない**。BH-1 が NW(7) で示した「争点は A ∩ Im の部分加群格子」という形は、狩場を変えても不変の照準線である。

## 札 1 【L3-BLIND】ℓ = 3 帯 — 今夜の全証明装置の共通死角(NW(4,3) / NW(6,3))

**規模: 現在線級 / 出所: 裁定 576 の除外条項の裏読み+構造からの外挿**

1. **主張の種(予想+監査)**: 場所 = **NW(d,3)(d=4 なら宇宙 2·3⁶ = 1,458 対・即悉皆可能)**。予想: BH-1 の ℓ=3 版(二値定理)は成立するが、**残る 1 ビット(gr₃⊗F₃ 非消滅 = κ₃ mod 3)は今夜の兵器庫のどれからも出ない**。すなわち NW(3) は「BH-α 型の勝ち筋が文献 1 ビットで閉じない最小の窓」= 装置の完備性が最初に破れる地点。あわせて監査指摘 1 件: **GREEN-A の判定式は ℓ=3 で空虚に真**(不規則対の定義域 2 ≤ k ≤ ℓ−3 が ℓ=3 で空集合 ⟹ 「不規則対でない」が内容ゼロで成立し、緑を返すが根拠の Herbrand–Ribet は何も言っていない)。
2. **なぜそこに住めるか(機構)**: 三重の沈黙が重なる唯一の素数。(a) **Kurihara Cor 3.8 は「奇素数 p≠3」— p=3 は明示的除外**(裁定 576 逐語)。K₄(ℤ)=0 経由の議論が p=3 で回らない。(b) ℓ=3 では (ℤ/3)^× = C₂・指標の法が ℓ−1=2 なので **全ての奇重み w が例外列 w ≡ 1 mod (ℓ−1) に乗る**: χ^w ≡ χ となり、κ₃, κ₅, κ₇, … が全部同一の ω 固有空間に積まれる。NW(7) で二値性を支えた「重みごとに指標が異なる」半単純構造の腕力が最弱になり、深さを上げるほど(NW(6,3) で gr₃⊕gr₄⊕gr₅ が見える)「像が埋めるべき次元 ≥ 供給の独立性」の不等式が最初に破れうる。(c) この帯は Iwasawa 理論の trivial zero 帯(ω¹ 成分)と同じ座標 — 非消滅を救うのは Herbrand–Ribet でなく Ferrero–Greenberg 型(L′_p ≠ 0)の**別装置**であり、それは工房にまだ搬入されていない。
3. **検証の一手目(B-HUNT ブラケットは組めるか)**: **組める・最安**。(J-i) 数学者 1 枚: BH-1(3) — A = gr₃⊕gr₄⊗F₃ に C₂ が diag(u³,u⁴)=diag(−1,+1) で作用・部分加群 4 個・二値 |𝔊_ar| ∈ {2, 2|L|} の書き下し(NW(7) の逐語移植・付録 A 型の整数検算つき)。(J-ii) NW(4,3) 悉皆 1,458 対(ローカル数分・ただし発火は類型認可の枠 = 司令塔/Sol)。(J-iii) 文献 1 ビット: **κ₃ mod 3 の非消滅判定** — CLASSICAL-SWEEP 配達候補 C1(Ichimura–Sakaguchi の明示判定式)が p=3 をカバーするかの一点確認+Ferrero–Greenberg の搬入要否。ブラケットの両側(下界 = c と χ 供給・上界 = 悉皆)が揃い、1 ビットの所在も名指しできている。
4. **破綻しそうな点**: κ₃ mod 3 はほぼ確実に非消滅(3 は正則・h(ℚ(μ₃))=1・直接計算の射程内)— つまり**「反例がいる」確率は本票 5 札中最低**。この札の実価値は (a) 装置完備性テスト(勝ち筋がどこまで自動で回るかの限界測定)(b) GREEN-A 空虚真の穴埋め(falsifier 向け監査点)(c) NW(4,3) が探索キュー札 N-2(fixture 供給目的)として既出のところ、**目的を「装置死角の踏破」に昇格再提案**するものであること。novelty grep: NW(4,3) 自体は既出(exploration_queue §枠1 N-2)・「Kurihara p≠3 除外との交差」「GREEN-A 空虚真」は裁定 576/578(昨日)以降の新観点で repo 未出。

## 札 2 【TWIN-DIFF】双子差動 — 指数 126 対(商 C₇⋊(C₃×S₃))の「像の非対称」検出器

**規模: 現在線級 / 出所: 構造からの外挿(census 実データ)+群論の T-系からの類推**

1. **主張の種(構成+反例狙い)**: 場所 = **裁定 573 census の 28 対(両メンバー c∈N・N⊆PB₃)、先頭は指数 126・商 C₇⋊(C₃×S₃)**。設計: 双子 (N,K)(N≠K・B₃/N ≅ B₃/K)で **|GT(N)| と |GT(K)| を悉皆比較**し、さらに BH-1 型ブラケットを両窓で組む。差が 1 箇所でも出れば、そこに「群論的に同じ顔をしているのに算術像の側だけ痩せている窓」が実在し、**痩せた側の差分元が非算術証人候補として即座に名指しできる**(差動増幅器)。
2. **なぜそこに住めるか(機構)**: 装置 (ii)(iii)(iv) は全て「商の抽象構造+円分指標」経由で作用する — **双子に対して対称に効く**。一方 Ih_N の像は f_σ mod N_{F₂} で決まり、**N の B₃ 内での位置(埋め込み)に依存する**。つまり「双子の間の差」は定義上、円分装置が原理的に見分けられない自由度であり、古典側の緑塗り(GREEN-A)が届かない座標軸そのものである。126 の商は非ニルポテント可解(7 と 3·6 の混合)で、円分 graded 軸(pro-ℓ)からも外れている。
3. **検証の一手目(組める・在庫済)**: (J-i) **census 174 対に Out(B₃) 軌道照合列を足す**(新走行ゼロの後処理): Out(B₃) ≅ C₂(鏡映 σᵢ ↦ σᵢ⁻¹・Dyer–Grossman。出所: 自前知識・要 pin)なので、双子が鏡映で移り合うなら像も共役で差動はゼロ — **鏡映で移らない対だけが本物の狩場**。この 1 列が対の数を大幅に絞る見込み。(J-ii) 絞った先頭対で |GT(N)| vs |GT(K)| 悉皆(位数 126 商・即時)。(J-iii) 一致した場合(見込み大)は BH-1 型の部分群格子を両窓で書き、**「残る 1 ビット」の問いの形が窓ごとに違うか**を見る — 1 ビットの形(どの部分体の Galois 元の非自明性か)が違えば、文献回答が片側だけ消滅側に倒れる余地が生まれる。
4. **破綻しそうな点**: (a) 174 対の大半が鏡映対で、フィルタ後に残りゼロの可能性がそれなりにある — その場合「B₃ 窓は鏡映を除き本質的に一意」という剛性観測に転じ、AS-GAP-6(non-isolated witness)の見込み評価に直結する(負けても地図が塗れる)。(b) 抽象同型 ⟹ |GT| 一致、は自明でない(hexagon 方程式は marked データで書かれる — collision の教訓)ため、(J-ii) は「GT 数は抽象不変量か埋め込み不変量か」という独立の問いを先に決着させてしまう。どちらに転んでも一級だが、差動狙いとしては空振りうる。novelty grep: 双子 census・GTSh(K,N)≠∅ 検査は既出(裁定 573 次弾)。**「Out(B₃) 鏡映軌道の先決フィルタ」「|GT| 差動による非算術証人の名指し」は未出**(grep: 差動/Out(B₃)/Dyer)。

## 札 3 【NC-ANCHOR】非合同窓 PSL(2,8) — u 装置の前件が立たない在庫済みの現物

**規模: 中間峰級 / 出所: 命題 K-cong+G6b(工房既在)と (2,3,7) 剛性(自前知識)の交差**

1. **主張の種(予想)**: 場所 = **PSL 窓在庫(W3-6)の S4 = PSL(2,8) 窓(|GT| = 54 実測済)**。予想: この窓では算術像の下界を (装置 i)(c と χ_vir 供給)より上に押し上げる装置が存在せず、**上界(悉皆 54)との間に「どの古典定理も埋めろと言わない gap」が構造的に残る** — 非算術証人候補が「居てもどの予想にも抵触しない」最初の実在窓。
2. **なぜそこに住めるか(機構)**: (a) **非合同性**: 命題 K-cong(窓の地理学 v3)は K⁽ⁿ⁾ 合同 ⟺ n=4 を確定済みだが、dihedral 窓は Thm 4.3+u 測定(BFC の cusp-Kummer 装置)が非合同性を補って像を統制した。その装置の前件は G6b の 5 条件(cusp の Galois 安定性・接剛性等)であり、**cusp の定義体が円分的であること**に実質依存する。(b) PSL₂(F₈) は SL₂(Ẑ) の有限商の合成因子に現れない(合成因子は素体上の PSL₂(F_p) 系のみ・F₈ は素体でない — 紙 3 行・出所: 合同商の合成因子論・自前知識)⟹ **S4 窓の押し像は PSL₂(ℤ) の非合同部分群**。非合同 modular curve の cusp の定義体は円分体に限らない ⟹ G6b 前件が破れ、u/Kummer 段が圏外。(c) 増幅機構: PSL(2,8) は (2,3,7)-生成(Macbeath 系)で、位数 7 の 3 つの共役類は ℚ(ζ₇)⁺ 上でしか個別に定義されず Frobenius が巡回置換する — **算術作用は「3 類をまとめて」しか動かせず、類を個別に指定する群論的自由度(窓側では合法)が像側で強制的に対角化される**疑い。像が「Frobenius 軌道対角」部分群に落ちるなら、軌道非対角の shadow が全部証人候補になる。
3. **検証の一手目(ブラケットは片側から組める)**: (J-i) 紙 3 行: 非合同性の証明を candidate として固定(上記 (b))。(J-ii) 数学者設問 1 枚: 「S4 窓の押し像の cusp 軌道の定義体は円分体か」— 円分でない cusp が 1 個でもあれば u 装置圏外が確定。(J-iii) ブラケット: 下界 = ⟨c⟩ と χ_vir 供給+「ℚ 上 Galois 実現済みの PSL(2,8) 拡大が窓の分岐条件({0,1,∞} 上)と両立するか」の文献 1 ビット(実現は trinomial 系で既知・分岐制約つき実現が争点 — CLASSICAL-SWEEP 型の要請に落ちる)。上界 = 在庫悉皆 54(再走不要)。gap の内訳を BH-1 型の部分群格子(54 = 2·27 の構造)で書く。
4. **破綻しそうな点**: (a) 非合同でも B₃ 水準の円分装置(χ_vir・c)は生きるため、ブラケットが BH-1 のような「1 ビット」まで縮まず**多ビット UNKNOWN に開く**可能性が高い — その場合本札は「証人の名指し」でなく「UNKNOWN の正確な座標登録」で終わる(それでも FV-WALL 台帳の初の非合同行になる)。(b) PSL 窓の case B は settled 半分(W3-6)で、非 settled 元の扱いは対角 GT(N,N) 前提の B 型定義からはみ出す — **「非 isolated 窓での非算術証人の正しい定義」を先に数学者へ設問する必要**(定義整備 1 枚)。(c) PSL(2,8) の ℚ 実現既知は「像が太い」側の証拠であり、直感と逆に gap が埋まっている可能性も正直にある。novelty grep: PSL 窓在庫・K-cong・G6b は既在。**「S4 窓の非合同性の名指し」「G6b 前件不成立との接続」「合同 PSL(2,p) 窓(同在庫内)との対照実験which 装置が届くか」は未出**(grep: 非合同/noncongruence/Macbeath — 本体 docs にゼロ)。封印注意: 本札は CLAIMS 公開値(|GT|=54 等)のみ参照・PSL ε bits と封印構造量に非接触。

## 札 4 【GW-ENT】Grunwald–Wang 特異帯 — entangled × 2-primary C₈ の交差点

**規模: 中間峰級 / 出所: 別分野(埋め込み問題の局所大域)の機構翻訳**

1. **主張の種(予想+装置提案)**: 場所 = **「N_ord の 2-part が 8 以上・非分裂(entangled)・dihedral 族外」の窓** — 現在庫にはこの三条件の交差が**ゼロ**であることの確認から始める(それ自体が一手)。予想: 非算術証人の最も自然な発生機構は「hexagon+PENT = 局所条件の束は全通過・大域の σ ∈ G_ℚ が不在」であり、数論でこの型(局所可・大域不可)が実証されている唯一の古典帯が **Grunwald–Wang の special case(2-primary・C₈・ℚ(ζ₈) の非巡回性が根)**。ゆえに証人が居るなら住所の第一候補はこの帯。
