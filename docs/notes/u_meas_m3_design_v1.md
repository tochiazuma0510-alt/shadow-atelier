## 1. M3 設計 — 窓 B(段 S4・$\mathrm{PSL}(2,8)$・$k=9$)

### 1.1 何を作るか(1 枚)

$$
\begin{array}{ccc}
W\ (g=4,\ \deg 9) & \xrightarrow{\ \ \text{étale }C_3\ \ } & C\ (g=2,\ \deg 9)\\
\downarrow{\scriptstyle\lambda}\ \text{passport }(9,9,9) & & \downarrow{\scriptstyle t}\ \text{passport }(3^3,3^3,(9))\\
\mathbf P^1_\lambda & \xrightarrow{\ \ t=\lambda+\frac1{1-\lambda}+\frac{\lambda-1}{\lambda}\ \ } & \mathbf P^1_t
\end{array}
$$
右辺の四角は**ファイバー積**: $W=C\times_{\mathbf P^1_t}\mathbf P^1_\lambda$。底の写像は $\mathbf Q$ 上明示($\lambda^3-t\lambda^2+(t-3)\lambda+1=0$、分岐 $t=3\zeta_6^{\pm1}$)。**未知なのは左下ではなく右上の $C\to\mathbf P^1_t$ ただ一つ。**

### 1.2 ★ 命題 U-LOC — 測定は $C$ 上の局所展開に還元される【proof】

> ### 命題 U-LOC
> $\bar P\in C$ を $t$ の唯一の極(位数 9)とし、$s$ を $\bar P$ の($K$-有理な)局所助変数、
> $$t=c\,s^{-9}\bigl(1+O(s)\bigr),\qquad c\in\kappa(\bar P)^\times$$
> と展開する。$P_0\in W$ を $\lambda^{-1}(0)$ の分岐点($e=9$)とすると $W\to C$ は $P_0$ で不分岐なので $s$ は $P_0$ の局所助変数でもあり、
> $$\lambda=-c^{-1}s^{9}\bigl(1+O(s)\bigr)\qquad\Longrightarrow\qquad \boxed{\ u_0=-c^{-1},\qquad [u_0^{-1}]_9=[\,-c\,]_9=[c]_9\ }$$
> (最後の等号は $-1=(-1)^9\in K^{\times9}$ による)。

> **一般形**: $M$ が奇数の case A 窓すべてで、$\mathrm{ord}_{\bar P_0}(t)=-M$、$\lambda=-c^{-1}s^{M}(1+O(s))$、$u_0=-c^{-1}$、$[u_0^{-1}]_M=[c]_M$($-1=(-1)^M\in K^{\times M}$)。$A_5$ 窓は $M=5$、窓 A・B は $M=9$。**底変換の Shanks 三次は $M$ に依らない**($S_3$ 対称性だけで決まる)。

**証明.** Shanks 三次を $\lambda\to0$、$t\to\infty$ で解くと $\lambda=-t^{-1}-2t^{-2}+O(t^{-3})$(係数比較)。$t=cs^{-9}(1+O(s))$ を代入して $\lambda=-c^{-1}s^{9}(1+O(s))$。$\varphi$ の固定点は $\mu$ の固定点($\lambda^2-\lambda+1=0$)の上にあり $P_0$($\lambda=0$)はそこに無いので $W\to C$ は $P_0$ で不分岐、よって $s$ は $P_0$ の助変数。$u_0$ の定義 $\lambda=u_0s^9(1+O(s))$ と比較。$[u_0]_9$ の助変数非依存性は補題 SL-2(lg34 v2 §1.2)。$\blacksquare$

> $$\boxed{\ \textbf{⟹ M3–M5 は「種数 2 の }\mathbf Q\textbf{-曲線 }C\textbf{ 上で }t\textbf{ を }\bar P\textbf{ で 9 次まで展開する」だけになる。}W\textbf{ の方程式は要らない。}\ }$$
> これは正本 `surj_s4_v2` §5 の M3–M5(「$W$ の $K$-モデル → $P_0$ と $K$-有理 uniformizer → $\lambda=us^9(1+\cdots)$」)を**そのまま 1 段軽くした置換**である。窓 A でも同じ(§2)。

### 1.3 ★ $C\to\mathbf P^1_t$ は $\mathbf Q$ 上定義される【proof】

> ### 命題 U-Q
> 窓 B の商被覆 $C\to\mathbf P^1_t$ は**モジュライ体 $=$ 定義体 $=\mathbf Q$** をもつ。

**証明.** 分岐点集合は $\{3\zeta_6,\ 3\zeta_6^{-1},\ \infty\}$ で、$G_{\mathbf Q}$ は $\infty$ を固定し 2 つの有限点を(高々)入れ替える。$\gamma\in G_{\mathbf Q}$ で被覆を捻ると、passport は第 1・第 2 成分が入れ替わるだけだが**その 2 成分は等しい**($3^3$ と $3^3$)。monodromy 群($\mathrm{PSL}(2,8)$)も Galois 不変。**M1 §3.5 の測定によりこの passport + monodromy をもつ dessin は同型を除きただ一つ**なので $\gamma$ で不変。⟹ モジュライ体 $=\mathbf Q$。$\mathrm{Aut}(C/\mathbf P^1_t)=N_{\Theta(\pi_1^{\rm orb})}(H)/H$ は $N_P(H)=H$((W3)、M1 §1.3)より自明ゆえ $H^1(G_{\mathbf Q},\mathrm{Aut})=1$ で降下障害が消え、定義体 $=\mathbf Q$。$\blacksquare$

**系 U-Q′.** $W=C\times_{\mathbf P^1_t}\mathbf P^1_\lambda$ も $\mathbf Q$ 上定義される(底変換が $\mathbf Q$ 上)。

> ### 【整合確認 — 理論の独立な裏取り】

### 1.4 具体的な方程式系(実装仕様)

$C$ は種数 2 ⟹ 超楕円。$\bar P$($t$ の 9 位の極)を無限遠に置く。

**(a) $\bar P$ が Weierstrass 点の場合**: $C:\ y^2=f_5(x)$、$\bar P=\infty$、$\mathrm{ord}_\infty x=-2$、$\mathrm{ord}_\infty y=-5$。
$$L(9\bar P)=\langle 1,\ x,\ x^2,\ x^3,\ x^4,\ y,\ xy,\ x^2y\rangle\quad(\dim=8=9-g+1\ \checkmark)$$
$$t=A(x)+B(x)\,y,\qquad \deg A\le4,\ \deg B\le2,\ \ \mathrm{lc}(B)\ne0 .$$
**(b) $\bar P$ が非 Weierstrass 点の場合**: $C:\ y^2=f_6(x)$、$\bar P=\infty_+$。$\mathrm{ord}_{\infty_+}x=-1$。$L(9\bar P)$ の基底は $1,x,\dots,x^4$ と $y-h(x)$ 型の元(具体形は実装時に確定)。**両分岐を実装で試す**(どちらかは M1 の passport から決まらない — §4 の schema に記録欄を置く)。

**分岐条件(3 重零点)**: $\tau\in\{3\zeta_6,3\zeta_6^{-1}\}$ に対し $t-\tau=(A-\tau)+By$ のノルム
$$\mathcal N_\tau(x):=(A(x)-\tau)^2-B(x)^2f(x)\ \in\ \bar{\mathbf Q}[x]$$
が **3 次式の 3 乗の定数倍**であること:
$$\boxed{\ \mathcal N_\tau(x)=\kappa_\tau\,g_\tau(x)^3\quad(g_\tau\ \text{モニック 3 次},\ \kappa_\tau\ne0),\qquad \tau=3\zeta_6^{\pm1}.\ }$$
2 本は $G_{\mathbf Q}$-共役なので、$\mathbf Q$ 上は **1 本の $\mathbf Q(\zeta_3)$-方程式** または **実部・虚部に分けた 2 本の $\mathbf Q$-方程式**として扱える。

**未知数と方程式の勘定**(場合 (a)): $f_5$ の 6 係数 + $A$ の 5 + $B$ の 3 + $\kappa_{1,2}$ の 2 + $g_{1,2}$ の 6 = **22**、$x\mapsto\alpha x+\beta$・$y\mapsto\gamma y$ の**正規化 3** を引いて **19**。方程式は次数 9 の恒等式 2 本 = **20**。⟹ ほぼ 0 次元で、**剛性(解が 1 個)により実際に 0 次元・解は $\mathbf Q$-有理**(命題 U-Q)。

### 4.2 設計上の要点(なぜこの欄か)

| 欄 | 塞ぐ穴 |
|---|---|
| `class_vector` | **C1′ の中核**。passport が同型な 6 個(窓 B)を一意に指定する。`i17_check` の $[\alpha]$ 3 類問題と同じ型の穴 |
| `ordered_passport_C` + `rigidity_C` | 実際に方程式を立てたのが**商**であることを固定。$W$ 水準と混同させない |
| `nielsen_class_count_*` | 剛性の主張を数値で残す(後から「一意だと思っていた」を防ぐ) |
| `j_table_ref` / `F0_labelling` | SD-c 証明書の $j$ 表(`sdc_twist_*` の `j_values`)へのハッシュ束縛。$\mathfrak F_0\cong C_9$ のラベルづけが測定と同じであることを固定 |
| `base_change` | Shanks 三次の**符号・向き**を固定(規約 W-4 型の向き事故の予防) |
| `Pbar_is_weierstrass` | §1.4 の場合分け (a)/(b) のどちらで解いたかを記録 |
| `gates` | (W1)・段 II-b・$(Z_{18}$-link$)$ の身分を**測定値と同じ証明書に**書く。値だけが独り歩きするのを防ぐ |

> ### 【M3-b】$j$ 表との接続について(委嘱の指定への回答)
> 委嘱は「$(j,[\alpha])$ 系 — SD-c の $j$ 表との接続」を求めた。本設計では:
> * $j$ 表(`sdc_twist_*` の `j_values`)は **$\mathfrak F_0\xrightarrow{\sim}\mathbf Z/9$ のラベルづけ**であり、$\Lambda$ 上の $\tau(\mu_9)$ の座標を固定する。⟹ `F0_labelling` 欄でハッシュ束縛する。
> * **一方 $[\alpha]$ の役(= 同一 passport の中でどの対象か)は、本キャンペーンでは `class_vector` が担う**($K^{(n)}$ 族の単元類 $[\alpha]$ とは別物だが、**果たす機能は同一**: passport の下に隠れた有限個の選択肢を一意化する)。
> * したがって C1′ は本キャンペーンでは **$(j\text{-table},\ \text{class\_vector})$ の対**として実装される。**窓 A ではこの対では足りない**(class_vector が 2 類しかない)— §2.1【M3-a】が残件。

## 5.【文献要請】

> ### 【文献要請 1】正種数の Belyi 写像を明示的に計算する標準手続き
> **困難**: 種数 2 の超楕円曲線 $C:y^2=f(x)$ 上の次数 9 の Belyi 写像で、passport が $(3^3,\,3^3,\,(9))$、monodromy が $\mathrm{PSL}(2,8)$(9T27)、しかも**その passport の中で一意(剛)**なものを、$\mathbf Q$ 上明示的に求めたい(§1.4 の 19 変数系)。
> **欲しい結果の型**: (a) 正種数 Belyi 写像の計算アルゴリズムの標準手続き(mod-$p$ 探索 → 有理再構成 → $p$ 進 Newton 持ち上げ、の各段の具体的なレシピと落とし穴); (b) 剛性がある場合に系を 0 次元化・削減する標準の正規化(どの自由度をどう固定するか); (c) 「単一点に全極が集まる」形($\mathrm{div}_\infty(t)=9\bar P$)の関数を扱う既知の技法。
> **注**: 工房には正典外の計算幾何文献が無い。降りれば §1.4 の実装仕様がそのまま確定する。

> ### 【文献要請 2】Belyi 写像データベースの被覆範囲
> **困難**: $A_5$ 窓では `5T4-5_5_5-a` として既存データベースの登録品が使えた(`week4-A5算術飽和_v4.md` §2.1・補題 FC-4(d))。本件で必要なのは
> * 窓 B の商: **9T27・種数 2・passport $(3^3,3^3,9)$**、
> * 窓 B の $W$: **9T27・種数 4・passport $(9,9,9)$**、
> * 窓 A の商: **10T44・種数 1・passport $(3^31,3^31,(9,1))$**。
> **欲しい結果の型**: これらが既存データベース(genus/degree の上限は何か)に**在るか無いか**の 1 ビットと、在れば明示方程式。**無い場合の「無い」も一級の情報**(自前構成が確定する)。
> **注**: 照合は M7-B5(完全独立な第二系統)になる。**測定前に引くと汚染になる**ので、**引く順序は司令塔が管理すること**(候補を作ってから照合するのが安全)。

> ### 【文献要請 3】種数 2 曲線の不分岐 $C_3$-被覆と $\mathrm{Jac}[3]$
> **困難**: 窓 B では $W\to C$ が**種数 2 曲線の étale $C_3$-被覆**(種数 $2\to4$)で、$\mathbf Q$ 上定義される。これは $\mathrm{Jac}(C)^\vee[3]$ の $\mathbf Q$-有理な位数 3 の元に対応するはずで、候補モデルの安価な篩(M7-B4)になる。
> **欲しい結果の型**: (a) 「種数 2 曲線の不分岐巡回 3 次被覆 ⟺ $\mathrm{Jac}[3]$ の(双対の)位数 3 の点」の正確な定式化と有理性の対応; (b) 種数 2 曲線の 3-捻れを計算する実用的手続き; (c) $\mathbf Q$-有理 3-捻れをもつ種数 2 曲線の族(あれば $C$ の探索空間が激減する)。
> **注**: これは測定量そのものには触れない(モデルの篩)ので、測定前に降ろしても汚染にならない。
