## 2. ★ 検分の第一結論 — 「7 族」は**実質 2 機構**である

- **族 1・2・3・4 は同一機構**: 「共通商が無い ⟹ 直積 ⟹ 還元が何も削らない」。2・3 は表自身が「1 の系」と書いており、4 も *3 群商の不存在 ⟹ 直積* という同型の論法(便 135 の補題「$Q$ は非自明 3 群商をもたない」も同じ族に属する)。
- **族 5・6・7 は同一機構**: 「**可換**核上で障害群 $H^2$ が消える」。5 は片側自明、6 は $\tau$-自由、7 は素数条件。

$$\boxed{\ \text{機構 A = 相互作用の不在(直積)}\qquad \text{機構 B = 可換核上の }H^2\text{ 消滅}\ }$$

⟹ **「盲の地図が 7 族に達した」という表現は被覆の広さを過大に見せる**。実際に押さえているのは**二つの退化した場合**であり、一般の細分(非可換核・非自由・非半単純)には**族定理が 1 本もない**。

## 4. cofinal まであと何が要るか(司令塔の見立て・Sol 版と突合する)

1. **機構 B を可換核の外へ延ばす定理** — 非可換核でも障害が消える条件(便 134 の一様 survival 16 はその候補データだが**定理化されていない**)。
2. **機構 A を拡大へ延ばす定理** — 便 135 が「商の不存在は拡大を直積にしない」と反証した以上、直積化を経由しない別の論法が要る。
3. ★ **命題 COCYCLE-ABSORB-137 の族化**(便 137)— 現状は凍結宇宙の**測定**。$C_t(Z^1)\subseteq\mathrm{Im}A_t$ が**どの範囲の加群・roof・marking で成り立つか**を仮定つきの定理にできれば、機構 B の一般化として大きく効く。**現時点で最も定理化に近い候補**。
4. **非分裂細分**の存在自体が未確認 — 作れるなら A 側の標的、作れないことが定理になるなら B 側の煉瓦。

⟹ **現状の被覆で cofinal に達する見込みはない**。族定理が 2 機構しかなく、しかも両方とも退化した場合を押さえているだけである。**B 型の確定は、いまの延長線上には無い**(正直な見立て)。
