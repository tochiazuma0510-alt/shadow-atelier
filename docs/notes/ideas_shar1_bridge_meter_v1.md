# 札 1: BRIDGE-IDEAS — 比較射の建設案 3 系(+推奨 = 二段橋)

## 1.0 問題の形

左辺 $E(k,p)$ は **方程式側**(ls 格子の余核・LAT-ls 上)、右辺 $\mathrm{coker}_p(\psi)$ は **Galois 側**(Sharifi の写像の余核)。P40-GAP-4 のとおり「同じ空間」がまだ無い。以下 3 案 — 各々に**定理部/建設部/失敗モード**を明記。

## 1.1 案 (a): 共通 ambient 埋め込み(HM ℚ_p-骨格+整正規化定数)

- **構成**: 共通 ambient $=\mathrm{Lie}(x,y)\otimes\mathbb Q_p$。左辺の格子 = LAT-ls(HNF 固定)。右辺 = pro-p π₁ への Galois 作用の像の Lie 格子 $\mathfrak g^{\mathbb Z_p}_{\rm arith}$(Magnus/導分埋め込みで同じ ambient に入る)。比較射 = **ambient の恒等写像の制限** — 内容は二格子の相対位置(基底変換の単因子)に全て移る。
- **定理部**: Brown 自由性(ℚ)・Hain–Matsumoto 生成(ℚ_ℓ・要 pin)・Soulé 非零(κ_m ≠ 0)。⟹ ℚ_p 骨格上で両者は同じ σ-生成系を持つ(**⊗ℚ_p で同型かは井原の問い — 橋には全射方向で足りる**、を明記)。
- **建設部(本体)**: **整正規化辞書** — 工房の y-正規化 σ_m と Soulé 整正規化 κ_m の比 $c(m)\in\mathbb Q_p^\times$(Coleman/Coates–Wiles 型の定数・$(1-p^{m-1})$ Euler 因子と p 進 L 値を含む見込み)。**この $c(m)$ の p-付値が「橋そのものが運ぶ算術」**であり、比較の主役(付値 0 なら格子は透明に重なり、付値 > 0 の点が まさに興味の番地)。
- **失敗モード**: (i) $c(m)$ に p 進 L の余剰零があると比較が退化 — ただし退化点 = 番地そのもの、の両義性を携行(罠②)。(ii) 深さ filtration の両側整合(DEPTH-WEIGHT)。(iii) ambient 同一視が π₁ の生成元選択(接基点)に依存 — 正規化 pin 1 点。

## 1.2 案 (b): 有界深さの表示対応(生成元 ↦ Soulé・関係 ↦ cup)

- **構成**: 写像でなく**表示の対応**: $\sigma_m\mapsto\kappa_m$、深さ次数付き関係(period polynomial 系・例: $\{\sigma_3,\sigma_9\}-3\{\sigma_5,\sigma_7\}$)↦ Galois 側の対応物(**Soulé 元の括弧 = McCallum–Sharifi cup 積の住所**)。有界深さ($\le4$)で両側の表示を突き合わせ、余核を表示水準で比較する。
- **状況証拠(既記録)**: 重み・深さの辞書、および **p−1 シフト周期の一致**(Kummer 合同の周期 ⟺ ω-固有空間分解 mod p−1)— 対応の座標系が同じ目盛りであることの傍証(証明ではない)。
- **定理部**: 左側表示は Brown(明示)。**右側表示が条件付き**(Sharifi/Ihara 系の表示は Greenberg/Vandiver 型仮定に依存 — どの命題がどの仮定かの台帳を pin(papers/ 収蔵済の Sharifi 正本から・reader 発注可能)。
- **失敗モード**: 対応の well-defined 性は実質的に井原の問い(核の非自明性)と絡む ⟹ **主張は「有界深さの表示比較」に限定**し、写像の存在は主張しない(過大禁止)。
- **効用**: P-SHAR-1 の比較を「同じ合同を二つの言語で見る」形に翻訳する最短路 — 橋が立つ前でも**比較の語彙**を供給する。

## 1.3 案 (c): 逆向き自然射 $\mathrm{gr}(\mathfrak g_{\rm arith})\to\mathrm{ls}$(形式的存在が最も固い)

- **構成**: Galois 像の深さ次数付き $\mathrm{gr}(\mathfrak g^{\mathbb Z_p}_{\rm arith})$ の元は、Galois 作用が π₁ の二つの積構造を保つことから **線型化二重シャッフル方程式を満たす**(Racinet 系の étale 実現・要 pin)⟹ **自然な包含 $\iota_{\rm br}:\mathrm{gr}(\mathfrak g^{\mathbb Z_p}_{\rm arith})\hookrightarrow\mathrm{ls}^{\mathbb Z_p}$ が写像として無条件に立つ**(同じ ambient 内の包含)。
- **比較対象の変換**: これで測れるのは $\mathrm{coker}(\iota_{\rm br})$ — 右辺(Sharifi の coker)と**同じものとは限らない**が、「算術格子 vs 方程式格子」という P-SHAR-1 の精神の**最も素直な定式**。$E(k,p)$ との関係: $L_{\rm gen}\subseteq\mathrm{im}(\iota_{\rm br})\subseteq\mathrm{ls}$ の三段(括弧語は算術像に入る)⟹ **$E(k,p)$ は $\mathrm{coker}(\iota_{\rm br})$ の上からの粗視化**という正確な包含鎖が書ける(P4-0 の $L_{\rm gen}/L_{\rm sat}$ 分離とちょうど噛み合う)。
- **定理部**: 包含の存在(étale 実現の shuffle 保存・pin 1 点)。**建設部**: 整水準の gr の飽和管理(LAT-TOR — SAT-JOIN 必須)・右辺との突合(Sharifi coker との同定は別仕事)。
- **失敗モード**: gr が生む擬捩れ(filtration 選択依存)— 二 filtration(下中心 vs 深さ)の一致検査を較正段に置く。

## 1.4 推奨 = **二段橋**(検分用の提案・拘束なし)

$$\boxed{\ \textbf{骨格 = 案 (c)(無条件の写像)+ 正規化層 = 案 (a)(c(m) 辞書)。案 (b) は語彙供給として並走}\ }$$
— (c) が「同じ空間」前件を先に作り、(a) の $c(m)$ が右辺(Sharifi 側の整構造)への目盛り合わせを担う。**P-SHAR-1 の比較が定義できる最小構成**はこれ、が本札の見立て。
