## 実装上の注記

- 段階①検査で規約が完全一致したため、段階②のスコアリング関数(積・冪・逆元・$c_s$・$d_\theta$・$d_\sigma$)は **各系統の JSON に記載された構造化係数(`t5_coef_ap_bw` 等)を系統ごとに独立に読んで**計算している。両系統が同じ式文字列を書いていたとしても、照合器はその文字列を信頼せず、各 JSON の係数フィールドから系統ごとに再構成した数値を diff する設計にした(片方の転写ミスがあれば表面化する)。
- $\sigma_m,E_m,\varepsilon_m$ の $m$ 依存項は多項式・二項係数閉形として構造化転写し(`sigma_table_poly`: $[c_0,c_1,c_2,c_3]$ で $c_0+c_1m+c_2\binom m2+c_3\binom m3$、`Em_components`: $\{coef,shift,k\}$ で $\mathrm{coef}\cdot\binom{m+\mathrm{shift}}{k}$ の和)、$m\in\{-3,\ldots,10\}$ の 14 点で整数評価して diff した(記号一致に頼らない数値照合)。
- 照合器・証明書は探索器(`docs/scout/hall5.mjs`、両文書の検算スクリプト)から完全に独立。GAP は使っていない(委嘱通り軽量・node のみ)。
- 用語: 本照合の結果は **cross-checked** であり、Lean 未実装のため **verified ではない**。
