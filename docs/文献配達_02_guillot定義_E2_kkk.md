## §1. Guillot GT(G) の正確な定義(arXiv 1407.3112 §2 からの抜粋翻訳 — P68 即応)

- **台**: F₂ = ⟨x,y⟩。N ⊴ F₂ が「index G をもつ」⟺ F₂/N ≅ G。**N_G := その全部の交わり**(有限個)、**Ḡ := F₂/N_G**。具体モデル: 生成対軌道の代表 (x₁,y₁),…,(x_r,y_r)(r = |P/Aut(G)|・P = G の生成対全体)で Ḡ ≅ ⟨(x₁,…,x_r),(y₁,…,y_r)⟩ ⊂ G^r。射影核 K_i は特性的な族。
- **標準自己同型**(Lemma 2.1(3) で存在): **θ: x ↦ y, y ↦ x**・**δ: x ↦ y⁻¹x⁻¹, y ↦ y**(xyz = 1 の z で書けば δ(x) = z)。
- **GT(G) の定義**: φ ∈ Aut(Ḡ) で (1) **φ(x) は x^k の共役**(k は |Ḡ| と素 — ただし **k は well-defined でない**: x^k 同士が共役になり得るため写像 φ ↦ k は存在しない。λ 座標をもつ主線 GTSh との決定的な差)・(2) **Out(Ḡ) 内で θ・δ と可換**。この φ たちの **Out(Ḡ) における像が GT(G)**。**GT₁(G)** = k = 1 に制限した正規部分群。hexagon の明示方程式は書かれず θ/δ 可換性にエンコード(Drinfeld 言語との翻訳証明は [Gui14] = Enseign. Math. 60 (2014) 293–375 に委任・逆極限は ĜT₀)。
- **単純群用の言い換え**(1604.04415 §2): T = {(x,y,z) ∈ G³ : xyz = 1, ⟨x,y,z⟩ = G}、T/G = 同時共役軌道。**θ·[x,y,z] = [y,x,z^x]・δ·[x,y,z] = [z,y,x^y]**(S₃ → S(T/G))。≡ は座標ごとの共役。**GT₁(G) = {φ ∈ S(T/G) : Out(G)×S₃ 作用と可換・≡ と両立}**。G 単純非可換なら Thm 4.9 で GT₁(G) ≅ C_S(Out(G)×⟨θ,δ⟩) ∩ Young。
- 比較写像の検討(P64-P65)に必要な範囲はこれで全部。原論文全文が要るときは司令塔へ(PDF 保管済み)。

## §2. 【GAP-E2】向け文献(要請 1 の成果 — 同時可解性 = θ-反不変元の存在)

1. **Burkhart, arXiv:2308.12286**(PRSE A 155 (2025) 345-351)"Fixed point conditions for non-coprime actions": **Glauberman 型不動点補題の coprime 仮定を外す** — 「各素数の Sylow が不動点をもてば全体がもつ」型への置換・N 冪零(= A が 2 群)の版あり。E2 の障害(gcd(|Θ|,|A|) = 2)への正面弾候補。
2. **Kawanaka–Matsuyama 1990**(Hokkaido Math. J. 19, 495-508)+ **Vinroot, arXiv:1811.05343**(strongly ι-real): **捻れ Frobenius–Schur 指標** — m_θ = |{f : θ(f) = f⁻¹}| = Σ_χ ε_θ(χ)χ(1) の型の指標和公式。存在問題を指標の正値性に変換する古典機構。**翻訳の要**: 我々が数えたいのは A 全体でなく**特定の捻れ共役類(補群軌道)S_m との交わり** — 類関数を S_m の指示関数と組む変形が必要(そこが新規作業・P51 の非可換 H¹ 定式化と相補)。
3. 補助: arXiv:1104.0216(捻れ類と twisted involution の交差の分類 — 問いの形が同型)・arXiv:2603.01679(bi-twisted 共役の類数公式)。
4. 空振り申告: 非可換コホモロジー H¹(S₃, A) の具体的消滅判定は直接文献なし(P51 は自前で組む必要)。

## §3. (Q7)/(k,k,k) 向け文献(要請 2 の成果)

1. **問いを潰した抽象化**(hunter 導出・要検証): Δ(k,k,k)^ab ≅ (ℤ/k)² ゆえ 3 ∤ k なら 3 ∤ |P^ab|、したがって **3 | |[P,P]| ⟺ 3 | |P|**。「生成元位数が導来素因子を押さえる」型の定理は原理的に存在しない。
2. **Jones–Mačaj–Širáň, arXiv:2508.10434**: 任意の双曲型 (ℓ,m,n)((n,n,n) 含む)を**無限個の p で PSL(2,p) が実現**する一般存在定理 — A₅ の先の単純群系列(P62)の供給源。
3. **MacBeath 1969**(書誌は Marion, DOI 10.1515/JGT.2009.004 経由で確認・原典 UNVERIFIED): PSL(2,q) の trace 三つ組分類 — **等 trace (t,t,t) から θ,τ が自動的に Aut へ延びる**機構(= 許容性の判定装置)。
4. **塔翻訳**(hunter 導出・要検証): μ 比較で **Δ(k,k,k) ◁ Δ(3,3,k) ◁ Δ(2,3,2k)**(指数 6・商 S₃)。B₃/⟨c⟩ ≅ PSL(2,ℤ) ゆえ、Q7 狩場は「**c が死ぬ B₃ の (2,3,2k) 型有限商の指数 6 部分群**」として事前登録可能 — S₃ 対称性は塔の中に最初から住んでいる。
5. hunter の GAP 一次観測(単系統・裁定 06 で開示済み): A₅(k=5)が最小(位数 < 60 悉皆で該当なし)・次点 PSL(2,8)(k=7)。Sol の紙上構成(便 06 F11)と独立収束 — A₅ は二経路一致。
