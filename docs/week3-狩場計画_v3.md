### 1.1 H8″ の撤回(F2・W41・W42)— 最重要

であり、(H-a) の解集合は

$$ \mathcal B_\theta \;=\; \{\, f \in A \;:\; \theta(f) = f^{-1}\,\} $$

である。**必要なのは 𝒮_m ∩ ℬ_θ ≠ ∅ だが、H8 はこれを一切述べない。** v2 §4.1 の表の「p 群(p ≠ 3)では残る障害は同時可解性」と同じ表の「2 群は完全に安全」は内部矛盾していた(Sol の指摘どおり)。

## 2. 新規: hexagon の torsion 再定式化 — 二つの hexagon は Q = B₃/N の中の 2-torsion と 3-torsion である

### 2.1 定理 T2(torsion 辞書)

記法。N を許容対象、**c ∈ N**、P := PB₃/N ≅ F₂/N̄、A := [P,P]、k := ord(X̄) = N_ord。
**Q := B₃/N**(位数 6|P|)、Δ := σ₁σ₂σ₁、δ := σ₁σ₂ の像を Δ̄, δ̄ ∈ Q と書く。

> **定理 T2.** 上の設定で、
> **(i)** Δ̄² = δ̄³ = 1、P ⊴ Q、Q/P ≅ S₃、**Q = ⟨Δ̄, δ̄⟩ は PSL(2,ℤ) ≅ C₂ * C₃ の有限商**である。σ̄₁ = δ̄⁻¹Δ̄、σ̄₂ = Δ̄δ̄⁻¹。
> **(ii)** P 上で **θ = Ad(Δ̄)**、**τ = Ad(δ̄)**(Ad(g)(w) = gwg⁻¹)。
> **(iii)** f̄ ∈ A、h := Ȳ^m f̄ と置くと
> $$ \boxed{\ (H\text{-a})\ \theta(\bar f)=\bar f^{-1} \iff (\bar\Delta \bar f)^2 = 1\ },\qquad
> \boxed{\ (H\text{-b}')\ E_m\mathcal N_m(\bar f)=1 \iff (\bar\delta^{-1}\bar Y^m \bar f)^3 = 1\ } $$
> **(iv)** ord(σ̄₁) = ord(σ̄₂) = 2k。ゆえに **Q は三角群 Δ(2,3,2k) = ⟨a,b | a² = b³ = (b⁻¹a)^{2k} = 1⟩ の有限商**である。

**証明.**
**(i)** B₃ ≅ ⟨Δ, δ | Δ² = δ³⟩、c = Δ² = δ³ は中心。c ∈ N ゆえ Q で Δ̄² = δ̄³ = 1、すなわち Q は B₃/⟨c⟩ ≅ PSL(2,ℤ) ≅ C₂ * C₃ の商。N ≤ PB₃ より P = PB₃/N ⊴ Q、Q/P ≅ B₃/PB₃ ≅ S₃。σ₁ = δ⁻¹Δ、σ₂ = Δδ⁻¹ は braid 関係から直接(δ⁻¹Δ = σ₂⁻¹σ₁⁻¹·σ₁σ₂σ₁ = σ₁、Δδ⁻¹ = σ₁σ₂σ₁σ₂⁻¹σ₁⁻¹ = σ₂σ₁σ₂σ₂⁻¹σ₁⁻¹ = σ₂)。

$$ (\bar\delta^{-1}h)^3 = \tau^{-1}(h)\,\tau^{-2}(h)\,\tau^{-3}(h)\,\bar\delta^{-3} = \tau^{2}(h)\tau(h)h $$
(τ³ = id_P、δ̄³ = 1)。原文 (3.11) は τ²(y^m f)τ(y^m f)(y^m f) ∈ N_{F₂}、すなわち P で τ²(h)τ(h)h = 1 であり、これは v1 §1.3 の変形により E_m𝒩_m(f̄) = 1 と同値 ✔。

### 6.3 【文献要請】(文献ゲート — 司令塔へ)

> **【文献要請 4】(最優先・【GAP-E2a】に対応)**
> **困難**: 有限群 Q と正規部分群 A ⊴ Q、固定元 w ∈ Q が与えられている。
> $$ N(w) = \#\{(g,r) \in Q^2 : g^2 = r^3 = 1,\ rg = w\} $$
> は古典的な Frobenius 指標和(命題 E4)で書ける。**欲しいのは、これを Q/A の中で「g の属する coset」で成層した個数** n_{(ḡ,r̄)} の閉じた表示である。
> **欲しい結果の型**: (a)「商群の元を指定した torsion 分解の数え上げ」= **relative / twisted Frobenius formula**(Q の指標と Q/A の指標の積で書く形)、(b) 三角群 Δ(2,3,n) から有限群への**全射準同型の数え上げ**で、像の marked coset を指定するもの((2,3)-生成の文献圏に近いはず)、(c) Hurwitz 型の数え上げ(Frobenius の被覆公式の相対版)。
> **効用**: 成立すれば **𝔐(N) の判定が指標表の計算に落ちる**。掃引の各対象で列挙を回さずに m 欠損が決まり、**E2 正面と Q7 正面の両方が同じ道具で撃てる**。

> **【文献要請 5】(【GAP-E2】の漸近版・部分結果の型 α)**
> **困難**: Q が(概)単純群のとき、命題 E4 の指標和 N(w) が**全 w について正**であることを保証する評価が欲しい。
> **欲しい結果の型**: 有限単純群における **character ratio bound**(|χ(w)|/χ(1) の上界)と、それを使った「位数 2 の元の集合 × 位数 3 の元の集合 = 群全体」型の定理(Liebeck–Shalev, Larsen–Shalev, Shalev の product-of-classes 系が近い圏だと推測する)。
> **効用**: **Q7 正面が漸近的に閉じる**(「十分大きい単純 P からは fake が出ない」)。狩場が有限個の小さい例に絞られる。

> **【文献要請 6】(低優先・【GAP-E9】の更新)**
> A₅ を marked 商にもつ GT-shadow(あるいは modular group の (2,3,10) 商の GT 類似物)が既知でないか。Dolgushev の GT パッケージ(B₄ 系・同名別物)や 2401/2405 の例に **A₅ が現れていないか**の確認。**較正の錨には使わない**(W48 と同じ留保)が、重複を避けるため。
