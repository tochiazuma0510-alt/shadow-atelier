#### 1.4.2 補題 C(絶対較正)— **新規・本 v3 で起草・Sol 未監査**

規約(§1.1)を再掲する。標準接基点は二つ使う:
- **0⃗1**: 局所座標 **β**、G_ℚ は Ω₀ := ℚ̄{{β}} の**係数のみに作用し全ての β^{1/n} を固定**。
- **1⃗0**: 局所座標 **s₁ := 1−β**、G_ℚ は Ω₁ := ℚ̄{{s₁}} の**係数のみに作用し全ての s₁^{1/n} を固定**。

p を実区間 (0,1) に沿う標準経路(1⃗0 → 0⃗1)、g_σ := σ(p)p^{-1} ∈ π₁(U_ℚ̄, 0⃗1) = F̂₂ とする(σ(p) = g_σ·p)。

> **補題 C(絶対較正).** 全ての σ ∈ G_ℚ に対し
> $$ \boxed{\;g_\sigma\in[\hat F_2,\hat F_2]^{\mathrm{top.cl.}}\;} $$
> したがって、Ihara 公式の f_σ(= g_σ^{±1};下記注)も交換子閉包に属する。

**証明.** [F̂₂,F̂₂]^{top.cl.} = ker(ψ: F̂₂ ↠ Ẑ² = F̂₂^{ab}) だから、**g_σ の x-成分と y-成分がともに 0** を示せばよい。各 n ≥ 2 について、次の二つの **ℤ/n-巡回被覆**(いずれも ℚ 上定義・U 上エタール)を使う。

| | 被覆 | 対応する商 ψ | 分岐 |
|---|---|---|---|
| **C_n** | w^n = β | x ↦ 1, y ↦ 0 | 0, ∞ |
| **D_n** | u^n = 1−β | x ↦ 0, y ↦ 1 | 1, ∞ |

**(a) 両端の繊維に Galois 不動点がある。**
- C_n の 0⃗1 上の繊維は {ζ_n^j β^{1/n}}。規約より β^{1/n} は G_ℚ-不動 ⇒ 不動点 **v₀ := β^{1/n}**。
- C_n の 1⃗0 上の繊維は w^n = β = 1−s₁ の根で、**(1−s₁)^{1/n} ∈ ℚ[[s₁]]**(二項級数・係数は有理数)は係数作用で不動 ⇒ 不動点 **v₁**。
- D_n の 0⃗1 上: **(1−β)^{1/n} ∈ ℚ[[β]]** が不動点 **v₀′**。D_n の 1⃗0 上: 繊維は {ζ_n^j s₁^{1/n}} で s₁^{1/n} が不動 ⇒ **v₁′**。

**(b) 実区間上の解析接続が両端の不動点を結ぶ。** β ∈ (0,1) では上記 4 つの分枝はいずれも**正の実数値**をとる分枝である(β^{1/n} > 0、(1−β)^{1/n} > 0)。正の実分枝は (0,1) 上で正の実分枝のまま接続するから
$$ p\cdot v_1 = v_0,\qquad p\cdot v_1' = v_0'. $$

**(c) 結論.** Galois 作用の関手性 σ(p·v) = σ(p)·σ(v) と (a)(b) より
$$ g_\sigma\cdot v_0 \;=\; (\sigma(p)p^{-1})\cdot(p\cdot v_1) \;=\; \sigma(p)\cdot v_1 \;=\; \sigma(p)\cdot\sigma(v_1) \;=\; \sigma(p\cdot v_1) \;=\; \sigma(v_0) \;=\; v_0. $$

### 2.3 主計算 — z′⁵ = 2t

> **補題 U2(u の抽出).** (2.1) の上で恒等式

## ★ 教材(本委嘱で学んだこと)

1. **接基点を取ることの利得は「基点を持つこと」そのものではなく、Galois 作用が outer から actual に上がること**である。Inn の層が見たいなら、rigidity(Out 層)ではなく接基点(actual 層)へ行く。
2. **「二つとも 5 元集合で、両方 C₅ が自由推移的」は比較補題の代用にならない**(Sol の ★ 教材 5 と同じ結論に、実例で到達した)。実際 −16/27 と 16 は**どちらも非自明な μ₅-torsor だが別のクラス**だった。**位数一致どころか「非自明性の一致」すら代用にならない。**
3. **DB のフィールドは記法を確認してから読む**。`[[1,2,3,4,5]]`(one-line = 恒等)と `"(1,2,3,4,5)"`(cycle = 5-サイクル)の取り違えは、本件では「捻れが 5 個ある/ない」= 「u が決まらない/決まる」の分かれ目だった。
4. **主張の依存を減らすと定理は強くなる**: v1 は補題 A・複素共役・(1.13) の三本柱で立てていたが、正しい比較補題を得たら **どれも要らなくなった**。「補題が増えたら設計を疑え」。
5. **一意性(S₅-軌道 1)と Aut = 1 は同じくらい重要**。前者は「対象が定まる」、後者は「モデルが定まる」。前者だけでは u は決まらない。
6. **★「式が一致した」は「規約が一致した」ではない。** 接基点のスケール v_c = c·0⃗1 を変えても (1.1) の**式の形は一切変わらない**(x は自身の冪と可換、f_γ ↦ f_γ x^{−χ(γ)κ_c(γ)} と動くだけ)。にもかかわらず答えは [2] ↦ [2]·[c]^{±1} と動き、**c ≡ 2^{∓1} なら判定が反転する**。**照合で閉じられるのは「観測可能な差」だけで、観測不能な自由度は数学で潰すしかない。**
7. **引用が立たないなら証明を書く**(【GAP-C8】【GAP-C1″】)。**二度効いた**: 特殊化包含は 5 行の自前証明で、絶対較正は補題 C+D で閉じた。**出典探しより自前証明の方が安く、依存が減って定理が強くなる。**
8. **★★【v3 の最大の教訓・Sol 便 17 F9.3 から】「正規化条件の一意性」は「絶対較正」ではない。** 「交換子条件を満たす scale は一つ」と「その scale が座標 β の速度 1 である」は**別命題**である。v2 の私は前者を証明して後者を主張し、**循環に落ちた**。**外部監査だけがこれを捕まえた** — 自己検査(規約表・失敗様式の列挙)は全て素通りした。q 式の教訓(裁定 15)と同じ構造の誤りである。
9. **★ 較正は「幾何側の観測量」から来る。** 補題 C が効いたのは、f_γ という**代数的な量を弄る**のをやめて、**接繊維の Galois 不動点という幾何側の観測量**を両端で見たからである。行き詰まったら「この規約は何を観測可能にしているか」を問え。
10. **一つの exact conjugator は passport 一意性の悉皆より強い**(Sol 教材 5)。h = (1 3 4 5) は kernel と marking を同時に固定するので、「同型が存在する」しか言わない悉皆より情報量が多く、しかも再検証が置換 2 回で済む。
11. **可約な特殊化も cycle type witness に使える**(Sol 教材 3)。要るのは既約性ではなく分離性・不分岐性・分解群への包含。ただし**得られた転置は算術 monodromy の元**であって幾何 monodromy の元ではない — 正規化群を経由して幾何群を判定する。
