## 1. 枝 (N_aff) の探索設計

### 1.1 正規形とゲージの使用

S5 設計 v1.2 §3.3.4(3.3):

$$ a(x)^2 - c_N(x-x_0)^5 = f_6(x)\,p_2(x)^2 \qquad(\textbf{N-0}:\ x_0\ \text{有限}) $$

Rule 1 v1.3 §2.2 M1 が (N_aff) について既に課しているゲージをそのまま使った:

- **x-平行移動**: $x_0=0$ に固定(Rule 1 M1「副枝(N_aff): 従来通り x-平行移動で x(P_0)=0」)。
- **y-スケール(f_6 を monic にする)**: これは $\deg a=5$(次数整合 $2\deg a = \deg f_6+2\deg p_2=10$ から強制)のもとで、$f_6$ の主係数が $a_5^2$ になることから、$a_5=\pm1$ に固定することと同値。よって $a_5\in\{1,-1\}$ とし、残り $(a_0,\dots,a_4)$ を自由変数にした。
- **μ-スケール(残る1自由度)**: これは $c_N$ の平方類を変える作用であり、これを使って $c_N$ を特定値に固定することは $\operatorname{sqfree}(c_N)$ の計算を要求する。$\operatorname{sqfree}(c_N)$ が (P1) を漏らすかどうかは S5 設計に明記がない(命題 S5-4/S5-4∞ は $c$ および $\hat c_\mu$ についてのみ確立)。★教材3(S5設計§6.3「禁止リストは枝ごとに再点検しなければならない」)の教訓により、未確立の量は安全側に倒し、**$c_N$ の平方類・平方因子・符号を一切計算せず**、$c_N$ を素朴な整数格子でブルートフォースした(ゲージで縮めない)。

### 1.2 二段階判定(厳密・浮動小数点不使用)

**段階1(N-2/N-3/N-4 — 分解構造の必要条件)**: $h(x):=a(x)^2-c_Nx^5$(次数10)に対し、$g:=\gcd(h,h')$ を厳密 Euclid 互除法(Frac 係数)で計算。$\deg(g)=2$ ちょうどでなければ棄却。$p_2:=\operatorname{monic}(g)$、$h$ を $p_2^2$ で厳密除算し余り0を確認、商 $f_6$ が次数6・monic・squarefree($\gcd(f_6,f_6')$ が定数)・$\gcd(f_6,p_2)$ が定数(N-3)であることを検査した。N-5(∞_- での leading cancellation)は $p_2$ の符号選択(±)で常に充足可能であることを確認し、追加の探索フィルタにはしていない。

**段階2(μ の分岐型 (5,2²1,2²1,5))**: 恒等式 (3.1) を使うと μ のファイバー方程式は
$$ g(x;v) := c_N x^5 - 2v\,a(x) + v^2 = 0 $$
に帰着する(枝 (W) の $f(x;v)$ と同型)。枝(W)・委嘱1の判別式パターン検査(`D(v)/v^k = c(v^2-h)^2`)をそのまま流用した。

### 1.3 ★実装中に発見・修正した重大なバグ(偽陰性リスク)

枝 (W) では $\deg a\le2$ だったため $f(x;v)$ の $x^5$ 係数は常に定数 1(v に依存しない)だった。しかし (N_aff) では $\deg a=5$ のため、$g(x;v)$ の $x^5$ 係数 $(c_N-2va_5)$ と $g'(x;v)$ の $x^4$ 係数($=5(c_N-2va_5)$、同一の線形式に比例)は **同時に** $v_0:=c_N/(2a_5)$ で消える。$v_0$ は幾何的には $\mu(\infty_-)$ の値に一致する(∞_- は $x=\infty$ 上のもう一つの点で、$P_0,P_\infty$ のいずれでもない一般点)。

固定次数(5,4)の Sylvester 行列で計算した判別式 $D(v)=\operatorname{Res}_{5,4}(g,g')$ は、この $v_0$ で**機械的に0になる**ことを具体例で厳密検証した(手計算例: $a=(1,1,1,1,1,1)$, $c_N=3$ で $v_0=3/2$、固定次数 resultant $=0$、実際の次数(4,3)で計算した resultant $=94041/16\ne0$)。これは「$x=\infty$ での射影的な共通根」という Sylvester 行列の形式的な性質であり、**μ の幾何的分岐点ではない**(∞_- は passport の4分岐点 $\{0,s,-s,\infty\}$ のいずれでもない一般点であることが、上の具体例での値の不一致(0 対 非零)から確認される)。

この線形因子 $(c_N-2a_5v)$ を除去せずに v^k 剥離・偶関数判定へ進むと、**真に有効な候補まで誤って棄却する**(false negative)。修正として、判定前にこの既知の線形因子を(厳密多項式除算で割り切れる限り繰り返し)除去する処理を追加した(`stripKnownLinearFactor`、`search/mb-naff-branch-search.mjs`)。

修正の前後で bound=3 の結果自体(候補0件)は変わらなかったが、これは偶然の一致ではなく、修正後に該当8候補の棄却理由を個別に確認し、いずれも「R(v) が偶関数でない」という**正当な**理由(旧バージョンの人工的な次数不整合等ではない)で棄却されていることを確認した(§3.1 参照)。**この確認をせずに旧バージョンの結果をそのまま採用していれば、偽陰性を看過するリスクがあった。**

## 3. 禁止事項の遵守

Sol 便42 F3 の12箇条をそのまま適用した。とくに:
- $c_N$(枝(N_aff)の norm 定数)・$c$($\lambda=c\mu^2$)・$\hat c_\mu$(枝(N_infty)用)のいずれも、平方類・平方因子・符号を計算・選択基準に使用していない。$c_N$ は完全な曲線データ(A1 whitelist 内)の一部としてのみ扱い、単独の量として計算・報告していない。
- $(N_\infty)$ は本委嘱でも探索していない(未探索のまま・BRIDGE-UNKNOWN 継続)。
- 両 dessin(sq/ns)は本委嘱の段階(モデル探索の必要条件フィルタ)では区別が現れない(候補が0件のため、片翼優先の問題は発生していない)。
- 独立照合器(crosscheck/)の新設は、候補が0件だったため本委嘱でも着手していない(委嘱1の申告を継続)。
