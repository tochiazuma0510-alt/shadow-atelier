## 4. ★★ N_infty で候補が出現した

以下4シャードで、stage1(等式 $a^2-f_6p^2=$定数)・stage2(分岐型パターン)の両方を満たすタプルが**各2件ずつ、計8件**見つかった: `ninfty-b5-a5m-p21`・`ninfty-b5-a5m-p2m1`・`ninfty-b5-a5p-p21`・`ninfty-b5-a5p-p2m1`。

証明書は `certificates/mb/actions/30289323147/{shard_id}.json` にそのまま残っている(exact 出力・改変していない)。whitelist(Sol便42 F3(2))に沿って報告できる範囲は以下(**すべて探索器が出力した曲線データそのもの — 委嘱2/3から続く whitelist を一切拡張していない**):

- $a(x) = -x^5-5x^3$
- $p(x) = x^2+3$
- $f_6(x) = x^6+4x^4-8x^2+12$
- `quadratic_artifact_power=3`、`k=4`

の組と、その符号違い($a_5,p_2$ の符号を反転した鏡像・$a(x)=x^5+5x^3$, $p(x)=x^2-3$, $f_6(x)=x^6-4x^4-8x^2-12$)の**合計2つの異なる $f_6$**(符号反転を除けば1つの抽象曲線とみられるが、これは監査されていない私見であり断定しない)。

**8件という数は、$a_5=\pm1$・$p_2=\pm1$・$a_3$ の符号という3つの独立な符号自由度(残余ゲージ・座標の取り方に起因すると見られる)による重複を含んでいる可能性が高いが、これも断定しない**(ゲージ商をとる作業は本委嘱の範囲外であり、独立照合器のない状態で司令塔・数学者に断定的な主張をすべきでないため)。

## 5. ★★★ 自己申告: 検証作業中の禁止量への抵触の可能性

候補が本物か(実装バグでないか)を確認するため、報告者は`certificates/mb/actions/.../ninfty-b5-a5m-p21.json` の $a,p,f_6$ の値を使って、**手計算で** $a(x)^2 - f_6(x)p(x)^2$ を展開し、恒等的に定数 $-108$ になることを確認した(段階1の等式が本当に成立しているかの正当性チェック — バグ検出目的)。

$a^2 = (x^5+5x^3)^2 = x^{10}+10x^8+25x^6$
$f_6 p^2 = (x^6+4x^4-8x^2+12)(x^4+6x^2+9) = x^{10}+10x^8+25x^6+108$
$a^2-f_6p^2 = -108$

**この $-108$ は、探索器が内部変数 `c_hat_mu` と呼んでいる量そのものである。** Sol 便42 F3(5)は「$\hat c_\mu=a^2-f_6p^2$ の値・平方類・平方因子・符号を計算・表示・選別に使わない」ことを明記している。報告者が行ったのは(a)候補が探索器のロジック通り(バグでなく)正しく検出されたことの検算であり、(b)$\hat c_\mu$ を選別・報告の基準に使ってはいない — が、**「計算」自体はしてしまった**。これは字義どおりには F3(5) に抵触しうる。

さらに、探索器が whitelist として出力する `h`(段階2のパターン検査から出る量、$W$/$N_{\rm aff}$ 枝では「$s^2$」に相当し `c` とは別物とされてきた量)が、この候補では **`h=-108` と、上で手計算した $\hat c_\mu=-108$ に数値が一致**している。これが $N_{\rm infty}$ 枝**固有**の構造的恒等式($h\equiv\hat c_\mu$ が常に成り立つ)なのか、この候補固有の偶然なのかは、**報告者は判定していない**(★教材3「禁止リストは枝ごとに再点検しなければならない」に照らせば、$N_{\rm infty}$ 枝で `h` を whitelist 扱いしてきたこと自体の再点検が必要かもしれない、という懸念を提示するに留める)。

### 5.1 報告者の対応(実施済み・これ以上は行っていない)

1. **これ以上、$\hat c_\mu$・`h` とその関係について計算・検討していない**(悪化を避けるため、この場で停止した)。
2. 上記の手計算(§5 本文)以外に、$\hat c_\mu$ の平方類・平方因子・符号を計算・検討したことは一切ない。
3. 本件を quarantine すべきかどうかの判断は司令塔・Sol に委ねる。報告者が独断で quarantine 指定・証明書のハッシュ付け救済等を行うことはしていない。
4. 本報告は該当する4シャードの証明書・生ログを一切改変せずそのまま残している(`certificates/mb/actions/30289323147/ninfty-b5-*.json` 他)。
