## 2. 主体: 副枝 (N_infty) 探索器の新設

### 2.1 設計(S5 設計 v1.2 §3.3.5・命題 S5-3∞)

正規形: $f_6$(monic・squarefree・deg6・depressed = $B_5=0$ — Rule 1 M1 の $x$-平行移動を使い切ったゲージ)、$\mu=a(x)+p(x)y$($\deg a=5,\ \deg p=2$)、命題 S5-3∞:

$$ a(x)^2-f_6(x)p(x)^2=\hat c_\mu\ (\text{定数・非零}) \iff \operatorname{div}(\mu)=5P_0-5P_\infty. $$

**ゲージ**: $x$-平行移動は Rule 1 M1 が $B_5=0$ に使い切る(N_aff と違い $x(P_0)=0$ は使えない — $P_0=\infty_-$)。残余スケール($x\mapsto tx,\ y\mapsto t^3y$、weight $6-j$)は N_aff と同型の議論で $a_5=\pm1$ に正規化できる(f_6 の主係数が $a_5^2$ になるため monic 性と同値)。$\mu$-スケール(残り1自由度)は $\hat c_\mu$ の平方類を変える作用であり、★教材3(S5設計§6.3)により**平方類・平方因子・符号を一切計算・選択基準に使わず**、ゲージで縮めずにブルートフォースした($p_2$ も独立変数として走査 — $a_5^2=p_2^2$ は monic 検査から自動的に必要条件として出るので、$p_2=\pm a_5$ に事前固定する必要がない)。

### 2.2 二段階判定(厳密・浮動小数点不使用)

**段階1**: $a^2$ を $p^2$ で厳密多項式除算し(`polyDivMod`)、商が次数6・monic・depressed($B_5=0$)であり、余りが次数0以下(定数 $\hat c_\mu\ne0$)であることを検査する。除算による直接復元というシンプルな構造検査であり、N_aff の GCD 計算より計算コストが軽い(実測: 1候補あたり約0.03ms、N_aff の約1.1msの1/30)。$f_6$ の squarefree 性(非特異性)も検査する。

**段階2**: $s:=1/x$(Rule 1 補題 R1-U∞ の $P_0$ 有理 uniformizer)で $\tilde a(s):=s^5a(1/s)$ と置くと、命題の等式を使って $\mu$ のファイバー方程式は

$$ h(s;v):=s^5(v^2+\hat c_\mu)-2v\,\tilde a(s)=0 $$

に帰着する(N_aff の $g(x;v)$ と同型)。$v=0$ では $h(s;0)=\hat c_\mu s^5$ となり $s=0$ の5重根が自動的に現れる(N_aff と違い $v=0$ での「見かけの次数低下」は起きない)。

### 2.3 ★2つ目のアーティファクト因子の発見(N_aff と同型・事前に予見して検証)

$h(s;v)$ の $s^5$ 係数と $h'(s;v)$ の $s^4$ 係数は、共に $v^2-2a_0v+\hat c_\mu$(**2次式**、N_aff の線形因子と同型だがここでは2次)に比例して同時に消える。これは $s=\infty$($x=0$、曲線上の2点のいずれか)が射影的な意味での共通根になる特異点であり、幾何的な分岐点ではない。固定次数(5,4)の Sylvester 行列で計算した $D(v)$ はこの根で機械的に0になることを確認した(`stripKnownQuadraticFactor`)。

**この因子は N_aff での発見を踏まえて事前に予見し、実装前に較正で検証してから本走に組み込んだ**(下記§3・当初の較正テストで一度、除去対象の変数を取り違える実装ミスをし、較正が失敗したことで検出・即修理した — この経緯自体が較正の価値を示す)。

> **較正の境界(誠実な記録)**: stage1 と stage2 を**同時に**満たす実際の $(a,p)$ タプル(genuine な positive control)は、探索範囲内(bound≤4)に見つかっていない(下記§4の通り hits=0)。したがって stage2 の positive/adversarial 較正は、$a,p$ からの実装出しではなく、**パターン検出ロジック自体を直接検証する合成構成**で行った。この境界は N_aff の委嘱2報告でも同様であり、genuine な end-to-end positive control の構成は探索そのものと同格の難度である(§2.1 の generic design count の議論のとおり)。

N_aff 側にも同型の較正5項目を追加した(委嘱3の指示「N_aff 再走にも入れられるなら入れる」に対応・§1のN_aff再走証明書に `calibration` フィールドとして記録済み・全5項目pass)。

## 6. まとめ・次委嘱への提案

- **整合性照合**: 5/5 一致・INTEGRITY_STOP なし。
- **fail-closed 修理**: N_aff だけでなく W 側(bound12/bound20/gaugefix-60/rational)にも同型の穴があり、横展開で発見・修理・全再走した。**全ジョブで skip 0件を確認**(結論「候補0」は無傷)。
- **N_aff 再走**: bound3+bound4×4(cap8割規則でさらに細分化)、stage1_passes合計200件・hits 0件、委嘱2の数値と完全一致。1シャードのみ8割規則(480秒)を超過(577.958秒・絶対capは超えず)。
- **N_infty 探索器を新設**: 命題S5-3∞に基づく二段階判定(等式の除算による検査 + 分岐型パターン検査)。実装中に N_aff と同型の第二のアーティファクト因子(2次式)を事前に予見・較正で検証してから本走に反映した(較正自体が実装ミスを一度検出)。
- **N_infty 実行結果**: bound3(全域)+bound4(全8シャード)、tested合計86,410,020・stage1_passes744・**hits 0**。1シャードが600秒cap超過(652.7秒・完走はして健全)。
- **較正**: N_aff・N_infty とも positive/negative/adversarial の5項目較正を実装し証明書に記録、全項目pass。ただし genuine な end-to-end(実際の a,p から stage1+stage2 を同時に通す)positive control は探索範囲内に存在せず、パターン検出ロジック単体の合成較正に留まる(境界を明記)。
- **本委嘱の結論**: **UNKNOWN**(枝 (W)・(N_aff)・(N_infty) すべて探索範囲内で候補なし。三枝の初深度が揃った)。非存在は主張しない。
- **次委嘱への提案**:
  1. 三枝とも探索範囲の拡張(bound=5以上)、または2変数終結式による直接消去への切替え。
  2. cap見積りの精度向上 — 同一形状のジョブでも実行時間に2倍程度のばらつきが観測された(運用メモに記録)。次回はこの変動を見込んだより保守的な見積り(実測最大値基準)を使う。
  3. 独立照合器(crosscheck/)の新設は、候補0件のため引き続き未着手。候補が出た時点で必須。
  4. genuine な positive control(実際の (a,c_N) や (a,p) から stage1+stage2 を同時に通す具体例)の構成は、探索範囲を大幅に広げるか、逆算的な代数的構成法(多項式Pell方程式の理論等)を要する — 文献要請の対象として検討に値する。
