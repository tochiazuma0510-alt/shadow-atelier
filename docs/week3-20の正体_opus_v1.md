## 1. 一般補題(c ∈ N の窓の骨格)

記法は狩場計画 v4 §2 に従う。N は許容対象、**c ∈ N**、P := PB₃/N ≅ F₂/N_{F₂}、A := [P,P]、k := N_ord = ord(X̄)、Q := B₃/N、Δ̄, δ̄ は Δ = σ₁σ₂σ₁, δ_B = σ₁σ₂ の像、σ̄₁ = δ̄⁻¹Δ̄、θ = Ad(Δ̄)|_P、τ = Ad(δ̄)|_P、u := 2m+1。

### 補題 1(split-inner ⇒ Q ≅ P × S₃)【紙上証明・新規】

> **補題 1.** c ∈ N、**Z(P) = 1**、かつ **θ = Ad(s)、τ = Ad(t) を満たす s, t ∈ P で s² = t³ = 1 なるものが存在する**とする。このとき
> $$ C := C_Q(P) \cong S_3,\qquad Q = P \times C,\qquad \bar\Delta = s\sigma,\quad \bar\delta = t\rho \quad(\sigma := \bar\Delta s^{-1},\ \rho := \bar\delta t^{-1} \in C). $$

**証明.** θ = Ad(Δ̄) = Ad(s) ⇒ Ad(Δ̄s⁻¹)|_P = id ⇒ σ := Δ̄s⁻¹ ∈ C_Q(P)、同様に ρ := δ̄t⁻¹ ∈ C_Q(P)。
Z(P) = 1 ゆえ P ∩ C = Z(P) = 1。Q = ⟨Δ̄, δ̄⟩ かつ Δ̄ = sσ, δ̄ = tρ なので Q = PC、よって **Q = P × C**(C は P を中心化し、P ⊴ Q、C ∩ P = 1、PC = Q)。
σ² = 1: c ∈ N ⇒ Δ̄² = c̄ = 1、s は Δ̄ で不動(θ(s) = ss s⁻¹ = s)ゆえ σ² = Δ̄s⁻¹Δ̄s⁻¹ = Δ̄²·(Δ̄⁻¹s⁻¹Δ̄)s⁻¹ = θ⁻¹(s⁻¹)s⁻¹ = s⁻¹s⁻¹ = 1。
ρ³ = 1: δ̄³ = 1(T2(i))、τ(t) = t ゆえ同様に ρ³ = τ⁻²(t⁻¹)τ⁻¹(t⁻¹)t⁻¹ = t⁻³ = 1。
C ≅ Q/P ≅ S₃(T2(i))で σ² = ρ³ = 1、C = ⟨σ,ρ⟩ ⇒ C ≅ S₃。∎

**A₅ 窓での確認**: s = tX³ = (1 4)(3 5)、t = (1 2 3)、s² = t³ = 1、θ = Ad(s)、τ = Ad(t)、Z(A₅) = 1 ⇒ **命題 A5-Q(Q ≅ A₅ × S₃)は補題 1 の特別な場合**であり、A5-Q は「計算で確かめた事実」から「**一般補題の系**」に格上げされる。

### 補題 2(**v_m = σ̄₁^u** — 完全一般)【紙上証明・新規・★最重要の一般化】

> **補題 2.** c ∈ N なる任意の許容対象 N について、系 T2-B の元 v_m := δ̄⁻¹Ȳ^mΔ̄⁻¹ は
> $$ \boxed{\,v_m \;=\; \bar\sigma_1^{\,2m+1} \;=\; \bar\sigma_1^{\,u}\,}\qquad \text{in } Q = B_3/N. $$
> ゆえに **m が charming ⟺ v_m は ⟨σ̄₁⟩ ≅ C_{2k} の生成元**であり、とくに **ord_Q(v_m) = 2k は全ての charming m で一定**。

**証明.** τ = Ad(δ̄) より δ̄⁻¹Ȳ^mδ̄ = τ⁻¹(Ȳ^m)。τ(x) = y ⇒ τ⁻¹(y) = x ゆえ τ⁻¹(Ȳ) = X̄。また c ∈ N ⇒ Δ̄² = 1 ⇒ Δ̄⁻¹ = Δ̄、よって δ̄⁻¹Δ̄⁻¹ = δ̄⁻¹Δ̄ = σ̄₁(T2(i))。したがって
$$ v_m = \bigl(\bar\delta^{-1}\bar Y^m\bar\delta\bigr)\bigl(\bar\delta^{-1}\bar\Delta^{-1}\bigr) = \bar X^m\,\bar\sigma_1 = (\bar\sigma_1^{2})^m\,\bar\sigma_1 = \bar\sigma_1^{\,2m+1}. $$
(最後から二番目で x = σ₁² を使った。)T2(iv) より ord(σ̄₁) = 2k、charming は gcd(u,k) = 1 かつ u 奇 ⇒ gcd(u, 2k) = 1 ⇒ v_m は生成元。∎

> **★ 系 T2-B の畳み込み.** T2-B は次と同値になる:
> $$ m \in \mathfrak M(N) \iff \bar\sigma_1^{\,u} \in T_3\cdot\bigl(T_2\cap\bar\Delta A\bigr). $$
> すなわち **hexagon の可解性は「巡回群 ⟨σ̄₁⟩ ≅ C_{2k} の各生成元が(位数 3 の元)×(Δ̄A 内の対合)に分解するか」という一本の問い**である。charming な m を走らせることは **σ̄₁ の生成元を走らせること**にほかならない。
> **これは狩場の宇宙を (2,3,2k) 三角群の側から見る視点と完全に整合する**: Q = ⟨Δ̄,δ̄⟩ は Δ(2,3,2k) の商で σ̄₁ が第三生成元、問題は「**第三生成元の各冪の (2,3)-分解**」— dessins / Hurwitz 数え上げの言葉そのものである(→ §6 文献要請 8)。

**A₅ 窓での確認(検算スクリプト)**: w := σ̄₁ の P 成分 = t⁻¹s = (1 4 3 5 2)、**w² = X ✔**、**w = X³ ✔**、v_m = w^u = X^{m+3} を m = 0,1,2,3,4 の全てで確認 ✔(m = 2 のみ v_m = 1、これはちょうど非 charming)。

### 補題 3(P 完全 ⇒ 判定は P 内の (2,3)-分解に落ち、**scalar Frobenius で足りる**)【紙上証明・新規】

> **補題 3.** 補題 1 の仮定に加え **P が完全**(A = [P,P] = P)とする。w := σ̄₁ の P 成分(w² = X̄)と置く。このとき任意の m について
> $$ n_m := \#\{f \in A : (\text{H-a}) \wedge (\text{H-b}')\} \;=\; N_P(w^u) := \#\{(r,g) \in T_3(P)\times T_2(P) : rg = w^u\}, $$
> かつ **E4′ の行列値 Fourier 公式は scalar 指標和公式に潰れる**:
> $$ n_m \;=\; \frac1{|P|}\sum_{\chi\in\mathrm{Irr}(P)} \frac{S_2(\chi)S_3(\chi)}{\chi(1)}\;\overline{\chi(w^{u})},\qquad S_j(\chi) := \sum_{x^j=1}\chi(x). $$

**証明.** 補題 1 で Q = P × S₃、Δ̄ = (s,σ)、δ̄ = (t,ρ)。f ∈ A = P について
- (H-a): Δ̄f̄ = (sf, σ)、(Δ̄f̄)² = ((sf)², σ²) = ((sf)², 1) ⇒ **(H-a) ⟺ (sf)² = 1**。
- (H-b′): δ̄⁻¹Ȳ^mf̄ = (t⁻¹Y^mf, ρ⁻¹)、その 3 乗 = ((t⁻¹Y^mf)³, 1) ⇒ **(H-b′) ⟺ (t⁻¹Y^mf)³ = 1**。

g := sf と置くと(s² = 1 ゆえ f ↦ g は A = P 上の全単射)第一条件は g² = 1、第二条件は t⁻¹Y^m f = t⁻¹Y^m s·g = v̂_m g(v̂_m = w^u は補題 2 の P 成分)の 3 乗が 1。r := w^u g と置けば r³ = g² = 1, rg = w^u g² = w^u。逆も同様。ゆえに n_m = N_P(w^u)。

scalar 化: E4′ の C = Δ̄A は今 A = P ゆえ **C = P × {σ}** という完全な coset であり、
$$ z_{2,C} = \Bigl(\sum_{g\in P,\ g^2=1} g\Bigr)\otimes\sigma = z_2(P)\otimes\sigma $$
となって **z₂(P) は ℂ[P] の中心元**である。ゆえに ρ_χ(z_{2,C}) = (S₂(χ)/χ(1))·I がスカラーになり、E4′ の Tr は χ(1)·(S₂(χ)/χ(1))·χ(w^{-u}) に潰れて古典 Frobenius 公式(命題 E4)に一致する。∎

> **★【GAP-E2a】への部分解答**: 「E4′ を指標表だけの scalar 式に落とせるか」という未解決問題は、**P が完全かつ θ,τ が P 内の (2,3)-元で内部的(補題 1)なとき、Yes** である。z_{2,C} が中心的でなくなるのは **A ⊊ P のとき**だけであり、**Q7 正面(非可解 P)の主要な対象では scalar 公式が使える**。文献要請 4 はこの分だけ射程を狭められる(§6)。

### 補題 4(**θ-捻れ共役 torsor**)【紙上証明・新規】

> **補題 4.** (a) 集合 ℬ_θ := {f ∈ A : θ(f) = f⁻¹} は、**任意の h ∈ P** による **θ-捻れ共役** f ↦ f^{(h)} := θ(h)·f·h⁻¹ で保たれる(h が A に入る必要はない)。
> (b) さらに h ∈ C_P(v̂_m) ならば (H-b′) も保たれる。ゆえに **C_P(v̂_m) は m-繊維 𝔉_m := {f : (H-a)∧(H-b′)} に作用する**。
> (c) 点 f の固定化群は {h ∈ C_P(v̂_m) : h ∈ C_P(g)}(g = sf)。とくに **gcd(ord(v̂_m), |C_P(g)|) = 1 ならば作用は自由**で、**ord(v̂_m) は |𝔉_m| を割る**。
> (d) 一つの解 f₀ が分かれば、⟨v̂_m⟩-軌道は **𝔉_m ⊇ {θ(v̂_m^j)·f₀·v̂_m^{-j} : j}**。

**証明.** (a) θ² = id より θ(f^{(h)}) = θ(θ(h)fh⁻¹) = h·θ(f)·θ(h)⁻¹ = h f⁻¹ θ(h)⁻¹ = (θ(h)fh⁻¹)⁻¹ = (f^{(h)})⁻¹。
(b) g = sf と置くと g^{(h)} := s·f^{(h)} = s θ(h) f h⁻¹ = s(shs⁻¹)fh⁻¹ = h·(sf)·h⁻¹ = hgh⁻¹(s² = 1 を使用)。すなわち **θ-捻れ共役は g 側では素の共役**である。h ∈ C_P(v̂_m) なら v̂_m g^{(h)} = v̂_m hgh⁻¹ = h(v̂_m g)h⁻¹ で、位数 3 の条件は共役不変 ✔。
(c) g^{(h)} = g ⟺ h ∈ C_P(g)。(d) は (b) を h = v̂_m^j に適用したもの。∎

> **注意(なぜ「捻れ」共役か)**: g 側から見れば単なる共役だが、**shadow の座標 f から見ると θ で捻れる**。L の C₃ が「[P,P] = Z(H₃) による平行移動」であったのと構造的に異なるのはこの点である。

### 補題 5(生成の自動性 — A₅ 型)【紙上証明】

> **補題 5.** P = A₅、w^u が 5-サイクルのとき、n_m 個の解はすべて **⟨g, r⟩ = A₅** を満たす(generation_fail = 0)。
