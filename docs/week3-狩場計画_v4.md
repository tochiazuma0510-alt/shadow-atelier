## 2. hexagon の torsion 再定式化(確定版)

### 2.1 定理 T2(便 07 合格・変更なし)

記法。N を許容対象、**c ∈ N**、P := PB₃/N ≅ F₂/N̄、A := [P,P]、k := ord(X̄) = N_ord。**Q := B₃/N**(位数 6\|P\|)、Δ := σ₁σ₂σ₁、δ_B := σ₁σ₂ の像を Δ̄, δ̄ ∈ Q と書く(**W55**: 以下 B₃ 側の δ は必ず **δ_B** と書き、Guillot 側の d_G = τθ と区別する)。

> **定理 T2.**
> **(i)** Δ̄² = δ̄³ = 1、P ⊴ Q、Q/P ≅ S₃、**Q = ⟨Δ̄, δ̄⟩ は PSL(2,ℤ) ≅ C₂ * C₃ の有限商**。σ̄₁ = δ̄⁻¹Δ̄、σ̄₂ = Δ̄δ̄⁻¹。
> **(ii)** P 上で **θ = Ad(Δ̄)**、**τ = Ad(δ̄)**(Ad(g)(w) = gwg⁻¹)。
> **(iii)** f̄ ∈ A、h := Ȳ^m f̄ と置くと
> $$ (H\text{-a})\ \theta(\bar f)=\bar f^{-1} \iff (\bar\Delta \bar f)^2 = 1,\qquad
> (H\text{-b}')\ E_m\mathcal N_m(\bar f)=1 \iff (\bar\delta^{-1}\bar Y^m \bar f)^3 = 1. $$
> **(iv)** ord(σ̄₁) = ord(σ̄₂) = 2k。ゆえに **Q は三角群 Δ(2,3,2k) = ⟨a,b \| a² = b³ = (b⁻¹a)^{2k} = 1⟩ の有限商**。

証明は v3 §2.1 のまま(土台は §1 末尾で閉鎖済み)。(iii) の第二式は便 07 F2 が独立に再導出した:h := Ȳ^m f̄ と置き δ̄⁻¹w = τ⁻¹(w)δ̄⁻¹ を三回使うと (δ̄⁻¹h)³ = τ⁻¹(h)τ⁻²(h)τ⁻³(h) = τ²(h)τ(h)h であり、これは簡約 hexagon (3.11) そのもの。**積の順序・逆元のずれはない**(便 07 の独立確認)。

### 2.2 系 T2-A′(**G-01 修正版** — 掃引宇宙の正しい parametrization)

v3 の系 T2-A は誤りではないが**不十分**だった。三角群の関係式 (b⁻¹a)^{2k} = 1 は **ord(b⁻¹a) \| 2k** しか課さない。実際の位数が 2d(d \| k、d < k)である商も混入し、その逆構成が与える N は N_ord = d であって k ではない。**exact order を data に追加**する。

> **系 T2-A′.** k ≥ 1 を固定する。次の二つは**一対一に対応する**。
> **(a)** 「c ∈ N かつ N_ord = k」なる許容対象 N ⊴ B₃(有限指数、N ≤ PB₃)の全体。
> **(b)** 三つ組 **(Q, φ, ε)** の **marked quotient 同型類**。ここで
> - Q は有限群、φ: Δ(2,3,2k) ↠ Q は全射、ε: Q ↠ S₃ は全射、
> - **ε∘φ は標準 modular 射影**(§2.4 の marking 規約に従う。標準 braid 射影との**同時共役**を許す — G-02)、
> - **`ord_Q(φ(b⁻¹a)) = 2k`**(← v3 に欠けていた条件)。
>
> **marked 同型類**: (Q,φ,ε) ~ (Q′,φ′,ε′) ⟺ 同型 ψ: Q → Q′ が存在して **ψ∘φ = φ′ かつ ε′∘ψ = ε**。
> 対応は N ↦ (B₃/N, 自然な全射, B₃/N ↠ S₃)、逆は (Q,φ,ε) ↦ N := ker(B₃ → Q; Δ ↦ φ(a), δ_B ↦ φ(b))。

**証明.**
**(a)⇒(b)**: 定理 T2(i) より Q := B₃/N は Δ̄² = δ̄³ = 1 を満たす二元生成群、すなわち PSL(2,ℤ) = ⟨a,b \| a²=b³=1⟩ の商。T2(iv) より ord(σ̄₁) = ord(φ(b⁻¹a)) = 2k なので Δ(2,3,2k) の商でもあり、exact order 条件を満たす。ε は B₃/N ↠ B₃/PB₃ ≅ S₃(N ≤ PB₃ ゆえ定義される)。ε∘φ は B₃ ↠ S₃ の標準射の Δ,δ_B 表示である。
**(b)⇒(a)**: B₃ = ⟨Δ, δ_B \| Δ² = δ_B³⟩(§1 末尾で原文照合済み)より、Δ ↦ φ(a), δ_B ↦ φ(b) は準同型 B₃ ↠ Q を定める(φ(a)² = 1 = φ(b)³ ゆえ関係 Δ² = δ_B³ が保たれる)。N := ker は有限指数正規。c = Δ² ↦ φ(a)² = 1 ゆえ **c ∈ N**。ε∘φ が標準射なので N ≤ ker(B₃ ↠ S₃) = PB₃、ゆえに補題 H1 より N は許容。最後に N_ord: c̄ = 1 かつ Ȳ = θ(X̄) は X̄ と同位数なので N_ord = ord(X̄)、そして X̄ = σ̄₁² = φ(b⁻¹a)² より **ord(X̄) = 2k/gcd(2,2k) = k** ✔。
両構成が互いに逆であることは生成元の像で直ちに従う(marked 同型類を法として)。∎

> **注意 1(W51 — 規律に格上げ).** presentation の関係式が与えるのは「**位数が割る**」であって「位数が等しい」ではない。掃引の宇宙定義・certificate の双方で `exact_order_binv_a` を**独立欄**として要求する(manifest の各段 `triangle_marking.exact_order_binv_a`)。

> **注意 2(本稿の追加観察 — 「2」の因子は自動).** ε(φ(b⁻¹a)) = ε(b)⁻¹ε(a) は S₃ の**転置**(§2.4)なので位数 2、ゆえに **ord_Q(φ(b⁻¹a)) は常に偶数**である。よって一般の (Q,φ,ε) では ord_Q(φ(b⁻¹a)) = 2d と書け、対応する N は N_ord = d を満たす。**追加すべきは「偶数性」ではなく「exactness(d = k)」だけ**である — F3 の要求はこの形で必要十分。
> **検算**: A₅ 対象(§5)で ord_Q(σ̄₁) = 10 = 2·5、k = ord(X) = 5 ✔(スクリプト)。

★ **掃引への影響**: v3 §3.6・§4.3 の宇宙定義は **exact order 条件つきに書き換える**。書き換え後の掃引は依然「Δ(2,3,2k) の有限商で S₃ にマークされたもの」の列挙だが、**列挙結果から ord(φ(b⁻¹a)) < 2k のものを落とす**(落としたものは k′ = ord/2 の段に属する別対象であって、捨てるのではなく**その k′ の宇宙へ移す**)。

### 2.3 系 T2-B(便 07 合格・ただし生成判定は分離 — G-05)

> **系 T2-B.** m ∈ 𝒳_N について、
> $$ m \in \mathfrak M(N) \iff \exists\, g \in \bar\Delta A:\ g^2 = 1 \ \text{かつ}\ (v_m g)^3 = 1,\qquad v_m := \bar\delta^{-1}\bar Y^m\bar\Delta^{-1}. $$
> 同値に、**v_m が「位数 3 の元 r」と「対合 g ∈ Δ̄A」の積 r·g として書けるか**(g² = 1 ゆえ rg = v_m ⟺ r = v_m g)。すなわち
> $$ m\in\mathfrak M(N) \iff v_m \in T_3\cdot(T_2\cap\bar\Delta A),\qquad T_n := \{q\in Q: q^n=1\}. $$

**便 07 の修正(F5/P70/W52 — 厳守)**: v3 は「shadow であるためには生成性が要り、それは ⟨g,r⟩ = Q と**同値に近い**」と書いた。**「同値に近い」は実装の判定基準にしてよい根拠ではない。**

> **実装規律(G-05)**: torsion 判定(系 T2-B)と生成判定は **別 certificate** に分ける。
> - torsion: `h10_fail` / `h11_fail`(排他的 staged count)。
> - 生成: **従来の marked generators test `⟨X^u, f⁻¹Y^u f⟩ = P` を正本**とし、`generation_pass_count`(候補別の欄。boolean 禁止 — 一つの m に複数解があり得る)で出す。
> - ⟨g,r⟩ = Q を正本判定に昇格するのは、**shadow の生成条件との同値を証明した後に限る**(W52)。それまでは**独立の観測欄** `torsion_generation_agrees`(参考値)として並走させてよい。

### 3.2 命題 E2′(**G-03 — 弱化した確定版**)

v3 の命題 E2 は「**ある** σ_A ∈ Aut(A) が存在して ρ が同変 ⟺ X^u ∈ C_P(A)」という必要十分形だった。**掲載計算が証明したのは canonical candidate に対する同値だけ**である。以下が確定版。

> **命題 E2′.** ρ(f) := θ(f)⁻¹、捻れ作用を λ(a)(f) := σ(a)⁻¹ f a と書く。**canonical candidate σ_A := σ⁻¹θ ∈ Aut(A)** について、

### 5.6 補題 A2A1(**G-08** — A2 → A1 の全 shadow 集合全単射)

v3 §5.5 は `R_to_NA` の全射性を「A1 の既知 4 解がそのまま持ち上がる」で根拠づけていた。**これでは未知の A1-shadow を覆わない**(F20)。以下が確定版で、**結論は一般に証明できる**。

> **補題 A2A1.** P_{A1} = A₅、P_{A2} = A₅ × C₅(v3 §5.3)。reduction R := R_{M_{A,5}, N_A} は
> $$ \mathrm{GT}(M_{A,5}) \longrightarrow \mathrm{GT}(N_A) $$
> の**集合としての全単射**である。とくに `gt_count_A2 = gt_count_A1`(両者が UNKNOWN のままでも等号は言える)。

**証明(F20 の論法を私の記法で書き下したもの).**
**(1) 候補集合の一致.** 両段の N_ord は 5(A1: lcm(5,5,1)、A2: lcm(5,5,5))、𝒳 = {0,1,3,4} も一致。f の動く範囲は導来部分群であり、
$$ [P_{A2},P_{A2}] = [A_5\times C_5,\,A_5\times C_5] = A_5\times 1 $$
(C₅ 可換・A₅ 完全)。射影 A₅×1 → A₅ は同型なので、**候補集合 𝒳 × [P,P] は両段で標準的に同一視される**(240 点)。
**(2) hexagon の A₅ 成分.** 任意の A1-shadow [m, f_A] を取る。A₅ は完全なので f は [F₂,F₂] の語で代表できる。その代表の P_{A2} における像は (f_A, 1) である(C₅ は可換なので [F₂,F₂] は C₅ 成分へ自明に写る)。hexagon の A₅ 成分は A1 の hexagon そのもの。
**(3) hexagon の C₅ 成分.** C₅ は可換商なので、その成分の hexagon は f に依らず m のみの線型条件に落ち、**N₅ 側の shadow [m, 1] の存在**(v3 §5.5 `R_to_N5 = surjective`・便 06 F13)がそれを与える。ゆえに全 m ∈ 𝒳 で成立する。
 ※ **c ∉ M なので (3) の検証は語レベルで行う**(§5.3)。これは manifest の fixture **A2-F4** として実地に検査する項目であり、紙上では上の N₅ の m-full 性に依拠している。
**(4) 生成性.** 持ち上げた組が生成する部分群 S ≤ A₅ × C₅ は、A₅ 成分へ全射(A1 の生成性)、C₅ 成分へ全射(N₅ の生成性)。**A₅ と C₅ には非自明な共通商が無い**(A₅ 単純非可換ゆえ商は 1 と A₅、C₅ の商は 1 と C₅、A₅^{ab} = 1)。Goursat より **S = A₅ × C₅** ✔。
**(5) 一意性と逆向き.** (1) により lift は候補として一意。逆向きの reduction(A2-shadow ↦ その A₅ 成分)は定義から明らか。ゆえに R は集合の全単射 ∎

> **W57(厳守).** A1・A2 の **isolated 性が UNKNOWN の間は、この全単射を「群同型」と呼ばない**。GT(A1)・GT(A2) は groupoid の hom-集合であって群であることが確定していない。呼べるのは「**集合の全単射**」と「**gt_count の等号**」までである。

★ **意義**: これで A2 段は「A1 の答え合わせ」ではなく「**c 生存対象で語レベル hexagon 配管が健全に動くか**」の独立な検査になる。A2 の答えが A1 と食い違えば、それは **語レベル評価の実装バグか、上の補題の誤り**のいずれかであり、どちらでも情報量がある。
