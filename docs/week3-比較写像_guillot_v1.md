## 1. Guillot 側の正本(配達 02 §1 の要約・我々の記法へ)

- F₂ = ⟨x,y⟩。有限群 G に対し **N_G := {N ⊴ F₂ : F₂/N ≅ G} の全部の交わり**(有限個の交わり)、**Ḡ := F₂/N_G**。
- 標準自己同型: **θ: x ↦ y, y ↦ x**、**δ: x ↦ y⁻¹x⁻¹ = z, y ↦ y**(z := (xy)⁻¹)。
- **GT(G) := {φ ∈ Aut(Ḡ) : (1) φ(x) は x^k の共役(k は |Ḡ| と素) かつ (2) Out(Ḡ) 内で θ・δ と可換} の Out(Ḡ) における像。** GT₁(G) は k = 1 に制限した正規部分群。
- **k は well-defined でない**(x^k 同士が共役になり得る)ので φ ↦ k という写像は存在しない — **λ 座標をもつ主線 GTSh との決定的な差**。
- hexagon の明示方程式は書かれず、**θ/δ 可換性にエンコード**されている。

**我々の (θ, τ) との関係(照合済)**: τ(x) = y, τ(y) = z, τ(z) = x に対し
$$ \boxed{\ \tau = \delta\circ\theta,\qquad \delta = \tau\circ\theta\ } $$
(δθ(x) = δ(y) = y = τ(x)、δθ(y) = δ(x) = z = τ(y)、δθ(z) = (yz)⁻¹ = x = τ(z))。ゆえに **⟨θ,τ⟩ = ⟨θ,δ⟩**、S₃ 対称性は同じものである。

## 2. 定義域の同定 — genus 対象 N^{(G)}

Guillot の GT(G) は **Ḡ = F₂/N_G** の上で定義される。我々の対象 N は marked 商 P = F₂/N̄ を与えるだけなので、**比較が well-posed になるのは P ≅ Ḡ のとき**、すなわち **N̄ = N_G** のときである。

> **定義.** 有限 2 生成群 G に対し **N^{(G)} := π⁻¹(N_G) ⊴ B₃**(π: PB₃ ↠ PB₃/⟨c⟩ ≅ F₂)を **G の genus 対象**と呼ぶ。

> **補題 G0.** N^{(G)} は**常に許容対象**であり、c ∈ N^{(G)}。
>
> **証明.** N_G は「F₂/N ≅ G なる N 全体」という Aut(F₂)-不変な族の交わりなので **F₂ の特性部分群**。特に θ, τ 不変。補題 H1 より N^{(G)} ⊴ B₃。c ∈ π⁻¹(任意) ✔。∎

★ **これで「有限 2 生成群 G ↦ 許容対象 N^{(G)}」という標準的な埋め込みが得られた。** Guillot の塔は我々の設計空間の中に**部分集合として**住んでいる(genus 対象のなす部分族)。

> **定理 G4(比較が well-posed な対象).** G が **その生成する多様体の階数 2 の相対自由群**であるか、あるいは **Aut(G) が G の生成対の集合に推移的に作用する**ならば **N_G = ker(F₂ ↠ G)**、すなわち **Ḡ ≅ G ≅ P**。とくに:
> - **Q₈**: 生成対は 24 個、|Aut(Q₈)| = 24 で単純推移 ⇒ **N_{Q₈} = ker(F₂ ↠ Q₈) = N̄_Q**。
> - **P₂ = F₂/F₂⁴γ₃、P₃ = F₂/F₂⁴γ₄**: 相対自由 ⇒ 任意の全射 F₂ ↠ P_i の核は多様体の verbal 部分群を含み、verbal 部分群自身がその一つ ⇒ **N_{P_i} = F₂⁴γ_{i+2}(F₂) = N̄_i**。
> - **A₅**: 生成対の Aut(A₅)-軌道は複数(位数型 (2,3,5), (5,5,5) 等が別軌道)⇒ **N_{A₅} ⊊ ker q**、すなわち **N_A は genus 対象ではない**。

⇒ **W48/P65 の検証順序(Q₈ → P₂ → P₃)は、まさに「genus 対象である最小の 3 つ」を並べたものだった**(結果的に正しい選択)。**A₅ は比較写像の定義域外**である(§7 で例外的に使える形を述べる)。

## 3. 写像の構成と well-definedness

記法は狩場計画 v3 §2 に従う: 許容 N(c ∈ N)、P = F₂/N̄、Q = B₃/N、u := 2m+1。
GT-shadow [m,f] は準同型 **T_{m,f}: B₃ → B₃/N = Q**、σ₁ ↦ σ̄₁^u、σ₂ ↦ f⁻¹σ̄₂^u f を与える(2401 Def 3.1 + Prop 3.6)。

> **補題 G0′.** T_{m,f} は **S₃ 上恒等**、すなわち B₃ ↠ S₃ との合成が標準射に等しい。ゆえに **T_{m,f}(PB₃) ⊆ P** かつ **T_{m,f}(Δ) ∈ Δ̄P、T_{m,f}(δΔ) ∈ δ̄Δ̄P**。
>
> **証明.** σ̄ᵢ^u は u 奇より転置 (i,i+1) へ、f⁻¹σ̄₂^u f も同じ転置へ写る。∎

> **定理 G1(well-definedness).** N を許容対象(c ∈ N)、[m,f] ∈ GT(N) が **settled**(ker T_{m,f} = N)とする。このとき
> $$ \alpha_{m,f}: P \to P,\qquad X \mapsto X^{u},\quad Y \mapsto \bar f^{-1}Y^{u}\bar f $$
> は **P の自己同型として well-defined** であり、**類 [m,f] = (m + N_ord ℤ, f N̄) のみに依存する**。
>
> **証明.**
> (a) x ↦ X^u, y ↦ f̄⁻¹Y^u f̄ は F₂ → P の準同型を定める(自由性)。これは T_{m,f}|_{PB₃} を PB₃/⟨c⟩ = F₂ へ落としたもの(c ∈ N ゆえ T(c) = c^u ↦ 1)。
> (b) shadow の全射性より F₂ ↠ P。**settled は ker(T^{F₂}_{m,f}) = N̄ を意味する**ので、これは P = F₂/N̄ → P の同型に降りる(補題 F)。
> (c) f の代表: f̄ ∈ P にしか依存しない ✔。
> (d) m の代表: c ∈ N ゆえ **N_ord = lcm(ord X̄, ord Ȳ, ord c̄) = k = ord(X)**。m を m + N_ord に替えると u ↦ u + 2k で X^{u+2k} = X^u、Y^{u+2k} = Y^u ✔。∎

★ **F15 の指摘への対応**: この α は **u を忘れていない**(α(X) = X^u)。忘れるのは「自己同型全体への同時内部共役」だけである。**「f だけを内部自己同型で割る」という v2 の案は型が違った** — Sol の指摘のとおり。

> **定理 G2(準同型性).** N が **isolated**(全 shadow が settled)ならば
> $$ \Phi_0:\ \mathrm{GT}(N) \longrightarrow \mathrm{Aut}(P),\qquad [m,f]\mapsto \alpha_{m,f} $$
> は群準同型(合成の向きは GT(N) の積の規約に従う)。
>
> **証明の骨格.** GT(N) = GTSh(N,N) の積は groupoid の合成であり、対応する T の合成である(2401 Thm 3.10 / Remark 3.16)。α は「T を PB₃/⟨c⟩ 上へ制限して落とす」という**関手的**操作なので合成を保つ。∎
> **【GAP-G1】**: 2401 Thm 4.6 の明示公式 (4.19)(4.20) との**符号・向きの逐語照合**は未了。準同型か反準同型かは規約依存であり、**初弾(§6)の Q₈ で数値照合する**。

## 4. Guillot 条件の検証

> **定理 G3(条件 (2) は自動).** N を許容対象(c ∈ N)、[m,f] を settled shadow とすると、**α_{m,f} は Out(P) 内で θ とも δ とも可換**である。
>
> **証明.** 任意の q ∈ B₃ と w ∈ PB₃ について T := T_{m,f} は準同型なので
> $$ T(qwq^{-1}) = T(q)\,T(w)\,T(q)^{-1}. $$
> 左辺は Ad(q̄)(w̄) ∈ P の α-像、右辺は Ad(T(q))(α(w̄)) であるから
> $$ \boxed{\ \alpha\circ \mathrm{Ad}(\bar q)\big|_P \;=\; \mathrm{Ad}(T(q))\circ\alpha\ }\qquad (\forall q\in B_3). $$
> ここで狩場計画 v3 定理 T2(ii) より P 上 **θ = Ad(Δ̄)**、**τ = Ad(δ̄)**、ゆえに **δ_{Guillot} = τθ = Ad(δ̄Δ̄)**。
> - q = Δ: 補題 G0′ より T(Δ) = Δ̄p(∃p ∈ P)、ゆえに Ad(T(Δ)) = θ∘Ad(p)。したがって **αθα⁻¹ = θ∘Ad(p) ≡ θ mod Inn(P)** ✔。
> - q = δΔ: 同様に T(δΔ) = δ̄Δ̄p′、**αδα⁻¹ = δ∘Ad(p′) ≡ δ mod Inn(P)** ✔。∎

★ **これは「hexagon が θ/δ 可換性にエンコードされている」という Guillot 側の設計(配達 §1)と、我々の「hexagon = B₃ 準同型の存在」という設計が、**同じ事実の二つの書き方**であることの証明**である。§2 の torsion 再定式化(狩場計画 v3 定理 T2)と合わせて、**主線と Guillot の橋は「B₃ → Q が準同型である」という一点に集約する**。

> **定理 G2′(条件 (1) は charming から出る).** α_{m,f}(X) = X^u であり、charming(gcd(u, N_ord) = 1、N_ord = ord X)より、**gcd(k, |P|) = 1 なる k で X^k = X^u なるものが存在する**。ゆえに Guillot 条件 (1) を満たす。
>
> **証明.** e := ord(X)、gcd(u,e) = 1。CRT で k を e と ∏_{p | |P|} p の積を法として選ぶ: p | e なる素数では k ≡ u (mod p^{v_p(e)}) から p ∤ k、p ∤ e なる素数では k ≢ 0 (mod p) と取れる。X^k = X^{k mod e} = X^u ✔。∎
> ★ **k が well-defined でない**(配達 §1)ことが、ここで**効いている**。素朴に「u と |P| が素であること」を要求すると **A₅・m = 1(u = 3, 3 | 60)で条件が破れる**が、代表を k = 13 に取り替えれば通る。**この一点は誤解しやすいので明記しておく。**

> **系(比較写像).** N が **genus 対象 N^{(G)}** かつ **isolated** ならば
> $$ \boxed{\ \Phi:\ \mathrm{GT}(N^{(G)}) \longrightarrow \mathrm{GT}(G) \subseteq \mathrm{Out}(\bar G) = \mathrm{Out}(P),\qquad [m,f]\mapsto[\alpha_{m,f}]\ } $$
> は well-defined な群準同型(定理 G1・G2・G2′・G3)。

## 7. 初弾の紙上結果(私の計算・単系統)

### 7.1 Q₈: **Φ は零写像**

- 4 つの shadow は [0,1], [1,−1], [2,−1], [3,1](v1 §3.5)。α_{m,f}(i) = i^u, α(j) = f̄⁻¹j^u f̄ = j^u(f̄ = ±1 は中心)。

- 後者は **Ad(k)**(k i k⁻¹ = −i、k j k⁻¹ = −j)ゆえ **内部**。
- ⇒ **Im Φ = 1、ker Φ = GT(N_Q) 全体(位数 4)。**
- 一方 Guillot 側: θ(i↔j)は Inn(Q₈) = Q₈/Z ≅ C₂²(偶数個の符号変更)に入らないので Out で非自明、δ(i ↦ (ij)⁻¹ = −k, j ↦ j)は Out で位数 3。ゆえに **⟨θ̄,δ̄⟩ = Out(Q₈) ≅ S₃**、したがって
 $$ \mathrm{GT}(Q_8) \subseteq C_{\mathrm{Out}(Q_8)}(\langle\bar\theta,\bar\delta\rangle) = Z(S_3) = 1. $$
 ⇒ **GT(Q₈) = 1**(私の導出。配達 §1 の定義に基づく。**Guillot 原論文 §5.4 の表とは照合していない** — W48 の留保どおり錨にしない)。
- **結論**: Φ: GT(N_Q) → GT(Q₈) は **4 → 1 の零写像**。**整合する**が情報量はゼロ。**「我々は 4 を見、Guillot は 1 を見る」という差別化の最小の実例**である。

### 7.2 A₅(定義域外だが Φ₀ は計算できる): **像は非自明**

A₅ は genus 対象でない(定理 G4)ので **Φ の定義域には入らない**。しかし **Φ₀: [m,f] ↦ α_{m,f} ∈ Aut(A₅) = S₅ 自体は定義できる**(4 解が settled であることを狩場計画 v3 §5.1 で確認した)。私の計算では

| 0 | () | 自明 |

⇒ **Out への像は非自明**(C₂ を張る)。**Q₈ と正反対**である。

★ **示唆(推測・証明ではない)**: 比較写像が「見える」のは **P が完全群/単純に近い側**、消えるのは **P が冪零な側**かもしれない。Q₈ で Inn が大きく(Q₈/Z = C₂²)、A₅ で Inn = A₅ だが Out = C₂ が生きている、という対比。**これは推測である** — G-1〜G-3 の実測と、genus 対象での再計算を待つ。
