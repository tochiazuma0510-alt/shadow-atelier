## 2. Q_J の同定(3 因子 Goursat — 慎重な議論)

### 2.1 素朴な主張は偽である

> **偽**: 「S ≤ A×B×C が部分直積(各射影が全射)で、3 つの**対射影** S → A×B, A×C, B×C がすべて全射なら S = A×B×C」。

反例: A = B = C = C₂、S = {(a,b,c) : a+b+c = 0} ≤ C₂³。各射影も各対射影も全射だが [C₂³ : S] = 2。したがって「3 因子だから対ごとに見れば十分」という論法は使えない。**Sol P22 の期待商 G₃×H₃×C₅ は、証明が要る。**

### 2.2 正しい補題

> **補題 J1(n 因子 Goursat).** A₁, …, A_n を有限群、S ≤ A₁×…×A_n を部分直積(各射影が全射)とする。すべての i ≠ j について A_i と A_j が**非自明な共通商をもたない**ならば S = A₁×…×A_n。

**証明**(n についての帰納法)。n = 1 は自明。n = 2 は Goursat の補題: S は共通商 A₁/A₁′ ≅ A₂/A₂′ 上の fiber 積であり、共通商が自明なら S = A₁×A₂。

n ≥ 3。T := pr_{A₁×…×A_{n−1}}(S) は部分直積なので帰納法の仮定より T = A₁×…×A_{n−1}。よって S ≤ T × A_n は部分直積で、Goursat より共通商 D(T の商かつ A_n の商)上の fiber 積。D ≠ 1 とすると、D は有限なので単純商 T₀ をもつ。T₀ は A₁×…×A_{n−1} の単純商だから、**ある i < n について A_i の商である**(理由: 各 A_i の像は T₀ の正規部分群で、それらの積が T₀。T₀ 単純なのでどれかの像が T₀)。一方 T₀ は A_n の商でもある。これは A_i と A_n が非自明な共通商 T₀ をもつことを意味し、仮定に反する。ゆえに D = 1、S = A₁×…×A_n。∎

### 2.2′ 累積型障害による再定式化【v2 新規 — 文献配達 01 §A】

## 5. gluing obstruction の数学的定式化

### 5.1 fiber 積

L, M₅ ≤ K⁽³⁾、J = L ∩ M₅。4 対象すべて isolated なので GT(·) は有限群、R は群準同型。**fiber 積**を

$$ \mathrm{GT}(L)\times_{\mathrm{GT}(K^{(3)})}\mathrm{GT}(M_5) \;:=\; \bigl\{(\lambda,\mu)\in \mathrm{GT}(L)\times\mathrm{GT}(M_5) \;:\; R_{L,K^{(3)}}(\lambda) = R_{M_5,K^{(3)}}(\mu)\bigr\} $$

と定める(群の fiber 積 = 引き戻し)。定理 A(iii)・定理 B(iii) により両 R は全射で繊維は一様に 3, 4 なので

$$ \bigl|\mathrm{GT}(L)\times_{\mathrm{GT}(K^{(3)})}\mathrm{GT}(M_5)\bigr| \;=\; \sum_{s\in \mathrm{GT}(K^{(3)})} 3\cdot 4 \;=\; 12\cdot 12 \;=\; \mathbf{144}. $$

### 5.2 自然な写像 Φ

$$ \Phi := (R_{J,L},\, R_{J,M_5}) : \mathrm{GT}(J)\longrightarrow \mathrm{GT}(L)\times \mathrm{GT}(M_5). $$

**像が fiber 積に入ること**: 還元の関手性 R_{L,K⁽³⁾}∘R_{J,L} = R_{J,K⁽³⁾} = R_{M₅,K⁽³⁾}∘R_{J,M₅}((3.60) は代表 (m,f) をそのまま送るだけなので明らか。Prop 3.12 の可換図式 (3.59) の帰結)。Φ は群準同型(4 対象 isolated)。

> **補題 J2(Φ は常に単射).** N₁, N₂ ∈ NFI_{PB₃}(B₃)、J := N₁ ∩ N₂ とすると (R_{J,N₁}, R_{J,N₂}): GT(J) → GT(N₁)×GT(N₂) は**集合として単射**(isolated 性も群構造も不要)。

**証明.** [m,f], [m′,f′] ∈ GT(J) の像が一致したとする。
- m ≡ m′ (mod (N₁)_ord) かつ m ≡ m′ (mod (N₂)_ord)。ここで **J_ord = lcm((N₁)_ord, (N₂)_ord)**(PB₃/J ↪ PB₃/N₁ × PB₃/N₂ なので x̄, ȳ, c̄ の位数がそれぞれ lcm になり、その lcm を取る)。ゆえに m ≡ m′ (mod J_ord)。
- f (N₁)_{F₂} = f′(N₁)_{F₂} かつ f (N₂)_{F₂} = f′(N₂)_{F₂} ⇒ f⁻¹f′ ∈ (N₁)_{F₂} ∩ (N₂)_{F₂} = **J_{F₂}**(J ∩ F₂ = (N₁∩N₂)∩F₂)。ゆえに f J_{F₂} = f′ J_{F₂}。
ℤ/J_ord × F₂/J_{F₂} の中で両者は等しい。∎

**⇒ obstruction は「Φ の全射性」に完全に集約される。**

$$ \textbf{gluing obstruction} \;:=\; \bigl[\,\mathrm{GT}(L)\times_{\mathrm{GT}(K^{(3)})}\mathrm{GT}(M_5) \,:\, \mathrm{Im}\,\Phi\,\bigr] \;=\; \frac{144}{|\mathrm{GT}(J)|}. $$

4 対象が isolated なので Φ は**単射群準同型**、Im Φ ≅ GT(J) は fiber 積の部分群であり、Lagrange より **|GT(J)| は 144 の約数**、上の指数は整数。obstruction が自明 ⟺ 指数 1 ⟺ |GT(J)| = 144。

### 5.3 A から従う制約(計算前に言えること)

定理 A・定理 B **だけ**から従う厳密な制約:

1. **|GT(J)| ≤ 144**(補題 J2 + §5.1)。しかも 144 の**約数**である(Im Φ が部分群)。
2. Im(R_{J,K⁽³⁾}) = R_{L,K⁽³⁾}(Im R_{J,L}) なので、**R_{J,K⁽³⁾} が全射 ⟺ Im Φ が GT(K⁽³⁾) の全 12 元の上に載る**。
3. 下界は A/B からは出ない(単位元しか保証されない)。**|GT(J)| ≥ 1** のみ。真の下界を得るには算術側の入力(Ihara 写像の像)が要り、本工房は計算していない。

**この証明が正しければ**、P23 の「二方向 obstruction」は J では検出できない。理由は構造的である: **L も M₅ も K⁽³⁾ に対して「直交」であり、しかも互いにも直交している**(H₃ と C₅ に共通商がない)。二つの直交方向が干渉しないのは当然で、干渉を見たければ**直交でない**2 つの細分を選ばなければならない。

### 5.5 命題 A / 命題 B の数学的意味(一般論として)

計算(あるいは監査)の結果として次の 2 つがあり得る。J についての予測は §5.4 で述べたが、**一般の (L′, M′, K) 三つ組**での意味を先に固定しておく。

**命題 A(Φ 全射 = obstruction なし)の意味**
- ML 関手(Thm 5.2 の Main Line functor)が、poset の「交わりの四角形」 J ≤ L, M ≤ K を**群の引き戻し四角形**へ写す。すなわち ML は当該の被覆に対し**降下(descent / Mayer–Vietoris)性**をもつ。
- 実務的含意: GT(J) は GT(L), GT(M), GT(K) から**再構成できる** — J を直接撃つ必要がない。atlas の計算量が積からファイバー積へ落ちる。
- lim(ML) ≅ ĜT_gen(Thm 5.2)の計算において、この種の四角形が多いほど cofinal 系を小さく取れる。
- **fake 狩りとしての価値はゼロ**(A なら R_{J,K} は自動的に全射)。

**命題 B(Φ 非全射 = obstruction あり)の意味**
- 「別々には持ち上がるが同時には持ち上がらない」対 (λ, μ) が実在する。これは **NFI poset 上で GT が局所的に決まらない**最初の証拠であり、それ自体が新しい構造現象である。
- ただし **fake witness とは別物**。階層は次の 3 段:
  1. **Im Φ = fiber 積**: obstruction なし。
  2. **Im Φ ⊊ fiber 積 かつ R_{J,K} は全射**: 「**fake なき gluing obstruction**」。K の shadow は全て J に survive するが、L と M の情報を貼り合わせられない。genuine 判定には効かないが、ML の降下性が破れる例として価値が高い。
  3. **R_{J,K} が非全射**: **fake witness**(Cor 5.4 の対偶)。この場合は「漏れた shadow・GT(J) の完全列挙の個数証明・像の完全計算」の三点セットを証明書化する(L 設計 §2 と同じ規約)。
- 非全射性を主張するには **GT(J) の完全列挙の個数証明**が必須(負の結果は非存在の証明ではない)。cap で全数を諦めた場合は **UNKNOWN** に倒す。

### 6.7 封印予測プロトコル【v2 新規 — Sol F11/P46/W38 採用】

**現行 J 封印の限界(Sol F11 の指摘・裁定 05 で採用)**:
1. |GT(J)| = 144 のような**低エントロピー値**は、hash の preimage を候補値から総当たりできる。共有 docs に 144 が書かれている以上、秘匿は**アクセス規律に依存**する。
2. append-only という運用宣言だけでは**時刻を第三者に固定しない**。

> **裁定**: 既存の J 封印は現行のまま維持するが、**「暗号学的秘匿」ではなく「アクセス規律による blind 運用」と再ラベルする**(W38)。実装レーンが共有 docs を読まないという役割規律は blind 実装として有用だが、commitment ではない。

**P46 標準形(次の封印から適用)**: 以下を満たすときに限り「封印(commitment)」と呼ぶ。

| # | 要素 | 内容 |
|---|---|---|
| S1 | **canonical payload** | 対象定義の hash・予測 field 一式・証明文書版を **canonical JSON**(キー辞書順・空白なし・UTF-8)で直列化 |
| S2 | **blinding** | **128 bit 以上のランダム nonce** を payload に含める |
| S3 | **commitment** | S1+S2 の**正確な byte 列**の SHA-256 を計算する |
| S4 | **時点の錨** | S3 の hash を**計算前の git commit** に記帳する(変更不能な時点の錨) |
| S5 | **秘匿** | nonce と平文は**実装レーンから読めない場所**に保持する |
| S6 | **開封** | 結果が出た後に byte 列と nonce を公開し、第三者が SHA-256 を**再計算**して一致を確認する |

★ これで **commitment(改竄不能)と blinding(候補総当たり不能)を区別**できる。S2 が無ければ低エントロピー予測は総当たりで開けられる — それが v1 封印の欠陥だった。
★ **適用範囲(F12/P47 の裁定)**: 封印は「**未知の数値を初めて計算する便**」に限定する。既知較正値すべてに機械的に課さない。
