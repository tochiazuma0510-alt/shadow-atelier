# 道具と検証の序列 — 棚卸し(2026-07-18)

原則(証明工房から継承): **どの道具の出力も、検証を通るまで「正」としない — そして「検証」の語は Lean(機械証明)に予約する**(2026-07-18 ユーザー指示)。node/python の独立再計算は**照合(cross-check)**であり、それ自体は未検証のコード。二系統の一致が与えるのは照合済みの信頼であって検証ではない。**Lean 層は未接続**(証明書形式の設計後に接続 — Week 2 項目)なので、現時点の台帳に verified は存在し得ない。
