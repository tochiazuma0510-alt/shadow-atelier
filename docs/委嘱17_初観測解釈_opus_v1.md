## 1. ★★ ω は 𝓛 上で定数でない — 「初観測」の再解釈

### 1.1 判定の正しい形(委嘱 16・批准済)

定理 E22′ + 命題 OB より、**系 $m$ が可解 $\iff$ $\exists\bar f\in\mathcal L$: $\mathrm{ob}(\bar f) = 0$**、すなわち $0\in\omega(\mathcal L)$。
命題 E22.3 より $\omega(\bar f_0+\bar k) = \omega(\bar f_0) + F(\bar k)$($F = \pi\ell+\pi\mathcal Q$、$\bar k\in K = \ker(1+\bar\theta)\cap\ker\bar{\mathcal N}$)。

**class 5 では定理 E23 が $F\equiv0$ を保証していた**ので「1 点で測れば十分」だった。**class 6 では E23 の機構((G2) $C^\sigma = 0$・(G3))が破れているので、$F\equiv0$ は保証されない。** 委嘱 16 §1 で示したとおり、$\theta\mathcal N_C\ne\mathcal N_C\theta$ で $\ker\mathcal N_C$ は $\theta$-安定ですらない。

### 1.2 データによる直接証明

**(i) $m$ と $m+32$ は同一系である。** $\bar\theta$ は $m$ 非依存。確定表から $\bar\sigma_m$(多項式係数)と $\bar E_m$(binomial 係数)を組み、**mod 4 で評価**すると

| 対 | $\bar E_m$ mod 4 一致 | $\bar\sigma_m$ mod 4 一致 |
|---|---|---|
| (11,43) | ✔ | ✔ |
| (3,35) | ✔ | ✔ |
| (5,37) | ✔ | ✔ |
| (13,45) | ✔ | ✔ |

したがって **30×15 系 $(1+\bar\theta,\ \bar{\mathcal N}_m\mid -\bar E_m)$ は $m$ と $m+32$ で文字通り同一**、$\mathcal L$ も同一、$\omega(\mathcal L)$ も同一。

**(ii) ところが ob が食い違う。**

| 対 | ob_b($m$) | ob_b($m{+}32$) | witness |
|---|---|---|---|
| **(11, 43)** | **1** | **0** | 相異なる |
| **(13, 45)** | **0** | **1** | 相異なる |
| **(19, 51)** | **0** | **1** | 相異なる |
| **(25, 57)** | **0** | **1** | 相異なる |
| **(29, 61)** | **0** | **1** | 相異なる |

(例: $m=11$ の witness $=[2,-6,-6,0,-1,0,0,0,0,-8,-8,0,-1,0,0]$、$m=43$ の witness $=[2,0,0,-2,1,-2,-1,0,0,-1,0,0,0,0,0]$。)

> **⇒ 同一の系で witness を変えると ob が変わる。すなわち $F\not\equiv0$ が実データで確認された。**
> **これは「非零 ob の観測」ではなく「$\omega$ が $\mathcal L$ 上で非定数であることの観測」である。**

### 1.3 13 系の再分類

| 分類 | $m$ | 状態 |
|---|---|---|
| **可解が確定した**(対の witness が ob = 0 を実現) | **11, 45, 51, 57, 61**(5 系) | **ob ≠ 0 の主張を撤回すべき** |
| 2 つの witness で ob = 1 だった | 3, 5, 21, 27, 35, 37, 53, 59(実質 4 系 × 2) | **UNKNOWN**(非零性未証明) |

> **★ したがって「プロジェクト初の非零中心障害を観測」という札は、現時点では立たない。** 正しい札は
> **「$\omega$ が $\mathcal L$ 上で非定数であることを初観測(= class 5 の E23 消滅機構が class 6 で実際に破れていることの実証)」**である。**これはこれで一級の成果**だが、E2 型 fake の実弾ではない。

### 1.4 何を計算し直せば決着するか(最小手順)

各系 $m$ について:
1. $K = \ker(1+\bar\theta)\cap\ker\bar{\mathcal N}_m$ を $\bar A_j = (\mathbb Z/4)^{15}$ 上で計算($|K|$ は有限)。
2. $F: K\to\mathrm{Ob}$ を **命題 E22.3 の (3.2)**($F = \pi\ell+\pi\mathcal Q$)で構成 — あるいは単純に、$\mathcal L = \bar f_0+K$ の**全点で ob を評価**して値の重複度表を作る。
3. **判定は「$0$ の重複度 $>0$」**。重複度表そのものを証明書へ(E22 §6.3 の `value_multiplicity_table` の要求はまさにこれ)。
> **現行証明書には `ob_a, ob_b` が 1 組しか無く、重複度表がない。** manifest の mass check(委嘱 16 §5 の M6)が要求していたのはこの表である — **M6 が実装されていれば今回の取り違えは起きなかった。**

## 2. 任務 1 — 線型段の可解律「$m$ 奇 または $8\mid m$」

**検算**: 64 系すべてで規則と一致(例外なし)。可解 40 = 奇 32 + $8\mid m$ の 8、不可解 24 = 偶かつ $8\nmid m$。mod 8 分布は $\{0{:}8,\,1{:}8,\,2{:}0,\,3{:}8,\,4{:}0,\,5{:}8,\,6{:}0,\,7{:}8\}$ — **可解 $\iff m\bmod 8\in\{0,1,3,5,7\}$**。

**なぜ mod 8 か(構造)**:
- 系は $\bar A_j = (\mathbb Z/2^j)^{15}$、$j=2$ ⇒ **法 4**。
- $\bar E_m$ の各成分は $\binom{m+s}{k}$($k\le6$)の $\mathbb Z$-結合(確定表 `Em_components`)。**$\binom{m}{k}$ の mod 4 での $m$-周期は $2^{2+\lceil\log_2k\rceil}$ 型**で、$k\le6$ なら 8 または 16、32。$\bar\sigma_m$ の成分は $m$ の 4 次以下の多項式ゆえ mod 4 での周期は 8 以下。**⇒ 系全体の $m$-周期は 2 冪で、実測では 32 で完全一致(§1.2)、可解性だけなら 8 で閉じる。**
- **最上位重み(weight 2 = $\langle w\rangle$)は常に可解**: $\bar\sigma|_{L_2} = 1$ ゆえ $\bar{\mathcal N}|_{L_2} = 3$(mod 4 で単元)、$(1+\bar\theta)|_{L_2} = 0$、$(\bar E_m)_w = -\binom{m+1}{2} = -T_m$ ⇒ $f_w = T_m/3$ が常に解。**⇒ 障害は weight ≥ 3 に住む。**
- 不可解系の証明書は **dual witness** を持ち、例えば $m=2$ では $yM\equiv0$、$yb = -6\equiv2\pmod4$。**障害値がちょうど 2(= $2^{j-1}$)である**ことは、破れが**「mod 2 では消えるが mod 4 で残る」一段の 2-adic 現象**であることを示す。
> **【GAP-17a】** 「なぜ $m\equiv0\ (8)$ だけが偶数側で救われるか」の**閉じた紙上証明**は本稿では未完。$T_m = m(m+1)/2$ の 2-adic 性(($m$ 偶なら $v_2(T_m) = v_2(m)-1$)と weight-4/5 の $\binom{m+s}{k}$ の mod 4 挙動の組合せであることまでは見えているが、30×15 の消去を紙で追い切れていない。**dual witness $y(m)$ を $m$ の関数として閉形式で書くのが最短**(実装向き)。

## 3. 任務 3 — $a$ ビットが全零な理由:**構造的、かつ $j=2$ 特有**

$a = u_4$、$b = u_1+u_2+u_3$ で、$\theta(a) = -a$、$\theta(b) = +b$(確定表・委嘱 16 §3 で検算)。

- **障害は $\mathrm{Ob} = C^\theta/(1+\theta)\ker\mathcal N_C$ に住み、代表元 $v$ は必ず $C^\theta$ に入る**(委嘱 16 §2)。
- **$j=2$ では $R = \mathbb Z/2$ なので $-1 = +1$**、したがって $\theta(a) = -a = +a$ となり、$a$ 方向も $\theta$-固定になる。**この退化のせいで $a$ が「見える」ようになっているが、$j\ge3$ では $\theta(a) = -a \ne a$** となり、$C^\theta$ の $a$-成分は $2$-捻れ部分($2\alpha = 0$)に限られる。
- **実測で $a$ ビットが全 64 系で零**なのは、$q_\theta$ の $u_4$ 成分が常に偶数になっているということ。$u_4 = [p,q]$ は **$w$ を含まない唯一の交換子**(確定表 A1)で、$\kappa$ の中でも $u_4$ 項だけが $(a_qb_p)$ という「$w$ を使わない」形をしている。**$\bar f\in\ker(1+\bar\theta)$ の $p,q$ 成分が $\theta$ の対合(($p\leftrightarrow -q$ 型)で縛られるため $a_qb_p$ 型の二次項が消える**、というのが構造的な理由と見る。
> **★ $j=3$ への予言**: $j=3$($R = \mathbb Z/4$)では **$\theta(a) = -a$ が非自明**になり、$\mathrm{Ob}$ の $a$ 方向は $\{\alpha : 2\alpha = 0\}$ に縮む一方、$b$ 方向は $\mathbb Z/4$ に伸びる。**したがって $j=3$ では「$a$ は依然として零に近く、$b$ が 4 値に細分する」**と予想する。**$j=3$ で $a\ne0$ が出たら、この構造読みは誤り。**
> **【GAP-17b】** $q_\theta$ の $u_4$ 成分が常に偶数であることの**証明**は未完(実測 64/64 のみ)。上の $\kappa$ の $u_4$ 項の形からの議論は概略。

## 4. 任務 2 — ob_b の閉じた条件:**現時点では「書けない」が正しい**

**実測の関係**: 全可解系で
$$ \mathrm{ob}_b(m) \;=\; \bigl(q_\theta\ \text{の}\ u_2\ \text{係数}\bigr)\bmod 2 $$
が成立(検算・40/40)。すなわち $3^{-1}(1+\theta)q_N$ の $u_2$ 成分は常に偶数で、補正項は $b$ ビットに寄与しない。

**しかし $q_\theta$ は witness 依存**なので(§1)、**この式から「$m$ の閉じた条件」を導くことはできない**。実測値もその通りで、$m$ と $m+32$(同一系)で $q_\theta$ の $u_2$ 係数が $-21$ と $-4$ のように食い違う。

> **⇒ 委嘱の「候補: $u = 2m+1$ の 2-adic 性質・$\kappa$ 項の寄与・$q_\theta$ の $u_2$ 係数の $m$-多項式」という筋は、いずれも $\mathcal L$ 上で ob が定数であることを暗に仮定している。** その仮定が成り立たないので、**まず §1.4 の重複度表を取る**のが順序である。
> **重複度表を取った後**なら、真の不変量は $\min\omega(\mathcal L)$ ではなく **「$0\in\omega(\mathcal L)$ か否か」の 1 ビット**であり、それが $m$ の関数として閉じるかを問うのが正しい設問になる。

## 6. 任務 5 — 予想 E15 の言明の書き直し案

**旧**: 「2 群に E2 障害なし・障害素数 = 3」。
**問題**: 「障害素数 = 3」は、class 5 で $\det(1-\sigma|_C) = 3$ と $\bar{\mathcal N}|_{L_2} = 3$ が可逆だったことの要約にすぎず、**class 6 で実際に破れているのは (G3)(誘導性)の側**である(委嘱 16 §1: $\theta\mathcal N_C\ne\mathcal N_C\theta$ で $\ker\mathcal N_C$ が $\theta$-安定でない)。

> **新 E15(書き直し案)**: 「**$C = [A,A]$ が $\langle\theta\rangle$-誘導加群であり、かつ $C^\sigma = 0$ である層では、中心持ち上げ障害は恒等的に消える**(定理 E23)。**障害が発火しうるのは、この二条件のいずれかが破れる層に限る** — 具体的には
> **(E15-a)** $C^\sigma\ne0$(class 6 で発火: $C^\sigma = Ra\oplus Rb\ne0$)、
> **(E15-b)** $\hat H^0(\langle\theta\rangle,C)\ne0$ もしくは Maschke 分解が $\theta$-非同変($p=2$ で発火・W139)、
> **(E15-c)** $3$ が $C$ 上非可逆($p=3$ 層)。
> **『障害素数 = 3』は (E15-c) だけを指す旧称であり、(E15-a)(E15-b) を含まない点で不完全だった。**」

**この形の利点**: (a)(b)(c) はいずれも**計算前に表現論で判定できる**(委嘱 15 の B1–B5 と同じ様式)。**そして今回の class-6 観測が示したのは (E15-a) の発火であって、障害元の非零ではない** — この区別が新言明では明示される。
