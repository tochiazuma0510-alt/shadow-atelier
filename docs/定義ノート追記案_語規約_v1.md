## 1. 規約(**正本** — これ以降すべての文書・コード・証明書がこれに従う)

> ### 規約 W-1(語の掛け算の向き)
> **論文(2401.06870 / 2405.11725)および本工房の全数学文書における語 "AB" は「A を掛けてから B を掛ける」= 通常の群論の左から右への積**である。すなわち写像として読むときは **A が先、B が後**ではなく、**元の積そのもの**として読む。
>
> **GAP の置換乗算はこの向きと逆になる**(GAP は右作用 `i^(a*b) = (i^a)^b`)。したがって
> $$ \boxed{\ \text{paper 語 } "AB" \ \longleftrightarrow\ \text{GAP 乗算 } \texttt{B*A}\ } $$
>
> ### 規約 W-2(語レベル評価の正本 = **prepend**)
> 語 $w = L_1^{e_1}L_2^{e_2}\cdots L_n^{e_n}$($L_i \in \{x,y\}$)を有限商 $P$ で評価するときの**正本の手続き**は、**語を左から右へ読みながら、GAP 側で像を左から掛け足す(prepend)**ことである:
> ```
> elt := One(P);
> for i in [1..n] do  elt := Image(L_i)^{e_i} * elt;  od;
> ```
> これは **M₅ explorer(`search/week3-M5-explorer.g`)が採用した規約**であり、これを工房の正本とする。
> 関数合成の向きで実装する言語(`mul(a,b)(i) = a(b(i))` を採る node/python 等)では、**同じ手続きが「左から順に append」**になる。**名前(prepend/append)は実装の乗算の向きに依存するので、名前ではなく W-1 の等式で照合すること。**
>
> ### 規約 W-3(証明書 `f_word` の読み書き)
> 証明書スキーマの `f_word = [[letter, exponent], ...]` は **paper 語の順序**で並べる。読み手は必ず W-2 の手続きで評価する。**書き手と読み手が別実装のときは §5 の適合テストを先に通すこと。**

## 2. 補題 W1 — 規約を取り違えたときに何が計算されるか

規約を取り違えた(語を逆順に掛けた)評価を $\mathrm{ev}^{\mathrm{bad}}$、正しい評価を $\mathrm{ev}$ と書く。語 $w$ に対し、**指数だけを一斉に反転して順序は変えない**操作を
$$ \iota\bigl(L_1^{e_1}\cdots L_n^{e_n}\bigr) \;:=\; L_1^{-e_1}\cdots L_n^{-e_n} $$
と定める($\iota$ は**準同型ではない** — 語の上の対合にすぎない)。

> **補題 W1.** 任意の語 $w$ と任意の商 $P$ について
> $$ \boxed{\ \mathrm{ev}^{\mathrm{bad}}(w) \;=\; \mathrm{ev}\bigl(\iota(w)\bigr)^{-1}\ } $$

**証明.** $\mathrm{ev}^{\mathrm{bad}}(w) = \mathrm{ev}(w^{\mathrm{rev}})$($w^{\mathrm{rev}} = L_n^{e_n}\cdots L_1^{e_1}$)。一方
$$ \bigl(\iota(w)\bigr)^{-1} = \bigl(L_1^{-e_1}\cdots L_n^{-e_n}\bigr)^{-1} = L_n^{e_n}\cdots L_1^{e_1} = w^{\mathrm{rev}} $$
なので両辺は同じ語の評価である。∎

**数値確認 ✔**: `certificates/A1.v2.json` の `gt_shadows_observed` 20 語すべてで補題 W1 の等式が成立(私の独立 node 実装・`scratchpad/conv_v1.mjs`)。

> ★ **教訓**: 語規約の取り違えは「順序が逆になる」だけでなく、**指数反転と逆元の二重の捻れ**として現れる。この二重性が §3 の盲点を生む。

## 3. 二重打ち消しの罠(盲点)

補題 W1 から直ちに次が従う。**これらの条件下では、規約を取り違えても答えが変わらない — すなわちその対象・その語では規約バグを検出できない。**

> **(a) $P$ が可換 ⇒ 完全に不可視.** $P$ 可換なら $\mathrm{ev}(\iota w) = \mathrm{ev}(w)^{-1}$(各文字の寄与が可換に並ぶ)。よって $\mathrm{ev}^{\mathrm{bad}}(w) = \mathrm{ev}(w)$ が**全ての語で**成立する。
> **(b) 単一生成元の冪 $w = x^a$ または $y^a$ ⇒ 不可視.** $\iota(w) = w^{-1}$ ゆえ $\mathrm{ev}^{\mathrm{bad}}(w) = \mathrm{ev}(w)$。**空語も含む。**
> **(c) 偶発的一致.** $\mathrm{ev}(\iota w) = \mathrm{ev}(w)^{-1}$ がその語だけで成り立つ場合(例: 値が対合になる語)も不可視。
>
> **(d) 【注意・過度な一般化の禁止】** 「$[P,P]$ が可換だから安全」とは**言えない**。$\iota$ は準同型ではないので、$\mathrm{ev}(\iota w)$ は $\mathrm{ev}(w)$ の共役類にすら制約されない。**盲点かどうかは対象ごと・語ごとに実測するしかない**。
> 例: class 2 の $P$ と交換子語 $w = xyx^{-1}y^{-1}$ では $\mathrm{ev}(\iota w) = [X^{-1},Y^{-1}] = [X,Y] = \mathrm{ev}(w)$(交換子が中心)なので $\mathrm{ev}^{\mathrm{bad}}(w) = \mathrm{ev}(w)^{-1}$ — 不可視ではないが**符号だけ**の違いになり、$f \mapsto f^{-1}$ で閉じた判定条件((H-a) は $\theta(f) = f^{-1}$ なので実際にそうなりやすい)では**やはり検出されない**。

> **語の掛け算の向きを自分で決めてはならない。** 規約 W-1/W-2 に従うこと。

> 4. 規約を変更したくなったら、**変更せずに司令塔へ差し戻す**(全証明書のハッシュが変わるため)。
