## 引用規範

1. **引用対象 = 使ったもの全部**(読んだだけのものは載せない): 正典(2401.06870・2405.11725 — 定理・式番号で指す)・古典(Ihara [LNS200]・Deligne 1989 §15 等)・二次資料(実際に検証経路にしたもの)・**LMFDB(公式形式: コラボレーション+URL+アクセス日+個別ラベル 54.b3 / 6T9-6_6_2.2.1.1-a 等)・GAP 4.16.0(公式引用形)・Lean 4/Mathlib**。
2. **本文中は定理番号まで**: [DKM, Thm 4.3] 型。根拠は D1/P1 系の式番号つき抽出ノート(ページ画像照合済みのもののみ)。
3. **未入手原典の扱い**: 原典を引用しつつ、本稿で実際に検証した経路(二次資料 or 自前証明)を併記。「見ていないものを見たように引用しない」(工房台帳規律の学術版)。
4. **references.bib は台帳から生成**: papers/delivered/ の全ファイル+LEDGER の使用記録が母集合。起草時に ops-clerk が bib 化 → 司令塔検分。
5. **AI 協働の開示**: 著者は研究者本人(AI は著者不可 — COPE 等)。謝辞/方法節で協働形態(二数学者体制・相互監査・証明書・Lean 検証)を明示。投稿先ポリシーを投稿前に確認(scout 案件)。

## 記法規範

docs/論文用対訳辞書_v0.md を正とし、原稿は正典記法のみで書く。工房新規概念(補題 C・u・接繊維 torsor 等)は論文内で定義節を設ける(辞書の「新規」印が一覧)。

## Lean 対応

論文の補題・定理と Lean ファイルを 1:1 対応(番号 = 定理名)。群論・組合せ層 = plain Lean 工場・数論層 = Mathlib + GitHub Actions。形式化状態(verified/未)を論文の表として掲載する案(機械検証つき論文としての差別化)。
