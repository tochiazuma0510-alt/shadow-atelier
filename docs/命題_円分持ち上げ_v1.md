## 2. 語レベル評価の必然性(c ∉ N の対象で何が壊れるか)

M₅ の実装で判明した事実(commit 9fcb893・定義ノート §2 の 2026-07-25 注記)を、命題の前提として数学的に固定しておく。

**補題 B0.** ν := Ad(σ₁σ₂) ∈ Aut(PB₃)、ε_y(w) を語 w ∈ F₂ の y に関する指数和とする。
1. **θ = Ad(Δ)|_{F₂}**。ゆえに任意の N ∈ NFI_{PB₃}(B₃) に対し **θ(N_{F₂}) = N_{F₂}**(θ は常に商へ降りる)。
2. **ν(x) = τ(x)、ν(y) = τ(y)·c**、したがって任意の w ∈ F₂ について
   $$ \boldsymbol{\nu(w) \;=\; \tau(w)\cdot c^{\,\varepsilon_y(w)}} \qquad (c \text{ は中心}). $$
   ゆえに τ(N_{F₂}) ⊆ N_{F₂} ⟺ **すべての w ∈ N_{F₂} で c^{ε_y(w)} ∈ N**。とくに **c ∈ N なら τ も商へ降りる**が、そうでなければ保証されない。
3. M₅ については実際に **τ(M₅_{F₂}) ⊄ M₅_{F₂}**(反例: w = x⁶y²⁴)。

**証明.**
1. (1.13) より Ad(Δ)(x₁₂) = x₂₃、Ad(Δ)(x₂₃) = x₁₂ — **c 因子なし**。すなわち Ad(Δ) は F₂ = ⟨x,y⟩ を保ち、その制限が θ。N ⊴ B₃ だから Ad(Δ)(N) = N、よって N_{F₂} = N ∩ F₂ を保つ。
2. (1.11)(1.12) から
   ν(x) = σ₁(σ₂x₁₂σ₂⁻¹)σ₁⁻¹ = σ₁(x₁₂⁻¹x₂₃⁻¹c)σ₁⁻¹ = x₁₂⁻¹·(x₂₃⁻¹x₁₂⁻¹c)⁻¹·c = x₁₂⁻¹·c⁻¹x₁₂x₂₃·c = x₂₃ = τ(x)、
   ν(y) = σ₁(σ₂x₂₃σ₂⁻¹)σ₁⁻¹ = σ₁x₂₃σ₁⁻¹ = x₂₃⁻¹x₁₂⁻¹c = τ(y)·c。
   ν は準同型で c は中心なので、語 w の各文字ごとに c が y^{±1} のときだけ ±1 個出る: ν(w) = τ(w)c^{ε_y(w)}。
   w ∈ N_{F₂} なら ν(w) ∈ ν(N) = N(N ⊴ B₃)、よって τ(w) = ν(w)c^{−ε_y(w)} ∈ N ⟺ c^{ε_y(w)} ∈ N。
3. w := x⁶y²⁴。G₃ 像は X_G⁶Y_G²⁴ = 1(両者とも位数 6)、C₅ 像は t^{2(6+24)} = t^{60} = 1。よって w ∈ M₅_{F₂}。
   ε_y(w) = 24 で c̄ の位数は 5、5 ∤ 24 なので c^{24} ∉ M₅。ゆえに τ(w) ∉ M₅。
   直接計算でも確認できる: τ(w) = y⁶z²⁴(z = y⁻¹x⁻¹)で ε_x = −24, ε_y = 6−24 = −18、和 = −42 ≡ 3 (mod 5)、C₅ 像 = t^{2·(−42)} = t ≠ 1。∎

**帰結(実装規約の数学的根拠).** Prop 3.4(簡約 hexagon)は **N に何の仮定も置かない定理**であり、M₅ でも無傷である。壊れるのは「θ, τ を商 F₂/N_{F₂} 上の自己準同型として評価する」近道だけ。**したがって (3.10)(3.11) は F₂ の語に θ, τ を文字置換として適用してから φ で評価する**。以下の証明はすべてこの規約に従う(§4 の独立検算も同じ)。

## 3. 準備補題

### 補題 B1(可換な P は hexagon-free)

**定義.** N ∈ NFI_{PB₃}(B₃) が **hexagon-free** であるとは、charming な pair がすべて GT-shadow であること、すなわち
GT(N) = 𝒳_N × [F₂/N_{F₂}, F₂/N_{F₂}](𝒳_N := {m ∈ ℤ/N_ord : gcd(2m+1, N_ord) = 1})。

**主張.** P := F₂/N_{F₂} が可換ならば N は hexagon-free。

**証明.** [P,P] = 1 なので charming な f の P 像は 1(代表を f ∈ [F₂,F₂] に取る)。
- (3.10): f·θ(f) の P 像は φ(f)φ(θf) = 1·1 = 1(θ(f) ∈ [F₂,F₂])。
- (3.11): 語 τ²(y^m f)τ(y^m f)y^m f の P 像。τ^i(f) ∈ [F₂,F₂](τ は自己同型)なので P 像は 1。残るのは τ²(y)^m τ(y)^m y^m = x^m z^m y^m の像 = (X Z Y)^m(P 可換)。ここで Z = 像(z) = (XY)⁻¹ なので X Z Y = X (XY)⁻¹ Y = X Y⁻¹X⁻¹Y = 1(可換)。よって 1。
- 全射性: ⟨X^u, Y^u⟩(f の P 像が 1 なので共役は消える)。gcd(u, N_ord) = 1 かつ ord(X) | N_ord なので ⟨X^u⟩ = ⟨X⟩、同様に ⟨Y^u⟩ = ⟨Y⟩、P = ⟨X,Y⟩。∎

**系.** N₅ は hexagon-free。GT(N₅) = 𝒳_{N₅} × 1、𝒳_{N₅} = {m ∈ ℤ/5 : gcd(2m+1,5) = 1} = {0,1,3,4} — **|GT(N₅)| = 4**(較正スイート項目 7 の期待値 C-2 と一致)。

### 補題 B2(N₅ は isolated)

**主張.** GT(N₅) の 4 元はすべて settled。

**証明.** [m,1] ∈ GT(N₅)、u = 2m+1。PB₃/N₅ ≅ C₅ で P_{N₅}: x,y ↦ t², c ↦ t。T^{PB₃}_{m,1}: x ↦ t^{2u}, y ↦ t^{2u}, c ↦ t^u。γ: C₅ → C₅, t ↦ t^u は gcd(u,5) = 1 より自己同型で、T^{PB₃}_{m,1} = γ ∘ P_{N₅}(生成元 x,y,c で一致)。補題 F(中心持ち上げ文書 §3)より settled。∎

### 補題 B3(全射性の自動性)

**主張.** m ∈ 𝒳_{M₅}、f ∈ [F₂,F₂] で Q_M 像が (f_G, 1)、u = 2m+1。G₃ 内で ⟨X_G^u, f_G⁻¹Y_G^u f_G⟩ = G₃ なら Q_M 内で ⟨x̄^u, f̄⁻¹ȳ^u f̄⟩ = Q_M。

**証明.** C₅ 射影は ⟨t^{2u}, t^{2u}⟩ = ⟨t^{2u}⟩ = C₅(gcd(2u,5) = 1)。よって部分直積。(M2) の共通商論法より全体。∎

### 補題 B4(𝒳 の単元群としての記述と全射性)

**主張.** 写像 m ↦ u = 2m+1 は **ℤ/N_ord → {2N_ord を法とする奇数類}** の全単射を与え、charming 条件のもとで
𝒳_N ↔ **(ℤ/2N_ord)^×** を与える。さらに (3.53) の下で χ_vir: GT(N) → (ℤ/2N_ord)^×, [m,f] ↦ 2m+1 は群準同型で、K ≥ N のとき図式は還元 (ℤ/2N_ord)^× → (ℤ/2K_ord)^× と可換、この還元は**全射**(核の位数 = |𝒳_N|/|𝒳_K|)。

**証明.** 2m+1 ≡ 2m′+1 (mod 2N_ord) ⟺ m ≡ m′ (mod N_ord)。奇数類は N_ord 個。u 奇 かつ gcd(u,N_ord) = 1 ⟺ gcd(u, 2N_ord) = 1。乗法性は (3.49)/(3.53) の第 1 成分: (2m₁+1)(2m₂+1) = 2(2m₁m₂+m₁+m₂)+1。K_ord | N_ord ⇒ 2K_ord | 2N_ord で、剰余環の単元群の還元 (ℤ/a)^× ↠ (ℤ/b)^×(b | a)は全射。∎

**注意(W3-2b の精密化).** 定義ノートは χ_vir を「2m+1 mod N_ord」としているが、**mod 2N_ord まで well-defined** である。C₄ が見えるのはこの細かい方の不変量においてであり、mod 30 では {1,13,7,19} と見た目が変わってしまう(30 を法にすると 37 ↦ 7、49 ↦ 19)。**mod 60 で述べるのが正しい**。

## 4. 定理 B の証明

**(i) 完全記述.**

charming な候補は m ∈ 𝒳_{M₅}、f L_{F₂} ∈ [Q_M,Q_M] = [G₃,G₃] × 1 で、代表を f ∈ [F₂,F₂] に取る。(M6) より **f の C₅ 成分は自動的に自明**。

交わりの補題(中心持ち上げ文書 補題 A・系 A′)と M₅_{F₂} = K⁽³⁾_{F₂} ∩ (N₅ ∩ F₂) により、
> (m,f) が hexagon mod M₅ ⟺ hexagon mod K⁽³⁾ かつ hexagon mod N₅。

- **K⁽³⁾ 側**: [m mod 6, f_G] が GT-pair(K⁽³⁾)であること。ここで語 y^m, x^m, z^m の G₃ 像は m mod 6 のみに依存する(ord = 6)ので、条件は **m mod 6** のみに依る。
- **N₅ 側**: 補題 B1(P = C₅ は可換)より **恒真**。
  (明示的に: (3.10) の語の指数和は 0 + 0 = 0。(3.11) の語 x^m τ²(f) z^m τ(f) y^m f の指数和は m + (−2m) + m + 0 = **0**。C₅ 像 = t^{2·0} = 1。)

charming も分解する: gcd(2m+1, 30) = 1 ⇒ gcd(2m+1, 6) = 1(補題 B4)。全射性は補題 B3 により G₃ 側に帰着。ゆえに

$$\mathrm{GT}(M_5) = \{\,[m,f_G] : m\in\mathcal X_{M_5},\ [m \bmod 6, f_G]\in \mathrm{GT}(K^{(3)})\,\}.$$

すなわち **𝒳_{M₅} ×_{𝒳_{K⁽³⁾}} GT(K⁽³⁾)**(m mod 6 での引き戻し)。Thm 4.3 より各 m mod 6 ∈ {0,2,3,5} に f_G は 3 個、𝒳_{M₅} は 16 元なので |GT(M₅)| = 16·3 = **48**。∎(i)

**(ii) settled.**

T^{PB₃}_{m,f}: PB₃ → G₃ × C₅ の成分は
- G₃ 成分 = K⁽³⁾-shadow [m mod 6, f_G] の T^{PB₃}((3.59))。K⁽³⁾ isolated(Thm 4.3)より β ∘ P_{K⁽³⁾}、β ∈ Aut(G₃)。
- C₅ 成分: x ↦ t^{2u}, y ↦ t^{2u}(f の C₅ 成分が自明なので共役は消える)、c ↦ t^u。これは γ ∘ P_{N₅}、γ(t) = t^u ∈ Aut(C₅)(補題 B2)。

ゆえに T^{PB₃}_{m,f} = (β × γ) ∘ P_{M₅}、β × γ ∈ Aut(G₃ × C₅) = Aut(PB₃/M₅)。補題 F より settled。全 48 元で同様、**M₅ は isolated**。∎(ii)

**(iii) 繊維.**

M₅ ≤ K⁽³⁾、K⁽³⁾_ord = 6 なので (3.60) は [m,f] ↦ (m mod 6, f K⁽³⁾_{F₂}) = (m mod 6, f_G)。(i) より全射。両対象 isolated なので Remark 3.16 で群準同型。

核 = { [m, f] : m ≡ 0 (mod 6), f_G = 1 }。(i) の記述から f_G = 1 は m mod 6 = 0 の shadow としての条件を満たす(単位元 shadow)。m の条件は
> m ∈ ℤ/30、m ≡ 0 (mod 6)、gcd(2m+1, 30) = 1。

m ≡ 0 (mod 6) の類は {0,6,12,18,24}(5 個)。この類では m = 6k ⇒ 2m+1 = 12k+1 ≡ 1 (mod 3) なので **3 ∤ (2m+1) は自動**。残る条件は 5 ∤ (2m+1)、すなわち m ≢ 2 (mod 5)。12 ≡ 2 (mod 5) のみが脱落(u = 25)。**残り {0, 6, 18, 24} の 4 個**。u = 2m+1 = **1, 13, 37, 49**(mod 60)。

これは補題 B4 の還元 (ℤ/60)^× → (ℤ/12)^× の核 = {u ∈ (ℤ/60)^× : u ≡ 1 (mod 12)} である。CRT ℤ/60 ≅ ℤ/12 × ℤ/5 の下でこの核は 1 × (ℤ/5)^× ≅ **C₄**。対応は 1↔1, 13↔3, 37↔2, 49↔4(mod 5)。3 と 2 は 5 の原始根なので **u = 13 も u = 37 も生成元**、49 ↔ 4 = −1 は位数 2。

核が (3.53) で群をなすことは χ_vir の乗法性から従う(f = 1 同士の合成は [2m₁m₂+m₁+m₂, 1])。全繊維は核の剰余類 = **C₄-torsor**、一様に 4 個。48 = 12·4 と整合。∎(iii)

**(iv) 分裂.**

χ₅: GT(M₅) → (ℤ/5)^×, [m,f] ↦ (2m+1 mod 5) は群準同型(χ_vir の合成)。(R_{M₅,K⁽³⁾}, χ₅): GT(M₅) → GT(K⁽³⁾) × (ℤ/5)^× の核は「m ≡ 0 (mod 6)、f_G = 1、u ≡ 1 (mod 5)」すなわち u ≡ 1 (mod 60) ⇒ m = 0、f = 1。単位元のみ。位数はともに 48 なので同型。∎(iv)

## 6. 一般命題(起案)— 直交細分と繊維の分解

### 6.1 命題 C(証明つき)

> **命題 C(直交細分).** K, N ∈ NFI_{PB₃}(B₃)、M := K ∩ N とし、G := PB₃/K、P := PB₃/N と置く。次を仮定する。
> - **(O1)** G と P は非自明な共通商をもたない。
> - **(O2)** F₂ ↠ G かつ F₂ ↠ P(すなわち PB₃ = F₂·K = F₂·N)。
> - **(O3)** K は isolated。
> - **(O4)** N は **hexagon-free** かつ isolated。
>
> このとき:
> **(a)** PB₃/M ≅ G × P、F₂/M_{F₂} ≅ G × P、M_ord = lcm(K_ord, N_ord)、[F₂/M_{F₂}, ·] = [G,G] × [P,P]。
> **(b)** GT(M) = { [m, (f_G, f_P)] : m ∈ 𝒳_M, [m mod K_ord, f_G] ∈ GT(K), f_P ∈ [P,P] }。
> **(c)** |GT(M)| = |GT(K)| · **e** · **|[P,P]|**、ここで e := |(ℤ/2M_ord)^×| / |(ℤ/2K_ord)^×| = |ker((ℤ/2M_ord)^× ↠ (ℤ/2K_ord)^×)|(= |𝒳_M|/|𝒳_K|)。
> **(d)** M は isolated、R_{M,K}: GT(M) → GT(K) は**全射群準同型**で
> $$ |\ker R_{M,K}| \;=\; \bigl|\ker\bigl((\mathbb Z/2M_{\rm ord})^\times \to (\mathbb Z/2K_{\rm ord})^\times\bigr)\bigr| \;\cdot\; |[P,P]|. $$
> 集合としては ker R_{M,K} = { [m, (1, f_P)] : u ≡ 1 (mod 2K_ord), f_P ∈ [P,P] }。

**証明.**
(a) 部分直積 + (O1) + Goursat(命題 A 補題 D と同じ)。M_ord: PB₃/M ↪ PB₃/K × PB₃/N なので各生成元の位数が lcm になる。導来部分群は直積の公式。
(b) charming な代表を f ∈ [F₂,F₂] に取る。交わりの補題 + Prop 3.4 で hexagon が K 側 / N 側に分解。N 側は (O4) の hexagon-free により恒真(m の単元条件だけ効く)。charming の単元条件は m mod K_ord・m mod N_ord の単元条件に分解((a) の lcm)。全射性は G 側 + P 側 + (O1) の Goursat。P 側の全射性は hexagon-free の定義に含まれる。
(c) (b) の数え上げ。𝒳_M → 𝒳_K は補題 B4 より全射で核は一様、Σ_{m ∈ 𝒳_M} #{f_G} = [𝒳_M : 𝒳_K]·|GT(K)|。
(d) settled: T^{PB₃}_M の 2 成分は、(3.59) によりそれぞれ K-shadow と N-shadow の T^{PB₃}。(O3)(O4) の isolated 性から各々 Aut(G), Aut(P) の元と標準射影の合成、直積は Aut(G × P) = Aut(PB₃/M) の元。補題 F より settled。R が群準同型なのは Remark 3.16。核の記述は (b) から直接。∎

### 6.2 hexagon-free の十分条件(現時点で証明済みのもの)

- **(HF-a)** F₂/N_{F₂} が**可換**(補題 B1)。→ N₅、および PB₃/N が巡回/可換なあらゆる control。
- **(HF-b)** F₂/N_{F₂} = H₃ = F₂/F₂³γ₃(F₂)(中心持ち上げ文書 補題 C・補題 G)。
  このとき **N_ord = lcm(3,3,1) = 3** なので 𝒳_N = {0,2}、すなわち **charming 条件そのものが m ≡ 1 (mod 3) を排除する** — 追加仮定は要らない。本質は「θ が [P,P] を反転する」+「exponent 3 で X·W·Y = 1」の 2 点。→ N₀。
- **(HF-c)(直積で保たれる)** N₁, N₂ が hexagon-free で PB₃/N₁ と PB₃/N₂ に共通商がなければ N₁ ∩ N₂ も hexagon-free。
  理由: 交わりの補題で (3.10)(3.11) が成分別に分解し、𝒳_{N₁∩N₂} の元は各 𝒳_{N_i} へ落ちる(gcd(2m+1, lcm) = 1 ⇒ gcd(2m+1, N_i,ord) = 1)。全射性は Goursat。→ **N₀ ∩ N₅**(P = H₃ × C₅)。

### 6.3 系(3 対象の統一)

命題 C を K = K⁽³⁾(isolated・Thm 4.3、K_ord = 6、|GT| = 12)に適用する。e := \|𝒳_M\|/\|𝒳_{K⁽³⁾}\| = \|𝒳_M\|/4。

★ **一般法則の言い方**: R_{M,K} の繊維は、**N が K に付け加えた「余剰」そのもの**である。余剰は 2 種類しかない —
> **(円分方向)** ℤ/2K_ord の上に増えた単元 = ker((ℤ/2M_ord)^× → (ℤ/2K_ord)^×)、
> **(非可換方向)** P の導来部分群 [P,P]。
L は後者だけ、M₅ は前者だけ、J は両方をもつ。

### 6.4 J への適用(命題 C の 2 段適用)

J = L ∩ M₅ = K⁽³⁾ ∩ N₀ ∩ N₅。N := N₀ ∩ N₅ とすると PB₃/N ≅ H₃ × C₅(共通商なし: 3 群と 5 群)。**(HF-c)** より N は hexagon-free、また isolated(成分別に補題 G と補題 B2)。(O1): G₃ と H₃ × C₅ に共通商なし(単純商 T は C₃ か C₅、いずれも G₃ の商でない: |G₃^{ab}| = 4、5 ∤ 108)。(O2): F₂ ↠ G₃、F₂ ↠ H₃ × C₅。(O3): K⁽³⁾ isolated。ゆえに命題 C より(e = 16/4 = 4、|[H₃×C₅, H₃×C₅]| = 3)

$$ |\mathrm{GT}(J)| = 12 \cdot 4 \cdot 3 = \mathbf{144},\qquad |\ker R_{J,K^{(3)}}| = 12. $$

詳細と gluing obstruction への含意は **`docs/week3-J設計_v1.md`** を参照。

### 6.5 予想の範囲(証明していないこと)

以下は**予想でも定理でもなく、未検査の疑問**として記録する(錨を下ろさないため、数値予想は立てない)。

- **(Q1)** hexagon-free でない N(= N 側の hexagon が実際に条件を課す細分)は存在するか。存在するなら命題 C は使えず、繊維は「余剰の全体」より真に小さくなり得る。**これが fake witness の最も自然な出所である**(K 側の shadow が持ち上がらない現象は、N 側の hexagon が K 側の m, f と干渉するときに起こるはず)。
- **(Q2)** (O1)(共通商なし)を落とすと何が起きるか。共通商 D ≠ 1 があると Q_M は fiber 積になり、charming/全射条件が絡む。**直交でない細分こそ本命**の可能性がある。
- **(Q3)** 命題 C の (c)(d) は「余剰がすべて繊維に落ちる」と言っているが、これは **K が isolated かつ N が hexagon-free** に強く依存する。Dih の外へ深く行くとき、この仮定がいつ破れるかは未知。
- **(Q4)** 命題 C の下では R が常に全射なので、**この構成法からは原理的に fake witness が出ない**。fake 狩りは (Q1)(Q2) の方向、すなわち **hexagon-free でない / 直交でない**細分に予算を移すべき。— これは戦略上の重要な帰結である(§8 の司令塔への含意)。
