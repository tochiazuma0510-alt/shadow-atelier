## A. 一般化 Goursat 補題 — arXiv **1109.0024** (Bauer–Sen–Zvengrowski, v3 2015)

1. **n 因子の部分直積の分類は「累積型」**(Thm 3.2): G ≤ G₁×…×Gₙ(各射影全射)は (3n−2) 個データで分類され、第 i 障害 θᵢ は「**先頭 i 因子の結合像** vs 第 i+1 因子」に住む(対ごとではない)。直積 ⟺ 全 θ 自明。
2. **「対ごと共通商なし ⇒ 全体直積」型の定理も反例も本論文には無い**(§5 の反例は対ごと共通商が非自明な別命題向け・対称版は未証明予想 Remark 5.1)。→ 便 05 F8 で監査合格した J1 補題(単純商への還元)は文献未収録の明示化 — **v2 では累積型障害の言葉で書き直すと文献整合的で n 因子拡張が自動化**する。
3. **副有限版**(Prop 4.2・2 因子): profinite ⟺ 各群 profinite+θ 連続(閉グラフ定理)。逆極限(genuine 判定の塔)を昇る際の連続性は無料。n 因子版は文献未展開(小さな空白)。
4. 引用注意: v3 は本文の相互参照が定理番号と 1 ずれ。頁+主張文で引用のこと。

## B. Guillot の GT(G) — arXiv **1407.3112** v3 / **1604.04415**

**系統札(引用時必須・3 軸)**: (a) pentagon **無** — hexagon 階層・逆極限は Drinfeld の **ĜT₀**。(b) **outer 変種** — λ 座標・(m,f) データ無し(k は well-defined でない)。(c) 塔は **F₂ の G-完備化 N_G** — PB₃ でなく、**中心 c が存在しない**。⇒ 主線(gentle GTSh)とも副線(B₄ 本来系)とも別の**第三変種**。同名 GT₁ の混同は 3 軸で防ぐこと。

1. **fake の文献先例**(1407 Prop 3.1+§3 末尾): 粗い dihedral 塔では GT₁(D_n)(n 奇)の位数 2 元が **D₄ₙ への持ち上げで全滅**(lim = 1)。(i) fake 検出 = 細分への持ち上げテスト、の独立先行例。(ii) **fake は塔相対的** — 同じ dihedral 世界でも粗塔は fake だらけ・K⁽ⁿ⁾ 塔は 2 冪で全射証明済み。atlas 解釈に「塔相対性」の注を立てるべし。
2. **単純因子 menu 定理**(1407 Thm 1.2): G 単純非可換 ⇒ GT₁(G) の単純因子は C₂ / C₃ / Out(G) 部分商 / A_s(s ≤ m²/|G|)のみ。PSL(2,q)(q 奇)は C₂^{n₁}×D₈^{n₂}(1604 Thm 1.1・MacBeath の trace 三つ組)。**2 群の表**(1407 §5.4・位数 2³–2⁷)では GT₁ ≇ S(G) の乖離が 2⁷ で顕在化 — **統合狩場(2 冪・class≥3)と同じ領域**である点に注意。
3. **λ 成分の算術全実現**(1407 Lemma 2.3): 任意の許容 k が Galois 元で実現。著者自ら「Galois に訴えない証明は知られていない」— 全射性の難所の所在について示唆的。
4. **比較写像の課題(未証明・評を請う)**: PB₃ ≅ F₂ × Z(c) ゆえ、c を先に殺す商に限れば Guillot 塔は主線塔の「c-自由断面」に見える。自然な写像 GTSh(N) → GT(G) の構成と核・余核の定量は新規性のある小課題候補 — **c 生存系(M₅ の円分 C₄)は彼の塔から原理的に見えない**ため、当工房の差別化点の定量化になる。
5. **計算技法(実装レーンに翻訳予定)**: (i) f 候補の両側剰余類パラメータ化+θ 前段フィルタ 1 ∈ C_x f θ(f) C_y^{θ(f)}(1407 Lemma 5.1)。(ii) centralizer∩Young の packet 分割。(iii) 計算済み表(PSL(2,q)・M₁₁ 等)は**比較写像が確立するまで較正に使わない**(対象が別物 — 答えの錨づけ禁止)。
