## 1. 準備 — 設計空間と hexagon の正規形

記法は `docs/命題_中心持ち上げ_v1.md` §1 に従う。π: PB₃ ↠ PB₃/⟨c⟩ ≅ F₂。以下、**c ∈ N** の対象のみを扱う(この仮定で PB₃/N ≅ F₂/N̄、N̄ := π(N)、N_F₂ = N̄ の同一視ができ、θ・τ が商へ降りる。c ∉ N の場合は M₅ 型の語レベル評価が必要で、設計を複雑にするだけ見返りがない)。

### 1.1 許容対象(admissible object)

> **補題 H1.** V̄ ⊴ F₂ を有限指数の正規部分群とし、N := π⁻¹(V̄) と置く。**N ⊴ B₃ ⟺ θ(V̄) = V̄ かつ τ(V̄) = V̄。**

**証明.** B₃ = ⟨Δ, δ⟩(δ := σ₁σ₂、関係 Δ² = δ³ = c)。実際 σ₁ = Δδ⁻¹·? を経由せずとも、δ⁻¹Δ = σ₂⁻¹σ₁⁻¹σ₁σ₂σ₁ = σ₁ より **σ₁ = δ⁻¹Δ**、σ₂ = σ₁⁻¹δ = Δ⁻¹δ² なので ⟨Δ,δ⟩ = B₃。N ≤ PB₃ が c を含むとき、N の B₃-正規性は PB₃/⟨c⟩ ≅ F₂ 上の共役作用で V̄ が不変であることと同値。補題 B0(命題 B §2)より Ad(Δ)|_{F₂} = θ、Ad(δ)(w) = τ(w)c^{ε_y(w)} で、c ∈ N ゆえ c-因子は V̄ の判定に無関係。∎

**定義.** 上の条件を満たす V̄(同値に、marked 商 P := F₂/V̄ が **X↔Y を延ばす自己同型 θ_P** と **X↦Y↦Z↦X(Z := (XY)⁻¹)を延ばす自己同型 τ_P** をもつこと)を**許容 (admissible)** と呼ぶ。

- verbal 部分群(F₂^n γ_k(F₂) など)は characteristic なので常に許容。**逆は成り立たない** — 許容の方が真に広い(§6 の A₄ が非 verbal な許容対象)。
- θ_P, τ_P は **inner でもよい**(P の自己同型でありさえすればよい)。
- 実装上の意味: 対象の探索は「F₂ の有限指数正規部分群で θ, τ 不変なもの」= **F₂ ⋊ ⟨θ,τ⟩ の正規部分群で F₂ に含まれるもの**の列挙に等しい。GAP の `LowIndexNormalSubgroups` で機械化できる(§5)。

> **系 H1′(2 生成の制約).** 許容 P では **ord(X) = ord(Y) = ord(Z)** が必要(τ_P が 3 元を巡回させる)。この共通位数を **k := ord(x̄)** と書く。c ∈ N より **N_ord = k**。

### 1.2 verbal ⇒ isolated

> **補題 H2.** N = π⁻¹(V̄)、V̄ が F₂ の **verbal** 部分群(= P が自身の生成する多様体の中で相対自由)ならば、GT(N) の全元は settled。ゆえに **N は isolated**。

**証明.** [m,f] ∈ GT(N)、u := 2m+1。x ↦ X^u, y ↦ f̄⁻¹Y^u f̄ は F₂ → P の準同型を定め、V̄ が verbal(= F₂ の任意の自己準同型で保たれる)なので P → P に降りる。GT-shadow の定義(Prop 3.6)よりこれは全射、有限群の全射自己準同型は自己同型 α。c ∈ N より T^{PB₃}(c) = c^u ↦ 1 = P_N(c)。ゆえに T^{PB₃}_{m,f} = α ∘ P_N。**補題 F**(命題 A §3)より settled。∎

★ この補題は定理 A の補題 G(多様体論法)を仮定なしに一般化したもの。候補 1・2 の isolated 性はこれで**紙上で**確定する(計算を待たない)。非 verbal な許容対象(A₄)では個別に見る(§6)。

### 1.3 hexagon の正規形

f ∈ [F₂,F₂] の代表を取り(charming の第 2 条項)、f̄ ∈ [P,P] をその像とする。τ²(y) = x, τ(y) = z に注意して Prop 3.4 の (3.10)(3.11) を P の中で書き下すと:

> **(H-a)** θ_P(f̄) = f̄⁻¹
> **(H-b)** X^m · τ_P²(f̄) · Z^m · τ_P(f̄) · Y^m · f̄ = 1

(H-b) の左辺から m の部分を括り出す。[P,P] は正規なので

$$ \textbf{(H-b′)}\qquad E_m \cdot \mathcal N_m(\bar f) = 1,\qquad
E_m := X^m Z^m Y^m,\qquad
\mathcal N_m(\bar f) := \bigl(\tau^2 \bar f\bigr)^{Z^mY^m}\cdot\bigl(\tau \bar f\bigr)^{Y^m}\cdot \bar f $$

(w^g := g⁻¹wg)。**E_m ∈ [P,P]**(P^{ab} で X^mZ^mY^m = (XZY)^m = 1)であり、𝒩_m: [P,P] → [P,P] は一般に準同型ではない。

> **定義(m-full).** 𝔐(N) := {m ∈ 𝒳_N : ∃ f̄ ∈ [P,P] で (H-a) かつ (H-b′)} と置く。**𝔐(N) = 𝒳_N のとき N は m-full** と呼ぶ。hexagon-free ⇒ m-full(逆は偽)。

> **補題 H3(fake の判定条件).** K, N を許容対象、M := K ∩ N、(O1)(O2)(O3) と N isolated を仮定する。このとき
> **R_{M,K} が全射 ⟺ 各 m₀ ∈ 𝒳_K に対し、m ≡ m₀ (mod K_ord) なる m ∈ 𝒳_M ∩ 𝔐(N) が存在する。**

**証明.** (O1)+Goursat で PB₃/M ≅ G × P、[·,·] も直積(命題 C(a))なので f̄ = (f_G, f_P) は独立に動く。交わりの補題(補題 A)で hexagon は K 側と N 側に分解し、K 側は [m mod K_ord, f_G] ∈ GT(K)、N 側は (H-a)(H-b′)。charming は m ∈ 𝒳_M に、全射性は Goursat で両成分の全射性に分解(命題 C(b) と同じ)。ゆえに [m₀,f_G] ∈ GT(K) の原像が存在 ⟺ 上の条件。∎

★ **含意**: (O4) を壊すだけでは足りない。**fake には「m 欠損」(𝔐(N) ⊊ 𝒳_N)が必要**であり、しかも欠損が K_ord を法とする剰余類**全体**を覆う必要がある。§2 はこの m 欠損がどこにしか起きないかを決める。

## 2. 狩場の境界(設計の副産物として得られた 3 つの定理)

### 2.1 E_m の消滅と k ≤ 3 の安全性

> **補題 H4.** 任意の許容 P と任意の m について **E_m は m mod k のみに依存**し、**E_0 = E_{−1} = 1**。

**証明.** X, Z, Y の位数はすべて k(系 H1′)なので E_m は m mod k のみに依存。E_0 = 1 は自明。E_{−1} = X⁻¹Z⁻¹Y⁻¹ = (YZX)⁻¹ = (X⁻¹(XYZ)X)⁻¹ = 1(XYZ = X·Y·(XY)⁻¹ = 1)。∎

> **定理 H5(k ≤ 3 は狩場でない).** 許容 N について k = ord(x̄) ≤ 3 ならば **f̄ = 1 が全 charming m で (H-a)(H-b′) を満たす**。ゆえに N は m-full であり、補題 H3 より **どの K と組んでも R_{M,K} は全射** — fake は出ない。

**証明.** f̄ = 1 は (H-a) を満たし、(H-b′) は E_m = 1 に帰着する。
- k = 1: P = 1。k = 2: 𝒳_N = ℤ/2 = {0,1} = {0,−1} で補題 H4 より E_m = 1。
- k = 3: charming は gcd(2m+1,3) = 1、すなわち **m ≢ 1 (mod 3)**、すなわち m ≡ 0, −1 (mod 3)。補題 H4 より E_m = 1。∎

★ これが **H₃(定理 A 補題 C)と A₄(§6)が同時に安全な理由の正体**である。定理 A では「θ が導来群を反転」+「exponent 3 で XWY = 1」という 2 つの偶然に見えていたが、真の理由は **charming が m を {0,−1} に閉じ込めること**の 1 点だった。3 の冪位数を狙う限りこの壁は破れない。

### 2.2 class 2 は常に可解(2 番目の壁)

> **定理 H6.** 許容 P が **class 2** ならば、[P,P] = ⟨c_P⟩(c_P := [X,Y])は巡回で τ_P は自明に作用し、(H-a) は空虚、(H-b′) は
> $$ c_P^{\,3a} \;=\; c_P^{\,m(m+1)/2}\qquad(\bar f = c_P^{\,a}) $$
> と同値。さらに e := ord(c_P) と置くと **e | k** であり、charming な m に対しこの方程式は**常に可解**。解の個数は gcd(3, e)。ゆえに **class 2 の許容対象は m-full**(fake は出ない)。

**証明.**
(1) 2 生成 class 2 では [P,P] = ⟨c_P⟩ は中心・巡回。θ_P(c_P) = [Y,X] = c_P⁻¹ なので (H-a): c_P^a c_P^{−a} = 1 は空虚。τ_P(c_P) = [Y, Z] で、class 2 では [Y,(XY)⁻¹] = [Y,XY]⁻¹ = ([Y,X][Y,Y])⁻¹ = [Y,X]⁻¹ = c_P。ゆえに τ_P|_{[P,P]} = id、また [P,P] は中心なので 𝒩_m(f̄) = f̄³。
(2) **E_m = c_P^{−m(m+1)/2}**: class 2 で X^aY^b = Y^bX^a c_P^{ab}、(AB)^m = A^mB^m[B,A]^{m(m−1)/2} を使う。Z^m = (Y⁻¹X⁻¹)^m = Y^{−m}X^{−m}c_P^{m(m−1)/2}(∵ [X⁻¹,Y⁻¹] = c_P)。ゆえに
 E_m = X^m·Y^{−m}X^{−m}·Y^m·c_P^{m(m−1)/2} = c_P^{−m²}·c_P^{m(m−1)/2} = c_P^{−m(m+1)/2}。
 (検算: H₃(e = 3)で m = 0,1,2 ↦ 1, c_P⁻¹, 1 — 定理 A 補題 C.2 と一致。Q₈(e = 2)で m = 0,1,2,3 ↦ 1, c_P, c_P, 1 — §3.1 の四元数直接計算と一致。)
(3) e | k: class 2 で c_P^k = [X^k, Y] = 1。
(4) 可解性: 3 ∤ e なら a ↦ 3a は ℤ/e 上全単射で常に一意解。3 | e のときは e | k かつ N_ord = k より 3 | N_ord、よって charming は 3 ∤ (2m+1)、すなわち m ≢ 1 (mod 3)、よって **3 | m(m+1)/2**(m ≡ 0 なら m が、m ≡ 2 なら m+1 が 3 で割れる)。ゆえに 3a ≡ m(m+1)/2 (mod e) は可解で解は 3 個。∎

★ **charming がちょうど必要な分だけ hexagon を救う**という「陰謀」が、class 2 では定理として現れる。fake が一例も知られていない理由の一端がここにある。
★ ただし **hexagon-free ではない**: 3 ∤ e のとき f̄ は m から一意に決まり、[P,P] の自由度 e が **1 に潰れる**。これが命題 C の公式 |GT(M)| = |GT(K)|·e·|[P,P]| を破る(§4)。

### 2.3 (Q2) 単独では f が結合しない

> **定理 H7(G₃ の許容商).** G₃ = PB₃/K⁽³⁾ の**許容商**(= θ,τ 作用と両立する正規部分群による商)は **G₃, C₂², 1 の 3 つのみ**。

**証明.** G₃ ≅ R ⋊ C₂²、R := [G₃,G₃] ≅ C₃³(2405 の位数と、G₃ ≤ D₃³ の回転部分)、G₃^{ab} ≅ C₂²(較正済み事実 F1)。
(1) R を F₃[C₂²]-加群として見る。x = (r,s,s) による共役は座標 2,3 の回転を反転、y = (rs,r,rs) は座標 1,3 を反転する(D₃ 内で s r s⁻¹ = r⁻¹)。すなわち C₂² は 3 つの座標に相異なる符号指標で作用し、R = ⟨e₁⟩⊕⟨e₂⟩⊕⟨e₃⟩ は**相異なる 1 次元加群の直和**。ゆえに G₃-不変部分群は座標部分空間 8 個に限る。τ は 3 座標を巡回置換するので、τ-不変なのは **0 と R** のみ。
(2) 商が R を殺す場合は G₃^{ab} = C₂² の商。τ は x̄, ȳ, z̄ = x̄ȳ(C₂² の 3 個の非自明元)を巡回置換するので、τ-不変部分群は 1 と C₂² のみ。
(3) 以上より許容正規部分群は 1, R, G₃ の 3 つ、対応する商が G₃, C₂², 1。∎

> **系 H7′.** K = K⁽³⁾、N を許容対象、M = K ∩ N とする。Goursat の共通商 D は G₃ の許容商だから D ∈ {1, C₂², G₃}。**D = G₃ ⟺ N ⊆ K⁽³⁾**(このとき M = N で「交わり」ではない)。ゆえに真の交わりでは **D は必ず可換**であり、
> - hexagon の分解(補題 A)は無傷、
> - f_G と f_P の**結合は起きない**(D 可換 ⇒ [G,G] と [P,P] の側で拘束が生じない; ただし [Q,Q] = [G,G]×[P,P] の等号は個別確認が要る —【GAP-D3】)。
>
> すなわち **(Q2) を単独で壊しても fake は出ない。(O1) の破れは |Q|・N_ord・数え上げにしか効かない。**

★ **戦略上の結論**: 司令塔タスクの (Q2) は、**単独では狩場ではない**。(Q1) と併発する場合にのみ意味をもつ(候補 2 がその型)。予算は (Q1) = **k ≥ 4 かつ class ≥ 3** に集中すべきである。

### 2.4 残った狩場の輪郭

定理 H5・H6 の対偶から、m 欠損(⇒ fake)が可能な許容対象は次を**すべて**満たす:

1. **k = ord(x̄) ≥ 4**。
2. **P の class ≥ 3**、または **P が非巾零**。
3. さらに欲しい性質: **N_ord = k が 2 冪**。このとき gcd(2m+1, k) = 1 は自動で、**charming が m に何の制約も課さない** — §2.1・§2.2 で hexagon を救ったのは常に charming だったので、この救済路を断てる。

⇒ **最小の狩場は「exponent 4・class ≥ 3 の 2 群」**。以下の候補 1 はこれを最小規模で実現する。

## 3. 候補 1 — T₄ 塔(2 進 exponent-4 塔)【第一撃の推薦】

### 3.1 対象の明示的定義(宇宙の事前登録に使える形)

### 3.2 Q₈ の許容性(明示構成)

τ_P: i ↦ j, j ↦ −k, −k ↦ i。準同型性の検査: (τi)(τj) = j(−k) = −jk = −i = τ(k)⁻¹·? — 正確には τ(ij) = τ(k) と (τi)(τj) = −i が一致すべきで、τ(k) := (τ(i)τ(j)) = −i と定めれば整合。τ³ = id(i→j→−k→i)。Aut(Q₈) ≅ S₄ の位数 3 の元。
