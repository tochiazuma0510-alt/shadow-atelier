## 0. 大原則 — 何を形式化し、何を形式化しないか

### 0.1 定理 K3 全体は形式化しない(できない)

定理 K3 の証明は次の三種の入力を混ぜている。

1. **有限群・組合せの計算**($G_3$、$\Lambda$、$\Phi$、$\mathfrak F_0$、位数の数え上げ)
2. **代数的数論**($[u]_6$ の位数・$L_3$ の同定・次数)
3. **副有限群論と数論幾何**(エタール $\pi_1$・接基点・Galois path cocycle・Kummer 被覆の接繊維・GT-shadow の圏)

**3 は Mathlib に存在しない**(エタール基本群も副有限自由群の中心化群も接基点も無い)。したがって「定理 K3 を Lean で証明する」は**現時点で不可能**であり、そう書けば嘘になる。

> **本設計の方針**: 定理を**分解**し、1 と 2 を層ごとに形式化して**補題単位で `verified` 札を付ける**。3 は**射程外と明示宣言**し、論文の形式化状態表では空欄でなく「**射程外(理由)**」と書く。
> これは工房規律「verified 札は補題ごとに付く」「検証手段の格の違いは隠さない」の直接の帰結である。

### 0.2 信頼札の階梯(論文の表に使う記号)

| 札 | 意味 | 使用公理 | 本設計での用途 |
|---|---|---|---|
| **✔K** | `decide` / `decide +kernel` で核が検算 | なし or `propext` のみ | 有限層の全項目(**実測でこれで足りる**) |
| **✔M** | Mathlib 上の通常証明 | `propext, Classical.choice, Quot.sound` | 数論層 |
| **△N** | `native_decide` | **`Lean.ofReduceBool` を追加**(コンパイラを信頼) | **本設計では不要**(§1.3)。使うなら別欄 |

**★ 重要な実測結果: 本設計の全項目で `native_decide` は不要**。最大コスト項(4096 部分集合探索・231 秒)も構造的証明に置換すれば 15 秒以下になる(§4.5)。

### 0.3 忠実性(mathematical equivalence)の規律

この対応表は**論文の付録**になる。各行に「Lean 命題」と「論文の主張」の**差**を明示する欄を設けた(**忠実性ノート**)。とくに次の 3 種の差は必ず書く。

- **(δ1) 存在量化の向き**: 論文が「$H$ は(幾何から)決まる」と言う所を、Lean は「ある明示の $H$ について」と言う。**同定は glue** = 射程外。
- **(δ2) 定義の代入**: 論文の $\mathrm{GT}(K^{(3)})$ は圏論的定義。Lean の `T` は**正典 Thm 4.3 のパラメータ表示を定義として採る**。両者の一致は正典 import。
- **(δ3) 抽象と具体**: 論文が抽象群 $A \le T$ について言う所を、Lean も抽象述語で受ける(**具体化しない**方が忠実 — §4.5)。

## 1. 実装方式の決定($G_3$ をどう書くか)

### 1.1 候補の比較

$G_3$ は位数 108、正典の定義は $G_n := \langle (r,s,s),\,(rs,r,rs)\rangle \le D_n^3$(D1 §3, p.14)。

| 方式 | 正典との距離 | 群公理の証明 | decide コスト | provenance | 判定 |
|---|---|---|---|---|---|
| **(i) $D_3^3 = (\mathbb Z/3\times\text{Bool})^3$ + パリティ述語** | **定義そのもの**($r^a s^e$ の直積) | 成分に落ちる($6^3=216$ で結合律) | **実測 §1.3** | リテラル不要 | **★採用** |
| (ii) 次数 12 の忠実置換表現 | 遠い(忠実性の証明が別途必要) | `Equiv.Perm` 相当を自作 | 速いが | **置換の出所が外部証明書** | 不採用 |
| (iii) 乗積表 $108\times108$ | 遠い | 表の正しさ自体が仮定 | 核の配列アクセスは遅い | **11664 個の未説明リテラル** | 不採用 |
| (iv) Mathlib `DihedralGroup 3` | 近い | 無料 | `Decidable` が `Classical` に落ちる危険 | 良い | **保留**(§1.4) |

> **★ (ii) を退ける決定的理由**: 委嘱 14/20 の★教材「**置換型は部分群を同定しない**」(W2)と同型の危険。次数 12 表現で $G_3$ を書くと、$\bar x,\bar y$ が正典の (3.6) と同じ元であることを別途証明せねばならず、そこが**新しい未検証の穴**になる。方式 (i) では $\bar x = (r,s,s)$ が**リテラルとして (3.6) そのもの**である。
>
> **★ (iii) を退ける決定的理由**: 工房の provenance 規律。乗積表は GAP/node 由来の外部データであり、Lean 側から見れば**検証されていない入力**。方式 (i) では **Lean ファイル中の未説明リテラルは $\bar x,\bar y$ の 2 個だけ**(どちらも正典 (3.6) の逐語)。$H$ も $\Lambda$ も $\Phi$ も**述語・閉形で書ける**(§3)ので、証明書からのコピーが一切要らない。

### 1.2 採用する型定義

```lean
/-- 二面体群 D₃ = ⟨r,s | r³, s², srs⁻¹r⟩ の元 rᵃsᵉ を (a, e) で表す。 -/
abbrev D : Type := Fin 3 × Bool
/-- D₃³(位数 216)。正典 D1 (3.1) の値域。 -/
abbrev E : Type := D × D × D

def dmul (a b : D) : D := (if a.2 then a.1 - b.1 else a.1 + b.1, xor a.2 b.2)
def dinv (a : D) : D := if a.2 then a else (-a.1, false)
def emul (x y : E) : E := (dmul x.1 y.1, dmul x.2.1 y.2.1, dmul x.2.2 y.2.2)
def einv (x : E) : E := (dinv x.1, dinv x.2.1, dinv x.2.2)

/-- 反射パリティ。G₃ = ker(par) は指数 2 の部分群。 -/
def par (x : E) : Bool := xor (xor x.1.2 x.2.1.2) x.2.2.2
def inG (x : E) : Prop := par x = false

/-- 正典 D1 (3.6): x̄ = (r,s,s), ȳ = (rs,r,rs), z̄ = (r²s, r⁻¹s, r)。 -/
def xb : E := ((1, false), (0, true), (0, true))
def yb : E := ((1, true),  (1, false), (1, true))
def zb : E := ((2, true),  (2, true),  (1, false))
```

**必須の補助インスタンス**(plain Lean 4 core には**直積上の decidable 全称量化子が無い** — 実測で確認):

```lean
instance instDecForallProd {α β : Type} {p : α × β → Prop}
    [inst : Decidable (∀ a : α, ∀ b : β, p (a, b))] : Decidable (∀ x : α × β, p x) :=
  decidable_of_iff _ ⟨fun h x => by cases x; exact h _ _, fun h a b => h (a, b)⟩
```

> **実測**: `∀ i : Fin n`・`∀ b : Bool`・`∀ i, i < n → …`(`Nat.decidableBallLT`)は core にあるが、`∀ x : α × β` は**インスタンス合成に失敗する**。上の 3 行で解決(公理追加なし)。

### 5.1 ★ 司令塔案(ノルム論法)の採否 — **採用。ただし一般化して使う**

司令塔案: 「4 が $\mathbb Q(\zeta_{12})$ で立方なら、その立方根 $x$ は $X^3-4$ の根で代数的整数、$N(x)^3=N(4)=4^4=256$、しかし 256 は整数の立方でない」。

**数学的検討(私の判定)**

1. **正しい**。$x^3=4$、$x\in K$ ⇒ $x$ は monic 整係数多項式の根 ⇒ 代数的整数 ⇒ $N_{K/\mathbb Q}(x)\in\mathbb Z$。ノルムの乗法性より $N(x)^3=N(4)=4^{[K:\mathbb Q]}=4^4=256=2^8$。$3\nmid 8$ ゆえ矛盾。
2. **ただし「256 が立方でない」だけでは閉じない** — $[K:\mathbb Q]=4$ を使っている。一般には $N(x)^3=4^d=2^{2d}$ から $3\mid 2d$、すなわち **$3\mid[K:\mathbb Q]$** が出る。つまりノルム論法は次数論法(塔 $\mathbb Q(\sqrt[3]2)\subset K$ から $3\mid4$)と**同じ結論に別経路で到達する**。
3. **それでも Mathlib 最短経路として採用する**。利得は次数計算の回避ではなく、**$X^3-2$ の既約性(Eisenstein)と塔の法則を使わずに済む**ことである:

| | 次数論法(v2 §2.3 (c′)の書き方) | **ノルム論法(司令塔案)** |
|---|---|---|
| 要る Mathlib 入力 | ① $[K:\mathbb Q]=4$ ② $X^3-2$ 既約(Eisenstein)③ 塔の法則 ④ $\sqrt[3]2\in K$ の構成 | ① $[K:\mathbb Q]=4$ ② 整性 ③ `Algebra.norm` の乗法性と `norm_algebraMap` ④ **整数の非立方性(`decide` 級)** |
| 難所 | ②の Eisenstein 適用(多項式の係数条件)が煩い | ②③の API 名が実在するか(**UNKNOWN**) |

4. **★ さらに一般化して両窓で再利用する**(私の追加):

> **補題 NC(ノルム障害・一般形).** $K/\mathbb Q$ を次数 $d$ の数体、$a\in\mathbb Z$、$p$ 素数とする。$a$ が $K$ で $p$ 乗ならば、$a^{d}$ は**有理整数の $p$ 乗**である。
> **系 NC-1**($K=\mathbb Q(\zeta_{12})$, $d=4$, $p=3$, $a=-4$): $(-4)^4=256=2^8$ は整数の 3 乗でない ⇒ **$-4$ は $K$ で立方でない**。
> **系 NC-2**($d=4$, $p=3$, $a=2$): $2^4=16$ は整数の 3 乗でない ⇒ $2$ は $K$ で立方でない ⇒ $X^3-2$ は $K$ 上既約(M5)。
> **系 NC-3**($K=\mathbb Q(\zeta_5)$, $d=4$, $p=5$, $a=2$): $2^4=16$ は整数の 5 乗でない ⇒ **$2$ は $\mathbb Q(\zeta_5)$ で 5 乗でない** = **$A_5$ 窓の $\mathrm{ord}([2]_5)=5$**。

**⇒ 補題 NC 一本で $K^{(3)}$ 窓と $A_5$ 窓の算術核が両方落ちる。** 論文の「比較スキーマ + 2 適用」構成(v2 §5.3)と完全に整合し、形式化の投資対効果が最も高い項目である。**司令塔案を採用し、一般形に昇格させる**のが私の判断。
