## 1. 一枚の地図: 宣言が言うこと・言わないこと

宣言はこう言っています:

> 有限側(GT-shadow の列挙・群構造)を、独立した二系統の計算で再現した。
> 算術側(G_ℚ からの下限)は論文の定理を引用した。両者を突き合わせると
> 2 冪の場合の「G_ℚ → GT(K^(2^α)) 全射」が復元される。

言って**いない**こと: (i) Galois 理論側を計算で再証明した(していません — 円分指標の全射性などは論文の入力)、(ii) Lean で機械検証した(していません — cross-checked 止まり)、(iii) 新しい定理を得た(得ていません — 既知結果の再現と、それを支える**検証基盤**が成果物)。

なぜ再現に 2 日もかけるのか: Week 3 から先は**答えのない対象**(Dih の外)を撃ちます。そのとき「計算機が言った」に頼れるためには、答えを知っている問題で機構全体が較正されている必要がある — ES7 の「答えを知っている問題を先に撃たせよ」の実践です。

## 2. GT-shadow とは「ĜT_gen の有限の窓」

profinite の群 ĜT_gen(Grothendieck–Teichmüller 群の gentle 版)は直接触れません。そこで有限指数正規部分群 N ⊴ B₃(N ≤ PB₃)ごとに「窓」を開けます:

- 窓に映るデータ = 組 [m, f] ∈ ℤ/N_ord × F₂/N_F₂(m は「ひねりの回数」、f は「置き換えの語」)
- 窓の条件 = hexagon 関係式 (3.3)(3.4) mod N+charming+全射性
- これが **GT(N) = GT-shadow の有限集合**。Thm 5.2(2401)により **ĜT_gen = lim GT(N)** — つまり窓を全部集めると元の群が復元される。shadow(影)という名前のとおり、各窓は ĜT_gen の影です。

Galois 群 G_ℚ は Ihara 埋め込みで ĜT に入るので、各窓に **G_ℚ の影**(arithmetical shadows)が落ちる。dihedral 予想(Conj 5.1)は「dihedral の窓では影が窓いっぱいに広がっている(全射)」という主張です。

## 3. hexagon は何を守っているか — そして c^m の出所

hexagon (3.3)(3.4) の役割は一言で「**σ₁ ↦ σ₁^{2m+1}, σ₂ ↦ f⁻¹σ₂^{2m+1}f が braid 関係を保つ**」ことの保証です(Prop 3.2 の証明がまさにそれ)。右辺に付く c^m は中心 ⟨c⟩ = Z(B₃) の寄与で、PB₃ ≅ F₂ × ⟨c⟩ の直積分解の「F₂ に見えない部分」を運びます。

これがどこから出るかは transversal-cocycle モデル(12 規則)で手で触れます: B₃ の元を「剰余類の代表 t × PB₃ 部分」に分解して σ を右から掛けると、**12 個中 2 個の規則だけが c を運ぶ**((σ₁σ₂)·σ₂ と (σ₂σ₁)·σ₁ — 交換公式 (1.11)(1.12) の c がそのまま現れる)。hexagon の c^m はこの 2 規則の蓄積です。

**N₅ 事件(★ sol_reply_02 F7)**: dihedral の窓では常に c ↦ 1 なので、この機構は一度も試されない。そこで c ↦ t(位数 5)となる control N₅ を追加しました。そこで見えた面白い事実 — **可換な窓では hexagon が全 m で成立してしまい(空回り)、shadow を絞る仕事は charming(単元条件)が全部やる**。探索器はこの 2 つを混同して counts を誤記しており、Sol がそれを「合格者だけを検査する較正は空虚 — 落とした候補の理由まで照合せよ」という原則ごと突いてきた。較正という営みの本質が出た瞬間です。

## 4. charming は pentagon の影

本来の ĜT は hexagon 2 本+**pentagon**(B̂₄ の中の 1 本)で定義されます。gentle 版は pentagon を、その帰結である「f̂ ∈ [F̂₂, F̂₂] の閉包」に置き換えた緩和版 — 有限の窓ではこれが **charming 条件「f は交換子部分群の元」**になります。つまり定義ノートの確認質問 2 の答え: **charming は pentagon の影**です。pentagon そのものを課す B₄ 系(2106.06645 の同名別物)との分岐点がここ。

## 5. dihedral の窓 K⁽ⁿ⁾ と「答えの書かれた本」Thm 4.3

ψₙ: PB₃ → Dₙ³ を x ↦ (r,s,s), y ↦ (rs,r,rs), c ↦ 1 で定め、K⁽ⁿ⁾ = ker ψₙ。2405 の Thm 4.3 が **GT(K⁽ⁿ⁾) の完全な明示式**を与えます:

- m は 𝒳ₙ = {gcd(2m+1, N_ord) = 1} を走る(charming の単元条件)
- f の像は (r^{2k}, r^{−2k}, r^{ϰ(m)}) の形(k は mod n/2)
- 4|n のときだけ追加の parity 条件 k ≡ ϰ(m)/2 (mod 2) — これが Thm 4.6 の H̃_α(指数 2 部分群)の正体

較正スイートの主戦はこれでした: **総当たり列挙(hexagon+charming+全射を愚直に検査)が、この閉じた式と 17 の窓すべてで集合として一致する** — 論文の手計算と私たちの機構が同じ答えに到達した、という照合です。

## 6. 検証の三本柱(★印の中心)

**(4.11) = kernel 証明書(★ sol_reply_02 F5・03 F1)**。shadow の「source の窓 = target の窓」(settled)を言うのに「ker T の指数が同じ」は**証明にならない**(全射なら指数一致は自動)。正しい証拠は Lemma 4.2 の共役 triple h = (h₁,h₂,h₃): 等式 x̄^{2m+1} = h x̄ h⁻¹ と g⁻¹ȳ^{2m+1}g = h ȳ h⁻¹ が成り立てば **T = Ad(h)∘ψₙ と factor** し、kernel の一致が従う。「同型らしい」ではなく「内自己同型を経由する」という有限の証拠 — 各 shadow に 1 枚ずつこの証明書を添付し、照合器が独立に検査しました。

**代表元不変性(★ sol_reply_03 F3)**。[m,f] は同値類なので、(m, f) と (m+N_ord, f·x^{N_ord}) で全下流(hexagon・T・合成・reduction)が同じ値になるべき。「理論上同じだから」はテスト省略の理由にならない — 実装が代表の取り方に依存していないことを、両代表への**実適用**で確認しました(K13 なら 97,344 の合成対を両側で)。

**非可換 witness(★ sol_reply_02 F11)**。GT(K^(2^α))(α≥3)は ĜT の**最初の非可換有限商族**(Cor 5.4)。その非可換性を「群の位数が合う」でなく、具体的な 2 元 — (0,−1)(複素共役の影)と (1,5) — の積が**順序で違う**ことを座標 ϱ(m,k) = (k, 2m+1) の affine 積で確認しました。G_ℚ の非可換な影を手で触れる最小例です。

## 7. cross-checked と verified の線(この工房の認識論)

- **candidate**: 単系統の出力(GAP だけ、ノートだけ、Sol の主張だけ)
- **cross-checked**: helper を共有しない二系統(GAP の置換計算 ↔ node の整数演算)が**独立に同じ答え**に到達し、fail-closed の照合器(壊れた入力を必ず落とすことをテスト済み)が受理した状態。いまの G1★ はここ
- **verified**: Lean の機械証明を通った状態。**まだ存在しない**(Week 2 以降の任意工程)

二系統一致が強いのは「同じバグは同じ答えを出す」を破っているから。それでも「両方が同じ誤読をした」可能性(共通仕様の誤転記)は残る — そこは仕様(12 規則)を Artin 忠実表現と Sol の手導出で**別経路監査**して塞ぎました(★ sol_reply_02 F3 の「二層に書き分ける」)。

## 8. おまけの数学 2 題(監査から出た小さな宝石)

- **平方根障害(★ sol_reply_02 F2)**: 「B₃/K⁽ⁿ⁾ を 3n 点で実現できるか」→ 偶数 n で不可能。Sol の一行証明: d² = r なら d は r と可換、n サイクルの中心化群は ⟨r⟩ 自身、ゆえに d = r^a で 2a ≡ 1 (mod n) — 偶数 n で解なし。cycle type で場合分けするより鋭い。この障害が 12n 点の transversal モデルを採らせた設計動機です。
- **JoinC 事件**: n=13 の証明書(合成表 97,344 行)の書き出しが 437 秒 → 文字列連結が O(長²)だったのが原因で、線形化により 0.67 秒。数学でなく工学ですが、「cap は結果を見てから免除しない」(Sol W21)という規律が最適化を強制した、良い因果でした。

## 9. Week 3 の賭け — なぜ L = K⁽³⁾ ∩ N₀ か

fake GT-shadow(ĜT_gen から来ない影)は**一例も知られていません**。fake の証明は有限で閉じます(Cor 5.4: ある細分 K ≤ N で reduction の像から漏れる shadow を 1 個、完全列挙つきで示せばよい)。狩場の設計(Sol P3 採用版):

- H₃ = 位数 27 の Heisenberg 群(自由 class-2 exponent-3)、N₀ = その kernel の引き戻し。**|PB₃:N₀| = 27 が奇数**なので、全 |Gₙ| が 4 の倍数であることと矛盾 → **N₀ が Dih の外にあることが位数だけで証明できる**
- L = K⁽³⁾ ∩ N₀ は |PB₃:L| ≤ 2916、raw 候補 ≤ 324 — 二桁安全な小ささ
- GT(L) を全列挙して R_{L,K⁽³⁾} の像を計算。**非全射なら fake 初例+Conj 5.1(最小 open ケース)の反例**。全射でも「Dih 外の細分 1 つを genuine 条件が通過した」という atlas の最初のデータ点(ただし arithmetical の証拠と呼ばない — Sol の限定)

どちらに転んでも意味がある、という設計が肝です。
