## 1. 目的

窓ごとの個別探索から、**不変量で層別した族単位の網羅探索**へ移行する。成果物の型は「層ごとの完全 atlas + 層を横断する圧縮法則」。

## 2. 分類軸(現有 4 本)

- **(A) 商+パスポート+マーキング軌道**: N ↔ (有限群 P・(ord X, ord Y, ord Z)・生成三つ組の Aut(P)-軌道)= regular dessin の辞書。P ごとに機械で悉皆可能(A₅ の S₅-軌道一意計算が原型)。理論値は Frobenius 計数。
- **(B) 合同/非合同**: B₃/⟨c⟩ ≅ PSL(2,ℤ) 経由のレベル塔(CRT で素数冪に分解)。T-6(candidate): N_A = レベル 10 主合同部分群の引き戻し・Galois 曲線 = X(10)。**宿題: K⁽ⁿ⁾ の合同性判定**。
- **(C) 表現論的層不変量**: (G2)(det(1−σ) の可逆性)・(G3)(中心の induced 性)型。E23 で実証済み — 「壊れる最初の層」を紙で特定してから撃つ。
- **(D) GTSh 作用との同変性**: GT-shadow は窓の poset に作用し、isolated = 固定点。**採用する不変量はこの作用で保たれる(または共変な)ものに限る** — 分類の整合条件。

## 3. 圧縮法則の候補(層を横断して検証するもの)

1. 統一定理 |GTSh(N,N)| = |N_{Aut(Ĝ)}(⟨w⟩)| の射程拡張(現状 7+1 窓・A₅ は k = 5 の case A として整合)。
2. settled 率の法則(case A = 100%・case B = 2/φ(e) 型)。
3. E23 型消滅定理(障害の構造的空白)の適用域と破れの初出層。
4. 飽和の A₅ テンプレ: 還元定理 R → 接基点 torsor → **Kummer 数 u を族の上の関数として**計算。
