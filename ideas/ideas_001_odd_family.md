## I-3. mixed の分解戦略 — R×R の単射性と「同時実現」への帰着(最小標的 n = 12)

$$ R_{K^{(n)},K^{(2^\alpha)}} \times R_{K^{(n)},K^{(n_0)}}:\ GT(K^{(n)}) \longrightarrow GT(K^{(2^\alpha)}) \times GT(K^{(n_0)}) $$
は単射で、Thm 4.6 の抽象直積分解 GT(K⁽ⁿ⁾) ≅ Aff(ℤ/n₀) × H̃_α と**両立**する(抽象同型が reduction で実現されるかは別問題 — そこが数学的内容。n = 12: 24 → 12 × 4 = 48 の指数 2 の像)。

(ii) **同時実現予想**: (i) と両成分の算術飽和(2 冪側 = Thm 5.3 既知・奇数側 = 定理 K3 と族線)の下で、Ih_{K⁽ⁿ⁾} の全射性は「単一の σ ∈ G_ℚ が指定された対 (shadow₂, shadow_odd) を同時に実現する」ことに帰着し、その障害は**両成分の固定体の合成における交差**(円分部の共有 = χ_cyc の合同条件で処理可能な部分と、それ以外 = Goursat 型の食い違い部分群)として単離される。n = 12 では奇数側固定体 L₃ = ℚ(ζ₁₂, ∛2)(W3-11 既出)と 2 冪側固定体の交差が円分部に限られるか、が判定の 1 点。

**何が新しいか(grep 済み)**: Goursat 装備(J1′ 累積型・三因子版)は細分窓 L・J の**構成**に既用(裁定 05/06)。**mixed dihedral の算術実現の貼り合わせへの転用は未出**。較正スイート 6 の branch (36,12)(12,4)(18,3) は R の関手性まで(単射性・同時実現は台帳になし)。K⁽¹²⁾ ⊆ K⁽⁴⁾ ∩ K⁽³⁾ は Prop 3.5 から出るが**等号は未検算**(ここも未出)。

## I-5. 奇数 dihedral 予想の算術的心臓の単離 — 「ord([u_n⁻¹]_{2n}) = n の n 一様性」と破れの危険地帯

**種(予想+反例狙い)**: I-1・I-2 が成立した世界では、奇数側 dihedral 予想(Conj 5.1 の n 奇全体)は R^cyc + B_FC 経由でただ 1 本の算術命題に縮む:

$$ \text{全奇数 } n:\quad \mathrm{ord}\bigl([u_n^{-1}]\bigr) = n \quad \text{in } K_n^\times / K_n^{\times 2n},\qquad K_n = \mathbb{Q}(\zeta_{4n}) $$

- **予想 B(反例狙い)**: ord 条件は K_n の**単数群・類群の n 依存**で破れうる。破れた n では(前件成立下)R^cyc の同値により Ih 非全射 = fake shadow の存在 = **Conj 5.1 の反例**。危険地帯の粗い候補: [u_n⁻¹] が virtual unit に退化しうる n・ℚ(ζ_{4n}) の類群の ℓ-階数が跳ねる n(単窓 K⁵ 用に scout 済みの Selmer 還元機構 — `docs/scout/scout_20260727_power_residue.md` — の**族方向への再利用**)。
