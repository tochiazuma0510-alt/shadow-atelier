**主張の種(別分野からの翻訳・出所 = Riemann–Hurwitz の一行)**: 補題 R の上界 Σc ≤ n+2 は、3 点分岐被覆の種数公式 2−2g = c(a′)+c(b′)+c(u′)−n の g≥0 に他ならず、**等号 = 種数 0**。ゆえに I7-2 の「実現族の共通署名 = Ree 等号」は幾何の言葉で「**D4 族の壁標本は、種数 0 の 3 点分岐被覆(= 平面的 dessin)にちょうど対応する**」と読める。帰結の候補:
1. **探索空間の言い換え**: 非可解窓・dl-3 核の標的探し(帯 2 の最重要空白)は「passport (2^k…, 3^m…, (ℓ,2^j)) の種数 0 dessin で単絡群が指定型」の探索と同値 — 被覆の連結性(= 推移性)が dessin 側では「絵が一枚に繋がるか」という組合せに落ち、I7-2 の「最小 ℓ は死ぬ」も dessin の非存在として描ける可能性。
2. **G_ℚ 軌道への出口**: 副線(2106 抽出ノート)の装置は passport・genus・Galois 軌道計算を既に持つ。壁標本の dessin としての **G_ℚ 軌道**が計算できれば、帯 3 の空白 Q-C(影の Frobenius 表)に壁キャンペーン発の最初の実データが入る — 壁(群論)と井原(算術)を繋ぐ最短の橋の候補。
3. **W6-6 の具体化**: 「核方向の固定体が D₈-拡大」の候補地は、dessin の moduli field の言葉で問い直せる(どの数体上で定義されるか)。

**何が新しいか(grep 済)**: 「種数 0 縁」の語は裁定 206・wac_tail8 に既出(予算計算の文脈のみ)。(2,3)-生成分野への言及は裁定 207 §3(文献 scout 標的として)。2106 ノートの genus/orbit 装置は副線として既存。**「等号 = 種数 0」の同定を壁族の構造原理として立てること・壁標本を dessin 化して副線の軌道計算に載せる接続・Q-C への供給路の指摘は未出**。

**検証の一手目(1 run・数分)**: implementer へ — 実現済み D4 窓 4 点(A16/A18/A20 + A₁₃ candidate)の (a′,b′,u′) 類から RH で種数を機械計算し 0 を確認(既知値の再導出 — 較正)、次に**未実現側**(A21 の 5 軌道の各推移成分など)の種数も並べ、「実現 ⟺ g=0 ∧ 連結」の表を作る。第二歩(委嘱一件): 最小の壁標本 1 個を B₄ 系の passport に翻訳できるか数学者に設問 — **ここが同名別物ゲート**(次項)。

**破綻しそうな点**: ①**同名別物の罠が正面にある**: 壁キャンペーンは B₃-gentle(hexagon のみ)・dessin 装置は B₄ 本来系(pentagon あり・2405 Rem 1.2)。「dessin として書ける」と「副線の GT♥ 装置で軌道が回せる」の間には正典水準の橋がなく、翻訳ゲート(司令塔の一工夫義務)を通さず接続すると型エラーになる。②種数 0 の同定自体は初等だが、それだけでは新情報がない — 価値は接続(軌道・moduli field)側にあり、そこが一番遠い。③G_ℚ 軌道計算は外部パッケージ(Dolgushev GT)の適用範囲・次数制限に阻まれる可能性(A₁₆ 級の次数は装置の想定外かもしれない)。夢級ラベルの所以。
