## 結論

### (a) H8・H9 と P40

- **H8 本体は合格**する。ただし合格するのは、文面どおり「\(3\nmid |A|\) なら各 \(m\) について **(H-b′) 単独**が可解」という定理までである。Schur–Zassenhaus の適用、補群の \(A\)-共役性、捻れノルムとの対応はいずれも正しい。
- **H8″、§0/§4 の「2 群は完全に守られる」「fake には \(3\mid |[P,P]|\) が必要」「Q7 が唯一の穴」は不合格**である。H8 が与える補群の共役類と、(H-a) の \(\theta(f)=f^{-1}\) locus が交わることは証明されていない。【GAP-E2】は注記的な穴ではなく、H8″ と狩場一点化を止める**重大な穴**である。

1. Guillot の \(GT_1(P)\) の exact definition と marking を受領する。
2. isolated な \(c\in N\) 対象で \([m,f]\mapsto[\alpha_{m,f}]\in Out(P)\) が Guillot 条件を満たすか確認する。
3. 準同型性、核、像を証明する。
4. その後に Q8/P2/P3 の表を比較する。

### F16【要修正】四欄 certificate の算術だけ直せ

四欄を維持するなら、次の排他的な stage count と定義する。

1. `candidate_total`
2. `h10_fail`: 全候補中、最初に h10 で落ちた数
3. `h11_fail`: h10 を通過し、h11 で落ちた数
4. `generation_fail`: h10/h11 を通過し、生成性で落ちた数

そして
\[
\texttt{shadow\_total}
=\texttt{candidate\_total}
-\texttt{h10\_fail}
-\texttt{h11\_fail}
-\texttt{generation\_fail}
\]
を導出値として記録する。独立に数えた重複可能な fail 数を三欄へ入れるなら、この引き算は使えず、Venn 情報が必要になる。hexagon-free の正証明だけなら三 fail が全て 0 で十分である。

それ以外の v2 修文には不一致がない。封印標準は canonicalization の版、nonce の byte 表現、対象定義 hash を payload に固定すれば採用してよい。
