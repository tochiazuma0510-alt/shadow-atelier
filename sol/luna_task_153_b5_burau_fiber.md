## Sound finite-fiber theorem to implement

Fix a finite Burau specialization \(\beta_{q,a}:B_4\to GL_4(\mathbf F_q)\), with \(a\ne0\), using the unreduced Burau block convention.  Verify the braid relation and determinant/invertibility canaries before scanning.

For the five literal A.18 pairs above, define the finite homomorphism

\[
E_{q,a}:F_2\longrightarrow
P\times\prod_{i=1}^{5}GL_4(\mathbf F_q),
\quad
w\longmapsto
(w(\bar x,\bar y),\,\beta(\varphi_i(w))_{i=1}^5).
\]

Let \(H=\operatorname{im}E_{q,a}\), \(H'= [H,H]\), and let \(\pi:H'\to P\) be the first projection.  For every roof row \(r=(m,\bar f)\), enumerate the **complete** finite fiber

\[
F_r=\{h\in H':\pi(h)=\bar f\}.
\]

Each `h` contains the five evaluations of one common commutator word.  Evaluate the displayed raw defect directly from those five components.  If

\[
\{h\in F_r:D(h)=1\}=\varnothing,
\]

then no profinite \(\widehat{GT}\) lift of row \(r\) can satisfy pentagon, so row \(r\) is fake.  Since every arithmetic row has a Galois lift, a complete zero row is automatically outside; with the fixed index-3 dichotomy this is terminal B4-A for all 648 outside rows.

This test deliberately ignores refined hexagon/onto constraints: omitting them enlarges `F_r`, so a zero pentagon fiber remains a sound obstruction.  A nonzero fiber is not B evidence.
