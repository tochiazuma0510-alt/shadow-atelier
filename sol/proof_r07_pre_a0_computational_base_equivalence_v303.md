# R07 pre-A0 computational-base A3 equivalence theorem (v303)

## 0. Scope

V302 proves that every registered A0 correction gives the same exponent-nine
residual target as the uncorrected base word.  The implementation consequence
needs one further typing statement.  The full v225 two-word package at the
identity correction is not the full package of an unknown actual correction:
its correction column, corrected source word, and exact PB data are different.
What is equal is exactly the projection consumed by the v216 single-seed
pre-gate.

This note defines that projection and proves the equality.  It justifies an
actual pre-A0 A3 calculation from accepted task198 and fixed (g_{760}), while
forbidding that computational point from being called an A0 word, a compatible
lift, a fake, or an Ihara witness.

## 1. Full two-word package and its A3 projection

Retain v225 notation.  Put (g_0=g_{760}), let (a) be a source correction,
and put (f=g_0a).  The full package contains, among other fields,

\[
 {cal S}_{\rm PB}(g_0,a)=
 \bigl(g_0,a,f,(Ba)_B,e_B,
       (r_o,P_o,\xi_o,w_o,u_{0,o})_{o=1}^{11},
       \bar\epsilon_1(f)\bigr).
\tag{1.1}
\]

Here

\[
 d_B=-\delta_BR_B(g_0),\qquad
 (Ba)_B=\delta_BR_B(f)-\delta_BR_B(g_0),
\qquad e_B=d_B-(Ba)_B,
\tag{1.2}
\]

and

\[
 \bar\epsilon_{1,B}(f)=D_{1,B}e_B=1-\overline{R_B(f)}.
\tag{1.3}
\]

By v225 Sections 2 and 5, the occurrence data

\[
 r_o=\overline{\rho_o(g_0)},\quad
 P_o,\quad \xi_o=r_o^{-1}-1,\quad
 w_o=\sigma_op_o\xi_o,
\tag{1.4}
\]

are constructed from (g_0) and the immutable task198 ledger, not from
(a) or (f).  The same is true of

\[
 w=(w_o)_o,qquad
 u_0=(z-1)\mathbin\odot w.
\tag{1.5}
\]

Define the **A3 gate projection**

\[
 \boxed{
 \Pi_{A3}{\cal S}_{\rm PB}(g_0,a)
   =({\cal L}_{198},{\cal Q},(p_o,\xi_o,w_o,u_{0,o})_{o=1}^{11},
     w,u_0,\bar\epsilon_1(f)).}
\tag{1.6}
\]

The ledger ({\cal L}_{198}) contains all signs, inverse slots, prefixes and
typed occurrence maps, while ({\cal Q}) contains the frozen PB3/PB4
class-two arithmetic and the marked (D_1)-action.  Fields used only to
authenticate the full two-word identity, such as the literal corrected word,
(rword_f), (B_a), and exact PB chains, are not identified by (Pi_{A3}).

## 2. The identity computational point

Let (1_F) denote the identity word, represented computationally by the empty
reduced list.  Then

\[
 f_0=g_0 1_F=g_0,qquad
 (B1_F)_B=0,qquad e_B(1_F)=d_B.
\tag{2.1}
\]

Therefore

\[
 \boxed{
 \bar\epsilon_{1,B}(f_0)
 =D_{1,B}d_B
 =1-\overline{R_B(g_0)}.}
\tag{2.2}
\]

Call ({\cal S}_{\rm base}:={\cal S}_{\rm PB}(g_0,1_F)) the
**computational-base package**.  Equation (2.1) is only an arithmetic device
for evaluating the right side of (2.2).  It does not assert that (1_F) is a
solution of the A0 raw roof equation.

## 3. Projection equivalence for every A0 correction

### Theorem 3.1 (PRE-A0 COMPUTATIONAL-BASE EQUIVALENCE)

For every registered A0 roof correction (a\in\Omega\),

\[
 \boxed{
 \Pi_{A3}{\cal S}_{\rm PB}(g_0,a)
 =\Pi_{A3}{\cal S}_{\rm base}.}
\tag{3.1}
\]

#### Proof

The ledger and quotient arithmetic in (1.6) are fixed inputs.  Equations
(1.4)--(1.5) show that every occurrence component, (w), and (u_0) depends
only on (g_0); hence those components agree with the computational base.

It remains to compare the residual target.  V302 Theorem 4.1 gives, separately
in H1, H2 and P,

\[
 \overline{R_B(g_0a)}=\overline{R_B(g_0)}.
\tag{3.2}
\]

Combining (1.3), (2.2), and (3.2) gives

\[
 \bar\epsilon_{1,B}(g_0a)
 =1-\overline{R_B(g_0a)}
 =1-\overline{R_B(g_0)}
 =\bar\epsilon_{1,B}(f_0).
\tag{3.3}
\]

Thus every component of (1.6) agrees.  QED.

### Warning 3.2 (NO FULL-PACKAGE EQUALITY)

Theorem 3.1 does **not** claim

\[
 {cal S}_{\rm PB}(g_0,a)={\cal S}_{\rm base}.
\tag{3.4}
\]

For a nontrivial correction the literal word (f=g_0a), its substituted
words, the universal PB correction column (Ba), and the exact PB residual
chains can differ.  These fields remain necessary after the projected A3
test.  An executable receipt must therefore label any retained base-side
`f`, `rword_f`, `B_a` or exact-chain diagnostics as
`BASE_REFERENCE_ONLY`; they cannot be used as evidence for an actual A0 word
or exact endpoint equality.

## 4. Transfer of a MEMBER or NONMEMBER certificate

Let (U_0\) be the v216 occurrence closure generated by (u_0), and let
(C) be the printed block-sum map.  Both are determined by the projection
(1.6).  Theorem 3.1 immediately gives

\[
 \boxed{
 \forall a\in\Omega:\quad
 \bar\epsilon_1(g_0a)\in C(U_0)
 \iff
 \bar\epsilon_1(g_0)\in C(U_0).}
\tag{4.1}
\]

More precisely:

1. if the computational-base calculation returns coefficients
   ((c_i)), their occurrence ancestry reconstructs the same target for every
   (a\in\Omega) in the exponent-nine block module;
2. if it returns a separating functional (arphi), the same functional
   annihilates (C(U_0)) and pairs nontrivially with the target of every
   (a\in\Omega).

Thus the certificate, not merely the MEMBER/NONMEMBER Boolean, transfers to
the whole fixed A0 branch.  A NONMEMBER certificate obstructs every registered
correction at this necessary gate.  A MEMBER certificate removes only this
projected obstruction and supplies no pointed multiplier.

## 5. Executable ABI consequence

The next producer/checker pair may use the existing task226 arithmetic at
the empty correction to construct ({\cal S}_{\rm base}), provided it emits
and authenticates a separate load-bearing object

```text

mode = PRE_A0_COMPUTATIONAL_BASE_ONLY
correction_word_constructed = false

```

and computes the v216 closure only from that interface.  The producer and
checker must independently reconstruct the projection.  A digest of the full
base package cannot substitute for the explicit projected fields, and no
full-package equality with an unknown correction may appear in the verdict.
