## 裁定

1. **差戻しを受理する(発射条件③ = NO-GO 維持)**。数学的骨格(補題 K5-a・封印予測 (P1)(P2)・較正三層・五札分類)は PASS — blocker は「封印の実体化」(fixture 実データ・hash・凍結時点の一意化・証明書型・結果規則)。Sol の必須修理 P1–P10 を**全採用**し manifest v1.2 へ反映する。
2. **司令塔の自己訂正**: 裁定 26-6 / v1.1 の「b ≠ 1 が出たら a ↦ ab⁻¹ を更新」は**誤り**(結果開示前であっても規則の事後変更・formal 封印と橋規約の混線)。正しい型は Sol F5: **formal invariant a = 1 は永久不変**・橋側の捻れは dessin ごとの b_sq, b_ns ∈ (ℤ/10)^× として凍結 1 の決定式 (5.1) で機械記録・比較指数は **a_eff = b_ns⁻¹ · a · b_sq**(5.3)。運用は推奨どおり **b_sq = b_ns を BRIDGE-IN の受理条件**とする(このとき自動的に a_eff = 1・不一致なら u を開けず規約不整合で停止)。★教材 17(= Sol ★2)。
3. **(P1) の破れの意味論を修正**: FORMAL-IN・BRIDGE-IN・数体演算が独立に閉じているなら、位数 2/10 は「記録事故」でなく **(5′) の候補反例 = BRIDGE-FAIL**。どの前件が壊れたか未確定なら integrity quarantine(新現象とも事故とも断定しない)。
4. **結果記録の分離**(F1.3・Sol 自己 erratum の採用): manifest は開示後も不変。結果は別 versioned record(bridge_result_sq/ns・pair_gate・saturation_result)に保存し凍結 manifest の hash を参照。**「存在型の飽和定理」「二 detector 橋の普遍性」「全二類整合 campaign」を別出力にする**(片翼 PASS で存在型が閉じ得ることと campaign PASS を混同しない — W6)。
5. **役割分離の格上げ**: transcript grep は補助検査に降格(語彙検査であって情報独立性の証明でない — W4)。主根拠 = Model-Builder の出力 **whitelist**(許可: モデル・Belyi map・分岐 divisor・cusp・uniformizer 式・exact conjugator/禁止: λ/t¹⁰ の非零定数項とその同値物・それらを候補選択に使うこと)+ 役割別 access log + 凍結済み入出力 schema。
6. **u 二経路の独立性要件**: 非共有 helper・別中間表現・raw 出力の別保存・一致判定のみを行う第三 checker。不一致時は平均・符号調整・座標再選択を禁止し即 integrity stop / BRIDGE-UNKNOWN。
7. **凍結時点の一意化**: 凍結 1 = 「両 dessin のいかなる個別モデル候補・係数・数値近似にも接する前・探索コマンド実行前」(「または初期」を削除 — W2)。凍結 2 = **両モデル・両 actual marking・両 uniformizer の atomic joint freeze**(片翼の u を先に開けたら (P2) は盲検でなくなる)。hash は canonical serialization 指定+timestamp+commit ID+対象ファイル一覧+発射錠の digest 束縛(一回性)。
8. **論点裁定の確定**(F8): ①K5-a PASS(D1 §6.3.2 の型修正 (7.2) を次版で)②b は上記 ③偶数側 = K5e で閉 ④攻略分岐は「①族外の repeated-primary かつ忠実な窓 = 現行スキーマの次 falsifier(短期)/②中心 C₂ の拡張スキーマ = 新スキーマ級の定理設計課題(並行・長期)」— **P から関手的に作った decoration は ker Φ を検出できない**(W7・★教材 18)⑤n=7 は K5 凍結 1 確定後・主線を遅らせない余剰資源がある場合のみ・別 manifest・K5 へのフィードバック禁止。

## ★教材(採録)

- **17**(Sol ★2): 複数 detector の規約捻れは一個の補正値でなく各翼の値。不変な formal 比較 a と橋由来の b_i を分けると a_eff = b_ns⁻¹ a b_sq が自動的に現れる。
- **18**(Sol ★4): ker Φ は表現の選び替えでは見えない。Aut(P) を経由する全 detector が同じ盲点を共有するなら、必要なのは decoration でなく作用の非因子化 lift。
- **19**(Sol ★1): hash は書かれて初めて seal。「別文書にあるはず」という参照は、実値・対象・serialization がなければ事前登録にならない。
- **20**(Sol ★3): blindness は結果を読まないことだけでなく、候補選択関数を先に殺すこと。二翼問題では一翼を開く前に両翼を同時凍結。
