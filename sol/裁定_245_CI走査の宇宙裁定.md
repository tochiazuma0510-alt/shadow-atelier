# 裁定 245 — CI 大規模走査 3 本の宇宙の事前登録: t 上限・一般型 cap の裁定と発射

日付: 2026-07-31
裁定者: 司令塔
入力: 実装者からの裁定要請(「t の上限 0..12・一般型 cap 20 は宇宙の絞りに相当しうる — 勝手な絞りは禁止という原則に触れるので裁定を仰ぐ」)

## 実装者の照会は正しい

「指示になければ勝手な絞りは禁止」は工房の**宇宙の事前登録**の規律そのもの。無限の対象を有限機械で走らせる以上、**絞りは必ず要る** — 問題は「絞ったかどうか」でなく「**絞りを誰が・いつ・明示的に決めたか**」。実装者が黙って cap せず司令塔に上げたのは正しい判断であり、本裁定で**司令塔が宇宙を確定**する(以後この 3 走査の宇宙はこれ)。

## 裁定(宇宙の事前登録)

### ジョブ 1: spectrum_scan
- **n の域**: 10 ≤ n ≤ 30(4 shard: 10-15 / 16-20 / 21-25 / 26-30)。**確定**。
- **型の枚挙順**: (ℓ,1^t) → (ℓ^r,1^t) → 一般型。**確定**。
- **一般型 cap = 20/n を承認**(SPEC_GENERAL_CAP=20)。理由: 予想 SPEC の主張は「非可解 ⟺ ある長さの巡回が 5 本以上」で、**判定に効くのは多重度の大きい型**。一般分割の網羅は今回の問いに必要ない。ただし `general_truncated` 欄で打ち切りを明記する設計を**必須条件として承認**(silent cap でない)。
- **注記**: 一般型が打ち切られている以上、本走査は「**spectrum の完全な分類**」ではなく「**(ℓ,1^t)/(ℓ^r,1^t) 型の完全表 + 一般型の標本**」である。台帳語法もこの範囲に限定する。

### ジョブ 2: wall_family_scan
- **域**: t ≥ 5・ℓ 奇素数 > n/2・20 ≤ n ≤ 34。**確定**。
- **SURV 検算**: |C| ≤ 5000 は全数・超過時はランダム 200 個(WALL_RANDOM_SAMPLE_N=200)。**承認** — ただし cert に「非全数(標本 200)」を明記すること(**非可解の主張自体は SURV+ の下限定理から従うので標本で足りる**: 200 個が全通過すれば下限側の実証として十分・全数は確定に不要)。
- smoke で n=20・ℓ∈{11,13} が予算不成立(SKIPPED_BUDGET)となったのは既存 dl3 cert の実測(ℓ=7,11,13 で feasible_k 空)と定性一致 — **予算式が正しく動いている証拠**として受理。

### ジョブ 3: ladder_family_scan
- **N_ord ∈ {11,13,15,17,19,21,25}**(4 shard)。**確定**。
- **t の上限 = 12 を承認**。ただし**理由を明記して宇宙に焼き込む**: 定理 LAD(u_meas_m1_passport_v1 §3.3)により **t ≤ (ℓ−1)/2** が紙で証明済み ⟹ 本走査の ℓ 域(11..25)では **t ≤ 12** が理論上限(ℓ=25 で (25−1)/2 = 12)。すなわち **t=0..12 は絞りではなく定理による完全域**。
  - ⟹ 実装者の懸念は解消。**cert の scope 欄に「t 上限 12 は定理 LAD による理論上限であり任意の cap ではない」と記載すること**(実装者へ指示)。
  - 副次: この走査は**定理 LAD の族的な実測検証**を兼ねる(t = (ℓ−1)/2 で実現し、t = (ℓ−1)/2 + 1 で予算不成立になるはず — 出れば LAD の独立確認)。

## 発射

上記の宇宙で 3 plan を発射する(push で mine-dispatch が自動発火・各 4 shard・timeout 180 分)。判定は artifact のみから(machine-piped)。

## 工程

1. 着弾後: spectrum 表を予想 SPEC の照合にかける(**予言は本裁定の commit で凍結** — 「非可解 ⟺ ある長さの巡回 5 本以上」「可解は全多重度 ≤4 の隅」)。
2. wall_family に第二・第三の非可解実例が出れば **P4 は「1 個ある」→「族としてある」へ格上げ**(Sol 監査は共通の SURV+/CENT-0 に依存するので、便 89 の結果がそのまま効く)。
3. ladder_family の t 上限の実測が定理 LAD と一致すれば、P1 側の定理に族的な傍証がつく。
