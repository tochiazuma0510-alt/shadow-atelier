## 1. The exact two kernels

Let `F=F(x,y)`, let `Theta:F -> Delta` be the fixed finite-group surjection, and let
`Delta -> Q` be a fixed marked quotient. Put

```text
Omega = ker Theta,
N = ker(F -> Q),
Gamma = N/Omega = ker(Delta -> Q),
Phi_3(H) = H^3 [H,H].                                  (1.1)
```

Use one fixed Fox convention throughout. The source Fox cycle isomorphism
of v516 identifies

```text
Z_Q = H_1(N;F3) = N/Phi_3(N)
    = the two-generator Cayley cycle space over Q.
```

The endpoint quotient induces the surjective linear map

```text
tau: Z_Q -> Gamma/Phi_3(Gamma).                        (1.2)
```

Surjectivity of `N -> Gamma` implies the elementary group identity

```text
Theta(Phi_3(N)) = Phi_3(Gamma),
Theta^-1(Phi_3(Gamma)) intersect N = Omega Phi_3(N).    (1.3)
```

For the first equality, lift each cube and each commutator factor in
Gamma to N. For the second, cancel an element's endpoint using the first
equality. This proves, constructively,

```text
J_Q(Omega) = ker tau.                                  (1.4)
```

The point below is how to retain an actual word in (1.4), not just its
existential or dimension statement.

## 2. Explicit materialization without compact-seed coordinates

Fix a prefix-closed spanning tree in the marked Cayley graph of Q. Its
non-tree oriented edges give a Schreier basis `(s_e)` of N. Retain each
`s_e` as a tree-path word/DAG. A cycle z has unique coordinates on the
associated fundamental-cycle basis. Represent its coefficient 2 by -1,
fix the edge order, and set

```text
w(z) = product_e s_e^(z_e),
h(z) = Theta(w(z)) in Gamma.                          (2.1)
```

The product need not be freely expanded. Every factor is in N, so the
mod-three Fox product rule is additive:

```text
J_Q(w(z)) = z.                                        (2.2)
```

If `tau(z)=0`, (1.2) says precisely `h(z) in Phi_3(Gamma)`.
Choose once a finite word-valued table

```text
u: Phi_3(Gamma) -> Phi_3(N),
Theta(u(h)) = h,             u(1)=1.                  (2.3)
```

Such a table exists by (1.3); Section 3 gives a particularly small actual
R07 construction. Define

```text
C_Q(z) = w(z) u(h(z)^(-1)).                           (2.4)
```

### Theorem 2.1 (literal endpoint-neutralized cycle)

For every `z in ker tau`, formula (2.4) satisfies

```text
C_Q(z) in Omega,
J_Q(C_Q(z)) = z.                                      (2.5)
```

Proof: its endpoint is `h(z) h(z)^(-1)=1`. The second factor is in
`Phi_3(N)` and hence has zero Q-Fox cycle, proving the second equality.
Both assertions concern one literal word before any occurrence
specialization. QED.

No expression of z in the 44 compact relator orbits is used. Compared to
v516 section 2, the available source certificate has changed: we use a
Schreier cycle and an endpoint-repair word, rather than coefficients in a
normal-generating roster. A consumer restricted to compact-seed DAG nodes
does not acquire this new input type automatically. A direct word/endpoint/
Fox consumer can check (2.5) without converting to those nodes.

## 3. At Q2, the endpoint-repair table has only 27 entries

Here `|Q2|=54,432`. The existing finite inputs used in v458 are

```text
|Gamma2| = 6,561 = 3^8,
Gamma2_ab = C3^3 x C9^2.                              (3.1)
```

They are recorded explicitly in
`scratchpad/a0_v2_rungs_output.txt` (the `rung3` record), generated by
`scratchpad/a0_v2_rungs.g`; v458 (2.4) uses the same abelianization. This
note does not rerun that group calculation or upgrade its workshop grade.

It follows that

```text
|Gamma2'| = 3^(8-7) = 3,
Gamma2/Phi_3(Gamma2) = C3^5,
|Phi_3(Gamma2)| = 3^(8-5) = 27.                      (3.2)
```

Moreover Gamma2 is a 3-group. Conjugation on its derived subgroup of order
three gives a homomorphism to `Aut(C3)`, of order two, and must be trivial.
Thus `Gamma2'` is central. For any a,b in Gamma2,

```text
[a^3,b] = [a,b]^3 = 1,
```

so every cube is also central. Therefore

```text
Phi_3(Gamma2) <= Z(Gamma2).                            (3.3)
```

Choose five elements `gamma_1,...,gamma_5` lifting a basis of
`Gamma2/Phi_3(Gamma2)`, with marked preimage words `a_i in N`.
They generate Gamma2: if their subgroup were proper, it would lie in a
maximal subgroup of the finite 3-group; such a subgroup has index three
and contains all cubes and commutators, contradicting the chosen basis.

The following fifteen endpoint elements generate `Phi_3(Gamma2)`:

```text
gamma_i^3                  (1 <= i <= 5),
[gamma_i,gamma_j]           (1 <= i < j <= 5).         (3.4)
```

Indeed their normal closure is exactly the kernel of the maximal
elementary-abelian quotient of the group generated by the gamma_i; by
(3.3) this normal closure is already their ordinary subgroup. Lift (3.4)
by the fifteen explicit N-words

```text
a_i^3,                     [a_i,a_j].                (3.5)
```

Every word (3.5) belongs to `Phi_3(N)`. A fixed-order BFS in the 27-element
group (3.2), using (3.4) and their inverses, retains a parent and a label
for each element. Reading the same labels as (3.5) constructs the whole
table (2.3).

This table requires at most 26 nonidentity insertions and at most
`27*30=810` generator-neighbor products if all signed labels are retained.
Every chosen repair word uses at most 26 labels (3.5), stored as a DAG.
These are bounds for the endpoint-repair table ONLY, not for all of A0,
not for construction of the Cayley tree or gamma_i preimages, and not for
the length of those preimage words when expanded.

No entries of this 27-element marked table have been exported in this
note. Its existence and size follow from (3.1); a future concrete table
must bind the actual marked gamma_i, their preimage words, and their
generation/endpoint equalities.

Since `epsilon(Omega)=18 Z^2`, write


```text

epsilon(C_Q^0(z)) = (0,0) exactly,

```

This uses integer A,B, not merely their residues modulo three. Power DAGs
retain potentially large exponents without word expansion. The facts in

the preservation statement.
